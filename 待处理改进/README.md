# 待处理改进

外部贡献者提交的**改进提案**落在这里。

这些不是改动，是「该改什么」的说明——提交时打包成一个 PR，由合伙人核实后改到
对应技能里。已经改好文件的走另一条路：`python contribute.py --from-installed`，
那个产生的是真实 diff，不进这个目录。

## 文件命名

`<日期>-<技能名>-<类型>.md`，例如 `2026-10-30-天信税务申报-政策过期.md`。
由 `contribute.py --proposal` 自动生成，手工放进来也行，照这个格式起名就好。

## 处理完之后

提案被采纳、改动落到技能里之后，把这个文件删掉，并在提交信息里写清
「采纳 xxx 提案，改到 `税务/天信税务申报skill/references/01-…`」。

**提案本身不要留在仓库里当档案**——它的价值在于被执行，执行完就是噪音。

## 看有哪些待处理

```bash
python contribute.py --list
```
