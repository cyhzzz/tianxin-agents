# 天信办公专家（专家包）

一个专家，挂仓库里全部 11 个技能。装好之后在 WorkBuddy 左侧「专家 → 我的专家」里选「天信办公专家」，点开即用；不用记哪个技能什么触发词。

## 这个包里有什么

| 文件 | 作用 |
|---|---|
| `plugin.json` | 专家元数据：显示名、行业分类、标签、推荐问法、**声明挂哪几个技能** |
| `agents/tianxin-office-expert.md` | 人设：七条核心能力、工作流程、输出规范、注意事项、改进回传方式 |
| `avatars/tianxin-office-expert.png` | 专家头像 |

## 挂的 11 个技能

| 技能（安装名） | 属于 | 干什么 |
|---|---|---|
| `tianxin-docs` | 公用 | 出 Word / A4 PDF / 网页长页 / 演示 deck / Excel 表 |
| `tianxin-shiwu-kb` | 公用 | 12 张会计审计实务判断卡 |
| `chenyiwei-bbs` | 公用 | 陈版主实务答疑与准则原文检索 |
| `tianxin-audit` | 审计 | 审计计划、风险评估、四程序、底稿索引、报告质控 |
| `tianxin-tax` | 税务 | 算税、申报、勾稽、风险自查、涉税鉴证 |
| `tianxin-bookkeeping` | 代理记账 | 建账、票据、凭证、月结、报表、申报、交接 |
| `tianxin-accounting` | 会计核算 | 报表编制、附注、四表一勾稽、合并、财务分析 |
| `tianxin-appraisal` | 资产评估 | 评估方法选型、参数校准、报告审核、准则检索 |
| `tianxin-performance` | 绩效评价 | 预算绩效评价、政府项目验收、项目后评价 |
| `tianxin-consulting` | 企业咨询 | 战略、组织、人力、流程、经营改善、尽调方案 |
| `tianxin-daily-brief` | 运营 | 每日行业热点与台州本地商机 |

## 当前状态（如实说明）

- **11 个技能均已建好、可触发**，覆盖审计、税务、代账、会计核算、资产评估、企业咨询、绩效评价七条业务线，外加文档与运营两条支撑线。
- **已在用**：《天信文档与报告》《天信日报》已在所里真实项目上日常使用。
- **已用真实报告校准**：审计、会计核算、绩效评价三条已用本所真实样本校准、复现测试达标——但都还没在所里真实项目上端到端整轮跑过。
- **其余为初稿**：底子基于外部成熟专家包，尚未用所里真实材料校准。

> 七条业务线目前都还是草稿：审计 / 会计核算 / 绩效评价已用真实报告校准，但都还没在所里真实项目上整轮跑过，其余仍是纯草稿。拿它当“该怎么走”的提示可以用，当成品交出去不行；对外交付前须经注册会计师复核，最终以执业准则和所内质控为准。
