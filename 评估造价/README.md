# 评估造价线

资产评估（成本法/市场法/收益法）、工程造价咨询、司法鉴定。

## 为什么合成一条线

评估和造价都是「出一个价值结论」，方法论相近（成本法要重置成本、市场法要比交易案例、收益法要折现），底稿框架可以共用。分成两条线维护成本高，实际所里也常是同一批人做。

## 和审计线的分工

评估报告和审计报告在要素上互通（委托方、目的、基准日、范围、方法、结论、限制条件），但**准则体系不同**：

- 审计：中国注册会计师审计准则
- 评估：资产评估执业准则 + 资产评估法
- 造价：建设工程造价咨询规范

报告格式不能互相套用。

## 需要什么材料

1. **一份评估报告**（任何一类：股权、房产、设备、无形资产）——看报告结构和参数披露程度
2. 常用评估方法的参数来源（重置成本从哪查、市场案例从哪找）
3. 造价咨询做哪类（预算编制、结算审核、全过程）
4. 这条线的业务量占比——决定投入多少
