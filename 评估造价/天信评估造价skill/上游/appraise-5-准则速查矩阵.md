# 业务场景 → 准则速查矩阵

> 这份矩阵是使用者**最常用的部分**："我做的是 X 类业务，应该引用哪些准则？哪些不能漏？哪些是 NO？"
> 规则：**必须引用的程序性+实体性准则（基础三件套）** + **专项指南（按业务加）** + **报告指南（按委托方加）**。

---

## ⚠️ 数据可靠性声明（AI 必读）

本矩阵中标注 📌 **准则原话** 的内容，均已从 `资产评估知识库汇编.md` 中 Grep 核实，**可直接引用**。

**未标注 📌 的内容属于以下三类，引用时须谨慎**：

| 类型 | 说明 | 能否作评估依据 |
|---|---|---|
| **准则原话**（📌 标注） | 已从全文知识库核实的条文 | ✅ 可引 |
| **体系性归纳**（本矩阵 A-G 节） | 对准则层级/适用范围的结构化整理 | ✅ 可引准则本身（但引的是准则文号，不是本表） |
| **实务习惯数值** | 如"成新率上限 XX%""折现率取 X%"等具体数字 | ❌ **严禁引用**——准则无此规定，属机构/地方口径 |

> **铁律**：凡涉及**具体数值、比例、参数**的断言，AI 必须先在 `资产评估知识库汇编.md` 中 Grep 到原话；**Grep 不到 = 准则无此规定**，此时应如实回答"准则未明确规定"，**不得用行业惯例填充**。

## 通用公式（所有评估业务）

```
评估依据 = 基本准则（财资〔2017〕43号）
         + 职业道德准则（**2026-12-31 前引中评协〔2017〕30号；2027-01-01 起引中评协〔2026〕7号**）
         + 程序性准则（委托合同 + 程序 + 报告 + 档案 + 方法）
         + 实体性准则（按资产类型选一项或多项）
         + 报告指南（按委托方/目的选一项或多项）
         + 适用的指导意见 / 专家指引（按业务选，作为参考引用）
```

## D · 三类**绝不能漏**的"基础三件套"

任何评估报告，无论什么资产、什么目的，**这三份必须引**：

1. **资产评估基本准则（财资〔2017〕43号）**——统驭性准则
2. **资产评估职业道德准则**——行为准则；**2026-12-31 前引中评协〔2017〕30号，2027-01-01 起引中评协〔2026〕7号**（⚠️ 2026 修订版尚未施行）
3. **资产评估执业准则——资产评估报告（中评协〔2018〕35号）**——报告格式准则

> 凡国资项目，再加：**企业国资报告指南〔2017〕42号**（称为"基础四件套"）。

## G · 准则衔接关系对比表（核心场景）

> 这是"差异对比"功能的高频查询点。每行对应一个实务场景，对比不同准则在该场景下的适用规则差异。

### 场景 1 · 评估对象为"软件/数据"

| 准则 | 适用判断 |
|---|---|
| 无形资产准则〔2017〕37 号 | 默认适用——所有无形资产含软件 |
| 知识产权准则〔2023〕14 号 | 若软件构成知识产权保护客体 → **优先**适用 |
| 计算机软件著作权评估专家指引〔2022〕23 号 | ⭐ **实务必查**——具体取值/披露规则 |
| 著作权意见〔2017〕50 号 | 若软件已登记著作权 + 准则未涵盖细节 → 补充适用 |

**优先级**：实体性准则 → 专家指引 → 指导意见

### 场景 2 · 评估对象为"专利技术"

| 准则 | 适用判断 |
|---|---|
| 知识产权准则〔2023〕14 号 | **统驭**——所有专利评估通用 |
| 专利意见〔2017〕49 号 | 准则未细化处的补充（如权属处置/许可使用特殊情形） |
| 知识产权侵权损害专家指引〔2023〕21 号 | **若目的是侵权损害评估** → 主要适用（替代普通价值评估） |

### 场景 3 · 评估对象为"数据资产"

| 准则 | 适用判断 |
|---|---|
| 数据资产意见〔2023〕17 号 | **主要适用**（2023 升格） |
| 数据资产专家指引〔2019〕40 号 | 补充适用（早期未升格版的细则） |
| 知识产权准则〔2023〕14 号 | 数据形成知识产权时 → 同步适用 |

### 场景 4 · "国资目的 vs 财务报告目的" 同对象

| 目的 | 主指引 | 报告指南 |
|---|---|---|
| 国企增资/股权转让/资产收购 | 折现率指引 + 价值类型意见 | **企业国资报告指南〔2017〕42 号**（国资必引） |
| 财报目的（公允价值/减值） | 折现率指引 + 财报目的指南 | **财报目的指南〔2017〕45 号** |

**冲突时**：国资目的 42 号 / 财报目的 45 号之间，按**合同/委托方声明的目的**定；若同一对象双目的，两份指南都要引。

### 场景 5 · "投资价值 vs 市场价值"

| 价值类型 | 必引 |
|---|---|
| 市场价值（默认） | 价值类型意见〔2017〕47 号 + 一般资产类型准则 |
| 投资价值（特定投资者视角） | 价值类型意见〔2017〕47 号 + **并购投资价值意见〔2020〕30 号**（⭐） |
| 在用价值 | 价值类型意见〔2017〕47 号 |
| 清算价值 | 价值类型意见〔2017〕47 号 + 司法处置意见〔2019〕14 号 |
| 公允价值 | 价值类型意见〔2017〕47 号 + 财报目的指南〔2017〕45 号 |

> **执业红线**：评估报告必须**显式声明**所采用的价值类型，并必须与所选方法的价值类型含义一致。市场价值 ≠ 投资价值，混用是执业质量问题。

### 场景 6 · "评估基准日 vs 出具报告日"

- **评估报告引注"近新原则"**：以评估基准日为时点选取价格依据（基本准则第二章）
- **市场价格依据<基准日**：基本准则第二章（时点参数）
- **期后事项 / 重大事项**：报告准则〔2018〕35 号 + 国资报告指南〔2017〕42 号 第四章特别事项披露

## H · 实务中**最高频的 5 类问题** 速答

| 问题 | 首答 |
|---|---|
| **国资评估报告依据怎么列？** | "基础四件套"（基本准则 + 职业道德准则 + 报告准则 + 国资报告指南〔2017〕42 号） + 实体性准则（按资产类型）+ 价值类型意见 + 法律权属意见 |
| **折现率怎么取值？** | 主规范：企业价值准则〔2018〕38 号；实操细则：**折现率专家指引〔2020〕38 号**（中评协）。<br>📌 **准则原话**："折现率不仅要反映资金的时间价值，还应当体现与收益类型和评估对象未来经营相关的风险，与所选择的收益类型与口径相匹配。"；"应当综合考虑评估基准日的利率水平、市场投资收益率等资本市场相关信息和所在行业、被评估单位的特定风险等相关因素。" |
| **机器设备贬值怎么算？** | 主规范：机器设备准则〔2017〕39 号 §第二十条。<br>📌 **准则原话（实体性贬值）**："实体性贬值，也称有形损耗，是指由于使用和自然力的作用导致资产的物理性能损耗或者下降引起的资产价值损失。"<br>⚠️ **注意**：准则**未规定**具体的成新率上限比例（如"60-80%"），此类数值属机构内部执业习惯或地方协会口径，**不得作为准则依据引用**。 |
| **投资性房地产用什么方法？** | 主规范：投资性房地产意见〔2017〕53 号 + 不动产准则。<br>📌 **准则原话**："采用市场法评估投资性房地产时，应当收集足够的同类或者类似房地产的交易案例…"；"公允价值的评估一般采取收益法。" |
| **司法处置的价值类型？** | 通常 **市场价值或清算价值**；司法处置意见〔2019〕14 号 |
