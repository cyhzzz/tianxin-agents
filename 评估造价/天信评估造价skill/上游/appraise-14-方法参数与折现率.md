# 三大评估方法参数口径与测算表骨架

所有测算表一律使用公式与单元格引用，**禁止硬编码结果**。参数取值须标注来源与取值时点。

---

## 一、收益法（企业价值 DCF）

### 1.1 模型选择

| 模型 | 现金流口径 | 折现率口径 | 适用情形 |
|---|---|---|---|
| 企业自由现金流（FCFF）折现 | 归属全部资本提供者 | WACC | 常态企业价值评估（首选） |
| 股权自由现金流（FCFE）折现 | 归属股东 | Ke | 资本结构恒定、股权直接评估 |
| 股利折现（DDM） | 预期股利 | Ke | 缺乏控制权的股东部分权益 |

> **口径匹配铁律**：FCFF 配 WACC；FCFE 配 Ke。折现率与现金流不得一个税前一个税后、一个含杠杆一个不含杠杆。

### 1.2 测算表字段

| 区域 | 字段 | 公式 / 口径 |
|---|---|---|
| 预测期 | 营业收入、营业成本、税金及附加、销售费用、管理费用、研发费用、财务费用、EBIT | 逐期分项预测；依据历史均值、增长率或行业对标；禁止整行复制历史数 |
| 现金流 | 所得税率 t、EBIT、NOPAT、折旧摊销、资本性支出、营运资金追加、FCFF | NOPAT = EBIT×(1−t)；FCFF = NOPAT ＋ 折旧摊销 − 资本性支出 − 营运资金追加 |
| 折现 | 折现系数、现值 | 折现系数 = 1/(1+WACC)^t；t 取距基准日年数（期中折现须说明口径） |
| 折现率 | 无风险利率 rf、市场风险溢价 ERP、Beta（βL）、特定风险 α、股权成本 Ke、债权成本 Kd、税率 t、资本结构 E/(E+D)、D/(E+D)、WACC | Ke = rf ＋ βL×ERP ＋ α；WACC = Ke×E/(E+D) ＋ Kd×(1−t)×D/(E+D) |
| 加项 | 溢余资产、非经营性资产、非经营性负债 | 逐项识别并说明依据 |
| 终值 | 永续增长：FCFFn×(1+g)/(WACC−g)，再折现至基准日 | g ≤ 宏观长期增长率（通常 ≤ 3%）；须论证 |
| 结论 | 经营性资产价值 ＋ 溢余及非经营净值 ＋ 终值现值 = 股东全部权益价值 | |

### 1.3 折现率参数口径要点

| 参数 | 口径要点 | 常见失分点 |
|---|---|---|
| rf（无风险利率） | 通常取评估基准日 10 年期国债到期收益率（或长期国债），标明来源与期限 | 用短期利率或未标期限 |
| ERP（市场风险溢价） | 成熟市场 ERP ＋ 国家风险溢价调整，或采信权威机构公布值，标明来源 | 无来源、直接套用陈旧数据 |
| Beta | 可比公司无杠杆 β 均值 → 按目标资本结构还原为有杠杆 β；标明指数、期间、频率 | 期间过短、指数与行业不匹配、未做杠杆还原 |
| α（特定风险） | 企业规模、客户集中度、经营与财务风险等逐项量化 | 凭感觉取值、不说明构成 |
| Kd（债权成本） | 取企业实际借款利率或行业平均融资成本，须为税前 | 与所得税处理不一致 |
| 资本结构 | 采用目标资本结构或可比公司平均结构并说明 | 权重口径（账面 / 市价）前后矛盾 |

### 1.4 交叉验证

收益法结果须与市场法（EV/EBITDA、P/E 等）、资产基础法结果比较，量化差异率并分析成因（如无形资产未在账面体现、协同效应、行业估值水平差异）。最终取值须有明确论证，**不得简单算术平均**。

## 二、成本法（资产基础法）

### 2.1 机器设备

| 区域 | 字段 | 公式 / 口径 |
|---|---|---|
| 重置价 | 设备购置价、运杂费、安装调试费、前期费、资金成本、可抵扣进项税 | 重置价 =（购置价＋运杂费＋安装调试费＋前期费）×(1＋资金成本率) − 可抵扣进项税；进口设备另计关税、增值税、外贸及银行手续费 |
| 实体性贬值 | 年限法 / 观察法 / 修复费用法 | 成新率 = 1 − 实体性贬值率；**成新率 ≠ 会计折旧年限 / 经济寿命** |
| 功能性贬值 | 超额投资成本、超额运营成本 | 单独列示并计算，不与实体性贬值混同 |
| 经济性贬值 | 外部因素导致的产能利用不足、产品滞销 | 按实际产能利用率或收益损失测算 |
| 评估值 | 评估值 = 重置价 × 成新率 − 功能性贬值 − 经济性贬值 | 各项贬值须列明计算依据 |

**进口设备重置价构成**：到岸价（FOB ＋ 国际运费 ＋ 运输保险费）→ 关税 → 消费税（如适用）→ 增值税 → 外贸手续费、银行财务费 → 国内运杂费、安装调试费 → 资金成本。

### 2.2 房屋建筑物

| 方法 | 要点 |
|---|---|
| 重置成本法 | 重置价（建筑安装工程费＋前期费＋其他费用＋资金成本）→ 成新率（年限法 / 打分法）→ 评估值 |
| 市场比较法 | 可比实例 → 交易情况、市场状况、区位、实物、权益状况修正 |
| 收益法 | 净收益 ÷ 报酬率（或资本化率）；须扣除空置率、运营费用、税费 |

### 2.3 流动资产及负债

| 项目 | 方法要点 |
|---|---|
| 货币资金 | 核对银行对账单与银行存款余额调节表；外币按基准日汇率折算 |
| 应收款项 | 账龄分析法；逐笔分析可回收性；坏账准备口径与账面差异须说明 |
| 存货 | 重置成本法（材料、在产品、产成品分列）；可变现净值法；长期积压与残次品单独处理 |
| 预付账款、其他应收款 | 核实对应权利或资产是否存在 |
| 负债 | 核实真实性、完整性；关注未入账负债、或有负债 |

## 三、市场法

### 3.1 企业价值市场法

| 环节 | 要点 |
|---|---|
| 具体方法 | 上市公司比较法（P、EV 类价值比率）；交易案例比较法 |
| 应用前提 | 充分发展活跃的资本市场；足够数量的可比对象；可收集市场与财务信息；信息具代表性且在基准日有效 |
| 价值比率 | P/E、P/B、EV/EBITDA、EV/EBIT、EV/S、P/S；分子分母口径期间须一致 |
| 可比对象筛选 | 同行业、相近规模、相近盈利模式；剔除 ST、异常值；筛选标准须成文 |
| 修正 | 盈利能力、成长性、营运能力、偿债能力等维度量化打分修正 |
| 折扣与溢价 | 流动性折扣（非上市公司）、控制权溢价（取得控制权时） |

### 3.2 房地产市场比较法修正表

| 列 | 口径 |
|---|---|
| 可比实例 | 成交价、交易情况、市场状况（期日）修正 |
| 交易情况修正 | 剔除关联交易、急售、非正常交易等特殊因素 |
| 市场状况修正 | 修正至评估基准日价格水平 |
| 区位状况修正 | 位置、交通、配套、环境等 |
| 实物状况修正 | 面积、结构、成新、层高、朝向等 |
| 权益状况修正 | 土地使用年限、权利限制、租赁负担等 |
| 比准价格 | 实例价 × 各项修正系数连乘；多实例取简单算术平均或加权平均，权重须说明 |
| 结论 | 市场法评估值，并与其他方法交叉验证 |

> 每项修正须有量化依据（因素打分表或价格指数），不得凭感觉给系数。

## 四、单项资产评估补充口径

### 4.1 无形资产

| 方法 | 适用 | 要点 |
|---|---|---|
| 超额收益法 | 有独立收益贡献的无形资产 | 剔除有形资产贡献后的超额收益折现 |
| 许可费节省法 | 可通过许可取得的技术、商标 | 按可比许可费率 × 相关收入，扣税后折现 |
| 增量收益法 | 有明确对比基准的无形资产 | 采用无形资产与未采用之间的收益差异 |

**可辨认无形资产与商誉边界**：能够单独或与相关合同、资产、负债一起辨认、可分离或源于合同性权利或其他法定权利者，为可辨认无形资产；其余归入商誉（不单独评估，由合并对价与可辨认净资产公允价值差额体现）。

### 4.2 数据资产

以收益法为主路径；关注数据规模、质量、应用场景、时效性与可替代性；数据权属（持有权、加工使用权、经营权）须核验。

### 4.3 金融不良资产

| 方法 | 要点 |
|---|---|
| 假设清算法 | 假设债务人破产清算，测算可回收金额 |
| 现金流偿债法 | 以债务人未来可偿债现金流测算 |
| 交易案例比较法 | 可比不良资产包交易数据 |
| 专家打分法 | 多因素定性打分量化 |
| 综合因素分析法 | 结合抵质押物价值、担保效力、诉讼进展综合判断 |

## 五、敏感性分析

关键假设（收入增长率、毛利率、折现率、永续增长率、成新率）须做敏感性分析，呈现单一参数或双参数变动对评估值的影响区间。敏感性分析维度过窄（仅一个参数）视为优化建议级问题。
