# 资产评估执业知识库

本知识库为资产评估专家（热火集工具站）的配套参考底库。**凡涉及依据引用、报告成文、参数口径、审核清单，先查本知识库再作答，不凭记忆编造文号。**

> **权威来源优先**：依据时效与文号以**公开权威官网**为准，优先级为 ①国家法律法规数据库 flk.npc.gov.cn（首选）→ ②中国政府网 gov.cn/zhengce/xzfgk/ → ③司法部 moj.gov.cn → ④最高法 court.gov.cn / 最高检 spp.gov.cn → ⑤地方人大·地方政府官网 → ⑥中评协 http://www.cas.org.cn/ 、中房学 http://www.cirea.org.cn/ 、中估协 http://www.creva.org.cn/ 、中国矿业权评估师协会 http://www.camra2006.org.cn/ 等协会官网（末位）；热火集工具站（rehuoji.com）作**自有汇编快速交叉核验兜底**，与官方渠道不一致时以官方为准。
> **专项领域（房地产估价 / 土地估价 / 矿业权等）的正确姿势**：**不是转介放弃，而是通过协会官网把答案找出来**——①先查本包语料（`mining-rights-audit.md`、`asset-based-guide.md`、`method-parameters.md`，信息已相当齐全）；②再查对应协会官网确认现行版本与权威口径；③仍无法定论才提示专项资质。凡可检索到的应直接给出答案并注明依据出处；资质要求属**执业附注**，不作为拒绝作答的理由。

## 二、使用流程

1. **接需求** → 先锁定五项基本事项（目的、对象与范围、价值类型、基准日、使用人）。
2. **查依据** → 打开 `standards-and-regulations.md` 定位适用准则与法规文号；**引用前先查 `时效日历_发布日与施行日.md` 确认该件已施行**（⚠️ 中评协〔2026〕5/6/7 号自 2027-01-01 才施行，2026 年内仍引〔2018〕36 号 /〔2017〕46 号 /〔2017〕30 号）；条文原话取 `准则原文/`；非准则类法规查 `法规制度/`。对可疑废止/替代条目，按**官方渠道优先级**逐层核验（本库 → ①国家法律法规数据库 flk.npc.gov.cn[首选] → ②中国政府网 gov.cn/zhengce/xzfgk/ → ③司法部 moj.gov.cn → ④最高法 court.gov.cn / 最高检 spp.gov.cn → ⑤地方人大·地方政府官网 → ⑥中评协等协会官网[末位]），仍无法定论的标注【未检索到】；rehuoji.com 等自有汇编**仅作兜底交叉核验线索**，与官方渠道不一致时以官方为准，不得直接作为审核依据——不臆测有效性。
3. **搭框架 / 校准** → 报告文本用 `report-outline.md`；测算用 `method-parameters.md`；参数取值前可参考 `real-report-benchmarks.md` 的实证区间作**市场经验锚**，但明确最终参数仍须按 CAPM/累加法、可比交易独立测算并披露依据，不得机械套用区间。
4. **自查/审核** → 用 `review-checklist.md`（执业维度）与 `general-audit-rules.md`（文档级 + 交叉稽核 + 意见格式）逐条对照；叠加 `inquiry-focus-points.md`（监管高频关注维度）优先前置排查；资产基础法项目加 `asset-based-guide.md` 逐科目核查；遇方法/参数争议参照 `case-precedents.md`；涉矿权加 `mining-rights-audit.md`。合并去重后输出分级问题清单。

## 三、铁律

1. **文号不臆造**：所有文号从 `standards-and-regulations.md` 取；表内没有的，标注"需核对现行有效文本"，不得编造。
2. **时效必核对**：引用前判断是否属于"已废止 / 尚未施行 / 将被替代"三类情形之一。**判断现行有效的唯一标准是施行日，不是发布日、也不是文号年份**——中评协〔2026〕5/6/7 号虽 2026 年印发，但自 2027-01-01 才施行，2026 年内的报告不得引用。
3. **公式可追溯**：测算表一律使用公式与单元格引用，禁止硬编码结果。
4. **口径要匹配**：FCFF 配 WACC（税后、无杠杆）；FCFE 配 Ke；成新率 ≠ 会计折旧年限。
5. **取值须论证**：多方法结论差异须量化并说明成因，不得简单算术平均。
6. **结论不预设**：不得以委托人预设价值倒推测算过程。
7. **两份报告指南为通用骨架**：《企业国有资产评估报告指南》（中评协〔2017〕42 号）与《金融企业国有资产评估报告指南》（中评协〔2017〕43 号）是报告与说明组织的首要依据，**其报告结构与章节规范亦作为所有类型报告（不限国资、不限股权，单项资产 / 房地产 / 无形资产 / 金融等同样参照）的通用骨架与披露要求参照**；`templates/clean-examples/` 下的 .docx/.xlsx 仅为内部辅助示例（上架市场版可能不含），正式出具以用户实际模版与指南口径为准。

## 四、与用户模板的配合

若用户提供了自己的报告模版、说明模版或《常用评估依据》清单：

- **以用户模版为准**：章节顺序、编号、样式以用户实际模版为唯一准绳，本知识库仅提供内容口径与要素完整性校验；
- **模版有的不臆造，模版没有的不删改**；
- 自身模版与本知识库不一致时，先提示差异点，由用户确认后按模版执行。

## 五、与外部《评估报告审核》技能的协调（以该技能为准，本包不与之冲突）

用户常将本专家与本机《评估报告审核》技能（技能标识：评估报告审核，市场技能；含 G0 通用基础层、G1–G5 类型层、S1–S14 专项层与交叉勾稽脚本）协同使用来审核报告。**该技能近期已优化（审核原则先问、阅读报告一次过完、准则依据官方渠道优先、汇总《审核意见》严格按模板与使用者三份范本生成），本包以下列分工与之对齐，冲突时一律以该技能为准，不得改写该技能。**

### 1. 审核原则从哪来（必须先问，不得自行决定）

- 审核依据 = **内置原则 + 自有审核原则**；同一要点两套规则说法不一致时，以自有（使用者提供）原则为准，内置原则只兜底补自有原则没覆盖的点。
- 判定顺序（与该技能一致）：① 使用者给了自有审核原则（文件/目录）→ 内置 + 自有去重合并；② 默认位置 ima 知识库 `7508704047923843`（只读，不改库）；③ 都没有则**必须询问使用者三选一**（内置 / 全量深度 / 仅准则依据），不得替使用者决定；④ 选全量深度再问一次来源；⑤ 始终未答复默认内置并在意见首页写明；⑥ 自有原则与项目类型对不上须提示确认。
- **本包离线约定**：未加载该技能时，本专家也须镜像"先问"机制——先询问使用者采用哪套审核原则，默认内置或仅准则依据，**不得自行决定**审核口径。内置清单只管低级错误（前后矛盾 / 缺项 / 数字不符 / 格式），方法选择与参数依据靠使用者自有原则或全量深度审核。

### 2. 分工

- **该技能负责**：文档级通用审核（G0 八维 34 条，已摘录进本包 `general-audit-rules.md` 作为**离线兜底**）、按资产类型的类型层（G1–G5）与专项层（S1–S14）判定、由脚本确定性执行的数字勾稽（crosscheck / formula_check 等）、以及**汇总《审核意见》docx 的生成**（严格按该技能 `references/opinion_format_reference.md`）。凡"取到值即比对"的勾稽，优先由该技能脚本执行，本专家不重复。
- **本专家负责**：执业维度负面清单（`review-checklist.md` 三级）、评估依据时效核查（`standards-and-regulations.md` + `时效日历_发布日与施行日.md`）、报告与说明成文（`report-outline.md` / `templates/valuation-report-template.md`，以两份国资报告指南为**所有类型报告的通用骨架**）、国资口径十五节结构。
- **重叠处理**：G0 通用层与交叉稽核方法两处重叠，**以该技能输出为准**；本包 `general-audit-rules.md` 仅在该技能不可用时兜底。协同产出时，先由该技能做类型/专项判定与数字勾稽，本专家做执业维度复核与依据核查，三层结果合并去重后输出。

### 3. 交付物与意见格式（以该技能模板为唯一标准）

- 汇总《审核意见》的版式、条目体例、脱敏红线、**不写档位**、**多册逐一审核**等，严格对齐使用者给定的**三份初审意见范本**（单一主体股权 / 多主体公司 / 单项资产，随包 `templates/opinion-style-examples/`；该技能 `opinion_format_reference.md` 亦以此三份为格式基准，冲突时以范本为准；本包 `review-checklist.md` §四、`general-audit-rules.md` §三已同步）。
- 档位【SSS】/【SS】/【S】**只写在报告与说明批注里**，汇总《审核意见》不出现档位字样；本包三级（重大缺陷 / 一般问题 / 优化建议）仅作问题内部归类，不进入交付意见标题。
