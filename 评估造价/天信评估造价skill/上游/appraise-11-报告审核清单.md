# 评估报告与底稿审核负面清单

审核输出按三级分类，每条注明"**问题描述 → 依据 → 修改建议**"。表述须落到具体章节、具体数字，不作笼统评价。

---

## 一、重大缺陷（影响结论有效性，必须修改）

### 1.1 价值类型与方法选型

| 检查点 | 判据 |
|---|---|
| 价值类型与评估目的、报告用途是否匹配 | 抵质押、税收、保险、财务报告目的的价值类型受法规或合同约束（中评协〔2017〕47 号） |
| 使用非市场价值时是否明确声明"不是市场价值" | 清算价值、投资价值、残余价值须声明 |
| 评估方法选择是否写明适用性论证 | 应说明选择理由**与不选择理由** |
| 法定应采用的方法是否缺失 | 国资业务与企业价值评估的通行要求 |

### 1.2 参数与口径

| 检查点 | 判据 |
|---|---|
| 折现率与现金流口径是否匹配 | FCFF 配 WACC（税后、无杠杆）；FCFE 配 Ke；不得税前税后混用 |
| 关键参数是否无来源、无取值口径 | rf、ERP、Beta、α、Kd、资本结构须逐项标注来源与时点 |
| 永续增长率是否超过宏观长期增长水平 | 通常须 ≤ 3% 且经论证 |
| 成新率是否直接套用会计折旧年限 | 成新率 ≠ 会计折旧年限 / 经济寿命 |
| Beta 是否完成杠杆还原 | 可比公司无杠杆 β → 目标资本结构还原 |
| 价值比率分子分母期间是否一致 | P/E 的 E 须与 P 同期口径 |

### 1.3 预测逻辑

| 检查点 | 判据 |
|---|---|
| 收益法预测是否与历史经营、行业趋势、基准日状况有逻辑衔接 | 收入增长率、毛利率、费用率须有依据，不得整行复制历史数或凭空跳增 |
| 预测期与收益期划分是否说明依据 | 预测期、稳定期、收益期的确定逻辑 |
| 溢余资产与非经营性资产负债是否识别并单独处理 | 逐项列示并说明识别依据 |

### 1.4 核查验证

| 检查点 | 判据 |
|---|---|
| 结论所依赖的权属、财务数据是否经核查验证 | 《资产评估法》第十三条：对文件、证明和资料的真实性、准确性、完整性进行核查和验证 |
| 是否以"假设资料真实"简单替代核查 | 须说明已履行的核查程序及未能核实部分 |
| 权属瑕疵、抵押查封租赁等限制是否披露 | 影响价值的权利限制须在特别事项说明中披露 |

## 二、一般问题（影响规范性与可复核性）

### 2.1 报告要素完整性

| 检查点 |
|---|
| 声明是否七项齐全（含现场调查声明、利益关系声明） |
| 摘要是否含评估目的、对象、价值类型、基准日、方法、结论、有效期 |
| 正文十四节是否齐备；附件目录与实物是否一致 |
| 特别事项说明是否覆盖产权瑕疵、期后事项、未核实事项、重大不确定事项 |
| 使用限制说明是否完整（使用人、范围、目的、有效期） |
| 报告日是否不早于现场调查完成日与结论形成日 |
| 评估结论有效期表述是否正确（一年，自基准日起算；国资须核准或备案后使用） |
| 签名是否满足至少两名资产评估师并加盖机构印章 |

### 2.2 底稿质量

| 检查点 |
|---|
| 测算表是否存在硬编码数值（公式不可追溯、无法勾稽） |
| 明细表与报告数据是否勾稽一致（汇总表 ↔ 明细表 ↔ 正文表述） |
| 参数取值时点与口径是否在底稿中标注 |
| 评估申报表、收益预测表与评估结果是否可逐项对应 |
| 会计政策影响是否说明（折旧政策、收入确认、金融工具计量、租赁、减值） |

### 2.3 评估依据章节

| 检查点 |
|---|
| 五类依据（经济行为、法律法规、评估准则、权属、取价）是否齐全 |
| 文号是否现行有效（识别已废止、尚未施行、将被替代三类） |
| 书写体例是否统一（书名号、文号格式、发布日与施行日） |
| 是否引用了与评估对象无关的准则（凑数） |

### 2.4 假设与披露

| 检查点 |
|---|
| 一般假设与特殊假设是否分列，每条特殊假设是否为结论成立的必要条件 |
| 产权瑕疵、期后事项、资料受限是否提示 |
| 未核实事项是否说明替代程序 |

## 三、优化建议（提升质量）

| 检查点 |
|---|
| 敏感性分析缺失或维度过窄（仅单参数） |
| 可比公司 / 可比案例筛选标准未说明，修正系数无量化依据 |
| 折现率、成新率等关键参数未以表格呈现，散落正文难以复核 |
| 报告语言冗余，结论前置不足 |
| 行业分析与宏观经济分析与预测参数之间未建立对应关系 |
| 图表缺失（评估结果汇总表、敏感性分析表、可比公司参数表） |
| 数据来源未标注具体出处（仅写"公开资料""行业统计"） |

## 四、审核输出模板（汇总《审核意见》严格对齐《评估报告审核》技能 `opinion_format_reference.md`）

> **交付的汇总《审核意见》必须用下方结构**，与《评估报告审核》技能生成的 docx 一致；本包三级（重大缺陷 / 一般问题 / 优化建议）仅用于**问题内部归类与台账统计**，不写进交付意见标题。
> 若已加载《评估报告审核》技能，以其 `opinion_build.py` 生成的 docx 为权威交付物，本节仅作离线起草与阅读参照。

### 1. 汇总《审核意见》版式（交付用，严格对齐使用者给定的三份初审意见范本）

> **版式基准（强制）**：交付的汇总《审核意见》严格按使用者给定的三份初审意见范本（单一主体股权 / 多主体公司 / 单项资产；随包附带于 `templates/opinion-style-examples/`，为样式参考样例，含样例项目数据，正式出具时由实际项目替换；与《评估报告审核》技能 `opinion_format_reference.md` 同源于使用者参考样式，冲突时**以这三份范本为准**）。若已加载《评估报告审核》技能，以其 `opinion_build.py` 生成的 docx 为权威交付物，但若生成版式与范本的「按主体短横拆分 / 落款含答复人」不一致，须以范本为准成稿后校订；本包三级（重大缺陷 / 一般问题 / 优化建议）仅用于问题内部归类与台账统计，不写进交付意见标题。

```
标题区（各自成行；项目名可按语句换行）：
  ××公司拟[经济行为]涉及的××[价值类型]评估项目
  审核意见
  ××评报字[2026]第××号

评估报告
评估说明
  （▼ 多主体 / 多册：按主体短横连接、不编号）
  评估说明-母公司 / 评估说明-SGD公司 / …
  （▲ 单主体：不设二级标题）
评估明细表及测算表
  （▼ 多主体：按「方法 + 主体」短横连接、不编号）
  资产基础法评估明细表及测算表-母公司 / -SGD公司 / …
  市场法评估明细表-母公司
  （▼ 单主体多方法：按方法「（一）（二）」编号、叠写方法全称）
  （一）收益法评估明细表
  （二）资产基础法评估明细表及测算表
  （三）市场法评估明细表
  （▲ 单主体单方法：不设二级标题）

审核人：
日期：2026年  月   日

答复人：
日期：2026年  月   日
```

结构硬规则：

- **一级章节不编序号**：直接写「评估报告」「评估说明」「评估明细表及测算表」，不带「一、二、三、」。
- **条目不编连续阿拉伯数字**：条首只写 `P页码` 或 `科目`；不写「1. 2. 3.」。
- **标题区分行**：项目名（可多行换行）、「审核意见」、「报告文号」各自成行，不合并成单行。
- **多册 / 多主体逐一审核（硬要求）**：项目涉及**多份评估说明、多套明细表 / 测算表**时，每一册、每一被评估主体都必须**单独成二级标题逐一审核**，不混排、不遗漏：
  - 多主体 / 多册 → 二级标题**按主体短横连接、不编号**：`评估说明-母公司`、`资产基础法评估明细表及测算表-SGD公司`、`市场法评估明细表-母公司`。
  - 单主体多方法 → 二级标题**按方法「（一）（二）」编号、叠写方法全称**：`（一）收益法评估明细表` 等；只一种方法时不插。
  - 单主体单方法 → 不插二级标题，问题直接列在父章节下。
  - 无发现的册 / 主体也要列出并写「已审核，未发现需提示的问题。」，让读者看得出确实审过；跨主体问题分列在各自主体标题下，同一主体下科目逐条分列。
- **脱敏红线（强制）**：不得出现具体项目名称、被评估单位、报告文号、金额、人名、联系方式、证照编号；只抽抽象审核关注要点（「XX 数据不一致」「XX 重复」）。
- **档位不进意见**：【SSS】/【SS】/【S】只写在报告与说明批注里，汇总《审核意见》不出现档位字样（与审核技能一致）。
- **落款含答复人**：末尾固定「审核人： / 日期：」与「答复人： / 日期：」四行（与三份范本一致）。

### 2. 行文体例

- **评估报告 / 评估说明（docx 类）**：`P{页码}，“{原文}”{简练描述}。`
  - P 为真实页码（借 Word 引擎反查），无页码回退为结构定位串（如 `评估说明/表2/第2行`）或段落号，**绝不编造页码**；引号内必须是段落真实原文。
  - 明显错误用肯定句；判断事项用疑问句（参数偏高/偏低、选取依据是否充分、方法适用性、披露是否充分、预测逻辑是否合理）。
- **评估明细表及测算表（xlsx 类）**：`{科目}：{问题}。`；同科目多处问题用①②③分述，一个科目一条，不同科目不并列成一条，跨主体分列在各自主体小标题下；科目顺序按明细表表页顺序。

### 3. 内部问题归类（仅用于台账与统计，不进交付标题）

审出的每条问题先归入三级，便于统计与答复跟踪；**交付意见时不写三级标题**，按上面版式直接列 P页码/科目条目：

- **重大缺陷（影响结论有效性，必须修改）**：价值类型/方法选型缺失或论证不足、参数与口径错配、预测逻辑断裂、核查验证缺失、权属瑕疵未披露等。
- **一般问题（影响规范性与可复核性）**：报告要素不完整、底稿硬编码、依据章节缺项/体例不统一、假设与披露不充分等。
- **优化建议（提升质量）**：敏感性分析过窄、可比案例筛选无量化、关键参数未表化、行业分析与参数无对应、图表缺失、数据来源未标注等。

### 4. 需委托人补充或核实的事项

列明需外部资料/职业判断方能定论的项目，注明「需人工复核」；可附在对应册或作为补充段落，不与上述版式冲突。

## 五、高频失分点速查

1. 折现率与现金流口径错配（税前 / 税后、含杠杆 / 无杠杆混用）；
2. 永续增长率超过宏观长期增长水平；
3. 成新率直接套用会计折旧年限；
4. 收益预测与历史、行业趋势无逻辑衔接；
5. 多方法结论差异未量化、最终取值无论证；
6. 测算底稿存在硬编码数值，公式不可追溯；
7. 评估依据引用已废止文号或体例不统一；
8. 特别事项披露不充分（产权瑕疵、期后事项、资料受限）；
9. 价值类型选择与评估目的不匹配；
10. 报告数据与明细表勾稽不一致。
