# IVS（国际评估准则）与中评协准则对照

> **本对照表仅供研究/对外业务参考用，**ⅣS 不是中评协体系规范，**严禁作国内评估报告的评估依据**。
> 数据来源：IVS《国际评估准则》2025 版（2025 年 1 月 31 日生效）及其中文版。

---

## 1 · IVS 体系架构（IVS 2025）

```
┌────────────────────────────────┐
│  IVS Foreword 前言              │
│  IVS 100 Valuation Framework    │  ← 总纲（框架）
│  IVS 101 Scope of Work  工作范围│
│  IVS 102 Bases of Value 价值基础│  ← 价值类型
│  IVS 103 Valuation Approaches   │  ← 三大方法
│  IVS 104 Data and Inputs  数据输入│
│  IVS 105 Valuation Models 评估模型│
│  IVS 106 Documentation & Reporting│  ← 报告
IVS 2025 ─┤                                  │
├────────────────────────────────┤
│  Asset Standards 资产类           │
│  IVS 200 Businesses & Interests │  ← 企业/股权
│  IVS 210 Intangible Assets      │  ← 无形资产
│  IVS 220 Non-Financial Liab.    │  ← 非金融负债
│  IVS 230 Inventory               │  ← 存货
│  IVS 300 Plant, Equipment & Infra│  ← 设备/基础设施
│  IVS 400 Real Property Interests │  ← 不动产
│  IVS 410 Development Property    │  ← 开发性不动产
│  IVS 500 Financial Instruments   │  ← 金融工具
└────────────────────────────────┘
```

**核心特征**（与中评协对比）：
1. IVS 不是"层级化体系"（没有"基本/程序/实体/指南/意见"四层），而是"**框架+类型**"两结构
2. IVS 不分"中评协/地方协会"等主体，任何 IVSC 会员适用
3. IVS 强调"价值基础（Bases of Value）"——与中评协的"价值类型"对应但不完全等价

## 2 · IVS ↔ 中评协准则映射表（核心条款）

### 2.1 通用标准（General Standards）映射

| IVS 2025 | IVS 核心内容 | 中评协对应 | 差异说明 |
|---|---|---|---|
| **IVS 100 Valuation Framework** | 评估目的/客体/基础/方法/报告/假设/重要性 | 基本准则（财资〔2017〕43号） | IVS 强调"三要素法框架"；中评协强调"评估行为规范" |
| **IVS 101 Scope of Work** | 工作范围识别与披露 | 程序准则 + 委托合同准则 | 概念高度相似，IVS 更详尽（如假设前后变化披露） |
| **IVS 102 Bases of Value** | 价值基础（市场价值/投资价值/公允价值/清算价值/协同价值/在用价值等） | 价值类型意见〔2017〕47号 | ⚠️ **IVS 102 有 13 种 Bases of Value**，中评协价值类型意见主要 5-6 种。重大差异：IVS 含 **"Premises of Value"**（最高最佳用途/有序清算/强制清算/协同/资本回收/有效用益等 9 种） |
| **IVS 103 Valuation Approaches** | 三大基本方法：市场法/收益法/成本法 + 衍生方法 | 方法准则〔2019〕35号 | 几乎完全对应；术语略有不同（如"income approach"对应"收益法"） |
| **IVS 104 Data and Inputs** | 数据来源/可观察性/假设/客观性 | 价值类型意见 + 程序准则（章节散布） | IVS 单独成章，中评协按需分散 |
| **IVS 105 Valuation Models** | 模型选用/参数验证/敏感性分析 | 折现率指引〔2020〕38号 + 实物期权意见〔2017〕54号 | IVS 把"模型"作为独立章节；中评协更细分到具体业务 |
| **IVS 106 Documentation & Reporting** | 报告格式/披露要求/假设说明 | 报告准则〔2018〕35号 + 国资报告指南〔2017〕42号 | IVS 报告体例与中评协大体一致，IVS 强调"assumptions and limiting conditions"章节 |

### 2.2 资产标准（Asset Standards）映射

| IVS 2025 | IVS 资产定义 | 中评协对应准则 | 差异说明 |
|---|---|---|---|
| **IVS 200 Businesses and Business Interests** | 整体企业/股东权益 | 企业价值准则〔2018〕38号 | 基本一致；IVS 强调"premium/discount control"测算 |
| **IVS 210 Intangible Assets** | 无形资产（含商誉、品牌、技术、合同、客户关系等） | 无形资产准则〔2017〕37号 + 知识产权准则〔2023〕14号 + 各项专利/著作权/商标意见 | IVS 涵盖类别更细；中评协知识产权刚升格（2023），与 IVS 210 范围接近 |
| **IVS 220 Non-Financial Liabilities** | 非金融负债（如环境负债、退役义务） | （无直接对应，主要在企业价值准则中处理） | ⚠️ IVS 单独规范；中评协一般合并到企业价值 |
| **IVS 230 Inventory** | 存货（按现行市价/成本与可变现净值孰低） | 机器设备准则〔2017〕39号 + 流动资产一般处理 | 中评协无单独存货准则，按资产类型在分项中处理 |
| **IVS 300 Plant, Equipment & Infrastructure** | 工厂设备/装备/基础设施 | 机器设备准则〔2017〕39号 | IVS 涵盖更广（含基础设施），中评协主要在 PE 范畴 |
| **IVS 400 Real Property Interests** | 不动产权益 | 不动产准则〔2017〕38号 + 投资性房地产意见〔2017〕53号 | 基本一致；中评协对房地产类型细分更多 |
| **IVS 410 Development Property** | 开发性不动产 | 不动产准则 + 假设开发法 | 概念直接对应 |
| **IVS 500 Financial Instruments** | 金融工具 | **无直接对应准则**（中评协金融领域薄弱，主要在金融国资报告指南〔2017〕43号引用） | ⚠️ **中评协重大缺口**——金融工具估值主要依赖专家指引（金融企业评估指引系列） |

### 2.3 中评协无对应 / IVS 独有章节

| IVS 2025 | 性质 | 中评协处理方式 |
|---|---|---|
| **IVS 102 §Appendix A60-A110**（Premises of Value） | 9 种评估前置条件 | 价值类型意见〔2017〕47号仅简述"前提假设"；无系统化 |
| **IVS 220 Non-Financial Liabilities** | 单独成册 | 散见企业价值准则 / 不动产准则 |
| **IVS 230 Inventory** | 单独规范 | 按流动资产一般条款处理 |
| **IVS 500 Financial Instruments** | 完整金融工具估值 | 主要靠"金融国资报告指南〔2017〕43号"+ 金融企业专家指引 1-5 号 |
| **IVS 105 Valuation Models** | 模型与敏感性 | 散见各专家指引 |

### 2.4 中评协有对应 / IVS 不单独成章

| 中评协 | IVS 处理 |
|---|---|
| 程序性准则（程序/委托合同/档案） | IVS 101 Scope of Work 部分涵盖 |
| 国资报告指南〔2017〕42号 | IVS 106 + 委托方要求中处理 |
| 司法处置意见〔2019〕14号 | IVS 102 bases of value 中"有序清算/强制清算"对应 |
| 评估机构质控指南（2026修订） | IVS 不涉及机构内部质控（属非评估技术内容） |
| 各种指导意见（无形资产/数据/碳资产等） | IVS 在 IVS 210 中统驭 |

## 3 · 价值类型 / 价值基础 差异 ⭐ 重要

### 3.1 IVS 102 Bases of Value（13 种）

| 序号 | Bases of Value | 中文常用译名 | 中评协对应 |
|---|---|---|---|
| 1 | Market Value | 市场价值 | ✅ 价值类型意见 |
| 2 | Investment Value | 投资价值 | ✅ 价值类型意见 / 并购投资价值意见 |
| 3 | Fair Value | 公允价值 | ✅ 价值类型意见 / 财报目的指南 |
| 4 | Equitable Value | 公平价值 | ❌ 无直接对应 |
| 5 | Synergistic Value | 协同价值 | ❌ 无直接对应（含在并购投资价值中处理） |
| 6 | Liquidation Value | 清算价值 | ✅ 价值类型意见 + 司法处置意见 |
| 7 | Distress Value | 受迫清算价值 | ❌ 包含在清算价值里 |
| 8 | Orderly Liquidation | 有序清算 | ❌ 含在清算价值 |
| 9 | Forced Sale | 强制出售 | ❌ 含在清算价值 |
| 10 | Cash Flow-Generating Value | 现金流价值 | ❌ 一般视为收益法结果 |
| 11 | **Premises of Value**（9 种二级基础） | 评估前置条件 | ❌ 中评协用"评估假设"概念 |
| 12 | Net Realisable Value | 可变现净值 | ❌ 散见存货/不动产处理 |
| 13 | Recoverable Amount | 可收回金额 | ❌ 在减值测试语境使用 |

### 3.2 IVS Premises of Value（A 级，前置条件）

9 种：
1. **最高最佳用途**（Highest and Best Use）
2. **现有用途**（Current Use / Existing Use）
3. **有序清算**（Orderly Liquidation）
4. **强制清算**（Forced Liquidation）
5. **协同合并**（Synergy / Combined Basis）
6. **资本回收**（Capital回收/Capital回收 Basis）
7. **有效用益**（Going Concern 持续经营）
8. **战时效力**（Salvage Basis 残余价值）
9. **退役/清算后用途**（Hypothetical）

> 中评协体系内对应概念散落于"评估假设"各章节，未形成独立、系统的体系。

## 4 · 实务对照要点

### 4.1 中评协项目的涉外引用原则

- **国内评估报告——绝对不引 IVS 作评估依据**（即使是涉外项目）
- **境外业主/境外评估师的项目**——可在报告"评估准则参考"列出 IVS 对应条款作辅助
- **境外报告与境内报告对接**——若境内评估报告需向境外使用方披露，可在附注加"亦符合 IVS 100-106 框架"说明

### 4.2 涉外项目一般准则选择

| 项目性质 | 国内评估师 | 境外评估师（含国际联合） |
|---|---|---|
| 中国境内标的 | 必引中评协（基础三件套 + 实体准则 + 报告指南） | 必引中评协 + 加注 IVS 对照 |
| 境外标的 | 中评协 + IVS 对照 | 仅引 IVS |
| 跨境资产 | 中评协 + IVS 对照 + 境外国别准则（如 USPAP、RICS Red Book、VALMIN 等） |

### 4.3 三大方法 IVS 术语对照

| 中评协 | IVS 术语 |
|---|---|
| 资产基础法 | Cost Approach（成本法） |
| 收益法 | Income Approach（收益法） |
| 市场法 / 市场比较法 | Market Approach（市场法） |
| 假设开发法 | Residual Method / Development Method（IVS 410 涵盖） |
| 许可费节省法 | Relief from Royalty Method（IVS 210 涵盖） |
| 增量收益法 | Incremental Income Method（IVS 210 涵盖） |
| 超额收益法 | Excess Earnings Method / Multi-period Excess Earnings Method（IVS 210 涵盖） |
| 实物期权法 | Real Options Valuation（IVS 105 涵盖） |

## 5 · IVS 引用时的实务提示

> "我应该在哪里引用 IVS？"

1. **国内评估报告"评估依据"列**：**❌ 不引 IVS**——按中评协规范要求列
2. **国内评估报告"方法说明"列**：✅ 可作辅助参考，简述所采用方法的国际通行做法
3. **涉外报告"准则参考"列**：✅ 引 IVS 标准号（如"IVS 103 Valuation Approaches"）
4. **学术研究/比较研究**：✅ 可作完整对照

## 6 · 关键差异警示 ⚠️

| 维度 | IVS | 中评协 |
|---|---|---|
| **强制力** | 自愿采用（IVSC 不强制） | 法定评估业务**必须遵守**（行业法规授权） |
| **组织主体** | IVSC（International Valuation Standards Council）国际机构 | 财政部主导 + 中评协（中国资产评估协会）起草 |
| **价值类型** | 13 种 bases + 9 种 premises | 主要 5-6 种 + "评估假设"概念 |
| **报告监管** | 不监管 | 财政部 + 证监会 + 国资委 多重监管 |
| **数据来源** | 国际通用，强调市场可观察 | 中国市场惯例，强调资料调阅+函证 |
