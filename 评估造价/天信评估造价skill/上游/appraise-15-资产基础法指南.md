# 资产基础法（成本法）操作与审核要点（蒸馏）

> **来源**：江苏省资产评估协会《企业价值评估操作指引——资产基础法》（2020 年 12 月），162 页，正文三章二十八节。
> **性质**：蒸馏后的**操作框架与审核清单**（结构性重组与提炼），非原文复制。具体条款以原指引原文及**现行资产评估准则**为准；指引与准则不一致的，**以准则为准**（原指引特别说明：本指引是专家意见，仅供参考，不能替代准则与职业判断）。
> **适用**：以持续经营为前提的**一般企业（非金融企业）**资产基础法评估。

## 〇、为什么对本专家重要

资产基础法是三大基本方法之一，也是**表内逐科目核查验证要求最密集**的方法。审核企业价值评估报告与底稿时，绝大多数"数字对不上 / 程序没做到位"的问题发生在资产基础法的各科目核查环节。本文件与 `method-parameters.md`（参数口径）互补：本文件管**逐科目程序与审核要点**。

## 一、资产基础法总体操作要求（第二章蒸馏）

资产评估专业人员采用资产基础法时，除执行各相关准则的基本操作要求外，须特别注意：

1. **全面、充分识别表内及表外各项资产负债**
   - 要求被评估单位识别资产负债表表内及表外各项资产、负债，指导填写"资产评估申报明细表"，全面反映其拥有的各项权益和义务；
   - 申报明细表内资产、负债账面价值合计数须与相应会计科目明细账、总账及会计报表核对一致，确保真实、完整、可靠；
   - 对能够识别并单独评估的资产和负债应充分识别，识别出的**表外资产与负债应纳入评估申报文件**，并要求委托人或相关当事人确认评估范围；
   - 当存在对评估对象价值有重大影响且**难以识别和评估**的资产或负债时，应考虑**资产基础法的适用性**（即可能不适用）。

2. **表外资产负债的常见类型**（识别线索）
   自创无形资产（未入账专利、专有技术、客户关系）、未入账的土地使用权、未决诉讼与仲裁、对外担保与承诺、经营租赁义务、人力资源与组织资本、已费用化但仍有价值的研发成果、账外实物资产等。

3. **评估结果的计算口径**
   股东全部权益价值 = 各项资产评估值 − 各项负债评估值；控股型长期股权投资须对被投资单位整体评估后按持股比例确定，并考量控制权溢价与流动性折扣；参股且无控制、无重大影响但有活跃市场报价的，可按公允价值计量。

4. **评估增减值的所得税影响**
   各项资产评估增减值形成暂时性差异的，应考虑**递延所得税资产 / 负债**的相应调整，不得遗漏（见第二十一节）。

## 二、逐科目核查验证与评定要点（审核清单）

> 每类按"**核查验证要点 → 评定估算口径 → 审核常见风险**"三段组织。审核底稿时逐项对照。

### 资产类

**1. 货币资金**
- 核查：获取申报明细表，复核加计并与总账、明细账核对；取得银行对账单与询证函，编制余额调节表，核实未达账项；关注**受限资金**（保证金、冻结、质押）并单独标注。
- 评定：一般按核实后账面值确定；外币按评估基准日汇率折算。
- 风险：未函证 / 未调节；受限资金未披露；银行余额与账面长期不符未查明。

**2. 交易性金融资产与负债**
- 核查：核实持有目的、数量、成本与期末计量依据；取得活跃市场报价。
- 评定：按公允价值计量；无活跃报价的采用估值技术并披露层次。
- 风险：以成本代替公允价值；估值模型参数未披露。

**3. 应收款项**（应收票据 / 应收账款 / 预付账款 / 其他应收款）
- 核查：复核加计并与总账、明细账、坏账准备科目核对；按金额与账龄**选样函证**（重点：大额、异常、逾期、长期挂账），编制函证汇总表，差异须调查取证；不能回函的实施**替代程序**（合同、发票、发货单）；关注基准日后期后回款并收集支付凭证；对长期挂账款调查原因，必要时查询债务人存续状态。
- 评定：应收票据一般按票面金额（权重较大时按贴现值）；应收账款区分**正常信用期内**与**逾期**两类——正常信用期内且信用状况良好的按核实后金额；逾期款项采用**个别认定法**，按预期信用损失率计算损失并编制计算底稿；预期信用损失率考虑历史坏账、历史债务重组、坏账准备会计政策三因素。
- 风险：不函证直接按账面值；预期信用损失率无依据或未考虑账龄；**基准日后已到期未承兑的商业承兑汇票**未关注信用风险；已抵押应收票据未收集资料；预付账款中费用性支出未重分类。

**4. 合同资产与合同负债**
- 核查：按收入准则识别已履约未收款的合同资产与已收款未履约的合同负债，与预收账款区分。
- 评定：合同资产考虑减值；合同负债按预计将履行的义务计量。
- 风险：合同资产与应收账款混同；合同负债与预收款项重复或遗漏。

**5. 存货**（原材料 / 在产品 / 半成品 / 产成品 / 商品 / 发出商品 / 周转材料 / 材料采购 / 委托加工物资）
- 核查：现场**盘点**核实数量；访谈与核对核实账面价值；重点关注**数量、品质、账面价值**三方面——是否可正常使用或销售、是否盘盈盘亏、品质是否毁损报废 / 霉烂变质 / 残次冷背 / 超储积压、是否潜亏挂账，并在明细表中注明。
- 评定：期末按**成本与可变现净值孰低**计量；可变现净值 = 估计售价 − 至完工估计成本 − 估计销售费用 − 相关税费。
- 风险：不盘点直接采信账面；残次冷背与超储积压未减值；在产品完工程度无依据；发出商品权属未核实。

**6. 房地产开发企业存货**（开发产品 / 开发成本）
- 核查：核实项目进度、预售与交付情况、预计售价与续建成本、土地增值税清算口径。
- 评定：按预计售价扣除续建成本、销售费用、销售税金及附加、土地增值税、所得税后的净值；可采用动态假设开发法等。
- 风险：售价假设无市场依据；续建成本与工程进度不匹配；土地增值税与所得税扣除遗漏。

**7. 长期债权投资**
- 核查：取得债券或借款协议，核实面值、票面利率、期限、付息方式、折溢价摊销。
- 评定：按本金加应计利息，结合债务人信用与可回收性确定。
- 风险：未核实债务人信用；折溢价未摊销；关联方资金占用未披露。

**8. 长期股权投资**
- 核查：取得被投资单位章程、验资报告、基准日财务报表；区分全资 / 控股 / 参股。
- 评定：全资、控股及有重大影响的，应**对被投资单位整体评估**后按持股比例确定，并考量控制权溢价与流动性折扣；参股且无控制、无重大影响但有活跃市场报价的，可按公允价值；无法获取报表且无替代程序的，应在报告中充分披露该限制。
- 风险：对被投资单位未履行评估程序直接按账面净资产乘持股比例；未考虑控制权溢价 / 流动性折扣；层层穿透缺失。

**9. 其他权益工具投资**
- 核查：核实指定为以公允价值计量且其变动计入其他综合收益的非交易性权益工具投资的依据。
- 评定：按公允价值计量并披露公允价值层次。
- 风险：分类依据不足；无活跃市场时公允价值确定方法未论证。

**10. 投资性房地产**
- 核查：核实权属、计量模式（成本 / 公允价值）、租约与收益情况。
- 评定：收益法（净收益、报酬率、收益年限）或市场比较法；须与《投资性房地产评估指导意见》口径一致。
- 风险：计量模式与评估口径错配；租约未核实导致净收益失真。

**11. 机器设备**
- 核查：现场勘查核实数量、规格、启用日期、运行状态与权属；核实重置价构成。
- 评定：重置成本 = 购置价 + 运杂费 + 安装调试费 + 前期及其他费用 + 资金成本 − 可抵扣进项税（进口设备另计关税、增值税）；成新率综合年限法与现场观测法；分别考量实体性、功能性、经济性贬值。
- 风险：**成新率直接等同会计折旧年限**；重置价漏计资金成本或可抵扣进项税处理错误；已提足折旧仍在用设备评估为零；经济寿命年限取用无出处。

**12. 房屋建筑物**
- 核查：核实权属证书、面积、结构、竣工与使用情况；核实施工图或决算资料。
- 评定：重置成本 = 建筑安装工程造价 + 前期及其他费用 + 资金成本 + 合理利润；成新率结合年限法与完好分值（观测）法；可采用市场比较法、收益法交叉验证。
- 风险：面积与权属证载不符；未取得造价依据而估算；成新率与实体状况背离。

**13. 在建工程**
- 核查：核实工程形象进度、付款进度与账面成本构成；核实施工合同、监理报告。
- 评定：按核实后账面成本（合理工期内计资金成本）；停缓建工程关注减值。
- 风险：账面成本含不合理支出；形象进度与付款进度严重背离；停缓建未减值。

**14. 使用权资产与租赁负债**
- 核查：按租赁准则核实承租人确认的使用权资产与租赁负债、折现率与租赁期。
- 评定：按核实后账面值或重新计量结果确定。
- 风险：经营租赁未纳入识别；租赁负债折现率未核实。

**15. 土地使用权**
- 核查：核实出让 / 划拨性质、用途、剩余使用年限、权属证载、规划条件。
- 评定：市场比较法、基准地价系数修正法、成本逼近法、假设开发法、收益还原法；划拨土地须扣除应补缴出让金。
- 风险：**划拨地按出让地评估**未扣出让金；剩余年限使用错误；用途与证载不符。

**16. 矿业权**
- 核查：核实勘查许可证 / 采矿许可证、资源储量评审备案、开发利用方案。
- 评定：折现现金流量法、收入权益法等；**须具备矿业权评估专项资质**。
- 风险：无矿业权评估资质承接；储量依据未经评审备案。**→ 超出本专家常规胜任范围，遇此类应提示引入矿业权评估专项机构（见第四节）。**

**17. 无形资产**
- 核查：核实权利证书、法律状态、剩余经济寿命、是否可辨认。
- 评定：超额收益法、许可费节省法、增量收益法；划清**可辨认无形资产与商誉**的边界。
- 风险：自创无形资产（客户关系、专有技术）漏评；超额收益与折现率口径错配；法律已失效仍评估。

**18. 研究开发支出**
- 核查：核实资本化 / 费用化判断是否合规。
- 评定：符合资本化条件的开发支出纳入评估；已费用化且无未来经济利益的部分评估为零。
- 风险：资本化依据不足而并入资产；费用化研发成果漏识别。

**19. 商誉**
- 核查：核实商誉形成来源与账面值；资产基础法中商誉通常**不单独评估**（为企业价值扣减可辨认净资产公允价值后的差额）；减值测试场景另按减值测试准则处理。
- 风险：资产基础法下重复评估商誉；减值测试与资产基础法口径混用。

**20. 长期待摊费用**
- 核查：核实受益期与摊销政策，判断能否带来未来经济利益。
- 评定：尚有受益期的按核实后摊余价值；**已不能带来未来经济利益的部分评估为零**（如开办费、部分租入固定资产改良支出）。
- 风险：开办费仍按摊余值评估；受益期判断无依据。

**21. 递延所得税资产（负债）**
- 核查：识别评估增减值形成的**暂时性差异**。
- 评定：按资产负债表债务法重新计算递延所得税资产 / 负债；评估增值通常产生递延所得税负债。
- 风险：**评估增减值未同步调整递延所得税**；可抵扣暂时性差异无未来 sufficient 应纳税所得额支撑仍确认资产。

### 负债类

**22. 银行借款**
- 核查：取得借款合同，核实本金、利率、期限、担保、逾期与展期情况；向银行函证。
- 评定：按核实后账面值确定；关注逾期罚息与展期。
- 风险：未函证；逾期 / 担保事项未披露。

**23. 应付款项**
- 核查：函证大额供应商，核对账龄；关注长期挂账款项与关联方款项。
- 评定：按核实后账面值；对确凿证据表明无需支付的，须谨慎处理并披露依据。
- 风险：长期挂账款直接评估为零而无证据；关联方款项未单独披露。

**24. 应付职工薪酬**
- 核查：核实在职与离职人员清单、计提与发放记录、辞退福利、设定受益计划。
- 评定：按核实后账面值。
- 风险：辞退福利与设定受益计划未识别。

**25. 应交税费**
- 核查：核实税种、计税依据、税率；检查税务申报表、税务稽查结论、欠税与滞纳金、税收优惠依据。
- 评定：按核实后账面值；补提欠税与滞纳金。
- 风险：欠税与滞纳金漏评；税收优惠无批文依据。

**26. 长期应付款**
- 核查：核实融资租赁款、分期付款购入资产的合同与未确认融资费用。
- 评定：按核实后账面值（含未确认融资费用分摊）。
- 风险：未确认融资费用未分摊；融资租赁未识别。

**27. 预计负债**
- 核查：核实未决诉讼、产品质量保证、重组义务、亏损合同、弃置费用等；判断确认条件（现时义务、很可能流出、金额可可靠计量）。
- 评定：按最佳估计数确定。
- 风险：**或有事项未识别披露**；预计负债确认条件不满足仍计提。

**28. 递延收益**
- 核查：核实政府补助文件，区分与资产相关 / 与收益相关。
- 评定：与资产相关的按相关资产的处理口径；与收益相关的按核实后账面值。
- 风险：政府补助分类错误；与资产相关的未随资产处理。

## 三、资产基础法审核高频风险点（审计视角速查）

1. **申报明细表与账表不符**：表内资产、负债合计数未与总账 / 明细账 / 报表核对一致（第二章首要要求）。
2. **表外资产负债漏识别**：自创无形资产、未入账土地、未决诉讼、担保承诺、经营租赁义务未纳入。
3. **程序替代不足**：应收款项未函证且未做替代程序；存货未现场盘点；银行借款未函证。
4. **参数口径错配**：成新率 = 会计折旧年限；FCFF 配 Ke；折现率口径与现金流不匹配。
5. **减值迹象未处理**：残次冷背与超储积压存货、停缓建工程、长期挂账款、已失效无形资产。
6. **递延所得税未联动**：评估增减值形成暂时性差异但未调整递延所得税。
7. **长期股权投资穿透不足**：未对被投资单位整体评估，直接按账面净资产乘持股比例。
8. **划拨与出让混淆**：划拨土地未扣除应补缴出让金即按出让地评估。
9. **硬编码与不可追溯**：测算表未用公式与单元格引用，结论无法追到来源。
10. **适用性未论证**：存在重大且难以识别评估的资产负债时，未论证资产基础法是否适用。

## 四、能力边界提示

- 下列专项领域**不是转介放弃的理由**，按"先查本包语料 → 再查协会官网 → 仍不足才提示资质"的路径求解：

  | 专项领域 | 本包对应章节 | 权威来源（协会官网） |
  |---|---|---|
  | 矿业权 | 第十六节（另见 `mining-rights-audit.md`） | 中国矿业权评估师协会 http://www.camra2006.org.cn/ |
  | 房地产估价 | 第十节（投资性房地产）、第十二节（房屋建筑物） | 中国房地产估价师与房地产经纪人学会 http://www.cirea.org.cn/ |
  | 土地估价 | 第十五节（土地使用权） | 中国土地估价师与土地登记代理人协会 http://www.creva.org.cn/ |
  | 森林资源资产 | — | 中评协森林资源资产执业准则（中评协 http://www.cas.org.cn/ ） |
  | 珠宝首饰 | — | 中评协珠宝首饰执业准则（中评协 http://www.cas.org.cn/ ） |

- **关键口径**：凡能通过本包语料与协会官网检索到的，直接给出答案并注明依据出处；资质要求属**执业附注**（正式报告须由具备相应资质的机构与评估师签署），仅在确实超出可检索范围时才提示引入专项评估师，并按《资产评估执业准则——利用专家工作及相关报告》（中评协〔2017〕35 号）说明利用专家工作的披露要求。
- 金融企业特有资产负债**不在**本指引覆盖范围，金融企业评估须另行适用相关准则与《金融企业国有资产评估报告指南》。
