# AGENTS.md — 天信实务知识库 Skill

> 本目录是「天信实务知识库」Skill 的物理落点，在仓库 `公用/` 下，与「天信文档」「陈版主实务问答」同级，供天信审计 / 会计 / 税务实务检索与系统化判断。
> 安装由仓库安装器复制完成，**不是 junction**——见下方「加载方式」。（以下带"仓库根"字样的命令只在本仓库里操作时用，技能装到全局后不适用）

## 结构

- `SKILL.md` — 12 张能力卡索引 + 使用方式 + 红线。
- `cards/` — 12 张能力卡（六节：核心理念 / 判断直觉 / 准则依据 / 天信场景 / 演练输出 / 关联卡）。
- Skill 名（frontmatter）：`tianxin-shiwu-kb`。

## 加载方式

- 源目录（开发位置，本目录）：`D:/project/天信/公用/天信实务知识库skill/`
- 安装目标：`~/.workbuddy/skills/tianxin-shiwu-kb/` —— **目录名取 frontmatter 的 `name`，不是源目录名**
- 安装命令（仓库根执行）：`python install.py --global`
- **是复制，不是 junction。** 早先用 junction 指向本目录，结果 Windows 文件锁导致技能目录移不动、被拆成两半，已改为复制安装。
- 改了本目录的内容后，要重跑 `--global --force` 才生效——全局那份是副本，不会自动跟随。

## 边界

- 本知识库为天信**内部编译**的实务参考，**不对外发布、不转售**；涉及监管处罚等敏感内容，对外引用须经合伙人复核。
- 卡内数据为公开监管处罚汇总 / 公开准则提炼，非特指任何第三方专有内容。
- 新增或修订卡：直接在 `cards/` 增改，并在 `SKILL.md` 表格登记；保持六节结构一致。
- 不替代注册会计师职业判断，重大疑难按执业准则与所内复核流程处理。
