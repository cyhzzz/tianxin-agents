## 一、核心理念

年报审计中常遇到"去年这笔账做错了/政策换了吗"。这三类情形处理完全不同：**政策变更**用追溯调整（调可比期间）、**估计变更**用未来适用（不追溯）、**前期差错**重要的要追溯重述（调期初留存收益）。判别错误会直接导致报表重述或审计意见问题。

## 二、判断直觉

**① 三者判别**
- **会计政策变更**：对相同交易改用新会计政策（如存货计价方法变更、收入确认模式变更）。**不包括**：准则强制要求的新准则首次执行、对初次发生交易采用政策。
- **会计估计变更**：对结果不确定的交易，因新信息更新估计（如坏账计提比例、资产寿命、预计负债）。**关键区分**：政策变更是"换规则"，估计变更是"换数字"。
- **前期差错**：前期财务报表漏报/错报（应用政策错误、疏忽、舞弊）。重要差错须追溯重述。

**② 处理方法**
- 政策变更 → **追溯调整法**：调整期初留存收益 + 重述可比期间。
- 估计变更 → **未来适用法**：不追溯，从当期起用新估计。
- 重要前期差错 → **追溯重述法**：视同该差错从未发生，调整期初留存收益及可比报表；不重要的当期更正。

**③ 报表批准报出前发现的差错**：属于资产负债表日后调整事项，调整报告期报表。

## 三、准则依据

- 政策变更无法追溯调整（累积影响数不能确定）时，用未来适用法。
- 估计变更与差错的边界：估计以新信息为基础属变更；原估计本身错误属差错。
- 不重要的前期差错直接计入发现当期，不追溯。

## 四、天信场景

| 天信场景 | 卡怎么用 |
|---|---|
| 客户换会计政策 | 判政策变更→追溯调整+重述可比期间 |
| 客户改坏账比例/资产寿命 | 判估计变更→未来适用，不追溯 |
| 发现去年漏记/错记 | 判差错重要性→追溯重述或当期更正 |
| 年报审计调整 | 复核调整分录归类是否正确（政策/估计/差错） |
| 报表批准前发现错 | 作资产负债表日后调整事项处理 |

## 五、演练输出

**输入**：一个调整事项的描述（如"去年少提折旧""今年起改应收坏账比例""今年起存货改成本法"）。
**输出**：
1. 判别类别（政策/估计/差错）；
2. 选处理方法（追溯调整/未来适用/追溯重述）；
3. 给出调整分录思路（调期初留存收益 or 当期）；
4. 报表重述范围提示。
**完成标准**：类别判别无误、方法对应正确、重要差错已追溯重述。
