## 一、核心理念

现代审计是**风险导向**而非"抽样查账"。核心逻辑：先识别哪里最容易错（风险评估），再把审计资源压到高风险领域（进一步审计程序），最后对"整体是否公允"发表意见。天信做普通企业年报，同样要走这条线——不是把账翻一遍，而是**证明风险已被合理应对**。监管处罚（见 `penalties.md`）绝大多数源于"该做的程序没做、没留痕"，本质是背离了风险导向。


## 二、判断直觉

审计四步走，缺一不可：

1. **风险评估（R）**：了解被审计单位及其环境（行业、业务、内控），识别财务报表层次与认定层次重大错报风险。→ 输出"风险清单"。
2. **重要性（M）**：选定财务报表整体重要性水平（常用营收/总资产/净利润的一定百分比，如营收 0.5%–5%），作为判断错报是否重大的标尺。→ 实际执行重要性通常为整体重要性的 50%–75%。
3. **进一步审计程序（P）**：针对评估的风险，用四类程序应对——
   - **函证**：银行存款、应收账款、往来款，由审计人员**直接控制**收发（见 penalties 卡第 2 道防线）。回函不符必追查；**未回函须执行替代程序**（检查期后收款、销售/收款凭证、发货记录），不得仅以未回函结案。
   - **监盘**：存货、固定资产、现金，必须实地、突击、留影像。
   - **截止测试**：收入、费用是否计入正确期间（防跨期，关联 cas14）。
   - **分析程序**：趋势、比率异常波动作为线索。
4. **意见形成（O）**：综合错报（已更正的 + 未更正的）与范围受限，判定报告类型。

**一句话直觉**：审计 = 用最少且恰当的程序，把"报表是否没重大错漏"这件事说得有凭有据。

## 三、准则依据

- **重要性运用**：实务中常见口径——整体重要性多选"营业收入×比例"或"总资产×比例"，小所常用区间较宽（如营收 1%–5%），但须记录选定理由。
- **函证控制**：监管处罚高频点（全库 544 例），准则要求函证过程审计人员主导，不得由被审计单位代庖。
- **持续经营**：准则要求在审计中评估被审计单位持续经营能力（通常展望 12 个月），存在重大不确定性时须在审计报告中专门段说明。

## 四、天信场景

| 天信场景 | 卡怎么用 |
|---|---|
| 承接年报审计立项 | 先写"风险评估 + 重要性水平"两节，再定程序，杜绝无方案开干 |
| 制造业/商贸客户 | 程序重点压到存货监盘 + 收入截止（高风险领域） |
| 函证执行 | 严格直接控制，回函不符必追查，对应 penalties 第 2 道防线 |
| 连续亏损/资金紧客户 | 必做持续经营评估并决定报告段 |
| 出具报告前 | 用 O 段意见判定树复核，避免意见类型错配 |

## 审计报告意见判定树（速查）

- 报表公允 + 范围不受限 → **无保留意见**（标准/带强调事项段）。
- 个别事项重大但不广泛 → **保留意见**。
- 错报重大且广泛（或持续经营重大不确定） → **保留/否定** 视影响广度。
- 范围受限重大且广泛、无法获取充分证据 → **无法表示意见**。

## 五、演练输出

**输入**：一份天信年报审计底稿（风险清单、重要性计算、函证/监盘/截止/分析程序记录、未更正错报汇总）。
**输出**：
1. 核对四步走是否齐全，缺项列出；
2. 验算重要性水平合理性（比例口径 + 记录理由）；
3. 对未更正错报汇总，判定是否超过实际执行重要性；
4. 给出报告意见类型建议 + 理由；
5. 标出是否触及持续经营段。
**分支**：若范围受限（如无法监盘、无法函证） → 提示"可能无法表示意见/保留意见，须上报合伙人"。
**完成标准**：四步走闭合、重要性有计算、意见判定有依据，覆盖 penalties 卡红线。
