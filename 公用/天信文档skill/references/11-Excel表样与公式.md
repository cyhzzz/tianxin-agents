# 11 Excel 表样与公式

> 天信原创。事务所的底稿、勾稽、抽样、税负测算、工资表**都在 Excel 里做**，但本技能原先只有 Word / PDF / 网页 / 演示四轨，表格靠各人手工拼，列宽、字体、边框、打印设置一人一样。
> 本文件把 Excel 定成**第五轨**：统一样式 + 统一公式 + 一个生成脚本。

## 一、什么时候该出 Excel，而不是 Word

| 判据 | 出 Excel |
|---|---|
| 列多（≥ 5 列）且要逐行比对 | ✅ |
| 有勾稽/合计/勾稽判定，客户或复核人要核数 | ✅ |
| 要给客户填、要反复更新（月度报表包、工资表、往来对账） | ✅ |
| 内容以文字论述为主（报告、意见、说明） | ❌ 走 A/B 轨 |
| 正式对外出具、要签字盖章的报告 | ❌ 报告本体走 A/B，表作为**附件** |

**一句话**：**文字进 Word，数字进 Excel，报告附 Excel。**

## 二、内置表样（四条命令就能出）

```bash
python scripts/build_xlsx.py --template 勾稽校验表 --output 勾稽校验表.xlsx
python scripts/build_xlsx.py --template 底稿索引表 --output 索引.xlsx
python scripts/build_xlsx.py --template 抽样表   --output 抽样表.xlsx
python scripts/build_xlsx.py --template 税负测算表 --output 税负测算表.xlsx

# 自定义：写一份 JSON 规格
python scripts/build_xlsx.py --spec my.json --output 自定义.xlsx

# 交付前自检（行列数、公式数、冻结）
python scripts/build_xlsx.py --verify 勾稽校验表.xlsx
```

| 表样 | 用在哪 | 来自 |
|---|---|---|
| 勾稽校验表 | 会计核算：四表一注 A/B/C 三组共 26 条校验 | `会计核算/references/02` |
| 底稿索引表 | 审计：索引号、编制人、复核人、页数 | `审计/references/00` |
| 抽样表 | 审计：凭证号、金额、是否异常、合计公式 | `审计/references/03`、`04` |
| 税负测算表 | 税务：分税种计税依据、税率、减免、差异、依据文号 | `税务/references/02` |

**依赖**：`pip install openpyxl`。缺库时脚本直接报错退出，**不会产出半成品文件**——这点比"生成一个坏文件再让人发现"重要。

## 三、天信表格样式（脚本已内置，手工做也要照这个来）

| 项 | 规范 |
|---|---|
| 标题 | 宋体 14 加粗，深蓝 `#1D3A5E`，合并居中，行高 26 |
| 表头 | 宋体 10.5 加粗 **白字**，底色 `#1D3A5E`，居中，自动换行，行高 28 |
| 正文 | 宋体 10.5，垂直居中；文字列左对齐，编号/金额/结论列居中 |
| 边框 | 全表细线 `#E0E0E0`，不用粗框、不用双线 |
| 隔行底色 | `#F4F4F4`（斑马纹），超过 10 行才加 |
| 金额 | `#,##0.00`；数量/人数 `#,##0`；比率保留 2 位小数 |
| 冻结 | 冻结表头行（`A3` 起），滚动时表头不跑 |
| 打印 | **A4 横向**、按宽度缩成一页、**重复表头行**、页脚"第 X 页 / 共 Y 页" |
| 合计 | 用公式，不手敲数字 |

## 四、十二个必会公式（照抄改范围即可）

| # | 用途 | 公式 |
|---|---|---|
| 1 | 合计 | `=SUM(C3:C20)` |
| 2 | 筛选后合计（**别用 SUM**） | `=SUBTOTAL(9,C3:C20)` |
| 3 | 按科目汇总 | `=SUMIFS(金额列, 科目列, "应收账款")` |
| 4 | 勾稽判定（差额是否为 0） | `=IF(ROUND(C3-D3,2)=0,"平","差 "&TEXT(C3-D3,"#,##0.00"))` |
| 5 | 差额列 | `=ROUND(C3-D3,2)` |
| 6 | 取上年同期数 | `=VLOOKUP($A3,上年表!$A:$D,4,FALSE)` |
| 7 | 精确匹配找不到就留空 | `=IFERROR(VLOOKUP($A3,客户表!$A:$C,3,FALSE),"")` |
| 8 | 未分配利润滚动 | `=期初+净利润-提取盈余公积-分配股利` |
| 9 | 文本型数字转数值 | `=VALUE(TRIM(CLEAN(A2)))` |
| 10 | 统计不重复客户数 | `=SUMPRODUCT(1/COUNTIF(B3:B50,B3:B50))` |
| 11 | 账龄分段 | `=IF(TODAY()-C3<=365,"1年以内",IF(TODAY()-C3<=730,"1-2年","2年以上"))` |
| 12 | 异常标记 | `=IF(ABS(C3)>实际执行重要性,"超重要性","")` |

**不要在勾稽表里用 `SUM` 汇总**：一筛选就错，且错得不明显（这是底稿被打回的高频原因）。

## 五、六个高频错误（Excel 底稿的"脏"通常就这几样）

1. **合并单元格**：排序、筛选、公式引用全废。要居中就设对齐，**不要合并**。
2. **文本型数字**：左上角绿三角，`SUM` 结果为 0。用 §四 第 9 条清洗。
3. **手敲合计**：改了一行数，合计不跟着变，查起来花半天。
4. **隐藏行/列**：复核人看不到，等于没披露。要隐藏就删或另建表。
5. **循环引用**：合计行把自己算进去，Excel 报循环引用但很多人点"确定"就过了。
6. **同一表里放两套口径**（如既是账面数又是调整后数却不标注）：必被质疑。

## 六、交付前自检（六项，逐项打勾）

- [ ] `--verify` 跑过，行列数与预期一致
- [ ] 合计是公式，改任意一行会跟着变
- [ ] 勾稽判定列全部显示"平"；有"差"的，差异原因写在备注列
- [ ] 打印预览：A4 横向、表头重复、页脚有页码、没有跨页断行到关键列
- [ ] 表名与文件名一致（`勾稽校验表.xlsx` 里的标题也是"勾稽校验表"）
- [ ] 客户名、税号等敏感信息未写进示例或模板

## 七、和报告怎么配合

- 报告正文（Word/PDF）里**只放结论与关键表**；完整表作为**附件**，附件在正文里按"附件 1""附件 2"顺序点名。
- 附件命名：`附件1-四表一注勾稽校验表.xlsx`，与正文附件目录一致。
- 附件页码独立编（`第 1 页 / 共 3 页`），不要接着正文排。
- 定稿后把 Excel 一并归档（保管期限随报告走）。

> **红线**：Excel 交付的不是"能打开就行"，是**复核人能顺着公式追到数**。手敲的死数、合并的单元格、藏起来的行，都是把复核成本转嫁给签字人。
