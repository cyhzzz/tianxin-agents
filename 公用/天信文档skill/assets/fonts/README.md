# 字体目录（空目录，仓库不分发字体）

这个目录留给你放**自己合法取得**的公文字体。放进来之后，Word 模板与 PDF 都会自动用上，不需要改代码。目录里的字体文件**不进仓库**（`.gitignore` 已排除）。

## 为什么要空着

三个都是硬约束，不是偷懒：

| 字体 | 能不能随仓库分发 | 原因 |
|---|---|---|
| 方正小标宋简体 | **不能** | 商业字体，需向方正购买授权。且该字体 `fsType=783`，**明确禁止嵌入文档**——连打包带走都不允许 |
| 仿宋_GB2312 / 楷体_GB2312 | **不能** | 中易字库，版权归属与分发条件受限；且已不是 Win7+ 系统自带 |
| 思源 / 华文系列 | 可分发但有条件 | SIL OFL 或厂商条款；体积 5–15MB/个，仓库总共才 6MB |

公开仓库里塞字体，等于把授权风险转给每一个克隆的人。所以只留目录和规则。

## 放什么

不用管文件名，脚本读的是字体内部的族名（name 表）：

| 族名 | 用途 | 常见文件名 |
|---|---|---|
| `方正小标宋简体` / `FZXiaoBiaoSong-B05S` | 公文标题 | 方正小标宋简体.ttf |
| `仿宋_GB2312` / `FangSong_GB2312` | 公文正文 | 仿宋_GB2312.ttf |
| `楷体_GB2312` / `KaiTi_GB2312` | 公文二级标题 | 楷体_GB2312.ttf |

放好后验证：

```bash
python scripts/check_fonts.py
```

三个都显示「✓ 规范名」就到位了。

## 会怎么被用上

| 轨道 | 机制 |
|---|---|
| **Word** | `build_template.py` 探测本机族名，命中就写规范名（`w:eastAsia=仿宋_GB2312`），没命中退兼容名（`仿宋`）。**只能选一个**——Word 没有 CSS 那种降级链 |
| **PDF** | `md2html.py` 把这里的字体注册成 `TX-Gongwen-Body/Title/Sub`，`gongwen.css` 的字体栈首位就是它们；没放则自动落到系统字体 |

## 一个必须知道的限制

**收件人没装字体时，Word 仍会回退成宋体。** 这是字体分发问题，不是排版问题。

两条出路：
1. 出的 PDF 交付（PDF 里字形已经固化成轮廓，不依赖对方装字体）——**推荐**；
2. 用 Word 的「文件 → 选项 → 保存 → 将字体嵌入文件」手工嵌一次——但方正小标宋禁止嵌入，嵌了也无效，所以标题字体这条路走不通。

结论：**要保证对方看到的就是你看到的，就交 PDF，不交 Word。**
