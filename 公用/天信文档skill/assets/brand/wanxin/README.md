**为什么用万信而不是天信**：税务申报、汇算清缴、涉税鉴证的受托主体是万信税务师事务所，对外文件（报告、说明函、汇总表页眉）应署万信品牌。会计师事务所与万信是两个受托主体，不能混用抬头。

| 文件 | 尺寸 | 用途 |

## 三、生成参数（与天信主体完全一致，不得逐次微调）

| 参数 | 取值 |
|---|---|
| 画布 | 2148×374 |
| 印章 | 350×358，置于 (8,8)，由品牌根目录（上一级）的 `seal-mark-color.png` Lanczos 缩放 |
| 中文字高 | 162px（字号 170，思源宋体 Bold） |
| 英文字号 | 51px（思源黑体 Regular，字距 0.18em） |
| 中文起点 | x=439，字形带顶 y=68 |
| 英文起点 | x=439，字形带顶 y=267 |

印章是母品牌符号，各主体共用。**不要为万信另画印章，也不要改印章颜色**（彩色版保持 `#AC3A3B`）。

## 四、使用

- 税务线出 Word / PDF / 网页长页时，页眉与封面用本目录 `logo-horizontal-color.png`；深色底用 `-white`；单色印刷用 `-navy`。
- 非税务业务仍用品牌根目录（上一级）的 `logo-horizontal-*.png`（天信会计师事务所）。
- 禁止：拉伸、改色、单独抽取文字、把万信 logo 与天信 logo 并排当「集团 logo」使用。
