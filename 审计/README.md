# 审计线

财务报表审计、专项审计、验资、离任审计、司法鉴定。

## 计划建的技能

| 技能 | 内容 | 状态 |
|---|---|---|
| `天信审计底稿` | 计划 → 风险评估 → 四程序（函证/监盘/截止/分析）→ 底稿索引 → 报告意见 | 待建 |
| `天信尽职调查` | 从 `公用/天信文档skill` 抽出尽调部分并强化（补假设框架、估值） | 待建 |

## 为什么单独成线

「天信实务知识库」里的 4 张卡（审计准则核心、监管处罚、监管提示、年报审计 SOP）讲的是**判断**，不是**作业**。真正做项目时缺的是：底稿怎么编索引、抽样抽多少、函证发几家、监盘记录写什么、什么时候能出报告。

这些每个所的做法都不一样，编不出来，只能用天信自己的模板。

## 需要什么材料

1. **一份完整的底稿**（某个已结项项目的，客户名可涂掉）——看结构、索引体系、复核痕迹
2. **常用表格**：函证清单、抽样表、监盘表、截止测试表、调整分录汇总
3. **报告模板**：标准无保留、带强调事项段、保留意见各一份
4. 一句话说明：一个审计项目从接单到归档，谁在哪个环节签字

## 已有什么

- `公用/天信实务知识库skill/cards/` 里 4 张卡可复用
- `公用/天信文档skill` 的四轨出版能力可直接出报告
