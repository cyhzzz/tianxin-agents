# 监管高频关注维度（审计问询函蒸馏）

> 本文件语料来源：**2026 年 6–9 月交易所/监管问询函语料库**，共 **536 份** 2026 年 6-9 月交易所/监管问询函中"年审会计师关于……问询函的回复 / 专项说明"（其中可提取文本约 442 份，其余为影像扫描件；含 ST 52 份、非 ST 484 份，覆盖上交所 51、深交所 55、未标注 430）。下文维度排名由语料关键词共现频率实证得出，作为自查时的"监管实际追问"经验锚。

## 二、典型追问范式（语料真实句式蒸馏）

监管追问高度程式化，会计师回复须对应"核查程序 + 核查比例 + 获取的审计证据 + 明确意见"。高频范式：

1. **收入真实性/确认口径**
   - "说明营业收入确认是否真实、准确、完整，是否符合《企业会计准则》相关规定。"
   - "结合前十大项目/客户的主要客户、关联关系、合同条款、收入确认时点，说明收入确认是否审慎。"
   - "说明采用总额法/净额法确认收入的依据，相关销售是否具备商业实质，是否存在由控股股东/实控人及其关联方指定的客户。"

2. **毛利率与可比性**
   - "结合同行业可比公司，说明毛利率波动/偏离的原因及合理性。"
   - "结合产能利用率、产销情况、价格变动趋势，说明毛利率变动是否审慎、测算是否谨慎合理。"

3. **应收与减值**
   - "说明应收账款账龄不断加长的情况下，坏账准备计提是否充分、合理，对应收入确认是否真实准确。"
   - "列示期末应收账款余额、期后回款情况及交易背景，说明是否为终端客户或新增大客户。"

4. **持续经营与非标意见**
   - "年审会计师就公司财务报告出具了带有强调事项段/保留意见，请说明针对持续经营能力相关审计意见所采取的程序。"
   - "补充披露公司就上期审计意见涉及持续经营相关的重大不确定性、具体影响并充分提示风险。"

5. **资金占用与内控**
   - "因控股股东资金占用、部分流出资金无法穿透核查，说明资金占用的性质、金额、还款来源及整改。"
   - "请年审会计师就内控否定事项整改发表意见，说明内控缺陷的严重程度与整改有效性。"

6. **减值与资产**
   - "逐项列示非标意见所涉工程项目/商誉资产组情况，包括可变对价初始估计金额、估计方法、可收回金额确定过程及依据。"
   - "说明在建工程转固、固定资产折旧分摊是否合理，产能利用率不足是否导致减值。"

7. **函证与审计证据**
   - "请年审会计师说明对客户/承运商执行的主要审计程序、核查比例、获取的审计证据，对回函不符查明原因并相应调整，对未回函部分执行替代程序。"

> 通用收尾句（几乎每份回复均出现）：**"请年审会计师（及保荐机构）对上述问题进行核查并发表明确意见。"** → 审核审计报告时，凡监管可能追问的事项，报告与底稿须已留下可追溯的核查程序与明确结论。

## 三、问询语气信号 → 关注点映射

| 信号词 | 指向的关注点 | 审核时对应动作 |
|---|---|---|
| "强调事项段" | 持续经营重大不确定性、重大诉讼 | 查 1324 段是否恰当、与审计意见衔接 |
| "保留意见 / 无法表示意见" | 审计范围受限或重大错报 | 查 1502 段、受限事项与报表影响披露 |
| "非标审计意见及责令改正" | 错报+监管处罚 | 查前期差错更正、追溯调整 |
| "内部控制被出具否定意见" | 内控重大缺陷 | 查内控审计意见、缺陷整改披露 |
| "资金占用" | 关联方非经营性往来 | 查 1323、其他应收款、函证穿透 |
| "前期会计差错更正" | 报表重述风险 | 查 1331 期初余额、追溯调整影响 |
| "关键审计事项" | 收入/重大资产减值 | 查 1504 选取是否恰当、描述是否聚焦 |

## 四、前置核查清单（审核报告时优先执行）

> 拿一份审计报告，按以下顺序逐项排查，凡命中即记入问题清单并标注依据（CSA 准则号）。

1. **收入与确认**：是否披露收入确认会计政策；经销/贸易/境外收入是否说明总额法/净额法及依据；是否存在期末突击确认、大额新增客户迹象。
2. **毛利率**：毛利率与同行业/上期偏离是否有解释；产能利用率、价格、成本结构变化是否支撑。
3. **应收与信用减值**：账龄结构是否恶化；坏账计提政策（组合/单项）是否一贯、充分；期后回款是否印证。
4. **关联交易与资金占用**：关联方清单是否完整；是否存在非经营性资金往来挂其他应收；是否执行函证/穿透。
5. **存货**：监盘程序与跌价测试是否留痕；滞销/残次是否计提。
6. **长期资产与减值**：商誉/长期股权/在建工程减值测试的关键假设（增长率、折现率、可收回金额）是否披露并可复核。
7. **持续经营**：是否存在持续经营重大不确定性；1324 段/强调事项段是否恰当；与前任/上期意见衔接。
8. **审计意见类型**：非无保留意见是否按 1502 恰当表述；事项段是否清晰。
9. **内部控制**：是否同时出具内控审计意见；否定/保留意见是否对应披露缺陷。
10. **关键审计事项**：1504 段是否聚焦最重大领域（收入确认、重大减值）；描述是否含审计应对。

## 五、会计师回复的共性要求（承接底稿质量时的标尺）

语料显示，监管对会计师回复的硬性要求高度一致，可作为底稿质量标尺：

- **程序可验证**：须说明"执行的主要核查程序"，不得仅作结论性陈述。
- **比例可量化**：抽样/函证须披露核查比例、样本覆盖。
- **证据可追索**：须列明获取的审计证据（合同、回函、银行流水、盘点表等）。
- **意见须明确**：每个问题须"发表明确意见"，不得含糊。
- **衔接须一致**：回复内容须与公司年报、前期回复、前任会计师意见保持一致，差异须解释。

> 成文与承接底稿时，凡监管可能追问的上述维度，若报告未披露、底稿无对应程序与证据，即视为"可能被问询的薄弱点"，优先在三级清单中提示。
