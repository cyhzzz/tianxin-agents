# 审计程序与参数框架

> 本文件给出审核"审计计划与底稿"时核查的参数口径与公式。准则依据见 `standards-and-regulations.md`（CSA 1221 重要性、1211 风险评估、1231 应对措施、1301 审计证据、1312 函证、1311 特定项目、1141 舞弊、1323 关联方、1324 持续经营、1331 期初余额、1332 期后事项）。

## 一、重要性水平（CSA 1221）

### 1. 三层次重要性
| 层次 | 定义 | 用途 |
|---|---|---|
| **财务报表整体重要性** | 错报单独或汇总起来可能影响使用者经济决策的最大金额 | 确定审计意见阈值 |
| **特定类别交易/账户余额/披露的重要性** | 针对使用者特别关注的类别（如关联方、收入）设定的更低阈值 | 这些类别即使低于整体重要性也须关注 |
| **实际执行的重要性** | 低于整体重要性，用于细节测试抽样与错报评价 | 通常为整体重要性的 50%–75% |

### 2. 经验基准与百分比（行业惯例，非准则强制，须披露选取理由）
| 基准 | 常用情形 | 经验百分比区间 |
|---|---|---|
| 经常性业务的税前利润 | 盈利、经营稳定 | 5%–10% |
| 营业收入 | 微利/波动大、营收驱动 | 0.5%–1% |
| 总资产 | 金融机构、重资产 | 0.5%–1% |
| 净资产 | 净资产为主要指标 | 1%–5% |
| 费用总额/毛利 | 特定场景 | 1%–2% |

> **核查要点**：基准选择须与报表使用者决策相关；盈利波动大时不得机械用"税前利润"得出畸高/畸低重要性；实际执行的重要性百分比须论证（首次审计偏低、连续审计可偏高）。

### 3. 公式（可追溯，禁止硬编码）
```
财务报表整体重要性 = 选定基准 × 适用百分比
实际执行的重要性   = 财务报表整体重要性 × 实际执行百分比(50%–75%)
错报汇总数阈值     = 实际执行的重要性（细节测试）；整体重要性（评价报表整体）
```

## 二、审计风险模型（CSA 1101/1211/1231）

```
审计风险(AR) = 重大错报风险(RMM) × 检查风险(DR)
```
- **重大错报风险 (RMM)** = 固有风险 × 控制风险，由被审计单位环境决定，CPA 只能评估不能消除。
- **检查风险 (DR)** = AR / RMM，CPA 通过程序设计降低。
- **认定层次**与**财务报表层次**风险分别应对。

> **核查要点**：评估 RMM 低而实际执行程序不足、或 DR 被压到不现实低位（即"程序缩水"）均属缺陷；反向：RMM 高却未增加实质性程序。

## 三、应对程序矩阵（CSA 1231）

| 风险评估结果 | 控制测试 | 实质性程序（细节/分析） | 核查关注 |
|---|---|---|---|
| 控制有效（信赖内控） | 须执行，保留证据 | 可减少但不可取消 | 控制测试样本量、偏差率结论是否支持信赖 |
| 控制无效/不拟信赖 | 不执行或仅了解 | 须全面实质性程序 | 是否以"不信赖内控"为由做了充分实质性程序 |
| 特别风险（舞弊/关联方/估计） | — | 须针对性程序 + 总体应对措施 | 是否设计了不可预见程序、是否由项目合伙人参与 |

## 四、关键审计程序参数口径

### 1. 函证（CSA 1312）
- 须函证：银行存款（含零余额、外埠）、借款、重大往来款项；应收账款通常须函证，除非不重要或风险低。
- 控制：CPA 直接控制询证函收发；回函不符须调查；未回函须执行**替代程序**（检查期后收款、发运凭证、合同等）。
- **核查要点**：函证范围/比例是否充分；回函率与差异处理；未回函替代程序证据是否完整；被询证者地址/邮箱是否由被审计单位提供（独立性）。

### 2. 存货监盘（CSA 1311）
- 制定监盘计划，观察盘点、抽盘、关注残次冷背、权属（寄售/代销）。
- 特殊情形：异地存货、在途物资、第三方保管——须执行函证/走访等替代。
- **核查要点**：监盘日与资产负债表日不一致时是否倒轧；监盘结果差异是否调整。

### 3. 分析程序（CSA 分析程序准则）
- 用作风险评估、实质性分析、复核期末；预期值须基于可靠数据（行业/历史/预算）。
- **核查要点**：偏差超过可接受差异额是否追查至细节；收入/毛利率波动是否有合理解释。

### 4. 抽样（审计抽样准则）
- 统计/非统计抽样；样本规模受可容忍错报、预计总体偏差率、信赖过度风险影响。
- **核查要点**：抽样单元、选样方法、推断总体偏差是否恰当；非统计抽样是否记录职业判断。

## 五、特殊领域考量参数

| 领域 | 准则 | 审核关键参数/动作 |
|---|---|---|
| 期初余额 | 1331 | 是否审计/恰当披露；上期非标事项是否消除 |
| 期后事项 | 1332 | 资产负债表日至报告日之间事项是否识别；调整/披露是否恰当 |
| 关联方 | 1323 | 关联方清单完整性、交易商业合理性、资金占用穿透 |
| 舞弊 | 1141 | 舞弊三角评估、收入虚构/资产挪用特别程序、管理层凌驾控制测试 |
| 持续经营 | 1324 | 重大不确定性段、管理层计划可行性 |
| 利用专家/内审 | 1421/1411 | 专家胜任能力与客观性、内审工作利用范围 |

## 六、承接底稿时的参数核验清单

- [ ] 重要性基准与百分比披露理由；实际执行重要性口径（50%–75%）
- [ ] 风险模型逻辑自洽（RMM 与 DR 反向配比）
- [ ] 函证/监盘/分析/抽样的范围、比例、替代程序有底稿支撑
- [ ] 特别风险（舞弊/关联方/估计）有专门应对且不可预见
- [ ] 期初/期后/关联方/持续经营四领域程序无缺漏
- [ ] 所有关键参数以公式/单元格引用呈现，无硬编码结果（底稿铁律）

> 参数取值须结合项目实际并披露依据；经验百分比仅为市场惯例锚，不得机械套用替代职业判断。
