# 05 报告与质控工作底稿

> 对应 GOA 能力"工作底稿 Checklist"终段。意见判定树见 ``公用/天信实务知识库skill/cards/`audit-core.md` O 段；本文件把判定、强调/持续经营段、质控签字落成可勾的底稿。

## 一、报告意见判定表（G 类）

| 判定条件 | 意见类型 |
|---|---|
| 报表公允 + 范围不受限 | 无保留（标准 / 带强调事项段） |
| 个别事项重大但不广泛 | 保留 |
| 错报重大且广泛 | 否定 |
| 范围受限重大且广泛、无法获取充分适当证据 | 无法表示 |
| 持续经营重大不确定 | 无保留+持续经营段 / 或保留（视影响） |

勾选结论 + 理由【推演】，链接 E 类证据与 G 类未更正错报汇总。

## 二、强调事项 / 持续经营段决策

- [ ] 是否存在重大不确定性（持续经营、重大诉讼、异常交易）→ 须专段说明。
- [ ] **不得用"范围受限"代替"错报"发表意见**（`reg-tips.md` 年报提示）。
- [ ] 关键审计事项不得模板化，须对应本项目实际高风险领域。
