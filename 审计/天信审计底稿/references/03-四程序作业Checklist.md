# 03 四程序作业 Checklist

> 对应审计程序环节。四程序的执行红线（函证直接控制、未回函须替代程序、监盘突击留影像）见本技能 SKILL.md §一；本文件给天信**操作控制点 + 记录要素 + 红线**，抽样量见 `04-抽样量指引.md`。

## 一、函证（银行存款 / 应收 / 往来）

**控制要求（红线，少一条即退回）：**
- [ ] 由审计人员**直接控制**收发，独立寄发，回函直寄事务所——**不得由被审计单位代发代收**（544 例处罚第一高频，`penalties.md` 第 2 道防线）。
- [ ] 银行存款函证**全部账户**（含零余额、异地、保证金），不止基本户。
- [ ] 回函不符**必追查**，记录差异原因与调整。
- [ ] **未回函须执行替代程序**（检查期后收款、销售/收款凭证、发货记录、合同），不得仅以"未回函"结案。
- [ ] 假回函防范：核对邮戳/地址/印章，异常即扩大样本或走替代。

记录要素：函证清单（见 `06`）、发函日、回函日、不符事项、替代程序结论。

## 二、监盘（存货 / 固定资产 / 现金）

- [ ] **实地、突击**（存货避免"提前摆拍"），留影像（带日期水印）。
- [ ] 监盘计划：路线、抽盘比例（见 `04`）、人员分工。
- [ ] 监盘记录要素：盘点日、地点、品名规格、数量、状况（残次冷背）、差异、监盘人签字。
- [ ] 盘亏盘盈**必须处理**（追查原因、计提/冲回），不得搁置（375 例处罚，`penalties.md` 第 3 道防线）。
- [ ] 在建工程：实地查看进度，防虚增。

记录要素：监盘表（见 `06`）、差异处理轨迹。

## 三、截止测试（收入 / 费用）

- [ ] 收入：抽取资产负债表日**前后各若干笔**（如 ±10 笔或覆盖大额），核对发运单/验收单/发票日期，确认计入正确期间（防跨期，关联 `cas14-income.md`）。
- [ ] 费用：预提/待摊、跨期费用抽查。
- [ ] 存货出入库截止：期末收货/发货是否在库。

记录要素：截止测试表（见 `06`），抽凭起止号。

## 四、分析程序

- [ ] 趋势分析：收入/毛利率/费用率同比环比，异常波动标【疑问】并追查。
- [ ] 比率分析：流动/速动/应收周转/存货周转，与同业/自身偏离说明。
- [ ] 合理性：产量-能耗-产量、工资-人数等勾稽。

记录要素：波动分析表（见 `06` 或自制），异常结论。

## 五、四程序完成标准

- 函证控制五条全勾，替代程序有结论。
- 监盘有影像+记录+差异处理。
- 截止测试覆盖期初期末边界。
- 分析程序异常均有去向（追查或说明）。
- 每张程序底稿回链 C 类风险点（见 `00` 勾稽）。
