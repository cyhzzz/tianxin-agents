# 07 专项审计骨架

> 天信原创。年报审计之外，县城所真正接得多的是**专项**：验资、高新、政府补助、清算、经责。本文件给这五类的骨架。
> **非年报审计就不套年报底稿**——专项的抓手是"某个特定认定 + 特定口径"，不是整体公允性。

## 一、先判是哪一类（判错，程序全废）

| 业务 | 委托方真实目的 | 报告形式 | 核心程序 | 依据（引用前核现行文本） |
|---|---|---|---|---|
| **验资 / 出资验证** | 证明注册资本已实缴 | 验资报告 | 银行进账核对、出资凭证、实物评估作价 | 《公司法》（2023 年修订，2024-07-01 施行）+ 注册会计师验资准则 |
| **高新认定专项** | 拿证书、享 15% 税率 | 专项审计报告（研发费用、高新收入两张表） | 研发费用归集、高新收入归集、科技人员占比 | 《高新技术企业认定管理办法》（国科发火〔2016〕32号）及工作指引 |
| **政府补助 / 科技经费专项** | 项目验收、资金合规 | 专项审计报告 | 支出合规性、专款专用、配套资金到位 | 项目合同/任务书 + 专项资金管理办法 |
| **清算审计** | 注销前清算所得税与剩余财产分配 | 清算审计报告 | 资产负债清查、清算损益、剩余财产分配 | 《公司法》清算规定 + 财税〔2009〕60号 |
| **经济责任审计** | 离任/任期评价 | 经济责任审计报告 | 任期内重大决策、财务收支、资产保值增值、内控 | 经济责任审计规定（现行文本） |
| 研发费用加计扣除专项 | 税前加计扣除 | 见税务线 | 按税务口径归集，**不是高新的研发口径** | 税务线 `天信税务申报` |

**验资的现实**：2023 年修订的公司法施行后，普通有限责任公司设立**不再强制验资**。仍需做的是：募集设立的股份有限公司、股东实缴出资要向银行/招标方/资质审批部门证明、减资或合并后的注册资本验证。**接单前先问"报告交给谁、用来干什么"**，用途决定口径。

## 二、专项审计通用骨架（五段式，五类都用）

1. **目的与范围**：为什么做、按什么口径做、报告只对谁负责（用途写错，报告白做）
2. **依据**：法律法规 + 认定/验收办法 + 委托合同；**逐条列原文出处**
3. **程序**：按"特定认定"设计，每项写清查了什么、查了多少、怎么查
4. **发现**：事实（数据）+ 判断（是否符合口径），分栏写
5. **结论**：只回答委托事项，超出范围的话一句不写

## 三、高新认定专项：三个比例是硬门槛

| 指标 | 门槛 | 口径要点 |
|---|---|---|
| 研发费用占销售收入比例 | 近一年销售收入 **< 5,000 万 → ≥5%**；5,000 万–2 亿 → **≥4%**；**> 2 亿 → ≥3%** | 按**近三个会计年度**研发费用总额 ÷ 同期销售收入总额；销售收入 = 主营业务收入 + 其他业务收入 |
| 境内研发费用占比 | **≥60%** | 境内外委托外部研发按 80% 计入，境外部分单列 |
| 高新技术产品（服务）收入占比 | **≥60%** | 分母为**总收入**（收入总额 − 不征税收入），不是营业收入 |
| 科技人员占比 | **≥10%** | 累计实际工作 183 天以上的研发与技术人员 ÷ 当年职工总数 |

**研发费用归集的坑**（专项审计最容易翻车的地方）：

- 归集范围按工作指引三类：人员人工、直接投入、折旧与长期待摊、无形资产摊销、设计费、装备调试、委外研发、其他（限 20%）。
- **"其他费用"不得超过研发费用总额的 20%**，超了要剔除。
- 研发领料与生产领料必须**分得开**；领料单只写"材料"没写项目 → 不予认可。
- 研发人员同时做生产的，**按工时分配**，要有工时记录；没有工时的，全额剔除。
- 政府补助形成的研发支出，**补助部分不得加计/不得计入**（按不征税收入处理的）。
- 委托境外研发费用按 80% 计入且不超过境内符合条件研发费用的三分之二（加计扣除口径；高新归集口径不同，**别串**）。

**报告出两张表**：研发费用结构明细表、高新技术产品（服务）收入明细表；两张表的合计数必须与附注/账簿能对上。

### 承接前先做资质自查（做不了就不能接，不是"尽力而为"）

《高新技术企业认定管理工作指引》（国科发火〔2016〕195 号）对出具报告的中介机构有**硬条件**，
不是建议：

| 条件 | 要求 | 怎么核 |
|---|---|---|
| 成立年限 | 成立 **3 年以上** | 执业证书批准日期（本所 1999 年，满足） |
| 不良记录 | 近 **3 年无不良记录** | 注协/财政部监管平台查本所与签字注师 |
| **人员规模** | 全年月平均在职职工 **20 人以上** | 按社保/工资表口径核，不是"所里感觉有多少人" |
| **专业占比** | 当年注册会计师或税务师人数占职工月均人数 **≥30%** | 注师数 ÷ 月均人数 |
| 备案 | 已在**省级科技主管部门备案**（部分地区还要求涉税机构信用积分 ≥200） | 查省科技厅备案名单 |
| 报告编码 | 2022-10-01 起须有统一监管平台备案的**二维码与报告编码** | 出报告时由平台生成 |

> **本所提示**：工商口径的参保人数与"月平均在职职工"不是一回事，前者常偏低。
> 接高企专项前，先按工资表算一遍月均人数与注师占比——**不够 20 人或占比不足 30%，
> 报告出了也不被认定机构采信**，白做还可能影响企业申报。这一条必须落到承接评估表上。

### 2026 年起新增一条卡口

**研发费用与加计扣除申报数据的差异不得超过 5%，超出直接不予认定。**
这意味着高企研发口径与税务加计口径**必须交叉核对**，不能再各算各的。
两套口径的归集范围本来就不同（见上「别串」那条），差异要能逐项解释到金额。

### 别把两种业务混了

| | 高企认定专项审计 | 县级科技资金验收（研发费用）审计 |
|---|---|---|
| 委托方 | 企业（自费） | 县科技局（政府购买服务） |
| 目的 | 拿高企证书、享 15% 税率 | 项目验收、拨付攻关资金 |
| 口径 | 国科发火〔2016〕32 号 + 195 号工作指引 | 县级科技资金管理办法 + 项目任务书 |
| 报告给谁 | 认定机构（科技、财政、税务三部门） | 县科技局 |
| 本所实际承接 | 需核资质（见上表） | **已承接**（2026 年度县级研发攻关资金项目验收，县科技局公示明确委托本所对研发费用做专项财务审计） |

两者**程序相似、口径不同、依据不同**。用高企的 5%/4%/3% 去套县级验收，或用县级
任务书去套高企认定，都是错报告。

## 四、政府补助 / 科技经费专项

- **先看合同/任务书**：钱是补给什么、要求什么、什么时候验收、要不要配套。
- 支出测试：逐笔核对**合同、发票、付款凭证、验收单**四件套；抽查覆盖金额 ≥ 70%，单笔超实际执行重要性的全查。
- **专款专用**：把资金挪去发工资、还贷、买设备的，逐笔列出金额与依据。
- 配套资金：承诺配套但未到位的，按合同条款判断是否构成违约，写进发现。
- 结余资金：按管理办法判断是退回还是留用，**不能想当然**。
- 结论只针对"资金使用是否符合规定"，**不对项目技术成果下结论**。

## 五、清算审计

- 起点：清算基准日的资产负债表（先做审计或审阅，确认期初可信）。
- 核心程序：资产变现/处置（评估或实际成交价）、债权申报与清偿顺序、职工债权优先、欠税清理、清算费用。
- **清偿顺序不能错**：清算费用 → 职工工资社保与法定补偿 → 税款 → 普通债权 → 剩余财产分配。
- 清算所得：全部资产可变现价值 − 计税基础 − 清算费用 − 相关税费 + 债务清偿损益（按财税〔2009〕60号口径）。
- 剩余财产分配：相当于**累计未分配利润和累计盈余公积**的部分，按股息红利处理；剩余部分按投资转让所得处理。
- 报告附**清算损益表**与**剩余财产分配表**，数字要能与税务注销申报对得上。

## 六、经济责任审计

- 先定**审计期间**与**责任人职责边界**（任期内决策，前任遗留的要区分）。
- 四条主线：重大经济决策（投资、担保、资产处置、大额采购）、财务收支真实性、资产保值增值、内控与廉洁风险。
- **"三重一大"必查**：决策程序有没有、记录全不全、事后有没有评估。
- 发现分三类写：**直接责任 / 主管责任 / 领导责任**——这是经责报告的专用语言，不能混写。
- 结论用"经审计，未发现/发现……"，**不做纪律评价**（那是纪检的事）。

## 七、专项审计的红线

- **不改口径凑门槛**：高新差 0.3 个点就调研发费用归集范围，是舞弊，不是"专业判断"。
- **不超范围下结论**：专项报告只答委托事项；顺手评价内控、评价管理层，都属于超范围。
- **依据必须写原文出处**：办法、指引、合同条款，写清名称与文号；记不清写"待查原文"，不编号。
- **报告用途写进报告**：限定使用范围与用途，"仅供××使用"，避免被挪作他用。
- 数字必须能追回账簿与原始凭证；客户口述的数不入底稿。

> 专项审计的价格战很凶，但**风险不在价格，在口径**。九个专项里有八个出事，出在"按年报的思路做了专项"或"按客户想要的口径调了数"。
