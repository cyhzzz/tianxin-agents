# 08 承接与独立性

> 天信原创。上游两个包都是"报告怎么写"，没有"这单该不该接"。而**出事最多的一段，正是接单前**。
> 口径：本文件是所内的前置把关清单，最终由项目合伙人决定接不接、签不签。

## 一、承接前五问（有一问答不上来，就别报低价）

| # | 问 | 危险信号 |
|---|---|---|
| 1 | **客户为什么要这份报告？** 报告交给谁 | 只说"银行要""老板要"；用途说不清；要求"出得快、别问太多" |
| 2 | **管理层是否诚信？** | 前任注师非正常更换；拒绝提供资料；要求调整合并范围/收入确认 |
| 3 | **我们有没有能力？** 行业、特殊业务、地域 | 首次接触的行业（如养殖、矿业、平台经济）；涉及境外主体 |
| 4 | **独立性有没有问题？** | 我们或近亲属在客户处任职、持股；同时为其做代账/内部控制设计 |
| 5 | **收费能否覆盖成本？** | 报价低于投入工时的 60%；客户明确要求"按我的意见出报告" |

## 二、客户诚信与背景核查（半小时能查完，别省）

| 查什么 | 哪里查 |
|---|---|
| 存续状态、股东、注册资本实缴、经营范围、异常经营名录 | 国家企业信用信息公示系统 |
| 涉诉、被执行、失信、限高 | 中国执行信息公开网、裁判文书网 |
| 税务处罚、欠税公告 | 税务机关公告、信用中国 |
| 行政处罚、行业监管处罚 | 信用中国、行业主管部门 |
| 管理层关联企业 | 工商穿透（同一实控人旗下公司） |
| 前任注师为什么走 | **经客户书面同意后**与前任沟通 |

**前后任沟通**：接受委托前，须征得客户同意后与前任注师沟通，询问分歧事项、是否发现舞弊、更换原因。前任拒绝答复或客户不同意沟通——**视为重大风险信号**，需合伙人书面决策。

## 三、业务约定书必须写到的 12 项

1. 业务性质与适用准则（财务报表审计 / 专项审计 / 鉴证）
2. 审计目标与报告用途（**限定使用范围**）
3. 管理层责任：编制报表、提供完整信息、内控设计与运行
4. 我们的责任：按准则执行、发表意见（不保证发现全部舞弊与差错）
5. 审计范围与不能覆盖的部分
6. 时间安排与关键节点
7. 收费与计费方式（**不得与审计结论挂钩**）
8. 需客户提供的资料清单与时限
9. 沟通机制（治理层沟通、重大事项沟通）
10. 底稿所有权归事务所、保密义务
11. 终止与解除条款
12. 签字盖章与生效

## 四、独立性：五类威胁与禁区

| 威胁 | 表现 | 处置 |
|---|---|---|
| 经济利益 | 持有客户股票/债券、与客户有借贷、收费长期挂账 | **绝对禁止**，有则退出项目 |
| 自我评价 | 我们编的报表我们再审；我们设计的内控我们评价 | 由另一团队做并披露；重大情形不接 |
| 过度推介 | 对外宣传客户、代客户招揽投资 | 停止 |
| 密切关系 | 项目组成员与客户有亲属/亲密关系、长期同一人 | 轮换项目组 |
| 外在压力 | 客户以更换事务所施压、股东施压调整意见 | 报告合伙人，必要时解除 |

**绝对不能碰的四条**：

- 收费与审计意见类型、审计结果挂钩（或有收费）
- 在客户处担任董事、监事、高管或行使管理职能
- 代客户做出经营决策（"这笔该怎么做账"→ 给可选方案与准则依据，决定权归客户）
- 为客户提供与审计对象直接冲突的服务（如代编报表后又审计该报表，且无隔离与披露）

## 五、非鉴证服务能不能同时做

| 服务 | 能不能做 | 条件 |
|---|---|---|
| 代记账 / 编报表 | 可做，但**不能审自己编的报表** | 由不同人员执行 + 客户管理层确认 + 在报告中披露；小所无人可轮换 → **放弃审计或放弃代账** |
| 税务申报 | 可做 | 不影响报表审计独立性 |
| 内部控制设计 | 谨慎 | 设计后不得评价该内控有效性 |
| 评估 | 谨慎 | 评估结果构成报表重要金额时，不得由同一项目组执行 |
| 内部审计外包 | 不可与年报审计同时做 | — |

## 六、收费

- 报价按**投入工时 × 小时费率**测算，写清假设（现场天数、人数、是否含专项）。
- **不得低价承接高风险业务**：收费不足会导致程序缩水，而程序缩水是监管处罚最常见的直接理由。
- 分期收费的，**报告出具前至少收至 70%**；长期挂账本身就是独立性威胁。
- 不得接受"成功费""节省税款分成"等安排。

## 七、底稿、档案与保密

- 底稿**所有权归事务所**，客户只有权查阅与自己相关的部分（经合伙人批准）。
- 归档期限：审计报告日后 **60 天内**完成归档；保存期限：自报告日起**不少于 10 年**。
- 归档后不得删改；确需补充的，另存"归档后补充记录"并说明原因与批准人。
- 客户信息（名称、税号、金额）**不入示例、不进公共仓库、不发群**。

## 八、什么情况下该解除业务约定

- 管理层不提供必要资料或提供虚假资料，且拒不纠正
- 发现舞弊且管理层/治理层不愿采取必要措施
- 独立性无法保持
- 收费无法保障必要程序
- 客户要求出具与事实不符的报告

解除须**书面**：说明原因、已完成工作、是否需向治理层/监管部门报告。已执行的程序与结论仍要归档。

> **红线**：接单前省下的两小时，后面要用两个月的返工和一个处罚来还。**宁可丢单，不接注定出事的单。**
