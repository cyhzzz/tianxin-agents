## 为什么单独成线

绩效评价不是审计，也不是咨询：

- **与审计的分工**：审计看"账对不对、有没有违规"，绩效评价看"钱花得值不值、目标达没达到"。专项资金常同时要两份报告，数据可复用，**结论不互相替代**。
- **与咨询的分工**：可研里的绩效目标由咨询线出，绩效评价负责评它合不合理。
- **与后评价的分工**：绩效评价多在项目完成当年或预算年度结束后做；后评价在**项目投运一两年后**做，产出是成功度定级 + 根因 + 分级改进建议。

## 为什么现在建

不是拍脑袋加线——公开渠道可查，天信在县财政局是**框架协议下的常态化派单**：

- 2025-2026 年度天台县会计审计、预算绩效评价咨询服务框架协议（入围）
- 2023-2024 年度天台县预算绩效管理服务开放式框架协议（成交）
- 2023 年天台县财政局绩效评价框架协议（成交）

这类业务量稳定、可标准化，却原来埋在企业咨询里，没有独立技能承接。
