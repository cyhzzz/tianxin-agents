# 天台本地口径与作业接口

> 天信原创，上游三个包都没有这部分。上游给的是通用方法论（四维框架、评分表、后评价流程），本篇补的是**在天台做绩效评价，跟谁对接、按什么口径、和别的线怎么分工**。

## 一、本地委托方与项目类型

绩效评价在县一级主要来自财政部门，其次是项目主管部门。天信实际中标/参与的类型（公开渠道可查）：

| 时间 | 项目 | 委托方 | 说明 |
|---|---|---|---|
| 2025-03 | 2025-2026 年度天台县会计审计、预算绩效评价咨询服务框架协议 | 天台县财政局 | 框架协议入围，按需派单 |
| 2025-01 | 2023-2024 年度天台县预算绩效管理服务开放式框架协议 | 天台县财政局 | 成交 |
| 2023-05 | 天台县财政局绩效评价框架协议 | 天台县财政局 | 成交 |
| 2023-02 | 2023-2024 年度天台县预算绩效管理服务开放式框架协议 | 天台县财政局 | 入围 |

**含义**：绩效评价对天信不是零散业务，是**框架协议下的常态化派单**。作业要能批量复用：指标模板、评分表、问卷、报告骨架都要标准化，不能每单重造。

常见委托方还包括：县发改局（政府投资项目）、经信局（技改/消费补贴）、科技局（研发攻关）、民政局（民生资金）、农业农村局（涉农资金）。

## 二、依据与口径（引用前逐条核）

| 层级 | 文件 | 用途 |
|---|---|---|
| 中央 | 《中共中央 国务院关于全面实施预算绩效管理的意见》（中发〔2018〕34 号） | 上位依据 |
| 财政部 | 《项目支出绩效评价管理办法》（财预〔2020〕10 号） | 四维指标、评分、报告提纲的直接依据 |
| 财政部 | 《中央部门预算绩效运行监控管理暂行办法》（财预〔2019〕136 号） | 事中监控 |
| 浙江 | 省级财政支出绩效评价办法（**具体文号以当年通知为准，引用前核**） | 地方评分口径 |
| 台州/天台 | 县财政局年度绩效评价通知、框架协议采购文件 | 当年度指标与时限 |

**硬规矩**：地方文件的评分口径**逐年会变**，同一年不同批次的派单也可能不同。每接一单，先要当次的**评价通知 + 指标体系表 + 评分细则**，不要拿上一单的模板直接套。

## 三、与各业务线的接口

| 场景 | 谁主责 | 接口怎么走 |
|---|---|---|
| 专项资金要同时做**审计**和**绩效评价** | 两条线并列 | 审计线出资金真实性/合规性结论（「天信审计底稿」），本线出目标实现与效益结论；两份报告数据可复用，**结论不互相替代** |
| 评价要取**账务数据** | 代账线 | 向「天信代账作业」要账套、明细账、凭证；本线不重做账 |
| 项目**立项/可研**阶段的绩效目标 | 企业咨询线 | 可研里的绩效目标由「天信企业咨询」出，本线负责评它合不合理 |
| 涉税数据、税收优惠 | 税务线（万信） | 转「天信税务申报」，本线不碰税法口径 |
| 资产评估、工程造价 | 资产评估线；造价不做 | 评估结论转「天信资产评估」；**工程造价不在本所经营范围，转有资质造价机构** |
| 出报告排版 | 文档技能 | 转「天信文档与报告」，品牌用天信会计师事务所 |

## 四、作业流程（本所口径）

```
接单 → 取当次评价通知与评分细则 → 判类型（事前/事中/事后/部门整体/后评价/验收）
→ 搭指标体系（四维，权重按细则）→ 列资料清单交委托方
→ 现场核查 + 抽样 + 问卷 → 逐指标打分（得分—依据—扣分理由）
→ 汇总得分与评级 → 写问题与建议 → 报告 → 抽评/复核前自查
```

**第 2 步最容易省，也最容易返工**：没有当次评分细则就开工，做完发现权重不对，整份重来。
