## 一、先说清两种评价口径，别混用

县财政局委托的绩效评价至少有两种，指标权重完全不同：

| | **部门整体支出**评价 | **项目支出**评价 |
|---|---|---|
| 评价对象 | 一个预算部门的全部支出 | 一个具体项目／一笔专项资金 |
| 四维权重 | 投入 10 · 过程 33 · 产出 20 · 效果 37 | 业务 65 · 财务 35 |
| 结论落点 | 部门整体运行绩效等级 | 项目是否达到绩效目标 |
| 本所实例 | 红十字会 2020 年度（本篇） | 浙江省财政支出项目表式（另见 `02-`） |

**接活时第一件事是问清是哪种。** 用项目支出的表去评部门整体，指标对不上，
分值也凑不齐 100。

## 三、四级指标与权重（部门整体支出，100 分）

| 一级 | 分值 | 二级（分值） | 三级指标举例 |
|---|---|---|---|
| **投入** | 10 | 目标设定（4） | 绩效目标合理性、绩效指标明确性 |
| | | 预算配置（6） | 在职人员控制率、"三公经费"变动率、重点支出安排率 |
| **过程** | 33 | 预算执行（11） | 预算完成率、预算调整率、支付进度率、结转结余率及其变动率 |
| | | 资金使用合规性（8） | 工资福利、"三公"经费、政府采购、项目资金、资金拨付、重大开支、预算批复、截留挤占 |
| | | 预决算信息公开性（2） | 公开内容、公开时限 |
| | | 基础信息完善性（4） | 真实性、完整性 |
| | | 固定资产利用率（1） | 利用率 |
| **产出** | 20 | 职责履行·实际完成（12） | 重点工作目标完成率（4）、项目完成率（4）、项目绩效管理有效性（4） |
| | | 质量达标（8） | 重点工作质量达标（4）、项目质量达标（4） |
| **效果** | 37 | 履职效益·社会效益（26） | 受益群体覆盖面、效果、宣传力度等 |
| | | 可持续性（4） | 中长期规划的支持、现有可持续因素支持 |
| | | 社会公众满意度（7） | 县级考核（2）、普通群众问卷（5） |

### 评分标准的三种写法（照这个粒度写，别写"酌情打分"）

1. **门槛式**：「小于等于 100% 得 3 分；大于 100% 小于 120% 得 1.5 分；大于 120% 不得分。」
2. **分档式**：「完成率 100% 得 4 分，90%–100% 得 3 分，80%–90% 得 2 分，80% 以下不得分。」
3. **扣分式**：「严格按照规定执行得 1 分；发现 1 处违规扣 0.5 分，扣完为止。」

**每个比率指标都要给出计算公式**，写在评分标准里。例如：

```
预算调整率 =（预算调整数 / 预算数）× 100%
在职人员控制率 =（在职人员数 / 编制数）× 100%
固定资产利用率 =（实际在用固定资产总额 / 所有固定资产总额）× 100%
```

### 二级指标加总示例（把 10 / 33 / 20 / 37 拆到二级，得分要能逐项复核）

**为什么要这张表**：只给"过程 22.50 分"这种维度分，财政抽评时无法复核。必须能顺着二级、三级一路加到维度分。

| 一级 | 槛分值 | 二级（分值） | 三级举例 | 加总校验 |
|---|---:|---|---|---|
| 投入 | 10 | 目标设定（4）+ 预算配置（6） | 绩效目标合理性 2 / 绩效指标明确性 2；在职人员控制率 2 / "三公"经费变动率 2 / 重点支出安排率 2 | 4 + 6 = **10** ✓ |
| 过程 | 33 | 预算执行（11）· 资金使用合规性（8）· 预决算信息公开性（2）· 基础信息完善性（4）· 固定资产利用率（1） | 预算完成率 3 / 预算调整率 3 / 支付进度率 3 / 结转结余率 1 / 结转结余变动率 1；合规性 8 个检查点各 1 分 | 11+8+2+4+1 = **26**，**与 33 差 7 分** ⚠ |
| 产出 | 20 | 职责履行·实际完成（12）+ 质量达标（8） | 重点工作目标完成率 4 / 项目完成率 4 / 项目绩效管理有效性 4；重点工作质量达标 4 / 项目质量达标 4 | 12 + 8 = **20** ✓ |
| 效果 | 37 | 履职效益·社会效益（26）+ 可持续性（4）+ 社会公众满意度（7） | 满意度拆：县级考核 2 + 普通群众问卷 5 | 26+4+7 = **37** ✓ |

> ⚠ **过程维度差 7 分，是原始样本的缺口，不是本文算错。**
> 原报告指标表跨 6 页且有扫描混排，`11-34` 的二级分值只能读到 26 分，剩余 7 分对应的二级指标未能完整录入。
>
> **处理规则（硬性）**：遇到这种缺口，**不许自行凑数**（比如把预算执行改成 18 分去凑 33）。正确做法是在指标表里留一行
> 「其他二级指标（7 分）——**待按委托方当年下发指标表补齐**」，并在报告"评价工作情况"一节说明分值来源。
> 差 7 分照实写，比凑成 33 分安全——凑出来的分一抽评就对不上。

**加总示例（以某部门为例，演示算法不演示结论）**：

```
投入 = 目标设定 4.00 + 预算配置 5.00                    = 9.00
过程 = 预算执行 9.20 + 合规性 6.80 + 公开性 2.00
       + 基础信息 3.50 + 固定资产利用率 1.00 + 其他 0.00  = 22.50
产出 = 职责履行 10.00 + 质量达标 7.20                    = 17.20
效果 = 社会效益 22.50 + 可持续性 3.50 + 满意度 6.44      = 32.44
──────────────────────────────────────────────────
综合得分 = 9.00 + 22.50 + 17.20 + 32.44                 = 81.14（良好）
```

每一个二级分后面都要能翻到三级指标得分与证据编号；翻不到的，写"待补证"，不写数。

### 问卷题号—指标对应表（模板，出报告时必填）

**规矩**：满意度与社会效益的分不是拍出来的，是"根据问卷调查第 X 题计算打分"。**报告里必须写清哪项指标对应第几题**，否则分数来源不可复核。

| 一级 | 三级指标 | 分值 | 对应问卷题号 | 计分口径 | 数据来源 |
|---|---|---:|---|---|---|
| 效果 | 社会公众满意度·普通群众问卷 | 5 | Q\_\_ ~ Q\_\_ | （满意 + 基本满意）÷ 有效样本数 | 问卷统计表 |
| 效果 | 社会公众满意度·县级考核 | 2 | 非问卷 | 按县考核得分折算 | 县考核结果文件 |
| 效果 | 社会效益·受益群体覆盖面 | \_\_ | Q\_\_ | 覆盖人数 ÷ 目标人数 | 问卷 + 台账 |
| 效果 | 社会效益·效果 | \_\_ | Q\_\_ | 按分档标准折算 | 问卷 |
| 效果 | 社会效益·宣传力度 | \_\_ | Q\_\_ | 按分档标准折算 | 问卷 + 台账 |

**填不出来时怎么办**：问卷原件未取得 → 该指标得分写「\_\_%（**待补问卷题号，分不可复核**）」，并在"局限"里写明未取得问卷原件与抽样方案。**不许直接给一个 92% 了事。**

## 四、问题段的写法（最见功力的一段）

本所实例的问题段，每条都是「现象 + 数字 + 原因」三段式：

> **1、预算编制与执行存在一定的偏差**
> 预算编制不够准确合理，预算调整率较高。2020 年部门预算 68.75 万元，年中追加预算
> 15.37 万元，**预算调整率达 22.36%**。其中：基本支出追加 14.17 万元，占总追加数的
> 92.19%……
> **评价人员认为**，造成这一现象的主要原因是：考核奖、年休假补贴等在年初无法准确
> 预算，只能通过追加方式解决。

三个要点：
- **数字要能追到表**：68.75 万来自表 1，15.37 万来自表 2 的追加列，22.36% 是算出来的。
- **必须写原因，且区分「可控/不可控」**：本例把追加归因于「考核奖年初无法预算」，
  属于制度性因素，不是单位管理失误——这种区分直接影响建议怎么写。
- **不写"管理不善"这种空话**，写清是哪一笔、多少钱、占多大比例。

## 五、建议段：与问题一一对应，落到动作

问题 1（预算调整率高）→ 建议「强化预算的科学化精细化管理」：以绩效为导向、
细化精准编制、反映项目与资金的匹配性。

问题 2（资金挤占）→ 建议「加强财务管理，规范资金使用」：专项核算、专款专用、
明确开支范围与标准、财政加强日常监管。

问题 3（基层组织建设欠完善）→ 建议「加快推进基层组织建设」：分步推进、
以点带面、示范典型。

**建议不新增问题之外的话题。** 问题提了三条、建议写了五条且其中两条没对应问题，
复核时会被问「这两条依据在哪」。

## 六、与本所上游方法论的对应

上游 `cpaaud-1-绩效评价方法论`（资深注册会计师包）给的是**通用四维：决策 / 管理 /
产出 / 效益**，配套中发〔2018〕34 号、财预〔2020〕10 号的框架。

本篇实例用的是**投入 / 过程 / 产出 / 效果**——同一框架的地方化表述，对应关系：

| 上游通用四维 | 天台部门整体支出口径 | 差异 |
|---|---|---|
| 决策 | 投入（目标设定 + 预算配置） | 天台把「目标设定」并入投入，更强调预算配置 |
| 管理 | 过程（预算执行 + 合规性 + 公开性 + 基础信息） | 天台拆得更细，过程占 33 分 |
| 产出 | 产出（职责履行 + 质量达标） | 基本一致 |
| 效益 | 效果（社会效益 + 可持续性 + 满意度） | 天台效果占 37 分，权重最高 |

**接活时按委托方给的指标表填，不要拿上游的四维硬套。** 上游是方法论，具体权重
由当地财政部门定，每年可能调。

## 七、局限（用之前先看这条）

- **只有一份实例**，且是 2020 年度、县红十字会（群团组织、3 人小单位）。部门和
  项目类型单一，不能代表全部口径。
- 指标表的**完整四级指标未逐条录入**（PDF 跨 6 页，部分为扫描混排）。要出报告时
  以委托方当年下发的指标表为准，本篇只做结构参照。
- **「过程」维度分值对不上**：槛分值 33，但能读到的二级指标只加到 26（预算执行 11 +
  合规性 8 + 公开性 2 + 基础信息 4 + 固定资产利用率 1），**差 7 分的二级指标未录入**。
  复现测试时按纪律留"待补"处理，不凑数——**别把这条当笔误去改，是样本本身缺页**。
- 报告未附**问卷原件与抽样说明**，问卷题号与指标的对应关系只能从文字推断。参照
  §三「问卷题号—指标对应表」模板填写；缺问卷时该指标写"待补问卷题号，分不可复核"。
- 缺**同一年度其他部门**的报告，无法横向比较评分松紧。
