# 浙江省财政支出项目绩效评价报告模板（真实样本）

> 样本来源：`校准样本/绩效评价/浙江省财政支出项目绩效评价报告-天台县财政局-2019.pdf`（天台县政府门户公开附件，16 页，可检索文字）。
> 项目：财政宣传及培训费用｜项目单位：天台县财政局｜评价类型：事后评价｜评价方式：部门（单位）绩效自评｜评价机构：部门（单位）评价组｜2019-11-20。
> **这是浙江省/天台县实际在用的表式**，比通用方法论更贴本地作业。年份较早，**现行版本以当年财政通知为准**。

## 一、封面字段

```
浙江省财政支出项目绩效评价报告
  项目名称
  项目单位
  主管部门
  评价类型：  事前评价□   事中评价□   事后评价√
  评价方式：  部门（单位）绩效自评√   财政部门组织评价□
  评价机构：  中介机构□   部门（单位）评价组√   财政评价组□
  日期
```

**注意评价机构那一栏**：中介机构是单独勾选项。天信作为第三方承接时，勾「中介机构」，不是「部门评价组」——这决定报告口径与责任。

## 二、正文结构

```
一、项目基本概况
  项目负责人 / 联系电话 / 地址 / 邮编 / 项目起止时间
  计划安排资金（万元）/ 实际到位资金（万元）
  其中：中央财政 / 省财政 / 市县财政 / 其它（到位与安排分列）
  实际支出（万元）

二、项目支出明细情况
  支出内容（经济科目）｜计划支出数｜实际支出数
  支出合计

三、项目绩效情况
  预期 vs 实际（项目绩效目标及实施计划完成情况）
  指标表（见下）

四、综合得分与评价等次
  综合得分 100 分制 → 评价等次（优秀/良好/合格/不合格）

五、评价报告文字部分（报告综述）
  项目基本概况、评价依据、评价过程、评价结论、存在问题、建议
```

## 四、与 cpaaud-1 怎么配合

| `上游/cpaaud-1-绩效评价方法论.md` 给的 | 本篇补的 |
|---|---|
| 四维框架（决策/过程/产出/效益）与权重的一般规则 | **浙江省/天台县实际表式**：业务 65 + 财务 35 的具体三级指标与分值 |
| 指标体系设计七步 | 现成可套的指标表（改指标名即可，不用从零设计） |
| 评分表标准结构 | 真实评分表列式：基本指标｜具体指标｜指标分值｜评价得分 |
| 报告提纲 | 真实报告的封面字段、正文五节、勾选栏 |

**用法**：接天台县财政局的评价单，先用本篇的表式起稿，再用 `cpaaud-1` 校方法；**两者的权重口径冲突时，以当年财政通知/评分细则为准**。

## 五、局限

- 2019 年模板，**指标与分值可能已调整**；每年接单前必须取当年的评价通知与评分细则。
- 只覆盖「项目支出」类，不含部门整体支出、政策评价、事前评估的表式。
- 样本里的项目名、金额、负责人不抄进技能。
