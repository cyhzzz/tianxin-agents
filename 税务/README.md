## 原专家里修掉的六处硬错误

这份专家的税率表是 2023 年口径，直接搬过来会让客户少缴、补税加滞纳金。核实后逐条修正：

| 原内容 | 问题 | 已改为 |
|---|---|---|
| 生产性服务业加计 5% / 生活性服务业加计 10% | **2023-12-31 到期未延续**，2024 年起继续申报要补税 + 滞纳金 + 可能罚 0.5–5 倍 | 删掉，改为现行三类（先进制造业 5%、集成电路 15%、工业母机 15%），并单列"已失效政策"警示 |
| 留抵退税"增量留抵 × 进项构成比例 × 60%" | 2019 年部分退还口径，已被取代 | 改为《增值税法》法定化：可结转下期或申请退还；明确"不要再用 60% 公式" |
| 小规模征收率含 5%（不动产、劳务派遣差额） | 《增值税法》2026-01-01 施行后征收率统一为 3% | 标注新法口径 + 申报栏次调整（2026 年第 6 号），提示以主管税务机关口径为准 |
| 财产保险合同印花税 0.003% | 用的是旧《暂行条例》按投保金额贴花的口径 | 改为印花税法：按**保险费的千分之一** |
| 证券交易印花税 0.1% | 漏了 2023-08-28 起减半 | 补：法定 1‰，实际 **0.5‰**，只对出让方征 |
| 各项优惠只写"以最新政策为准" | 无文号无期限，无法判断是否还有效 | 逐条补文号与期限，并区分"制度性安排（研发加计 100%）"与"阶段性（至 2027-12-31）" |

**新增原专家没有的内容**：申报表勾稽与自查清单（`03`）、纳税调整项目清单（`02` §3.2）、小微 300 万临界点陷阱测算（`02` §3.3）、经营所得税率表、逾期与更正处理（`03` §五）。

## 和「天信实务知识库」的分工

| | `公用/天信实务知识库skill/cards/tax-practice.md` | 本线 `天信税务申报` |
|---|---|---|
| 管什么 | **判**：业务怎么定性、红线在哪 | **做**：怎么算、怎么填、风险在哪 |
| 典型问法 | "这笔收入算不算价外费用" | "这个季度增值税怎么算、表怎么填" |

判性质的问题先看卡，落地算税用这个 skill。两处不重复维护——卡里的数值如与 `references/01` 不一致，**以 `01` 为准**（`01` 有文号和核实日期）。
