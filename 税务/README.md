## 上游原文（`上游/`）

平台「银橙AI·银橙税务师」（`tax-advisor-expert`），原包 8 个文件收 5 个，**原样收录、一字未改**，逐份 `sha256` 已核。不收的 3 个是包元数据、头像、下载时间戳。

**注意**：该上游包未附许可证文件（`plugin.json` 的 license 为空），法律上属"保留所有权利"，
**仅限所内使用，不得随仓库对外分发**。这与代账线的 `finance` 包（Apache-2.0）不同。

## 已移除：`tax-compliance-team`（2026-10-31）

这条线原先还收过另一个包（企业税务合规团队：1 个组长 + 5 个专员 + 税引擎）的 9 份原文，含会计科目表、各税种计算要点、六阶段分工。

**已全部删除。** 原因：该包**源文件已不在本机**（原路径不存在，全盘搜不到），无法与原始字节比对。收了却证明不了是原文，等于给技能埋一处无法追溯的引用。处置规矩从此定为：**上游只收有源可核对的文件**——本机原包在、`sha256` 一致，缺一条就不进 `上游/`。

**影响与处置**：

- `SKILL.md` 与本文中指向 `tax-2`（计算要点）、`tax-6`（合规报告）、`tax-8`（科目表）、`tax-1`（分工）的路由已全部改写或删除。
- **会计科目表在本线没有依据了**。建账、开明细科目按会计准则与客户行业惯例处理，别硬编；要回填依据，重新下载该包后按 §3.1 重收。
- **知识没丢**：当时比对中发现的 7 处税率口径问题（生产性/生活性服务业加计已到期、留抵退税 60% 公式作废、证券交易印花税 0.05%、财产保险印花税千分之一、小规模征收率随《增值税法》调整、优惠期限与文号缺失），**已全部并入 `references/01`，每条带文号与执行期限**。税率一仍以 `01` 为准。
- 详细记录（含恢复方式）见 `上游/README.md`「已移除的上游包」。

> 曾有一处表述说"从 `tax-filing-specialist` 提取五类计算、从 `compliance-auditor` 提取七个风险指标阈值"——**不准确**：那些角色卡里风险指标只是一张 `{X%}` 占位模板，`02`~`05` 的作业方法实际是天信自己写的。

## 能力边界：判在定性，做在这里

| | 判断（定性） | 作业（算与报） |
|---|---|---|
| 管什么 | 业务怎么定性、红线在哪 | 怎么算、怎么填、风险在哪 |
| 典型问法 | "这笔收入算不算价外费用" | "这个季度增值税怎么算、表怎么填" |

**本线技能独立运行**：判类、算税、勾稽、风险、发票五块方法都在技能内，不指向其他技能文件。
若所内另装「天信实务知识库」，其 `cards/tax-practice.md` 可作深读补充；两处数值不一致时，**以 `references/01` 为准**（带文号与核实日期）。
