# 税务线

企业所得税汇算清缴、增值税申报、税收优惠适用、税务风险自查、发票合规审查，以及**涉税鉴证（税审）报告的审核与撰写**。

## 已建技能

| 技能 | 装成名字 | 管什么 |
|---|---|---|
| `天信税务申报skill` | `天信税务申报` | 申报路径：判类 → 算税 → 申报 → 勾稽 → 风险扫描 → 发票审查；鉴证路径：涉税鉴证报告审核（五轮核）与撰写（六步成文） |

## 能力边界：判在定性，做在这里

| | 申报（算与报） | 鉴证（表态） |
|---|---|---|
| 管什么 | 怎么算、怎么填、风险在哪 | 这份报告能不能签、意见类型对不对、依据是否现行有效 |
| 典型问法 | "这个季度增值税怎么算、表怎么填" | "这份汇算清缴鉴证报告能不能出" |
| 交付物 | 税费汇总表、纳税调整明细表、自查清单 | 三级问题清单（审核）/ 鉴证报告成文（撰写） |

**本线技能独立运行**：判类、算税、勾稽、风险、发票、涉税鉴证六块方法都在技能内，不指向其他技能文件。
若所内另装「天信实务知识库」，其 `cards/tax-practice.md` 可作深读补充；两处数值不一致时，**以 `references/01` 为准**（带文号与核实日期）。

**与审计线的接口**：同一家企业常同时要审计报告和涉税鉴证报告。两份报告的口径衔接按 `taxcta-2` §3 四必查（利润总额可比、审计调整是否同步进纳税调整、审计非无保留意见对鉴证意见的影响、差异的税法口径说明）。**第四种意见措辞别写混**：审计是"无法**表示**"，鉴证是"无法**表明**"。
