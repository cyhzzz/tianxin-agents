# 税务线

企业所得税汇算清缴、增值税申报、税务筹划、涉税鉴证、税务咨询与争议。

## 计划建的技能

| 技能 | 内容 | 状态 |
|---|---|---|
| `天信税务申报` | 汇算清缴全流程、税会差异调整、优惠适用判定、涉税鉴证要点 | 待建 |

## 这条线最容易标准化

税法是全国统一的，不像审计底稿那样一所一样。所以这条线的 skill 最有可能做成「拿过来就能用」。

商店里的 `tax-compliance-team` 提供了两块可直接接的东西：

| 内容 | 状态 |
|---|---|
| 会计科目表（三级科目 + 编码） | 可用，需核准 |
| 各税种税率速查（增值税/所得税/个税/附加/印花/房产） | **必须逐条核现行政策**——小微优惠、小规模征收率这两年都调过 |

## 需要什么材料

1. **汇算清缴的工作底稿**——纳税调整明细表怎么填、哪些项目常调
2. 客户行业分布（制造业/商贸/服务各几家）——决定哪些优惠用得上
3. 涉税鉴证做不做，做的话报告模板
4. 当地税务局的特殊口径（天台县有没有地方性要求）
