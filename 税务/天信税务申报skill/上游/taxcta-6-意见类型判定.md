# 04 鉴证意见类型判定

## 0. 先记住两个与 CPA 审计不同的口径

| 项 | 税务师·涉税鉴证 | CPA·财务报表审计 |
|---|---|---|
| 第四种意见的名称 | **无法表明意见** | 无法表示意见 |
| 保证程度二分 | 无保留、保留 = **提出鉴证结论**，合理保证；无法表明意见、否定意见 = **提出鉴证意见**，有限保证（消极方式） | 保留/否定/无法表示意见均非无保留，表述体系不同 |
| 结论的落点 | 落到**具体税款金额**能否确认 | 落到财务报表是否公允反映 |
| 报告的用途后果 | 无保留/保留意见**可以作为**办理纳税申报或审批事宜的依据；无法表明意见/否定意见**不能作为**依据 | 无此「能否作申报依据」的法定效果区分 |

**写报告时不要用「我们认为……在所有重大方面公允反映了……」这类审计措辞。** 涉税鉴证的落点是「是否遵从法定性标准」和「具体金额能否确认」。

---

## 1. 无保留意见的鉴证报告

**必须同时满足三个条件**（缺一不可）：

1. 鉴证事项**完全符合法定性标准**，涉及的会计资料及纳税资料遵从了国家法律、法规及税收有关规定；
2. 税务师已按规定**实施了必要的审核程序，审核过程未受到限制**；
3. 税务师获取了鉴证对象信息所需的**充分、适当的证据，完全可以确认涉税鉴证事项的具体金额**。

**表述方式**：以**积极方式**提出鉴证结论，对鉴证对象信息提供**合理保证**；**应当提出鉴证结论，并确认审核事项的具体金额**。

**效果**：可以作为办理纳税申报或审批事宜的依据。

---

## 2. 保留意见的鉴证报告

**符合下列情形之一**：

1. 涉税鉴证的**部分事项**因税收法律、法规及其具体政策规定或**执行时间不够明确**；
2. 经过咨询或询证，对鉴证事项所涉及的具体税收政策在理解上**与税收执法人员存在分歧，需要提请税务机关裁定**；
3. **部分**涉税事项因**审核范围受到限制**，不能获取充分、适当的证据，**虽然影响较大，但不至于出具无法表明意见**的鉴证报告。

**表述方式**：以适当方式提出鉴证结论，对鉴证对象信息提供**合理保证**；**对能够获取充分适当证据的部分确认具体金额**，**对不能确认具体金额的部分予以说明**，提请预期使用者（税务机关）决策、裁定。

**操作要点**：
- 持保留意见的报告**仍应提出鉴证结论**，并对持保留意见的审核事项予以说明，**提出初步意见或解决方案供税务机关审核裁定**；
- 必须写清：哪些事项保留、为什么保留（政策不明 / 理解分歧 / 证据不足）、影响金额能否量化（能量化写区间，不能量化写「暂无法准确计量」）；
- **效果**：可以作为办理纳税申报或审批事宜的依据。

---

## 3. 无法表明意见的鉴证报告

**适用条件**：审核范围受到限制，对涉税鉴证事项可能产生的影响**非常重大和广泛**，不能获取充分、适当的证据，以至于**无法对涉税事项发表审核意见**。

**表述方式**：以**消极方式**提出鉴证意见，对鉴证对象信息提供**有限保证**，并**说明涉税鉴证事项无法表明意见的理据**（逐项阐述）。

**操作要点**：
- 要**逐项**阐述无法表明意见的理据，不能一句「因资料不全」带过；
- 要区分「未获取证据的事项」与「已获取证据的事项」，后者能确认多少说多少；
- **效果**：**不能作为**办理纳税申报或审批事宜的依据（企业不能据此办理申报或审批）。

---

## 4. 否定意见的鉴证报告

**适用条件**：发现涉税事项**总体上没有遵从法定性标准**，存在违反税收法律、法规或有关规定的情形，经与被审核方（治理层、管理层）**沟通或磋商，在所有重大方面未能达成一致**，不能真实、合法地反映鉴证结果。

**表述方式**：以**消极方式**提出鉴证意见，提供**有限保证**，并**说明持否定意见的理据**（逐项描述违反情形）。

**操作要点**：
- 必须记录**已与被审核方沟通磋商且未能达成一致**这一前置条件，否则不宜直接出否定意见；
- **逐项**描述存在违反税收法律法规的情形、涉及税种、期间、金额；
- **效果**：**不能作为**办理纳税申报或审批事宜的依据。

---

## 5. 判定流程（按此顺序走，不要跳）

```
① 审核程序是否受到限制？
     ├─ 未受限 → ②
     └─ 受限，且影响「非常重大和广泛」、无法获取充分适当证据 → 无法表明意见
② 是否存在违反税收法律法规的情形、且沟通磋商后重大方面未达成一致？
     ├─ 是 → 否定意见
     └─ 否 → ③
③ 是否存在：政策规定/执行时间不明确？与执法人员理解分歧需提请裁定？
   或审核范围受限影响较大但不至于无法表明意见？
     ├─ 任一为是 → 保留意见
     └─ 全部为否 → ④
④ 三条件全满足（符合法定性标准 + 程序未受限 + 证据充分可确认金额）
     └─ 无保留意见
```

**判定的第一原则是「结论与底稿证据匹配」**：
- 底稿里有未解决的重大事项（大额无票支出未处理、重大政策分歧未裁定、关键资料缺失）→ 不能出无保留意见；
- 报告出无保留意见但底稿显示审核范围受限 → **审核时判为硬伤**。

---

## 6. 说明段写什么（按意见类型）

| 意见类型 | 说明段内容 |
|---|---|
| 无保留意见 | 一般无强制说明段；可在「特别事项说明」中披露重大涉税事项（如大额亏损弥补、资产损失扣除、优惠适用），**不影响结论** |
| 保留意见 | 逐项说明保留事项、保留理由（政策不明/分歧/证据不足）、对金额的影响（能量化则量化）、提请税务机关裁定的建议 |
| 无法表明意见 | 逐项说明审核范围受限的具体情形、受影响的事项与范围、已获取的证据情况、无法表明意见的理据 |
| 否定意见 | 逐项描述违反税收法律法规的情形、税种、期间、金额、已进行的沟通磋商及其结果 |

**说明段纪律**：能进结论段的不要堆进说明段；说明段只放政策分歧、范围受限、重大不确定性、提请裁定事项。说明段不是免责声明，写得越含糊，执业风险越高。
