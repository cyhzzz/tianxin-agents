# 07 交付前自查清单

审完或写完，出稿前逐项打勾。**有未通过项必须说出来，不许默认通过。**

## A. 要素完整性（硬伤级）

- [ ] A1 标题＝「鉴证事项 + 鉴证报告」，未自造名称
- [ ] A2 有业务成果编号，首页注明
- [ ] A3 收件人为全称，与委托协议一致（受机关委托的写机关全称）
- [ ] A4 引言段**明确划分双方责任**：被鉴证方对资料真实性、合法性、完整性负责；事务所对鉴证结论负责
- [ ] A5 引言段说明了审核标准与审核原则
- [ ] A6 有鉴证实施情况（程序方法 + 内控评述 + 内外部证据评述）
- [ ] A7 有鉴证结论（或鉴证意见）段
- [ ] A8 有使用限制段（用途 + 不得擅自提供他人）
- [ ] A9 附件齐全（已审申报表、会计报表、鉴证报告说明等）
- [ ] A10 签章齐全：**税务师事务所盖章 + 所长和税务师签名或盖章 + 事务所名称地址**
- [ ] A11 报告日期已填，且不早于鉴证程序完成日

## B. 意见类型适当性（硬伤级）

- [ ] B1 意见类型按 `04-意见类型判定.md` 的判定流程得出，有判定过程
- [ ] B2 **结论与底稿证据匹配**：无保留意见项下不存在未解决的重大事项
- [ ] B3 保留意见：逐项写明保留事项、理由（政策不明/分歧/证据不足）、金额影响、提请裁定
- [ ] B4 无法表明意见：逐项写明受限情形、影响范围、理据
- [ ] B5 否定意见：写明已沟通磋商且重大方面未达成一致；逐项描述违法违规情形
- [ ] B6 未使用 CPA 审计措辞（「公允反映」「无法表示意见」等）；用的是「**无法表明意见**」
- [ ] B7 无保留/保留＝积极方式提结论；无法表明/否定＝消极方式提意见（保证程度表述正确）

## C. 数字与勾稽（硬伤级）

- [ ] C1 申报表主表 ⇄ 附表 ⇄ 报告结论 ⇄ 底稿审定表，四处一致（跑 `05` §5 的 12 项核对表）
- [ ] C2 纳税调整链每一环有底稿出处
- [ ] C3 每一笔调整写明：事项、金额、**计算过程**、政策依据、证据
- [ ] C4 不存在「其他调整」「其他事项」等不给明细的金额
- [ ] C5 金额单位统一，全篇一致
- [ ] C6 汇总纳税企业分配比例、三项权重计算正确
- [ ] C7 底稿有索引编号、编制人签名日期、**复核人签名日期**

## D. 税法依据（硬伤级）

- [ ] D1 每条引用为「文件名 + 文号 + 条款号」三件套
- [ ] D2 每条引用**已通过官方源核实**（见 `01`），记录核实来源与日期
- [ ] D3 施行日期覆盖鉴证所属期（不是看发布日期）
- [ ] D4 修订过的注明「×年×月×日修订，自×年×月×日起施行」
- [ ] D5 无「根据税法有关规定」这类无出处表述
- [ ] D6 引用的准则/指引为**现行版本**（旧版「注册税务师」时期准则须核实是否被替代）
- [ ] D7 凡【待核实】项已列入缺口清单，未伪装成确定结论

## E. 风险披露（应修改级）

- [ ] E1 按 `06` 的 8 类高频风险逐类排查过
- [ ] E2 重大涉税事项（亏损弥补、资产损失、优惠适用、大额无票支出）已在特别事项说明中披露
- [ ] E3 风险提示与整改建议已给出，未替企业遮掩
- [ ] E4 应补税费及滞纳金风险已提示
- [ ] E5 底稿证据不足以支撑的事项，已按相应意见类型处理，未用估算值填坑

## F. 撰写路径专项（撰写时适用）

- [ ] F1 用户模板已拆解为槽位清单，并经用户确认
- [ ] F2 模板缺失的必备要素已补齐，并**明确告知用户改了什么、为什么改**
- [ ] F3 沿用了用户模板的段落结构与措辞习惯（除纠正错误部分）
- [ ] F4 底稿缺的数写「待补充」并列入缺口清单，未自行估算
- [ ] F5 意见类型先于正文确定
- [ ] F6 说明段未堆砌无关内容，只放政策分歧、范围受限、重大不确定性、提请裁定事项

## 输出模板

**审核任务**：
> **结论**：（能不能签 / 意见类型是否适当 / 还需补什么）——一句话。
>
> **问题清单**（表格）：序号 | 位置 | 问题描述 | 依据（文件名+文号+条款） | 档次（硬伤/应修改/建议优化） | 修改建议
>
> **待补充证据清单**：序号 | 事项 | 需补充什么 | 用于支撑哪个结论

**撰写任务**：
> **成稿**：按模板槽位逐段成文。
>
> **模板改动说明**：序号 | 原模板情况 | 改成了什么 | 为什么改（依据）
>
> **缺口清单**：序号 | 槽位 | 缺什么数据/证据 | 影响哪段结论 | 向谁要
>
> **待核实法规清单**：序号 | 引用事项 | 拟核实来源 | 备注
