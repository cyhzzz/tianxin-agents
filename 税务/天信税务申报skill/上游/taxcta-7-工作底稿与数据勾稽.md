# 05 工作底稿要件与数据勾稽

## 1. 工作底稿的法定要素

涉税鉴证业务工作底稿应当包括（依据《注册税务师执业基本准则》第三十五条、《涉税鉴证业务指引》第三十三条，**引用前核实现行版本**）：

| # | 要素 | 常见缺失（审核时重点查） |
|---|---|---|
| 1 | 鉴证项目名称 | 只写「汇算清缴」，不写具体年度/事项 |
| 2 | 被鉴证人名称 | 用简称，与营业执照/申报表不一致 |
| 3 | 鉴证项目所属期间 | 期间与申报所属期不一致 |
| 4 | **索引** | 缺索引编号，导致底稿无法交叉引用 |
| 5 | 鉴证过程和结果的记录 | 只有结论、无过程；只有数字、无判断依据 |
| 6 | **证据目录** | 无证据清单，证据与结论无法对应 |
| 7 | **编制人签名和编制日期** | 缺签名或日期 |
| 8 | **复核人签名和复核日期** | 无复核痕迹，三级复核无从证明 |

**底稿编制目标**：①适当记录业务过程，列明判断过程及依据，为出具报告提供基础性资料；②有效收集整理证据，形成支持鉴证结果的**证据链条**，证明业务过程符合业务指引；③规范记载业务实施情况，保证执业质量。

**形式**：可采用纸质或电子形式；有视听资料、实物证据的可同时采用其他形式；可在鉴证过程中随时形成，由实施人员签名。

## 2. 底稿体系构成

### 2.1 管理类（综合类）
业务约定书 · 审核计划 · 三级复核记录 · 企业基本情况表 · 营业执照与资质文件 · 独立性声明 · 被鉴证单位声明书/管理层声明 · 与税务机关沟通记录（如有） · 意见分歧处理记录。

### 2.2 业务类（按项目）
财务与涉税数据：资产负债表、利润表、现金流量表、科目余额表；企业所得税年度纳税申报表及全部附表；预缴税款凭证；优惠备案/留存备查资料。

审核工作底稿：收入、成本、费用各项目审核表；**纳税调整明细表**；资产类调整表；优惠明细表；亏损弥补计算表。

资产负债权益类审定表：货币资金、存货、固定资产、借款、实收资本等。

证据附件：合同、发票复印件、银行对账单、盘点表、政府补助文件、资质证书等。**复印件须注明「与原件一致」并加盖企业公章。**

## 3. 证据规则

**证据资格（能不能用）**：
- **相关性**：鉴证材料与待证事实之间具有实质性证明意义的关联；
- **合法性**：取证主体、取证程序、证据形式符合法律要求。

**证明能力（够不够用）**：
- **真实性**：经适当方法查证属实，能够**排除合理怀疑**；
- **充分性**：获取鉴证材料整体的证明力，足以支持鉴证结果。

**适用标准**：
- 纳税申报类和涉税审批类涉税鉴证业务，**必须遵守税法的规定**；
- 税收法律、行政法规、规章以及规范性文件之间规定不一致的，按照**有权部门作出的解释**执行；没有解释的，可以向税务机关咨询；
- **对面临税务机关处罚风险的鉴证项目，可以参照行政诉讼证据规则确认证据**；
- 可能引起争议的鉴证项目，应充分考虑诉讼法中的证据规则。

## 4. 纳税调整口径转换链（企业所得税）

报告的核心就是这条链。**每一环都要有底稿出处**：

```
会计利润总额（利润表）
  ├─ + 纳税调整增加额
  ├─ − 纳税调整减少额
  ↓
纳税调整后所得额
  ├─ − 免税、减计收入及加计扣除
  ├─ − 所得减免（如适用）
  ├─ − 抵扣应纳税所得额（如适用）
  ├─ − 弥补以前年度亏损
  ↓
应纳税所得额
  × 适用税率
  ↓
应纳所得税额
  ├─ − 减免所得税额
  ├─ − 抵免所得税额
  ↓
实际应纳所得税额
  ├─ − 本年累计实际已预缴的所得税额
  ↓
本期应补（退）所得税额
```

**常见调增项**：业务招待费超标、广告费和业务宣传费超标、职工福利费/工会经费/教育经费超标、公益性捐赠超标、利息支出超标准、罚金罚款和被没收财物的损失、税收滞纳金、赞助支出、与取得收入无关的支出、**未取得合规税前扣除凭证的支出**、资产减值准备（未经核定的准备金）、折旧摊销税会差异、资产损失未按规定申报、关联交易调整等。

**常见调减项**：国债利息收入、符合条件的居民企业之间股息红利等权益性投资收益、研发费用加计扣除、残疾人员工资加计扣除、固定资产/无形资产加速折旧（税会差异的时间性部分）、以前年度应扣未扣支出（符合规定追补扣除）、不征税收入对应的支出等。

**纪律**：每一笔调整在底稿里都要有「事项 → 金额 → 计算过程 → 政策依据（文件名+文号+条款）→ 证据」。报告里写「其他调整 ××元」而不给明细的，审核时判为硬伤。

## 5. 四处勾稽核对表（审核必跑）

| # | 核对项 | 通过标准 |
|---|---|---|
| 1 | 申报表主表「利润总额」⇄ 利润表利润总额 | 一致；不一致须有差异说明且合理 |
| 2 | 主表「纳税调整增加额/减少额」⇄ A105000《纳税调整项目明细表》合计数 | 一致 |
| 3 | A105000 各明细行 ⇄ 底稿纳税调整明细表 | 逐行一致，金额可追到底稿 |
| 4 | 资产损失申报金额 ⇄ A105090《资产损失税前扣除及纳税调整明细表》 | 一致 |
| 5 | 优惠金额（调减或减免）⇄ 优惠明细表 ⇄ 备案/留存备查资料 | 金额、条件、程序三者均匹配 |
| 6 | 弥补亏损额 ⇄ A106000《企业所得税弥补亏损明细表》⇄ 以前年度申报/鉴证数据 | 可衔接，年限正确 |
| 7 | 主表「应纳税所得额」⇄ 底稿计算表 | 一致 |
| 8 | 主表「本期应补（退）所得税额」⇄ 底稿税款测算表 ⇄ 报告结论段第 11 项 | 一致 |
| 9 | 汇总纳税企业：总机构与分支机构分配比例、营业收入/资产总额/职工薪酬 | 三项权重与比例计算正确 |
| 10 | 报告结论段各项 ⇄ 已审申报表各项 | 逐项一致 |
| 11 | 报告附件中的申报表版本 ⇄ 鉴证所属期适用版本 | 版本正确（**表单编号与格式历经修订，以当期版本为准**） |
| 12 | 底稿审定数 ⇄ 报告数字 ⇄ 申报表数字：三处一数 | 三处一致 |

> 表中 A105000、A105090、A106000 等表单编号为通行编号，**以鉴证所属期适用的申报表版本为准**，核对前确认版本。

## 6. 底稿缺口的处置

底稿不足以支撑某项调整时，三选一，按顺序：

1. **要求补充证据**——最优先，写进「待补充证据清单」；
2. **对该事项持保留意见**——证据不足但影响不至于无法表明意见；
3. **出无法表明意见**——受限影响非常重大和广泛。

**不要为了报告完整而用估算值填数。** 报告里的估算数字在税务检查和行业质量检查中是最容易被击穿的部分。
