# 01 法规源与效力核查

这份是知识库的入口。**任何要写进报告的法规、准则、公告，先按本文件核一遍再写。**

### 1.1 效力状态交叉验证

官方页面常直接标注效力。税务总局政策法规库与各省税务局转载页面通常带字段：

- **【是否有效】**：现行有效 / 已修改 / 已废止 / 部分失效
- **【备注】**：如「修改第九条第三款」「根据××年第××号公告修正」

**只看一个页面不够**：同一文件在不同站点标注可能不同步。至少做一次交叉核对（官方源 + 省级税务机关转载页 + 政策解读稿），三者一致才落笔。

## 2. 效力核查四步（每条引用必走）

**第 1 步：确认文件身份**
全称（含「试行」「修订」「修正」字样）＋ 文号（如「国家税务总局公告2017年第13号」「人社部发〔2015〕90号」）＋ 发布机关 ＋ 发布日期。

**第 2 步：确认施行日期**
**施行日期 ≠ 发布日期。** 报告里写「依照××（文号）」时，务必确认该依据在鉴证所属期间内**已经施行**。

**第 3 步：确认修订与废止**
查是否有修订公告、修正公告、废止决定。常见形态：
- 《××办法》（国家税务总局公告2017年第13号发布，**2019年第43号修改**）→ 修改后内容自 2020 年 1 月 1 日起施行。
- 上位法变更后配套文件失效。
- 专项清理公告整批废止。

**第 4 步：记录核实来源**
在内部工作记录里记下：来源网址 + 页面显示的效力标注 + 核查日期。报告定稿时便于复核。

## 3. 三类时间陷阱（审核报告时重点排查）

| 陷阱 | 形态 | 排查动作 |
|---|---|---|
| **已废止** | 报告引用了一份已被公告废止的文件（如旧版准则、旧通知） | 去官方源查废止决定；确认废止日是否早于鉴证所属期 |
| **已修订 / 已修正** | 引用了文号，但没写「×年×月×日修订」，实际条款已变 | 查修改公告，确认**修订后的施行日期**是否覆盖鉴证所属期；条款内容是否变化 |
| **尚未施行** | 引用了一份已发布但施行日在鉴证所属期之后的公告 | 比对施行日期与鉴证所属期；尚未施行的不得作为该期间依据 |

**另需排查**：过渡期口径。新法施行前发生的事项按旧法处理，报告要写明适用的是哪一个期间口径。

## 4. 引用格式规范

**报告正文**：
> 《中华人民共和国企业所得税法》（主席令第63号）第×条
> 《涉税专业服务监管办法（试行）》（国家税务总局公告2017年第13号发布，2019年第43号修改）第×条
> 《土地增值税清算鉴证业务指引》（税务师行业涉税专业服务规范第3.5.5号，试行）第×条

**规则**：
- 写「文件名 + 文号 + 条款号」三件套；修订过的注明修订文号与修订后施行日。
- 只写「根据税法有关规定」「依照相关税收政策」视为**不合格**，审核时直接列入「硬伤」。
- 政策依据表（底稿/报告附表）要单独列：事项 → 依据文件名 → 文号 → 条款 → 施行日期 → 核实来源 → 核实日期。

## 5. 检索实操提示

- **搜不到就换层级**：总局公告在 flk 查不到，就去 chinatax.gov.cn 或 fgk.chinatax.gov.cn；自律规范只在协会官网。
- **用完整文号搜**：「国家税务总局公告2019年第43号」比「涉税专业服务监管办法」命中更准。
- **认域名**：只信 `.gov.cn` 与协会官网；商业网站、题库站、公众号转载只当线索，**必须回官方源确认**后才可引用。
- **看解读稿**：重大政策总局同步发布「关于《××》的解读」，解读稿会明确施行日期、新旧衔接，是判断效力的高效入口。
- **核不到的处理**：写「【待核实】」并注明拟核实路径（去哪个源、查什么），列入交付缺口清单。**不写猜测的文号或条款号。**
