# 税务核查清单与纳税调整参考

> 用途：`tax-advisor-expert` 与 `tax-report` skill 的核查底稿。
> **说明**：本清单是核查思路与风险指向，用于组织审查程序；具体适用条件、比例、限额与申报表口径，**以现行有效法规原文与主管税务机关执行口径为准**。政策年度间常有调整，使用时须核对适用年度。

---

## 一、增值税核查要点

| 核查方向 | 具体检查点 |
|---|---|
| 纳税人身份与计税方法 | 一般纳税人/小规模纳税人适用是否正确；是否应登记未登记；简易计税项目的适用条件 |
| 销售额完整性 | 未开票收入是否申报；视同销售（自产/委托加工货物用于非应税项目、投资、无偿赠送等）；价外费用是否并入；预收款与纳税义务时间 |
| 纳税义务发生时间 | 直接收款、赊销分期、预收货款、委托代销等不同结算方式下的时点判定 |
| 进项税额 | 抵扣凭证是否合规（专票、海关缴款书、农产品收购发票、通行费电子发票）；不得抵扣情形（集体福利、个人消费、免税项目、简易计税项目对应进项）；已抵扣后用途改变的进项转出 |
| 异常凭证 | 走逃失联企业开具、货物与服务不符、开票品目与经营范围不符的进项是否已作处理 |
| 税率与征收率 | 兼营与混合销售适用是否正确；税率下调或调整的衔接期处理 |
| 差额征税 | 劳务派遣、旅游、建筑服务分包、金融商品转让等差额扣除凭证与计算 |
| 留抵退税 | 适用条件（纳税信用等级、无违规记录、增量与存量计算）、进项构成比例 |
| 发票管理 | 开票项目与实际业务一致；红字发票开具条件与流程；作废与冲红适用场景；发票保管与丢失处理 |

## 二、企业所得税核查要点

### 收入类

- 收入确认时点是否与税法口径一致（与会计收入存在时间性差异时是否调整）。
- 视同销售（非货币性资产交换、捐赠、用于市场推广、职工福利等）。
- 不征税收入与免税收入是否区分清楚（不征税收入对应的支出不得扣除，需做配套调整）。
- 政府补助：与资产相关/与收益相关的划分，以及税会差异调整。
- 跨期收入：预收账款、合同负债对应的纳税义务判断。

### 扣除类

| 项目 | 关键要点 |
|---|---|
| 税前扣除凭证 | 真实性、合法性、关联性；应取得发票而未取得（含对方注销、失联等特殊情形）的处理与补充证明要求 |
| 业务招待费 | 按发生额一定比例与营业收入一定比例孰低扣除，两项均需计算 |
| 广告费和业务宣传费 | 一般行业与特殊行业扣除比例不同；超过部分结转扣除 |
| 职工福利费 / 教育经费 / 工会经费 | 分别按工资薪金总额的规定比例计算限额，超支部分处理方式不同 |
| 利息支出 | 金融机构借款、非金融企业借款、关联方债资比限制、股东借款利息的扣除条件 |
| 捐赠支出 | 公益性捐赠的扣除限额与结转；直接捐赠不得扣除 |
| 不得扣除项目 | 罚金罚款与被没收财物损失、税收滞纳金、赞助支出、与取得收入无关的支出、未经核定的准备金 |
| 预提与暂估 | 年末预提未实际发生的费用是否已做调整 |
| 工资薪金 | 未实际发放部分（计提未付）的扣除时点 |

### 资产类

- 折旧年限与残值是否符合税法最低要求；会计与税法年限差异是否调整。
- 加速折旧与一次性扣除政策的适用条件与备案/留存备查。
- 在建工程长期挂账未转固导致的折旧少提。
- 无形资产摊销年限；长期待摊费用的摊销期限。
- 资产损失：清单申报与专项申报的区分，证据资料是否完整。
- 存货：成本计价方法与税前扣除的匹配。

### 优惠类

- 小型微利企业条件（从业人数、资产总额、应纳税所得额阈值）与年度适用。
- 高新技术企业资格有效期、研发费用归集与辅助账、科技人员占比。
- 研发费用加计扣除：可加计范围、不可加计情形（如已计入无形资产的摊销）、负面清单行业。
- 西部大开发、区域性或行业性优惠的适用条件与备案要求。
- 优惠叠加规则与不得叠加情形。

### 其他

- 亏损弥补年限（一般与特殊情形）、弥补顺序与结转台账。
- 关联交易的独立交易原则与同期资料准备义务。
- 境外所得抵免与税收协定待遇适用。
- 以前年度纳税调整事项的追溯与更正申报。

## 三、个人所得税与社保

- 工资薪金、全年一次性奖金计税方式的适用与一年一次的限定。
- 劳务报酬、稿酬、特许权使用费的预扣预缴与年度汇算。
- 经营所得（个体工商户、个人独资与合伙企业）的核算与申报。
- 财产租赁、财产转让（含股权转让）的计税依据是否明显偏低。
- 利息股息红利所得与股东借款长期未归还的视同分配风险。
- 股权激励的计税时点与备案。
- 专项附加扣除项目是否申报完整、是否有重复扣除。
- 全员全额扣缴申报是否覆盖全部用工形式（含劳务派遣、临时用工、非全日制）。
- 社保与公积金的缴费基数是否与工资总额匹配，是否存在按最低基数缴纳的情况。

## 四、其他税费

| 税种 | 关键要点 |
|---|---|
| 消费税 | 应税消费品范围、生产与委托加工环节、连续生产抵扣 |
| 房产税 | 从价与从租计征的区分、免租期与无租使用的处理、原值包含范围 |
| 城镇土地使用税 | 计税面积、等级税额、减免情形 |
| 印花税 | 应税合同与凭证范围、税目税率、资金账簿的计税依据与减免 |
| 城市维护建设税及附加 | 计税依据为实际缴纳的增值税与消费税，税率按所在地确定 |
| 契税 | 权属转移方式与计税依据、减免情形 |
| 土地增值税 | 四级超率累进的适用、扣除项目、普通住宅优惠、清算条件 |
| 环境保护税 | 应税污染物种类、排放量计算与监测依据 |
| 其他 | 残疾人就业保障金、文化事业建设费等的计缴基数 |

## 五、发票与征管

- 发票领用、保管、开具与作废的规范性；开票品目与实际业务、合同、资金流是否一致（三流一致）。
- 进销项匹配度：长期进项大于销项且无合理理由、大量顶额开票、富余票风险。
- 申报期限（各税种月度/季度/年度申报节点）与延期申报的申请。
- 更正申报、退税与留抵抵欠的办理条件。
- 税务稽查应对：资料准备、陈述申辩权利、税务行政处罚听证的适用情形。
- 纳税信用等级的评价指标与影响（影响发票领用、出口退税、融资等）。

## 六、汇算清缴纳税调整项目表结构

| 类别 | 常见项目 | 调整方向 | 依据要点 |
|---|---|---|---|
| 收入类 | 视同销售、未按权责发生制确认收入、不征税收入对应支出 | 调增为主 | 税法收入确认时点与口径 |
| 扣除类 | 业务招待费、广告宣传费、福利费、教育经费、工会经费、利息、捐赠、不得扣除项目、预提费用 | 以调增为主；部分可结转 | 各限额比例与扣除条件 |
| 资产类 | 折旧摊销年限差异、加速折旧、资产损失、长期待摊费用 | 可调增或调减 | 税法最低年限与损失申报要求 |
| 优惠类 | 免税减计收入、加计扣除、减免税额、抵扣应纳税所得额 | 调减 | 优惠适用条件与备案/留存备查 |
| 其他 | 亏损弥补、境外所得抵免、特别纳税调整 | 视情形 | 弥补年限与抵免限额 |

## 七、常见风险点与后果

| 风险点 | 触发情形 | 潜在后果 |
|---|---|---|
| 收入确认滞后 | 已开票未确认、预收款长期挂账、跨期收入 | 补缴增值税与企业所得税、滞纳金、罚款 |
| 无票支出税前扣除 | 以白条、收据入账并税前扣除 | 纳税调增、补税并加收滞纳金 |
| 进项抵扣不合规 | 取得异常凭证、用途改变未转出 | 进项转出、补税、发票风险等级上升 |
| 关联交易定价不合理 | 与关联方之间价差明显偏离独立交易原则 | 特别纳税调整、补税加利息 |
| 股东借款长期未还 | 股东借款跨年度未归还且未用于生产经营 | 视为股息红利分配，补缴个人所得税 |
| 社保基数不实 | 按最低基数缴纳、工资与社保数据不匹配 | 补缴社保、滞纳金、影响纳税信用 |
| 优惠条件不符 | 高新资格失效、小微条件超限仍享受 | 追缴已减免税款、滞纳金 |
| 亏损弥补超期 | 超出法定弥补年限仍结转 | 纳税调增、补税 |
| 印花税漏缴 | 合同、资金账簿未按规定贴花或申报 | 补税、罚款 |

> 提示：上表为风险指向清单，具体认定与处理以现行法规和主管税务机关意见为准。审查中发现问题时，应在报告中作为风险事项提示并给出合法整改路径，不作定性指控。
