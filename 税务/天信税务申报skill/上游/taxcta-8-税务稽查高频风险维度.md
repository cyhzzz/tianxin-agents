# 06 税务稽查高频风险维度

审核报告时按此清单前置排查；撰写报告时按此决定披露深度。**每一项都要落到「程序 + 比例 + 证据 + 明确结论」四要素。**

## 1. 收入完整性（第一高频）

| 排查点 | 典型问题 | 核查动作 |
|---|---|---|
| 未开票收入 | 现金收款、个人卡收款未入账 | 银行流水、POS/第三方收款账户与账面收入核对；发货/出库单与收入确认比对 |
| 视同销售 | 自产产品用于职工福利、捐赠、样品、以物易物未视同销售 | 核对产成品出库用途；核对 A105010 视同销售申报 |
| 跨期收入 | 预收款已发货未确认收入；提前/延后确认 | 合同、发货单、验收单、发票日期与收入确认日四单比对 |
| 价外费用 | 违约金、包装费、运输装卸费等价外费用未并入 | 合同价外条款、其他业务收入/营业外收入明细 |
| 关联方定价 | 关联交易价格明显偏低 | 可比价格分析；同期资料备查 |

**报告披露要求**：收入类调整逐项写事项、金额、依据、证据。

## 2. 税前扣除凭证合规性（第二高频）

| 排查点 | 典型问题 |
|---|---|
| 不合规发票 | 无票支出、白条入账、抬头不符、与业务不相关发票 |
| 第三方发票 | 发票开具方与实际供应商不一致（资金流、票据流、货物流不一致） |
| 大额费用无合同 | 咨询费、服务费、推广费大额列支但无合同、无成果交付证据 |
| 个人消费混入 | 股东/高管个人费用（诉讼费、律师费、车辆、房产）在企业列支 |
| 银行手续费 | 仅凭银行回单列支，未取得发票 |
| 工资薪金 | 预提年终奖未在汇算清缴前实际发放而提前扣除 |
| 劳务费 | 未代扣代缴个税即列支 |

**核查动作**：抽取大额费用凭证逐笔核验（合同 + 发票 + 付款流水 + 成果/验收四单齐全）；核验发票真伪与状态；无合规凭证的一律纳税调增并披露。

## 3. 税收优惠适用

| 优惠 | 常见失效点 |
|---|---|
| 小微企业 | 从业人数、资产总额、应纳税所得额三项指标超标；从事国家限制和禁止行业 |
| 高新技术企业 | 研发费用占比、高新收入占比、科技人员占比不达标；资格失效或被取消 |
| 研发费用加计扣除 | 非研发人员工资、办公费混入；无研发辅助账；委外研发超比例；负面清单行业 |
| 固定资产加速折旧 | 不符合行业/条件；税会差异未在申报表正确填报 |
| 不征税收入 | 政府补助不符合不征税收入条件；**其对应的支出仍税前扣除**（应调增） |
| 农林牧渔、环保节能、软件企业等 | 资质、目录、备案与留存备查资料不全 |

**核查动作**：先核「条件」，再核「程序」（备案/留存备查），最后核「金额计算」。三者任一不满足即调增并披露。

## 4. 资产与资产损失

- 固定资产投入使用后**未取得全额发票**未按规定暂估入账并计提折旧，或超过规定期限未调整；
- 折旧年限、残值率、折旧方法与税法规定不一致未调整；
- 资产损失**未按规定申报/留存备查**即税前扣除；
- 存货盘亏、报废无专项报告、无技术鉴定或残值处理证据；
- 股权投资损失、坏账损失的证据链不完整。

## 5. 关联交易与转让定价

关联方购销、资金拆借（无息或低息）、无形资产许可、服务费分摊；同期资料准备义务；是否符合独立交易原则；是否存在通过关联方转移利润。核查：关联方清单、交易合同与定价政策、可比性分析、同期资料。

## 6. 增值税相关（虽非所得税鉴证主体，但常被联动核查）

- 进项税额转出是否完整（用于免税、集体福利、个人消费、非正常损失）；
- 视同销售未计提销项；
- 留抵税额异常变动；
- 发票开具与收入确认时点差异；
- 进项发票取得与业务真实性（**虚开风险**，涉刑事红线）。

## 7. 个人所得税代扣代缴

工资薪金、劳务报酬、股息红利、偶然所得（促销赠品、抽奖）；股东借款年度终了未归还且未用于生产经营的视为股息分配；非货币性福利未并入工资。

## 8. 其他高频点

- **跨期费用**：本年度费用次年取得发票的处理；以前年度应扣未扣支出追补扣除的年限与程序；
- **核定征收**：不符合核定条件而核定；清算所得与经营收入混淆以适用核定方式少缴税款；
- **政府补助**：不征税收入与应税收入的划分，对应支出的调增；
- **资本公积/实收资本变动**：个人股东未缴个税；
- **亏损弥补**：超期弥补、顺序错误；
- **滞纳金与处罚**：报告应提示应补税费及滞纳金风险（尤其纳税情况审查报告）。

## 9. 税务机关常见追问句式（写报告时先自答一遍）

- 「请说明××年度收入总额与增值税申报收入、企业所得税申报收入存在差异的原因及构成。」
- 「请提供××笔大额咨询费/服务费的合同、发票、付款凭证及成果交付证明。」
- 「请说明××项政府补助作为不征税收入处理的政策依据，及其对应支出是否已作纳税调增。」
- 「请说明研发费用归集口径，并提供研发辅助账、立项文件、人员工时分配记录。」
- 「请说明资产损失的类型、金额、证据及申报方式。」
- 「请说明关联交易的定价政策及是否符合独立交易原则，提供同期资料。」

**自答要求**：每个问题的答案都要能在底稿里找到对应证据；找不到的，就是待补充项，进缺口清单。

## 10. 风险分级与报告处置

| 风险级别 | 判定 | 处置 |
|---|---|---|
| 高 | 金额重大且证据不足 / 存在违法情形且未达成一致 | 保留意见或否定意见 + 说明段详述 + 单独风险提示 |
| 中 | 金额较大但可量化、政策存在分歧 | 保留意见或特别事项说明 + 提请税务机关裁定 |
| 低 | 金额不重大、可量化、证据充分 | 正文披露 + 风险提示与整改建议 |

**报告中「风险提示与整改建议」的作用**：帮助企业规避风险，同时明确事务所的执业边界，降低自身执业风险。该写的必须写，不该替企业遮掩的绝不遮掩。
