# 08 撰写报告六步工作流

用户给了底稿 + 模板，要求出报告时，照此走。

## 第 1 步 · 认类型

确认是哪一种鉴证，骨架随之确定（见 `03`）：

| 类型 | 骨架/要点所在 |
|---|---|
| 企业所得税汇算清缴纳税申报鉴证 | `03` §1 |
| 土地增值税清算鉴证 | `03` §2 |
| 资产损失税前扣除鉴证 | `03` §3 |
| 税前弥补亏损鉴证 | `03` §4 |
| 研发费用加计扣除鉴证 | `03` §5 |
| 高新技术企业认定专项鉴证 | `03` §6 |
| 注销税务登记/清算所得税鉴证 | `03` §7 |
| 纳税情况审查（受机关委托） | `03` §8 |

**同时确认**：委托方是谁（企业 / 行政机关 / 司法机关）→ 决定收件人、责任段措辞、报告用途与结论形式。

**类型不确定就问**：「这份是汇算清缴鉴证，还是土增清算/其他专项？委托方是企业还是税务机关？」

## 第 2 步 · 解模板

把用户模板拆成槽位清单，**先给用户看，确认后再动笔**。

输出格式（表格）：

| 槽位号 | 段落名称 | 对应通用要素（`03` §0 编号） | 内容来源（底稿哪项 / 需引用法规 / 需计算） | 备注（缺失/待确认） |

同时标注：
- **缺失的必备要素**（最常见：编号、鉴证实施情况、使用限制段、责任划分不清）→ 建议补齐并说明依据；
- **需填数的槽位** → 对应底稿哪个数；
- **需引用法规的槽位** → 待核实清单。

## 第 3 步 · 建映射

从底稿审定数出发，跑通这条链（企业所得税口径；其他税种按对应口径）：

```
会计利润总额 → +调增 → −调减 → 纳税调整后所得
  → −免税减计加计 → −所得减免 → −弥补亏损
  → 应纳税所得额 → ×税率 → 应纳所得税额
  → −减免/抵免 → 实际应纳 → −已预缴 → 本期应补（退）
```

**做一张映射表**，交付时一并给出：

| 报告槽位 | 数值 | 底稿出处（底稿名称/索引） | 计算过程 | 政策依据 |

跑 `05` §5 的 12 项勾稽核对，不一致的标出来向用户核。

## 第 4 步 · 定意见

**先判意见类型，再写正文**（`04`）：

1. 程序是否受限？受限且影响非常重大广泛 → 无法表明意见
2. 存在违法情形且沟通磋商未达成一致 → 否定意见
3. 政策不明/理解分歧/部分受限但不至于无法表明 → 保留意见
4. 三条件全满足 → 无保留意见

**判定依据要写在工作记录里**：为什么不是更「轻」的意见、为什么不是更「重」的意见。

**注意**：意见类型决定结论段措辞、说明段有无与长短。定错意见类型，整篇要重写。

## 第 5 步 · 逐段成文

按槽位清单一段段写：

1. **标题 / 编号 / 收件人** —— 照 §1 与模板，全称、编号规则。
2. **引言段** —— 责任划分 + 审核标准 + 审核原则。沿用模板措辞，但必须含责任划分；模板缺的按准则补齐并告知。
3. **鉴证依据段** —— **逐条查官方源**（`01`）。格式：文件名 + 文号 + 条款；修订过的注明修订与施行日。
4. **鉴证实施情况段** —— 程序方法 + 内控有效性评述 + 内外部证据相关性与可靠性评述 + 职业推断情况。
5. **纳税调整段 / 鉴证报告说明** —— 按 `03` §1 的章节（企业基本情况 → 会计政策与税会差异 → 纳税调整汇总表 → 主要审核情况分项目）。**每笔调整四件套：事项、金额、计算过程、依据。**
6. **结论段 / 意见段** —— 按第 4 步判定的意见类型写。企业所得税无保留意见须确认 `03` §1 的 11 项。
7. **说明段** —— 只放：政策分歧、范围受限、重大不确定性、提请裁定事项。
8. **使用限制段** —— 用途 + 不得擅自提供他人。
9. **附件** —— 已审申报表、会计报表、鉴证报告说明等。
10. **签章与日期** —— 事务所盖章 + 所长和税务师签名或盖章 + 事务所名称地址 + 报告日期。

**税法依据段必查官方源**：这一段是执业风险最集中的地方，不许凭记忆写文号。

## 第 6 步 · 交付前自查

跑 `07` 全套清单（A～F），逐项打勾。未通过项如实列出。

交付时同时给出：
- **成稿正文**
- **模板改动说明**（改了什么、为什么改、依据什么）
- **缺口清单**（缺什么数据/证据、影响哪段结论、向谁要）
- **待核实法规清单**（引用事项、拟核实来源）
- **映射表**（报告槽位 ⇄ 底稿出处）

---

## 成文纪律（再强调）

- 沿用用户模板结构与措辞，**擅自换一套写法等于没按模板做**；模板有错才改，改必说明。
- 金额标单位，与底稿一致；底稿没有的写「待补充」。
- **数字可溯源、依据现行有效、口径是税法口径**——这三条是本专家的底线。
