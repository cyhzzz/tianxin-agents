# 06 土地增值税清算

> 天信原创。上游只有"清算条件"一行（银橙核查清单）与"清算鉴证报告骨架"（cta `taxcta-5` §2），**没有计算口径**。本文件补计算。
> 依据：《土地增值税暂行条例》及实施细则、土地增值税清算管理规定（国税发〔2006〕187号）、清算管理规程（国税发〔2009〕91号）。**引用条款前核现行文本**；地方口径以浙江省及台州税务机关规定为准。

## 一、先判：该不该清算、该谁清算

**应当清算**（纳税人须主动办）：

- 房地产开发项目**全部竣工、完成销售**
- 整体转让**未竣工决算**的房地产项目
- 直接转让**土地使用权**

**可要求清算**（税务机关可下通知）：

- 已竣工验收，**已转让面积占可售面积 85% 以上**，或虽未达 85% 但剩余面积已自用/出租
- 取得**预售许可证满 3 年**仍未销售完毕
- 纳税人申请**注销税务登记**但未办清算
- 省级税务机关规定的其他情形

**清算单位**：以规划部门审批的**开发项目**为单位；分期开发的，以**分期项目**为单位。**这个划分决定成本怎么分摊，划错整盘重算。**

## 二、收入怎么定

- 转让房地产取得的**全部价款及有关经济利益**（含装修、代收款项中属于价外费用的部分）。
- 实物、视同销售、以房抵债：按**同类房地产公允价值**（同期同类均价或评估价）确认。
- 预售款已按预征率预缴的，清算时**并入总收入**统一计算，再抵扣已预缴。

## 三、扣除项目五项（算错就在这五项）

| # | 项目 | 口径要点 |
|---|---|---|
| 1 | **取得土地使用权所支付的金额** | 地价款 + 按国家统一规定缴纳的有关费用（契税等）；**土地闲置费不得扣** |
| 2 | **房地产开发成本** | 土地征用及拆迁补偿费、前期工程费、建筑安装工程费、基础设施费、公共配套设施费、开发间接费用 |
| 3 | **房地产开发费用** | 见下方两种算法（**不是据实扣除**） |
| 4 | **与转让房地产有关的税金** | 城建税、教育费附加、地方教育附加；**房企的印花税已计入管理费用，不再单独扣除**；非房企可扣印花税 |
| 5 | **加计扣除** | 仅**从事房地产开发**的纳税人可加计：**(1+2) × 20%**；非房企不得加计 |

**开发费用的两种算法（二选一，选定后不得混用）**：

- 能按转让项目分摊利息、并能提供金融机构证明的：**利息 + (1+2) × 5% 以内**（利息不得超过按商业银行同类同期贷款利率计算的金额）
- 不能分摊利息或不能提供证明的：**(1+2) × 10% 以内**

**利息的坑**：超过贷款期限的利息、加罚利息不得扣除；全部使用自有资金、无利息支出的，只能按 (1+2) × 10% 以内计算。

## 四、税率：四级超率累进 + 速算扣除

| 增值额与扣除项目金额之比 | 税率 | 速算扣除系数 |
|---|---|---|
| 未超过 50% | **30%** | 0 |
| 超过 50%、未超过 100% | **40%** | 5% |
| 超过 100%、未超过 200% | **50%** | 15% |
| 超过 200% | **60%** | 35% |

```
增值额 = 转让收入 − 扣除项目金额合计
增值率 = 增值额 ÷ 扣除项目金额合计
应纳税额 = 增值额 × 税率 − 扣除项目金额合计 × 速算扣除系数
```

**算一遍（示范）**：

| 项 | 金额（万元） |
|---|---|
| 转让收入 | 10,000 |
| 取得土地使用权支付金额 | 2,000 |
| 房地产开发成本 | 4,000 |
| 开发费用（不能分摊利息，按 (1+2)×10%） | 600 |
| 税金（城建税及附加） | 100 |
| 加计扣除（(2,000+4,000)×20%） | 1,200 |
| **扣除项目合计** | **7,900** |
| 增值额 | 2,100 |
| 增值率 | 2,100 ÷ 7,900 = **26.6%** → 30% 档，速算扣除 0 |
| **应纳税额** | 2,100 × 30% = **630** |

## 五、普通住宅优惠（唯一的大额优惠，条件卡得很死）

纳税人建造**普通标准住宅**出售，**增值额未超过扣除项目金额 20% 的，免征**土地增值税；超过 20% 的，**全额计税**（不是只对超过部分计税）。

- "普通标准住宅"按**当地**规定的面积与价格标准认定（浙江省有具体标准，按项目所在地执行）。
- **必须分别核算**：普通住宅与非普通住宅（以及商业等其他类型）**分别计算增值额**；未分别核算或核算不清的，**不得享受免税**，且可能被从高适用。
- 一处项目里既有普通住宅又有商铺，**先分类型再算**，不能合并算完再套优惠。

## 六、预征与清算补退

- 预售阶段按当地**预征率**预缴（各地按类型分档，查台州现行规定）；预征率不是最终税负。
- 清算后：应缴 > 已预缴 → 补税；应缴 < 已预缴 → **可申请退还**（需按规定办理，不是自动退）。
- 清算后再转让剩余房产的，按**清算时的单位建筑面积成本费用**计算扣除，不再重新清算。

## 七、清算底稿清单（做清算要准备的）

1. 项目立项、规划许可、预售许可、竣工验收备案
2. 土地出让合同、地价款缴纳凭证、契税完税凭证
3. 施工合同、结算书、发票（**建筑安装发票必须齐全，白条不得扣除**）
4. 拆迁补偿协议与支付凭证
5. 公共配套设施移交证明
6. 销售明细表（房号、面积、单价、合同金额、收款时间）
7. 预征申报表与完税凭证
8. 利息支出凭证与金融机构证明（用 5% 口径时必备）
9. 普通住宅认定资料（面积、价格）
10. 成本分摊方案（按建筑面积/可售面积/占地面积，**方法要一贯**）

## 八、常见错误

1. **开发费用据实扣除**——费用不是据实扣，是 5% 或 10% 计算。
2. **加计 20% 给了非房企**——只有房地产开发企业能加计。
3. **普通住宅优惠合并计算**——普通与非普通未分别核算，优惠直接没了。
4. **印花税重复扣**——房企印花税已进管理费用，再单独扣就是重复。
5. **成本分摊方法中途更换**——前期按面积、后期按售价，清算必被调。
6. **预征款漏并收入**——只算合同额，忘了价外费用与视同销售。
7. **建筑安装发票不合规**——白条、收据入成本，清算时全额剔除，补税金额往往远超服务费。

> **红线**：土增清算是税务里**技术密度最高、争议最多**的一块。金额大、口径多、地方差异明显，**超出能力范围的直接说要请税务师事务所做鉴证**（cta 上游有鉴证报告骨架，但签字要资质）。不要"先按我的算法报上去试试"。
