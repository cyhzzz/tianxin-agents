# 07 股权转让个税与社保费

> 天信原创。上游银橙只在核查清单里各提了一句（"财产转让计税依据是否明显偏低""社保基数是否与工资总额匹配"），没有口径。本文件补两块。
> 依据：《个人所得税法》及实施条例、《股权转让所得个人所得税管理办法（试行）》（国家税务总局公告 2015 年第 67 号）、《印花税法》。**具体征管要求以浙江/台州税务机关现行规定为准。**

## 一、股权转让个税：基本公式

```
应纳税所得额 = 股权转让收入 − 股权原值 − 合理费用
应纳税额 = 应纳税所得额 × 20%（财产转让所得）
```

| 要素 | 怎么定 |
|---|---|
| **纳税人** | 转让方（自然人股东） |
| **扣缴义务人** | **受让方**（企业或个人）；受让方未扣缴的，转让方自行申报 |
| **申报地点** | 被投资企业**所在地**主管税务机关 |
| **申报时限** | 股权转让行为发生后**次月 15 日内**（以工商变更、协议生效、款项支付等先发生者为准） |
| **股权原值** | 实际支付的价款 + 相关税费；以非货币性资产出资取得的，按投资时该资产的评估价 + 税费 |
| **合理费用** | 印花税、评估费、中介费、公证费等直接相关费用（**需凭证**） |

**股权原值不能乱定**：以现金出资的按实缴金额；以未分配利润/盈余公积转增的，按转增额计入；以股权激励取得的，按实际支付价款。**没有凭证的"原值"不予认可**。

## 二、收入"明显偏低"就会被核定（这是本条最常出事的地方）

**明显偏低的四种情形**（税务机关可核定）：

1. 申报的转让收入**低于股权对应的净资产份额**
2. 低于**初始投资成本**
3. 低于**相同或类似条件下同一企业同一股东**、或**其他股东**转让的股权价格
4. 不具有合理理由的**无偿让渡**股权

**正当理由**（有其一，可不核定）：

- 能证明被投资企业因国家政策调整、经营受影响导致**低价转让**
- 继承或将股权转让给**配偶、父母、子女、祖父母、外祖父母、孙子女、外孙子女、兄弟姐妹**及承担直接抚养/赡养义务的人
- 相关法律、政府文件或企业章程规定，并有资料充分证明转让价格合理
- 员工**持股计划**内部转让，且不涉及外部人员
- 其他合理情形

**核定方法**（顺序适用）：

| 方法 | 做法 |
|---|---|
| **净资产核定法**（最常用） | 按每股净资产或股权对应净资产份额核定；净资产需**评估**的（如土地使用权、房屋、股权等占比超 20%），按评估值 |
| 类比法 | 参照相同或类似条件下同一企业其他股东、同类行业企业的转让价格 |
| 其他合理方法 | 上述无法核定时 |

**净资产口径**：以转让时点（协议签订日或工商变更日，按当地口径）的**账面净资产**为基础；有评估要求的按评估净资产。

## 三、六种常见情形怎么处理

| 情形 | 处理 |
|---|---|
| **平价/象征性价格转让给外人** | 大概率被按净资产核定，补 20% 个税 + 滞纳金 |
| 转让给**直系亲属** | 属正当理由，可不核定；但仍需**申报**（零税额也要申报） |
| **继承** | 不征个税；再转让时原值按继承前原值确定 |
| **未实缴出资**转让 | 原值为实际已缴部分；转让收入明显高于原值的，差额计税；**认缴未缴部分不能在原值中扣除** |
| **多次转让** | 每次单独计税，前次已税部分体现在本次原值中 |
| 转让**合伙企业财产份额** | 按"财产转让所得"20%（不是经营所得）；口径与公司股权类似，注意地方差异 |
| 个人转让**上市公司股票** | 境内上市公司流通股**暂免**个人所得税（限售股除外，限售股按财产转让所得计税） |

## 四、印花税（别漏，金额小但检查必看）

- 股权转让书据属**产权转移书据**，按《印花税法》税率 **0.05%**（万分之五）由**立据双方各自**缴纳。
- 计税依据为**列明金额**；未列明金额的按实际结算金额。
- 小规模纳税人、小微企业可享受"六税两费"减半（按现行政策，注意执行期限）。

## 五、社保费：税务侧只管三件事

社保申报与缴费在**代账线**（「天信代账作业」技能的社保公积金申报一节），税务线只管这三件：

| 事项 | 口径 |
|---|---|
| **企业所得税前扣除** | 企业为职工缴纳的基本社保与公积金，**据实扣除**；**补充养老/补充医疗**在职工工资总额 5% 以内可扣（超出不得扣）；为**非本企业员工**缴纳的社保不得扣除 |
| **个人所得税** | 单位缴的部分不计入个人所得；个人缴的部分作为**专项扣除**在综合所得中扣除（需与社保申报数一致） |
| **欠费影响** | 社保欠费会进纳税信用评价与联合惩戒，间接影响发票领用与出口退税；代账客户欠费要书面提示 |

**两个高频错误**：

- 把"商业保险"当社保扣除——商业保险一般不得扣除（特殊工种人身安全保险等例外）。
- 工资表、个税申报、社保申报三处人数或基数不一致——金税系统比对会直接弹出风险提示。

## 六、红线

- **不设计"阴阳合同"**：一份报税、一份实际，是逃税，不是"税务安排"。
- **不建议"零元转让"过关**：无正当理由的无偿转让必被核定，且可能触发反避税调查。
- **不承诺"核定不下来"**：能不能按低价过，由税务机关判断，我们只负责把资料做扎实、把风险说清。
- 涉及**上市公司限售股、跨境股权、股权激励、并购重组**的 → 转持证税务师/税务师事务所，不在所内处理。

> 一句话记法：**股权转让个税看"净资产"，土增清算看"扣除五项"，社保看"三处一致"。**
