# 发票合规审查

> 代账客户送来的票，**先审票再记账**。票有问题，记进去就是替客户担风险。
> 审票只做两件事：这张票能不能用（合规性）、这笔业务真不真（实质性）。前者看票面，后者看证据链。

## 一、票面要件：六项缺一项就不能用

| 要件 | 检查点 |
|---|---|
| **购买方信息** | 名称、纳税人识别号**一字不差**（含括号全半角、有无"有限公司"后缀）；地址电话开户行非必填，但专票建议填全 |
| **货物或应税劳务名称** | 必须是**具体品名**，不能是"办公用品""材料一批""综合费用"这类笼统名称（需附清单的除外） |
| **规格型号、单位、数量、单价** | 服务类可空；货物类必须填，且与合同、入库单一致 |
| **金额、税率、税额** | 三者必须自洽：`税额 = 金额 × 税率`；税率与该业务适用税率一致 |
| **开票日期** | 与业务发生期间匹配；跨年发票要判断归属期 |
| **开票方签章** | 数电票为电子签名，纸票为发票专用章 |

**数电票（全面数字化电子发票）**：与纸质发票具有同等法律效力（增值税法明确，2026-01-01 起）。核验方式变为在电子发票服务平台查验，票面没有发票专用章，靠电子签名。**不能因为"没有红章"就判为不合规。**

## 二、七类异常发票：识别与处置

### 2.1 虚开发票（最严重）

**三种形态**（依据：国税发〔1996〕210 号、国家税务总局公告 2010 年第 22 号）：

| 形态 | 表现 |
|---|---|
| 无货虚开 | 没有真实交易，凭空开票 |
| 有货不实开 | 有交易，但金额、数量、品名与实际不符 |
| 让他人代开 | 有真实业务，但开票方不是实际交易方（如让关联公司开票） |

**识别信号**（出现两条以上就要查）：

- 供应商与合同签约方、收款方**三者不一致**
- 资金回流：付款后短期内经个人账户或其他关联方转回
- 品名与客户经营范围明显不符（做建材的收到"技术咨询费"）
- 开票方为异地且无实际经营场所
- 同一供应商短期内为多个不相关行业客户开票
- 金额整齐（整数、大额），无零头
- 发票开具时间集中在月末、季末

**处置：一律提请合伙人，不建议客户自行处理。** 虚开专票是刑法第 205 条的刑事风险，不是补税能了结的。本 skill 只做识别，不做方案。

### 2.2 异常增值税扣税凭证（走逃失联企业）

**依据**：国家税务总局公告 2019 年第 38 号。

**列入异常凭证的五种情形**：

| # | 情形 |
|---|---|
| 1 | 纳税人**丢失、被盗税控专用设备**中已开具未上传的发票 |
| 2 | **非正常户**未向税务机关申报或未按规定缴纳税款的发票 |
| 3 | 增值税发票管理系统稽核比对发现**"比对不符""缺联""作废"**的发票 |
| 4 | 经**大数据分析**发现涉嫌虚开、未按规定开具的发票 |
| 5 | 税务总局认定的其他情形 |

**处理规则**：

```
尚未申报抵扣的 → 暂不允许抵扣
已申报抵扣的   → 除另有规定外，一律作进项税额转出
已申请出口退税 → 按现行规定处理，可能被追回
```

**关键点**：转出是**先转出再说**，不是"等查清楚"。客户如果要申辩，走的是"申请核实"程序，但税款要先转出。**所以供应商筛选比事后申辩重要得多**——新供应商先查一下是否正常户。

### 2.3 善意取得虚开专票（有救的一类）

**依据**：国税发〔2000〕187 号。

**四个条件同时满足**才构成"善意取得"：

1. 购货方与销售方存在**真实交易**
2. 销售方使用的是其**所在省的专用发票**
3. 专用发票注明的销售方名称、印章、货物数量、金额及税额等**全部内容与实际相符**
4. 没有证据表明购货方知道销售方提供的专用发票是以非法手段获得的

**后果**：不以偷税或骗取出口退税论处，**但不得抵扣进项、不予退税**。
**出路**：能重新取得合法有效专用发票的，准予抵扣。

> 这一条的价值在于：**证明"真实交易"能免掉偷税的定性。** 所以合同、付款凭证、入库单、运输单据、验收记录这些证据链，平时就要留。出事时再找，就找不齐了。

### 2.4 过期/超期发票

认证确认期限自 2020-03-01 起**已取消**（国家税务总局公告 2019 年第 45 号），不再有 360 天的限制。

**但"不过期"不等于"可以随便抵"**：
- 跨年发票的所得税扣除，按权责发生制归属年度；汇缴期结束前取得的可追溯扣除，之后取得的要追补到发生年度（追补年限不超过 5 年）。
- 上年度费用在汇缴后才取得发票的，需专项申报追补。

### 2.5 不合规发票（票面瑕疵）

| 瑕疵 | 后果 |
|---|---|
| 抬头错误、税号错 | 不得作为抵扣凭证，也不得税前扣除 |
| 品名笼统（"办公用品"无清单） | 不得税前扣除 |
| 备注栏该填未填（见 §三） | 特定业务不得扣除 |
| 发票专用章模糊、错章 | 需重开 |
| 机打发票压线、错格 | 需重开 |
| 复印件、拍照件入账 | 不得作为原始凭证（除按规定可复制的） |

### 2.6 大额现金交易发票

**判断点是业务合理性，不是金额本身**：
- 现金支付的采购，有没有入库单、验收人签字？
- 收款方是个人还是单位？个人大额现金收款，是否存在代开、挂靠？
- 同一供应商反复现金交易，为什么不走对公？

### 2.7 关联方发票

**三个必查**：
- 价格是否公允（同产品卖给非关联方多少钱）
- 有没有真实货物/服务流（合同、出库、验收）
- 资金是否回流（形成闭环就是虚开）

## 三、特殊业务的备注栏要求

**备注栏该填未填，是实务中最容易漏、后果最直接的一类**——不得作为抵扣凭证，也不得税前扣除。

| 业务 | 备注栏必须注明 |
|---|---|
| 建筑服务 | 建筑服务发生地县（市、区）名称 + 项目名称 |
| 销售不动产 | 不动产详细地址 + 产权证书号 + 面积单位 |
| 货物运输服务 | 起运地、到达地、车种车号、货物信息（内容较多可附清单） |
| 差额征税 | "差额征税"字样（开票系统自动带出） |
| 出租不动产 | 不动产详细地址 |
| 代收车船税 | 代收车船税税款信息 |

## 四、开票操作常见错误

**这些是开票方（很多时候就是代账方代开）会犯的**：

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 税率开错（如服务开 13%） | 购买方不得抵扣，需红冲重开 | 按业务实质定税率；不确定的按"从高"风险更大，先问 |
| 免税业务开了专票 | 违反免税规定，需追回 | 免税业务只能开普票（国有粮食企业等特例除外） |
| 混合销售未按主要业务定税率 | 税率适用错误 | 一项交易多税率 → 按主要业务；多项交易 → 分别核算 |
| 跨年冲红 | 影响两个年度的申报 | 当期发现当期红冲；跨年的要同步调整汇缴 |
| 作废发票未全联次收回 | 可能被认定为违规 | 作废要收回全部联次并注明"作废" |
| 为未发生的业务预开票 | 虚开风险 | 按纳税义务发生时间开 |

**红冲的规矩**：专票红冲需按规定流程（购买方已抵扣的由购买方填开红字信息表；未抵扣的由销售方填开）。普票红冲相对简单，但也要留痕。

## 五、审票清单（每批票过一遍）

```
□ 1. 票面六要件齐全（购买方信息 / 品名 / 数量单价 / 金额税率税额自洽 / 日期 / 签章）
□ 2. 购买方名称与税号与本企业完全一致
□ 3. 品名具体，非"办公用品""材料一批"（有清单的看清单）
□ 4. 税率与该业务适用税率一致
□ 5. 开票方在正常经营状态（新供应商必查）
□ 6. 合同、付款、发票三者主体一致
□ 7. 有货物/服务的交付证据（入库单/验收单/成果物）
□ 8. 特殊业务备注栏已按规定填写
□ 9. 大额现金交易有合理性说明
□ 10. 关联方交易价格公允、有真实业务流
□ 11. 汇总开票的附有税控系统开具的清单
□ 12. 无重复报销（同张票号只报一次，台账登记）
```

**第 5 项怎么做**：登录全国增值税发票查验平台 `inv-veri.chinatax.gov.cn` 或电子税务局，输入发票代码、号码、开票日期、金额、校验码后六位。数电票在电子发票服务平台查验。**新供应商第一批票必须查，老供应商抽查。**

**第 12 项为什么单列**：重复报销是员工层面最常见的舞弊，也是代账最容易背锅的地方——票是真的，业务也是真的，但报了两次。台账能防住。

## 六、红线

**一、虚开是刑事风险，不是税务风险。**

《刑法》第 205 条：虚开增值税专用发票，处三年以下有期徒刑或拘役；数额较大或有其他严重情节的，三年以上十年以下；数额巨大或情节特别严重的，十年以上或无期。

**受票方也可能构成犯罪**（让他人为自己虚开，同样属于虚开）。所以"我们只是收票的"不是免责理由。

**发现虚开苗头时的动作顺序**：
1. **停止**——不再接受该供应商的票，不再为其开票
2. **保留**——合同、付款记录、往来沟通，全部留档（这些是后续证明善意的关键）
3. **上报**——提请合伙人，不自行处置
4. **建议**——客户咨询专业律师，本所不出处置方案

**二、不做"票货分离"的安排。**

客户要求"货从 A 买、票从 B 开"，无论理由多合理（B 是 A 的关联公司、A 没票、B 有税收优惠），都是虚开。没有例外。

**三、不代客户"找票"。**

客户缺成本票，问"能不能想办法"，答案是不能。可以提供的是：梳理真实发生的支出、补齐合规凭证、用足法定优惠。**帮客户找票，是把自己的执业资格押上去。**

**四、审票结论要留痕。**

每批票的审查结果写进工作记录：查了什么、结论是什么、有问题的怎么处理。事后追责时，这份记录是唯一的证明。
