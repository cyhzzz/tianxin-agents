# 税务风险指标

> **先说清一件事：下面所有阈值都是经验值，不是法定标准。**
> 没有一个文件规定"税负率偏差 30% 就违法"。这些数是税务机关风险管理系统里常见的预警参考区间，用来**主动发现问题**，不是用来给客户下结论的。
> 真正定性的依据永远是：账、凭证、合同、实际业务。指标只是提示"这里该看一眼"。

## 一、为什么要自己先扫

税务系统的大数据比对已经常态化。它的比对逻辑不神秘，就是**拿你的申报数与其他来源的数对**：

```
申报的销售额  ←→  开票数据（金税系统）
申报的进项    ←→  上游企业的销项（链条比对）
申报的工资    ←→  社保缴纳人数与基数
申报的收入    ←→  银行流水、平台流水、海关数据
申报的房产原值 ←→  不动产登记信息
```

**被推风险提示之后，解释成本远高于自查成本。** 客户被约谈一次，代账方的信任就掉一层；被查补一次，下一年的服务费就得打折。所以每年至少一次自查，比事后补救便宜得多。

## 二、七个指标：算法、阈值、含义

### 2.1 增值税税负率

```
增值税税负率 = 本期应纳增值税额 ÷ 本期应税销售额 × 100%
```

**注意分母是"应税销售额"，不含免税销售额。** 含进去会把税负率算低，误判为正常。

| 判定 | 参考区间 |
|---|---|
| 正常 | 与行业参考值偏差在 ±30% 内 |
| 偏低预警 | 低于行业参考值 30% 以上 |
| 偏高 | 高于行业参考值 30% 以上（多为进项取得不足，客户多缴了） |

**"行业参考值"从哪来**（这是落地时第一个卡住的地方，按顺序找）：

1. **主管税务机关发布的行业预警值** —— 最权威，直接问税源管理部门或看电子税务局的风险提示。
2. **当地同行** —— 县城所的优势：同行业客户横向比。做建材的几户一比，异常的那户立刻显出来。
3. **上市公司/行业报告** —— 粗略参考，规模差异大，只能看数量级。
4. **本所历史数据** —— 同一客户逐年比，比跨企业比更有意义。

**税负率偏低说明什么**（逐条排，不要直接跳到"有问题"）：

| 可能原因 | 是否合理 | 怎么核实 |
|---|---|---|
| 本期有大额进项（设备采购、备货） | 合理，但要能说明 | 查采购合同、发票、入库单 |
| 销售结构变化（低税率业务占比上升） | 合理 | 查分档销售额 |
| 享受了免税/减征优惠 | 合理 | 查优惠依据 |
| 有留抵抵减 | 合理 | 查留抵台账 |
| **隐匿收入、未开票收入未申报** | **不合理** | 银行流水与账面双向核对 |
| **虚增进项、接受虚开发票** | **不合理** | 查供应商、货物流、资金流是否一致 |

### 2.2 进销项比率

```
进销项比率 = 本期进项税额 ÷ 本期销项税额 × 100%
```

| 判定 | 参考区间 |
|---|---|
| 正常 | 60%–85%（因行业而异，商贸企业偏高） |
| 预警 | **持续 > 90%**（长期几乎不缴税） |
| 异常 | > 100%（长期留抵，需解释合理性） |

**持续 > 90% 为什么敏感**：意味着企业长期"进多少抵多少"，几乎不产生应纳税额。这在商贸企业可能是薄利走量，但在服务、加工类企业就说不通——没有那么多物料可抵。

**长期留抵的真实原因**（要能说清）：
- 建设期集中采购（新厂、新店装修）
- 大额设备投入
- 出口企业（免抵退，留抵正常）
- 季节性备货（旺季前）
- **隐瞒收入**（销项少报，进项照抵）

### 2.3 毛利率异常

```
毛利率 = (营业收入 − 营业成本) ÷ 营业收入 × 100%
```

| 判定 | 说明 |
|---|---|
| 与同行业、本企业历史相比**偏离 30% 以上** | 需解释 |
| 毛利率连续多年为负 | 除非有明确原因（新市场开拓、清库存），否则不成立 |
| 毛利率大幅低于同行但规模在扩张 | 典型的"隐匿收入"特征——收入少报，成本照记，毛利被压缩 |

**这条比税负率更能说明问题。** 税负率受进项结构影响，毛利率直接反映收入与成本的匹配关系。收入少报而成本真实，毛利率必然塌下来。

### 2.4 费用率异常

```
期间费用率 = (销售费用 + 管理费用 + 财务费用) ÷ 营业收入 × 100%
```

| 判定 | 说明 |
|---|---|
| 费用率显著高于同行 | 可能：期间费用混入个人消费、虚列费用套取资金 |
| 费用率显著低于同行 | 可能：费用计入成本、或者关联方代垫 |
| 某一费用项目突然大幅增长 | 逐项看，尤其"咨询费""服务费""会议费" |

**重点盯三类费用**（虚开高发区）：
- **咨询费 / 服务费** —— 有没有真实服务成果？合同、成果物、交付记录在不在？
- **会议费** —— 有没有会议通知、签到表、场地发票、议程？
- **差旅费** —— 与业务规模匹配吗？有没有与个人旅游混同？

### 2.5 往来款异常

**不看比率看账龄。** 长期挂账的往来款是两类问题的信号：

| 科目 | 预警线 | 可能的问题 |
|---|---|---|
| 应收账款 | 账龄 > 1 年占比高 | 收入虚增（货没发就确认）／ 坏账未处理 |
| 预付账款 | 账龄 > 6 个月 | 资金外流（预付给关联方）／ 虚开发票的资金回流通道 |
| 其他应收款 | 余额大、长期不动 | **股东借款**——跨年未还且未用于经营，视同分红征 20% 个税 |
| 其他应付款 | 余额大、长期不动 | **隐匿收入**——收了钱不确认收入，挂在往来 |
| 应付账款 | 长期大额挂账 | 成本虚增（无真实采购）／ 已付款但未核销 |

> **其他应收款里的股东借款是县城所最常见的个税风险。** 财税〔2003〕158 号：纳税年度内个人投资者从其投资企业借款，在该纳税年度终了后既不归还、又未用于企业生产经营的，视同股息红利分配，按 20% 征个税。每年 12 月 31 日前必须提醒客户处理。

### 2.6 现金交易占比

```
现金交易占比 = 现金收款金额 ÷ 营业收入 × 100%
```

| 判定 | 说明 |
|---|---|
| 有合理业务场景（零售、餐饮、农贸） | 正常，但要有现金日记账、POS 记录 |
| 一般制造业/服务业现金收款占比高 | 异常，是隐匿收入的典型手法 |
| 大额现金收支无合理解释 | 高风险 |

**关键不是比例，是有没有痕迹。** 收现金不入账，是收入少报最常见的方式。查的时候看：银行流水与账面收入的差额、现金日记账的完整性、个人账户收款。

### 2.7 关联交易集中度

```
关联交易占比 = 关联方销售(采购)金额 ÷ 全部销售(采购)金额 × 100%
```

| 判定 | 说明 |
|---|---|
| > 50% | 需关注转让定价是否符合独立交易原则 |
| 关联方之间价格明显偏离市场 | 高风险，可能被特别纳税调整 |

**县城所客户的实际情况**：多数小客户没有关联交易，这一条可以略过。**但只要出现"老板名下有两三家公司、互相开票"，就必须看**——这是虚开和利润转移的高发结构。

判断要点：
- 有没有真实货物/服务流？（合同、出库单、验收单）
- 资金是否回流？（A 付给 B，B 转给老板个人，再回 A）
- 价格是否公允？（同产品卖给非关联方多少钱）

## 三、按风险等级分类处置

扫描完不是列一堆"存在风险"，要分级、给动作。

| 等级 | 特征 | 处置 |
|---|---|---|
| 🔴 **高** | 涉及虚开、隐匿收入、股东借款未还、已废止优惠继续享受 | **立即处理**。主动更正、补税、留存说明。涉及虚开的提请合伙人，必要时建议客户咨询律师 |
| 🟡 **中** | 指标偏离但能解释、凭证不完整、优惠依据缺失 | **限期补齐**。列清单，约定完成时间，补齐后归档 |
| 🟢 **低** | 指标小幅偏离、账务处理不规范但金额小 | **下期改进**。在服务记录里写一条，下次做账时调整 |

### 自查报告结构

```
## 税务风险自查报告

企业：{全称}    期间：{YYYY-MM-DD} 至 {YYYY-MM-DD}    纳税人身份：{}

### 一、结论
{合规 / 基本合规需整改 N 项 / 存在重大风险需立即处理}

### 二、指标扫描
| 指标 | 本期值 | 参考值 | 偏差 | 判定 |

### 三、发现清单
按风险等级分组，每项写：问题描述 / 涉及金额 / 依据 / 处置建议 / 责任人 / 期限

### 四、需要客户确认的事项
{客户才能回答的问题，逐条列}

### 五、本次未覆盖的范围
{明确写出没查什么，避免被理解为"全面审计"}
```

**第五节不能省。** 自查不是审计，范围有限。写清边界既是对客户负责，也是对自己的保护。

## 四、几条判断纪律

**一、指标异常不等于有问题，指标正常不等于没问题。**

税负率正常但收入全走个人账户的，指标上看不出来。反过来，新办企业前两年税负率天然偏低，报"异常"是浪费客户时间。**指标是入口，不是结论。**

**二、先问业务，再看账。**

看到毛利率低，先问"今年是不是打了价格战""有没有新开的店在爬坡"。客户一句话能解释的事，不要先入为主地怀疑。**问完之后再决定要不要深查。**

**三、不确定的写"待确认"，不要写成结论。**

"应收账款账龄超过 1 年的占 45%，需确认是否存在虚增收入或坏账未核销"——这是对的。
"该公司虚增收入"——这是错的，你没法从账龄推出来。

**四、涉及虚开的，一律往上交。**

虚开增值税专用发票是刑事风险（刑法第 205 条），不是补税能解决的。本 skill 只做识别与提示，不做处置方案。发现苗头：停止操作、保留证据、提请合伙人、建议客户咨询专业律师。

**五、自查结果不外传。**

风险清单是客户的商业秘密，也是所的执业记录。不进示例、不进公共仓库、不在群里传。
