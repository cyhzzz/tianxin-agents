# 税种计算规则

> 读这份之前先定身份：一般纳税人还是小规模、查账还是核定、什么行业。同一个客户，身份不同算法完全不同。
> 税率数值见 `01-税率与优惠速查.md`，这里只讲**怎么算**。

## 一、通用计算顺序：先增值税，再其他的

**增值税是龙头。** 城建税、教育费附加、地方教育附加的计税依据就是增值税额，增值税算错，后面三个全错。所以顺序固定：

```
增值税 → 附加税费（依赖增值税额）→ 企业所得税（利润受前两者影响）
                                  → 个税（独立，但要与工资表勾稽）
                                  → 印花税（独立，按合同/账簿）
                                  → 房产税、土地使用税（独立）
```

**唯一的例外**：企业所得税的"税金及附加"里含附加税费，所以附加税费要先算完，才能算准利润总额。这不是循环依赖——附加税费按增值税算，增值税不依赖利润。

## 二、增值税

### 2.1 一般纳税人：一般计税

```
应纳税额 = 当期销项税额 − 当期可抵扣进项税额
销项税额 = 不含税销售额 × 适用税率
不含税销售额 = 含税销售额 ÷ (1 + 适用税率)
```

**进项税额的三类来源**：

| 来源 | 抵扣凭证 |
|---|---|
| 增值税专用发票 | 发票上注明的税额 |
| 海关进口增值税专用缴款书 | 缴款书上注明的税额 |
| 农产品收购发票/销售发票 | 买价 × 扣除率（9% 或 10%） |
| 通行费电子普通发票、国内旅客运输凭证 | 按规定计算的税额 |

> **认证确认期限自 2020-03-01 起已取消**（国家税务总局公告 2019 年第 45 号）。取得专票不再有 360 天的认证期限，但**这不等于可以无限期放着不管**——抵扣所属期与收入所属期错配，仍会被系统比对出来。

**计算步骤**（顺序不要乱）：

```
① 按税率分档归集销售额：13% 档、9% 档、6% 档分别汇总
     ↓ 未分别核算的，从高适用（这一步不做，后面全错）
② 逐档算销项税额
     ↓
③ 归集可抵扣进项，剔除不得抵扣的（见 2.3）
     ↓
④ 兼营免税/简易计税的，按公式分摊转出
     ↓
⑤ 销项 − 进项 = 应纳税额；负数形成留抵
     ↓
⑥ 有加计抵减的，再减加计抵减额（不改变留抵，只能减应纳税额）
```

**算例：兼营不同税率，分别核算 vs 混算**

某一般纳税人本期：销售货物含税 113 万，提供技术服务含税 106 万。

| 处理方式 | 销项税额 | 差额 |
|---|---|---|
| 分别核算 | 100×13% + 100×6% = **19 万** | — |
| 未分别核算，从高适用 13% | 200×13% = **26 万** | **多缴 7 万** |

这就是为什么代账必须把不同税率业务分科目记。客户图省事全记"主营业务收入"，一年多缴的税够付几年服务费。

### 2.2 小规模纳税人：简易计税

```
应纳税额 = 不含税销售额 × 征收率
不含税销售额 = 含税销售额 ÷ (1 + 征收率)
```

**征收率**：法定 3%，2026-01-01 至 2027-12-31 期间**减按 1%**（2026 年第 10 号）。

**免税判定（最容易做错的一步）**：

```
第一步：算季度（或月）合计销售额（含免税、含普票、含专票，不含税额）
第二步：≤ 30 万（季）/ 10 万（月）？
          ├─ 是 → 普票部分免征；**专票部分不免，照章纳税**
          └─ 否 → 全部销售额照章纳税（不再有免税额度）
```

**算例：开了专票的季度，28 万也要交税**

某小规模纳税人 2026 年三季度：销售货物开**增值税普通发票** 20 万（不含税），提供咨询服务开**专用发票** 8 万（不含税），合计 28 万。

| 部分 | 金额 | 处理 | 税额 |
|---|---|---|---|
| 普票销售货物 | 20 万 | 季度合计未超 30 万，免征 | 0 |
| 专票咨询服务 | 8 万 | 开专票的部分**不得免税**，按 1% 征收 | **800 元** |
| 合计 | 28 万 | | **800 元** |

**常见错误**：看到"季度 28 万 < 30 万"就全额申报免税。开了专票的部分对方已用于抵扣，这边不缴就是链条断裂，系统一比就出来。

**再算例：超了额度，全额纳税**

同上一户，若三季度普票 24 万 + 专票 8 万 = 32 万 > 30 万：

```
全部销售额 32 万 × 1% = 3,200 元
```
**不是**"30 万以内免、超出 2 万缴税"。免税额度是**全额免征或全额征税**的开关，不是扣除额。

### 2.3 不得抵扣的进项与转出

| 情形 | 判断要点 |
|---|---|
| 用于集体福利、个人消费 | 食堂、宿舍、职工福利发放、旅游 |
| 用于免税项目 | 兼营免税业务的，按销售额比例分摊 |
| 用于简易计税项目 | 简易计税项目对应的进项不得抵 |
| 非正常损失 | **管理不善**造成的被盗、丢失、霉烂变质 → 转出；**自然灾害**损失 → **不转出** |

**分摊公式**（无法划分的进项）：

```
不得抵扣的进项税额 = 当期无法划分的全部进项税额
                    × (当期免税项目销售额 + 简易计税项目销售额) ÷ 当期全部销售额
```

**算例**：某企业当期无法划分的进项 10 万，全部销售额 500 万，其中免税项目 100 万。
```
不得抵扣 = 10 × 100 ÷ 500 = 2 万 → 转出 2 万，可抵 8 万
```

### 2.4 加计抵减（仅三类主体）

```
当期计提加计抵减额 = 当期可抵扣进项税额 × 加计比例
当期可抵减加计抵减额 = 上期末余额 + 当期计提 − 当期调减
```

**三个约束**：
- 只能减**应纳税额**，不能增加留抵（当期应纳税额为 0 的，加计抵减额结转下期，不退钱）。
- 不得抵扣的进项不得计提；已计提后又转出的，转出当期同步调减。
- 加计抵减额**不调整进项税额**，会计上计入"其他收益"（执行企业会计准则）或冲减费用，不影响进项账。

## 三、企业所得税

### 3.1 应纳税所得额的推导链（核心公式）

```
会计利润总额
  ± 纳税调整增加额（调增）
  ± 纳税调整减少额（调减）
= 纳税调整后所得
  − 弥补以前年度亏损
  − 免税、减计收入及加计扣除
= 应纳税所得额
  × 适用税率 − 减免税额 − 抵免税额
= 应纳税额
```

**注意"利润总额"和"应纳税所得额"是两个东西。** 小微企业判定看的是**应纳税所得额**（调整后），不是利润总额。很多客户拿利润表上的数直接比 300 万，会判错。

### 3.2 纳税调整项目清单（按大类，不编行次）

行次以《企业所得税年度纳税申报表（A 类，A100000）》及各明细表为准，这里只列**调什么**：

**收入类**
| 项目 | 方向 | 说明 |
|---|---|---|
| 视同销售 | 调增 | 将货物用于捐赠、赞助、职工福利、利润分配等，会计不确认收入，税法要视同销售 |
| 不征税收入 | 调减 | 财政拨款、依法收取的行政事业性收费、政府性基金（**注意：不征税收入的支出不得扣除，要同步调增**） |
| 免税收入 | 调减 | 国债利息、居民企业间股息红利、符合条件的非营利组织收入 |
| 政府补助 | 视情况 | 与资产相关/与收益相关，看是否作为不征税收入处理 |
| 跨期收入 | 调增/调减 | 会计按完工百分比、税法按收款或完工，口径差异 |

**扣除类**
| 项目 | 方向 | 说明 |
|---|---|---|
| 业务招待费 | 调增 | 发生额 60% 与收入 5‰ **孰低** |
| 广告费和业务宣传费 | 调增 | 超收入 15% 部分，可结转 |
| 职工福利费 | 调增 | 超工资总额 14% |
| 工会经费 | 调增 | 超工资总额 2%，且需拨缴凭证 |
| 职工教育经费 | 调增 | 超工资总额 8%，可结转 |
| 公益性捐赠 | 调增 | 超利润总额 12%，可结转 3 年 |
| 罚金、罚款、滞纳金 | **全额调增** | 行政罚款、税收滞纳金不得扣除（**注意：银行罚息、违约金可以扣**） |
| 赞助支出 | **全额调增** | 非广告性质的赞助 |
| 与收入无关的支出 | **全额调增** | 股东个人消费、家庭开支混入公司账 |
| 手续费及佣金 | 调增 | 超收入 5%（保险 18%） |

**资产类**
| 项目 | 方向 | 说明 |
|---|---|---|
| 折旧年限差异 | 调增/调减 | 税法有最低年限：房屋建筑物 20 年、飞机火车轮船机器机械 10 年、器具工具家具 5 年、运输工具 4 年、电子设备 3 年。会计短于税法的要调增 |
| 减值准备 | **调增** | 坏账准备、存货跌价准备、固定资产减值准备，会计计提但税法不认，**实际发生时才能扣** |
| 资产损失 | 调减 | 实际发生的损失，需留存备查资料（清单申报或专项申报） |

**优惠类**
| 项目 | 方向 |
|---|---|
| 研发费用加计扣除 | 调减（需辅助账） |
| 安置残疾人员工资加计 | 调减 |
| 创投企业抵扣所得额 | 调减 |

### 3.3 小微临界点陷阱（务必点给客户）

**算例**：某企业营业收入 2,000 万，利润总额 295 万，业务招待费实际发生 20 万。

```
业务招待费扣除限额：
  发生额 60% = 12 万
  收入 5‰ = 2,000 × 0.5% = 10 万
  孰低 = 10 万 → 调增 10 万

应纳税所得额 = 295 + 10 = 305 万 > 300 万
→ 不符合小型微利企业条件
→ 全额按 25%：305 × 25% = 76.25 万
```

对照：若招待费只有 4 万（调增 0，假定 60%=2.4万 < 10万，全额可扣），
```
应纳税所得额 295 万 ≤ 300 万 → 小微 → 295 × 5% = 14.75 万
```

**差距：多花 16 万招待费，多缴 61.5 万税。**

这不是理论——县城所客户在 300 万附近徘徊的不少。每年 11–12 月要做一次测算，超了就提示客户：延后确认收入、提前列支可扣费用、或者调整业务节奏。

> 但**不能建议客户做假**。合法的手段是时点安排与真实业务调整，虚构业务、虚开发票是另一回事。

### 3.4 预缴与汇缴

| 阶段 | 时间 | 依据 |
|---|---|---|
| 季度预缴 | 季度终了后 15 日内 | 按实际利润额预缴（多数企业）；按上年度平均数预缴（特定情形） |
| 年度汇缴 | 次年 **5 月 31 日**前 | 全年应纳税所得额，多退少补 |

**预缴不是"大概缴一点"。** 预缴少缴、汇缴补缴的，要按日加收滞纳金（从汇缴期届满次日起算）。预缴多缴的可以申请退税或抵缴下一年度。

## 四、个人所得税

### 4.1 工资薪金：累计预扣法

企业作为扣缴义务人，按月预扣预缴。

```
累计预扣预缴应纳税所得额
  = 累计收入 − 累计免税收入 − 累计减除费用 − 累计专项扣除
    − 累计专项附加扣除 − 累计依法确定的其他扣除

本期应预扣预缴税额
  = 累计预扣预缴应纳税所得额 × 预扣率 − 速算扣除数 − 累计已预扣预缴税额
```

（减除费用按 5,000 元/月累计；专项扣除是三险一金个人部分）

**算例：月薪 2 万，三险一金 3,000，专项附加扣除 2,000**

每月累计应纳税所得额增加：20,000 − 5,000 − 3,000 − 2,000 = **10,000**

| 月份 | 累计应纳税所得额 | 累计税额 | 本月扣缴 |
|---|---|---|---|
| 1 | 10,000 | 10,000×3% = 300 | **300** |
| 2 | 20,000 | 600 | 300 |
| 3 | 30,000 | 900 | 300 |
| 4 | 40,000 | 40,000×10%−2,520 = 1,480 | **580** |
| 5 | 50,000 | 2,480 | 1,000 |
| … | … | … | 1,000/月 |
| 12 | 120,000 | 120,000×10%−2,520 = **9,480** | 1,000 |

**全年 9,480 元**，与直接按年度税率表算一致（120,000×10%−2,520）。

**第 4 个月为什么从 300 跳到 580？** 累计所得跨过 36,000 的档，进入 10% 区间。这是累计预扣法的正常特征，不是算错。客户问起来要能一次说清。

### 4.2 劳务报酬、稿酬、特许权使用费（预扣）

| 项目 | 预扣应纳税所得额 | 预扣率 |
|---|---|---|
| 劳务报酬 | 每次收入 ≤ 4,000 元：收入 − 800；> 4,000 元：收入 ×(1−20%) | 20%/30%/40% 三级 |
| 稿酬 | 同上，再 × 70% | 20% |
| 特许权使用费 | 同上（不减 70%） | 20% |

**年度汇算时并入综合所得**，按 3%–45% 七级重算，多退少补。所以预扣多了不是最终税负，要跟客户讲清楚。

### 4.3 经营所得（个体户、个人独资、合伙企业的自然人合伙人）

```
应纳税所得额 = 收入总额 − 成本 − 费用 − 损失 − 弥补以前年度亏损
              （个体户还可减除 60,000/年 业主生计费）
应纳税额 = 应纳税所得额 × 五级超额累进税率 − 速算扣除数
```

**减半优惠**：年应纳税所得额 ≤ 200 万的部分减半（2023 年第 12 号，至 2027-12-31）。
**算法**：`减免税额 = (应纳税所得额 ≤ 200万的部分 × 税率 − 速算扣除数) × 50%`

> 经营所得**不适用**综合所得的专项附加扣除，个体户业主的生计费是 60,000/年定额。

## 五、附加税费

```
城建税     = (实际缴纳的增值税 + 消费税) × 适用税率（7%/5%/1%）
教育费附加 = (实际缴纳的增值税 + 消费税) × 3%
地方教育附加 = (实际缴纳的增值税 + 消费税) × 2%
```

**三条要点**：

1. **计税依据是"实际缴纳"的增值税**，不是"应纳税额"。有留抵抵掉的部分不缴增值税，也就不缴附加。
2. **有减免时要同步**：增值税免征的，附加税费也免（依据为零）。六税两费减半的，城建税、教育费附加、地方教育附加都在减半范围内。
3. **城建税档次看纳税人所在地**：天台县属县城/镇 → **5%**。填 7% 客户多缴。

**算例**：小规模纳税人季度应缴增值税 3,200 元（32 万 × 1%），天台县，享受六税两费减半。

```
城建税     = 3,200 × 5% × 50% = 80 元
教育费附加 = 3,200 × 3% × 50% = 48 元
地方教育附加 = 3,200 × 2% × 50% = 32 元
附加合计 = 160 元
```

## 六、其他税种

### 6.1 印花税

```
应纳税额 = 计税依据 × 税率
```
- 按**合同所列金额**，不含增值税（合同分别列明不含税金额与税额的，按不含税金额计税；未分别列明的，按含税金额）。
- 同一合同涉及两方以上的，**各自全额计税**，不是分摊。
- 营业账簿只对"实收资本 + 资本公积"合计金额计征，**增资时按增加部分补缴**。

### 6.2 房产税

```
从价计征：应纳税额 = 房产原值 × (1 − 扣除比例) × 1.2%
从租计征：应纳税额 = 租金收入 × 12%（个人出租住房 4%）
```
- 扣除比例由省级确定，浙江按 **30%**。
- **自用 vs 出租要分开**：自用部分从价、出租部分从租，不能一律从价。
- 免租期内的房产由**产权所有人**按房产余值从价计征。

### 6.3 城镇土地使用税

```
应纳税额 = 实际占用土地面积 × 单位税额
```
单位税额按地段等级，由省级确定，**天台县的具体标准必须问主管税务机关**，不要套用其他地区。

### 6.4 土地增值税（四级超率累进）

```
增值额 = 转让收入 − 扣除项目金额
增值率 = 增值额 ÷ 扣除项目金额

增值率 ≤ 50%        → 30%，速算扣除 0
50% < 增值率 ≤ 100% → 40%，速算扣除 5%
100% < 增值率 ≤ 200%→ 50%，速算扣除 15%
增值率 > 200%       → 60%，速算扣除 35%
```
扣除项目包括：取得土地使用权支付的金额、开发成本、开发费用、与转让房地产有关的税金、加计扣除（房地产开发企业按前两项之和加计 20%）。

> 土地增值税超出日常代账范围。天信客户涉及房产转让的，本 skill 只做初步测算，正式申报建议联合税务师事务所。

## 七、算完必做的三项勾稽

算得对不对，靠这三项能抓出大部分错：

| 勾稽项 | 查什么 | 不平时的典型原因 |
|---|---|---|
| **增值税申报表 vs 利润表** | 申报的销售额 ≈ 利润表营业收入（差异要有解释：视同销售、免税收入、跨期） | 收入跨期、把不同税率业务混记、漏报未开票收入 |
| **个税申报 vs 应付职工薪酬** | 个税申报的工资总额 ≈ 账上计提的工资（差异：劳务派遣、离职补偿、非货币福利） | 工资表与账不符、漏报临时工、把劳务报酬按工资报 |
| **附加税费 vs 增值税** | 附加税费的计税依据 = 实际缴纳的增值税 | 城建税档次填错、忘记六税两费减半、留抵抵减后没调整 |

**这三项不平时不要"抹平"。** 每一项差异都要能写出一句解释，写不出来的就是错。
