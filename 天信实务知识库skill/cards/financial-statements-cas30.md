## 一、核心理念

年报审计的**交付物就是一套报表**。审计人员不能只"审"不"编"——很多中小客户的账由天信代理记账或整理，最终要由天信编出符合准则、内部勾稽一致的报表。报表编不平、勾稽对不上，是新手最常卡住的地方。本卡把"编平 + 勾稽"做成速查。

## 二、判断直觉

**① 报表范围**
- 企业准则：**四表一注**——资产负债表、利润表、现金流量表、所有者权益变动表 + 附注。
- 小企业准则：**三表**（资产负债表、利润表、附注；现金流量表可选）。见 `small-business-standards.md`。

**② 核心勾稽关系（必过）**
1. **会计恒等式**：资产 = 负债 + 所有者权益（资产负债表内必须平）。
2. **利润表→资产负债表**：净利润（利润表）经"提取盈余公积 + 分红 + 其他综合收益"调节后，等于资产负债表"未分配利润"的期初期末变动。
3. **现金勾稽**：现金流量表"期末现金及现金等价物余额" = 资产负债表"货币资金"（剔除受限制的保证金等）。
4. **权益勾稽**：所有者权益变动表各权益项目期初期末变动 = 资产负债表权益各栏目变动。

**③ 常见不平原因**
- 漏记/重记凭证；借贷金额不等未察觉。
- 科目错配（如将费用计入资产、将负债计入权益）。
- 权益变动漏项（分红、计提盈余公积、其他综合收益未过账）。
- 未达账项/银行对账差异未调整。
- 以前年度损益调整未计入"未分配利润"期初。

**④ 列报原则**：重要性（不重要的合并或分项）、流动性列报（资产按流动性、负债按到期日）、可比性（上期数须重述可比）。

## 三、准则依据

- 资产负债表按流动性列报：流动资产/非流动资产、流动负债/非流动负债分项。
- 现金流量表分经营/投资/筹资三活动；附注明细披露。
- 附注须披露重要会计政策、会计估计、报表项目明细、或有事项、关联方等。

## 四、天信场景

| 天信场景 | 卡怎么用 |
|---|---|
| 代理记账期末结账 | 先确保试算平衡（资产=负债+权益），再出表 |
| 年报审计编报 | 编完后逐条过"四勾稽"，不平即查原因清单 |
| 客户账套乱/多年未审 | 用"常见不平原因"清单逐项排查 |
| 小企业客户 | 按三表范围出，不强行编现金流 |
| 前期差错更正后 | 同步调整期初未分配利润与可比报表（见 error-correction 卡） |

## 五、演练输出

**输入**：一户企业的科目余额表（资产/负债/权益各科目余额、本期损益、分红与计提数据）。
**输出**：
1. 编制资产负债表并验证恒等式；
2. 编制利润表，将净利润调节至未分配利润变动；
3. 验证现金勾稽（货币资金 vs 现金流表期末现金）；
4. 列出发现的任何不平项及修正建议。
**完成标准**：四勾稽全部通过、不平项有修正路径、报表范围与适用准则一致。
