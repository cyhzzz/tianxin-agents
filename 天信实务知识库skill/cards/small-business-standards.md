## 一、核心理念

天信服务的客户绝大多数符合"中小企业"定位。《小企业会计准则》（财会〔2011〕17号）是为这类企业"减负"的准则：**能简则简、税务导向、避免职业判断**。它的设计哲学和企业准则相反——企业准则追求"公允价值+审慎估计"，小企业准则追求"历史成本+实际发生"。天信的第一判断永远是：**这客户能不能用小企业准则？**能用就用，双方都省。


## 二、判断直觉

判断与执行分两步：

**第一步·能不能用**（排除法）：
- 金融业？→ 不能用。
- 已上市/发债？→ 不能用。
- 企业集团内的母公司（即使自身小）？→ 不能用。
- 都不踩 → 可用，且推荐用。

**第二步·用的时候抓"五不"**（与企业准则最刺眼的区别）：
1. **不提资产减值**：坏账、存货跌价、长期资产减值——不计提准备，实际发生损失时直接计入营业外支出/管理费用。
2. **不确认递延所得税**：所得税采用**应付税款法**，税法与会计差异不确认递延，直接按当期应交所得税列支。
3. **不编现金流量表**：报表只三张——资产负债表、利润表、附注（现金流量表可选，多数小企业不编）。
4. **长期股权投资不区分**：统一按**成本法**（不确认损益调整、不转公允价值）。
5. **资本公积仅限资本溢价**：不确认其他资本公积（如权益法下份额变动、可转债拆分等不适用）。

**一句话直觉**：小企业准则 = 历史成本记账 + 实际发生才入账 + 尽量贴近税法，少做"估计与调整"。

## 三、准则依据

- **坏账处理对比**：企业准则需"预期信用损失"模型计提坏账准备；小企业准则"实际发生坏账时计入管理费用"，不提准备——这是代理记账最常见的错配点（用企业准则思路给小企业提了准备，反而违规）。
- **所得税对比**：企业准则资产负债表债务法（递延所得税资产/负债）；小企业准则应付税款法，无递延。
- **报表对比**：企业准则四表（含现金流量表、所有者权益变动表）；小企业准则三表（现金流可选）。

## 四、天信场景

| 天信场景 | 卡怎么用 |
|---|---|
| 新客户建账/承接审计 | 先跑"第一步排除法"，在底稿写"适用小企业准则"及依据；三类排除命中则改企业准则 |
| 代理记账复核 | 查"五不"是否守住：有无不该提的减值、有无递延所得税、有无多余报表 |
| 年报审计收入成本 | 小企业准则收入按"实现"确认（不引入五步法/控制权），复核是否过度复杂化 |
| 客户问"为什么不用大准则" | 用"减负合规"逻辑解释，降低客户被过度审计成本 |
| 准则切换 | 提醒"一经选择不得随意变更"，切换需有合理商业理由并留存说明 |

## 五、演练输出

**输入**：一家客户的基本信息（行业、是否上市/发债、是否集团母公司、营收规模）+ 当前账务处理样本（有无减值准备、递延所得税、现金流量表）。
**输出**：
1. 给出"适用准则"判定（小企业 / 企业）及排除法依据；
2. 逐条核对"五不"，标出已守 / 违反项；
3. 对违反项给出更正建议（如冲回不应提的减值、删掉递延所得税分录）；
4. 输出"准则适用性说明"一句话结论。
**分支**：若客户属"排除三类"但已用小企业准则 → 提示"适用错误，须改按企业准则追溯调整并说明"。
**完成标准**：判定有划型标准/排除条款支撑，五不逐条核对无遗漏。
