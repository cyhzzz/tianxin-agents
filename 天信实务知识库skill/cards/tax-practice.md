## 一、核心理念

天信是县城所，**代理记账 + 税务申报是营收基本盘**，使用频次高于年报审计。税务实务的核心不是"算税"本身，而是**在合规前提下帮客户把税交对、交少、交稳**：用足法定优惠（小微、研发加计、六税两费减半），守住扣除限额与凭证合规红线（虚开、不合规凭证是高频行政/刑事风险）。

> 政策时效提示（已核实）：小微企业所得税减按25%计入、增值税小规模月10万以下免征且3%减按1%、六税两费减半、个体户所得≤200万减半——均依据财政部 税务总局公告2023年第12号/第19号等，**执行至2027年12月31日**。后续年度须核验是否延续。

## 二、判断直觉

三条主线 + 一条红线：

**① 企业所得税（查账征收客户）**
- **小微优惠**：年应纳税所得额 ≤300万，减按25%计入应纳税所得额、按20%税率 → **实际税负5%**。三指标同时符合：应纳税所得额≤300万、从业人数≤300人、资产总额≤5000万、从事非限制禁止行业。判定以汇算清缴结果为准。
- **六税两费减半**（至2027底）：资源税、城建税、房产税、城镇土地使用税、印花税、耕地占用税、教育费附加、地方教育附加，对小规模/小微/个体户减半，可叠加其他优惠。
- **扣除限额（纳税调整高频）**：业务招待费（发生额60% 且 ≤ 营收0.5%）、广告业务宣传费（≤营收15%，超可结转）、职工福利费（≤工资14%）、工会经费（≤工资2%）、职工教育经费（≤工资8%，超可结转）、公益性捐赠（≤利润总额12%，超3年结转）、利息（非金融不超同期同类利率）。
- **免税/不征税**：财政拨款不征税；居民企业间股息红利免税；国债利息免税。

**② 增值税**
- **小规模**：月销售额 ≤10万（季≤30万）免征增值税；适用3%征收率的应税收入减按1%（至2027底）。
- **一般纳税人**：销项−进项；专票作抵扣凭证；用于免税/简易计税/集体福利/个人消费的进项不得抵扣。

**③ 个人所得税**
- **工资薪金**：累计预扣法（5000起征 + 三险一金 + 专项附加扣除）。**累计预扣率速查表**（含税级距与速算扣除数）：

     | 累计预扣应纳税所得额 | 预扣率 | 速算扣除数 |
     |---|---|---|
     | ≤ 36000 | 3% | 0 |
     | 36000–144000 | 10% | 2520 |
     | 144000–300000 | 20% | 16920 |
     | 300000–420000 | 25% | 31920 |
     | 420000–660000 | 30% | 52920 |
     | 660000–960000 | 35% | 85920 |
     | > 960000 | 45% | 181920 |
- **经营所得**：5级超额累进（5%–35%）；个体工商户年所得≤200万部分减半（至2027底）。
- **股息利息红利**：20%比例税率。

**④ 红线——发票与凭证**
- 虚开发票（无货开票/为他人虚开）触碰行政法且可能涉刑，是监管处罚最高频领域之一（见 penalties 卡）。
- 扣除凭证依据《企业所得税税前扣除凭证管理办法》（国家税务总局2018年28号）：外部凭证（发票为主）+ 内部凭证；小额零星可用收款凭证（个人≤增值税起征点）。

## 三、准则依据

- 小微判定"季度平均值"公式：季初+季末÷2，全年平均；年度中间开业以实际经营期为纳税年度。
- 研发加计扣除：未形成无形资产按100%加计（制度性长期，2023年第7号），形成无形资产按200%摊销；7月/10月预缴可自主选享。注意研发费用与生产经营费用须分别核算，划分不清不得加计。
- 亏损弥补：一般5年；高新/科技型中小企业10年。

## 四、天信场景

| 天信场景 | 卡怎么用 |
|---|---|
| 代理记账月末/季末 | 核增值税小规模免征额、个税扣缴、社保公积金代扣代缴 |
| 所得税汇算清缴（1–5月高峰） | 先判小微三指标→算优惠税额；逐项核扣除限额做纳税调整 |
| 客户问"能不能少交" | 用足小微/研发加计/六税两费减半，但不得编造 |
| 发票/报销审核 | 查凭证合规性、虚开红线，超限额费用单独提示 |
| 高新/科技型客户 | 亏损弥补10年 + 研发加计100% 重点适用 |

## 五、演练输出

**输入**：一户查账征收企业的年度数据（营收、利润总额、各项费用发生额、是否小规模/小微、有无研发、人员资产规模）。
**输出**：
1. 小微三指标判定（是/否小微）及优惠税额测算；
2. 增值税身份与适用（免征/减按1%/一般计税）；
3. 逐项扣除限额测算，列纳税调增项；
4. 个税（工资累计预扣/经营所得）测算；
5. 提示发票凭证合规点与虚开红线。
**完成标准**：优惠适用有政策文号支撑、扣除限额逐项有据、未编造减免。
