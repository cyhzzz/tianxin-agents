## 三、处理方式（可复现）

从原始 PNG 去背景：

1. 判据取「彩色 或 深色」：`sat > 22` 或 `lum < 205`。背景 (250,250,250) 与网格 (243,243,243) 两项都不满足，因此被排除。
2. alpha 二值后做 0.5px 高斯羽化，`<12` 归零。
3. 用颜色 mask 定边界（红：`R - max(G,B) > 35`；蓝：`B - R > 25`），排除网格噪声。
4. 裁切留 4px 安全边距；印章按红色 mask 单独切出（原图印章 174×178，正方形）。
5. 横版按上表参数重新排版，印章 Lanczos 放大到 372px 高以保证 60mm 显示的清晰度。

## 五、使用规范

- 安全空间：四周留白 ≥ logo 高度的 0.5 倍。
- 禁止：拉伸、倾斜、加阴影、加描边、单独抽取文字部分、改变内部配色。
- 深色底用 `-white` 版，不要用 CSS 滤镜反白（印章也会被漂白且边缘发灰）。
- 印章色 `#AB393A` 只属于 logo 内部，不得作为正文强调色、表头底色或图表配色。
- 封面主标题不复用横版（横版文字在封面尺寸下太细），改用印章标 24mm + 衬线大字。

## 六、已知限制

- **没有原始矢量源**。原品牌规范目录里的 `logo.svg` 是 imagetracer 自动描摹（20 个 path、印章残缺、边缘毛刺），不可用，已随目录并入时一并废弃删除。若拿到 AI / CDR / PDF 源文件，应重新导出替换本包。
- 横版位图上限 2148px 宽，A4 上超过 60 mm 会发虚；展架、海报需矢量源。
- 印章位图上限 182px，超过 24 mm 会发虚。
