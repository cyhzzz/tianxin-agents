唯一标志，按场景缩放

全品牌仅交付一份 logo.svg——矢量、官方、可在任何尺寸下保持锐利。深色背景场景通过 CSS filter 反白得到反白版，尺寸与场景靠 CSS 控制，不另存文件。

使用准则

  • 仅交付一份 logo.svg，不另外保存 PNG / JPG 变体
  • 深色背景用 CSS filter: brightness(0) invert(1); 反白
  • 页眉场景最小宽度 32px；卡片 / 封皮 80–120px
  • favicon 场景 16 / 32 / 48px，使用同一份 SVG 缩放
  • 周围保留 logo 高度 × 0.5 的安全空间

使用禁令

  • 禁止把 SVG 导出为 PNG / JPG 重新分发
  • 禁止拉伸、压缩、倾斜、旋转 logo
  • 禁止改变 logo 内的颜色与笔画粗细
  • 禁止把 logo 放在低对比度背景上
  • 禁止给 logo 加阴影、描边、其他滤镜
  • 禁止把 logo 文字部分单独抽出来用
03 / 色彩系统

深蓝为骨，金色为睛

品牌主色取自 IBM Carbon Design 体系的深蓝/亮蓝组合——传达「机构、可靠、合同感」；金色仅作为「点睛 / 权威」信号，不承担可点击 / 链接语义。所有色值已转写为 OKLch，可直接 bind 到 design system。

品牌色

08 / 设计禁区

这些做法在所有物料中禁止

为了把「AI 味模板」挡在门外，所有品牌物料在交付前必须通过以下检查。违反任一项的稿件需重做。

×
禁止以 #6366f1 系列紫色作为主色或链接色（这是最常见的 AI 默认色）。
×
禁止紫 → 蓝渐变作为背景（trust-gradient 是 AI 味第二特征）。
×
禁止任何 ≥ 4px 的 border-radius——全品牌统一 0 圆角。
×
禁止 emoji（✨🚀🎯⚡🔥💡）作为图标或装饰——使用单色线性 SVG。
×
禁止「带左侧色条的圆角卡片」——这是 AI 仪表盘模板的典型痕迹。
×
禁止装饰性光晕、模糊背景、blob SVG、暖米色 / 桃色 / 粉色页面底。
×
禁止单屏超过 2 处金色 --brand-gold——金色只点睛，不渲染。
×
禁止字号 ≤ 11px（脚注最小 12px）、禁止 font-weight: 700（最多 600）。
×
禁止 Inter / Roboto / Arial 单独作为 display 字体（必须配 Noto Serif SC）。
×
禁止「+」「...」作为标题文案，禁止「10× faster」「99.9% uptime」式无源数据。
