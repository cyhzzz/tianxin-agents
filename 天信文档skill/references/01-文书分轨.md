# 文书分轨：三类文书各自要什么

判性质的目的是**决定哪些东西不能动**。法定文书的段落顺序和必备要素是准则规定的，改一个词的顺序都可能被复核挑出来；咨询报告反过来，结构可以按读者需要重组。

---

## 一、法定业务文书

### 通用判断

同时满足两条即为法定文书：

1. 由执业人员（注册会计师 / 资产评估师 / 税务师）签字并加盖事务所印章
2. 对社会或特定第三方出具，承担相应执业责任

### 审计报告（财务报表审计）

依据《中国注册会计师审计准则第 1501 号》。标准结构：

| 顺序 | 要素 | 备注 |
|---|---|---|
| 1 | 标题 | 统一为「审计报告」 |
| 2 | 收件人 | 按审计业务约定书确定的委托人 |
| 3 | 审计意见 | 意见段必须前置，不得埋在正文中段 |
| 4 | 形成审计意见的基础 | 含「我们按照中国注册会计师审计准则执行了审计工作」 |
| 5 | 管理层对财务报表的责任 | |
| 6 | 注册会计师对财务报表审计的责任 | |
| 7 | 按相关要求报告的事项 | 如有 |
| 8 | 签字和盖章 | 两名注册会计师签名盖章 |
| 9 | 事务所名称、地址和盖章 | |
| 10 | 报告日期 | 不应早于取得充分适当审计证据的日期 |

> 上述为通用骨架。**具体表述以现行准则文本和所内底稿模板为准**，不要照本文件逐字抄。

意见类型（无保留 / 带强调事项段的无保留 / 保留 / 否定 / 无法表示）的措辞差异是法定表述，不允许"写得更好读一点"。

### 验资报告

依据《中国注册会计师审计准则第 1602 号》。结构与审计报告相近，核心差异在结论段：需明确说明截至验资基准日，被审验单位注册资本实收情况，以及出资方式、出资金额。

### 资产评估报告

依据《资产评估执业准则——资产评估报告》。要素多且顺序敏感，通常包含：标题及文号、声明、摘要、正文、附件。正文含委托人及其他相关当事人、评估目的、评估对象与范围、价值类型、评估基准日、评估依据、评估方法、评估程序实施过程、评估假设、评估结论、特别事项说明、使用限制说明、报告日。

**评估报告的「特别事项说明」和「使用限制」不能省略**，这是执业检查的高频扣分项。

### 这类文书的排版规矩

- 版式从所内既有模板出发，不做视觉再设计
- 字体按 `gongwen` 版式或所内既有格式，不改
- 页码连续，骑缝章位置留白
- 附件清单单列一页
- **不用整页背景图**——归档扫描时底纹会被压成灰底，OCR 识别率下降

## 二、咨询与尽调报告

### 判断

署名是项目组，目的是给委托方内部决策参考，不对社会出具鉴证意见。典型：财务尽调、战略咨询、AI 赋能方案、可行性研究、专项财务分析。

### 结构可以重组，但有四块不能省

| 必含 | 为什么 |
|---|---|
| **结论摘要** | 管理层只看这一页。写不出一句话结论，说明还没形成判断 |
| **口径与资料来源** | 数据从哪来、覆盖哪个期间、有没有未取得的部分 |
| **待确认事项** | 尽调的价值一半在这里——明确哪些没查清，比假装都查清了专业 |
| **免责说明** | 未审数据、未经审计调整、仅供内部参考，一句话说清边界 |

### 允许做的

- 按读者关心的问题重排章节顺序
- 用字号层级、留白、细线建立视觉结构
- 三线表、图表、旁注
- 把长论证拆成「结论 → 依据 → 反例」

### 不允许做的

- 编造没取得的数字，或用行业均值"补"企业数据
- 把口径冲突抹平（两个来源不一致就并列写）
- 写 ROI 承诺、写"必将""确保"这类绝对化判断

---

## 三、汇报演示

判断标准最简单：有没有人站在前面讲。有 → 演示；没有、要装订 → 报告。

- 一页一个结论，标题就是结论句，不是"经营情况分析"
- 数字要能指回报告的某一行，不能是页面上凭空出现的
- 不写内部筛选过程、不写"我们是怎么做的"
- 客户现场电脑可能是老机器，不要用 WebGL 背景和重动效
