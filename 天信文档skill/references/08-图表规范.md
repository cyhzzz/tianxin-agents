# 图与表

事务所报告以**表**为主、图为辅。这不是审美选择——客户要核数，表格能核，图不能。

先定一条总规矩：**一个数字不画图。** 单一关键数字用大字 + 一行说明，画成图是浪费半页纸。

---

## 什么时候用表，什么时候用图

| 读者要干什么 | 用什么 |
|---|---|
| 核具体数字 | **表** |
| 比几个对象在几个指标上的差异 | **表** |
| 看几年、几期的走向 | 图（折线） |
| 看收入/成本的构成 | 图（横条）或表 |
| 记住一个关键数 | 大字，不画图 |
| 看两期对比 | 图（成对柱）或表 |

判据一句话：**读者会不会拿手指着某个格子对账？** 会 → 表格。

尽调报告的财务分析章，表格和图的比重大约 7:3。

---

## 三线表

事务所报告的标准表型。上下各 1pt，表头下 0.5pt，其余全无。

| 项目 | 2026年1—9月 | 2025年同期 | 变动 |
|---|---|---|---|
| 营业收入（万元） | 4,820 | 4,291 | +12.3% |
| 毛利率 | 21.4% | 23.2% | −1.8pct |

规则：

- **表头浅灰底（`#F4F4F4`），不加粗边框**——全框线网格看着像 Excel 截图
- **数字右对齐，用等宽数字**（`tabular-nums`），上下行才能对齐
- **百分号统一放在数值后**，不写在表头里
- **零值写 0%，不留空**——留空的意思可能是"没有"也可能是"没取到"，歧义
- **合计行加粗**，并在行的上方加一条 0.5pt 线
- **单位写在表题里**，不写在每个单元格里

## 表题与来源

```
表 1  2025—2026 年分业务收入构成（单位：万元）     ← 表格上方
        [表格]
数据来源：企业提供的销售明细账，天信整理            ← 表格下方
```

表题编号全文连续（表 1、表 2……），图单独编号（图 1、图 2……），**不要混编**。

---

## 图的基本要求

每张图必须有四样：

1. **结论式标题**——写「毛利率连续两年低于同业区间下限」，不写「毛利率变化趋势」
2. **数据源行**——区分谁采的数、谁做的分析（见 `04-行文与口径.md`）
3. **单位与期间**——「万元」「2023—2026Q3」
4. **编号**——图 1、图 2……

## 配色

天信的图表只用三类颜色：

| 用途 | 色值 | 说明 |
|---|---|---|
| 主数据 | `#1D3A5E`（navy） | 默认系列色 |
| 强调／对照 | `#B8860B`（金） | 一页最多一处，用于"要读者注意的那一条" |
| 负值／风险 | `#DA1E28` | 只用于负数和警示，不做系列色 |
| 背景／历史 | `#F4F4F4` 填充、`#8A8A8A` 文字 | 表示"这不是重点" |

**禁止**：彩虹色板、渐变填充、3D 效果、阴影、双 Y 轴。

**只用颜色区分是不够的**——约 8% 的男性有色觉障碍。系列之间还要有形状、位置或直接标注的差异。

## 三个会改变结论的陷阱

这三个和"不好看"不是一个量级——它们让读者得出**错误的结论**，而且不会有任何报错。

### 一、负值被画成零高度

图表代码不处理负值时，`−11%` 会渲染成 0 高度的柱子。于是「下降 11%」和「没有变化」在图上长得一模一样。

**画完先确认**：零线在哪？负值是不是在零线下方？数据标签有没有带负号？

### 二、Y 轴不从零开始且不标注

把 3% 的差异画成三倍高。财务图尤其容易犯——因为毛利率、增长率这类指标本身基数小，截断 Y 轴能让任何差异看起来很显著。

**默认永远从零开始。** 确实需要截断时（比如比较 97% 和 99%），必须在轴上画出断裂标记，并在图注里写明。

### 三、图型错配

用成对柱去画只有一组数据的对比，第二根柱子会是 0 高度并标注「0%」——读者会以为那是个真实的零值。

**一组数据用横条，两组才用成对柱。**

---

## 常见坏做法

- 饼图超过 3 块（人眼读不出 5 块以上的角度差）——改用横条
- 双 Y 轴——两条轴的缩放可以拼出任何想要的相关性
- 图例放在图外很远——读者在图表和图例之间来回跳
- 用面积/体积表达倍数——人对长度的判断比对面准确得多
- 一张图塞三个结论——读者一个都记不住

## 用 chart.py 生成，不要手画

图不要截图贴进来。在 Markdown 里写块，脚本生成内联 SVG——输出小、能跟着报告样式走、改数据不用重画。

````markdown
:::chart bar
caption: 图 1　木制工艺品占收入 64.7%，是唯一规模业务
unit: 万元
highlight: 木制工艺品
source: 企业提供的销售明细账（2026 年 1—9 月），天信整理
| 木制工艺品 | 3120 |
| 竹藤制品 | 980 |
| 来料加工 | 620 |
:::
````

四种图型：

| 类型 | 数据形状 | 用在 |
|---|---|---|
| `bar` | `| 类别 | 数值 |` | 类别名长、要排序比较 |
| `column` | `| 类别 | 数值 |` | 时间序列、少量类别 |
| `line` | 首行表头，其余每列一个系列 | 趋势、多系列对比 |
| `grouped` | `| 类别 | 本期 | 上期 |` | 两期/两组对比 |

可用参数：

| 参数 | 说明 |
|---|---|
| `caption` | 图题，**写成结论句**，带「图 N」编号 |
| `unit` | 数值后缀（万元、%、pct） |
| `source` | 数据源行，写清谁采的数 |
| `highlight` | 指定某一项用金色强调，一图只给一个 |
| `truncate` | `true` 时 Y 轴不从零开始（仅 `column`），会自动画断裂标记并标「轴已截断」 |
| `series1` / `series2` | `grouped` 的两组名字 |

### 工具替你守的三条

写进代码里，不靠作者记：

1. **Y 轴默认从零**（`truncate` 要显式打开，且打开后会画断裂标记）
2. **负值画在零线下方**，不是零高度
3. **折线多系列量级差超过 5 倍时，图上直接标红字警示**——不同量纲的指标画一根轴，小量级那条会被压成贴底的直线

### 什么时候该开 truncate

小基数指标：毛利率、增长率、百分比占比。这类数据从零开始，几根柱子几乎一样高，读者看不到差异。

**不要**对金额类开 truncate——收入 4,820 万和 5,730 万从零开始是对的，截断会放大差异。

开了 truncate 的图，图注里要写一句「纵轴自 19% 起，未从零开始」。
