# 报告骨架：三种原型与各自的组件

天信出的报告不是一种。**先认原型，再搭骨架**——用错原型的代价是结构从头再来。

三种原型对应三种委托关系：

| 原型 | 谁委托 | 读者拿它干什么 | 典型篇幅 |
|---|---|---|---|
| **尽调报告** | 拟投资方 / 收购方 / 银行 | 决定投不投、贷不贷 | 20–40 页 |
| **专项咨询报告** | 企业管理层 | 决定改不改、怎么改 | 15–30 页 |
| **专项说明** | 单一事项的利害方 | 核一个具体结论 | 3–10 页 |

法定业务文书（审计、验资、评估报告）的要素由执业准则规定，见 `01-文书分轨.md`，不在这里。

---

## 一、尽调报告

天信最常出的一种。读者是投资决策人，他关心的顺序永远是：**能不能投 → 值多少钱 → 有什么坑**。

```
封面（所名 + 报告名 + 被调查单位 + 文号 + 日期）
目录（两级，必须做）
一、结论摘要            ← 决策人只看这一页
二、企业概况            ← 工商、股权、组织、资质
三、经营分析            ← 业务结构、客户、供应商、产能
四、财务分析            ← 收入质量、成本、资产、现金流
五、风险与待确认事项     ← 尽调的价值一半在这里
附录：资料清单
```

### 各章的硬要求

**结论摘要**（1 页，不超过 1.5 页）

必须能独立读懂。写法见 `04-行文与口径.md` 的「结论摘要」。这里只强调一条：**摘要里出现的每个数字，正文里都要能指回去**。摘要不是正文的缩写，它是正文的索引。

**企业概况**

只写可核查的事实：工商登记信息、股权结构、历次变更、资质证照。这一章不出现判断，出现判断就是越位。

**经营分析**

按「收入从哪来 → 客户是谁 → 成本花在哪 → 产能够不够」的顺序。每一节结尾要有一句判断，不能只有数据。

**财务分析**

四个必答：收入是不是真的（质量）、毛利为什么是这个数（结构）、资产里有没有水分（减值）、现金流跟不跟得上利润（造血）。

**风险与待确认事项**

这一章是尽调报告区别于"资料汇编"的地方。**没查清的事必须写出来**，列成编号清单，每条写清：缺什么、为什么重要、补上之后可能改变什么结论。

写「未取得」比写「假设」专业。假设会被当成事实引用，未取得不会。

**附录：资料清单**

按来源分类编号（企业提供 / 公开渠道 / 现场访谈 / 第三方报告），每条一行：资料名、期间、提供方、取得日期。

> **体量闸：附录不超过正文的 10%。** 附录是资料清单，不是把企业给的 200 页报表转印一遍。完整数据表随交付物给电子文件，不排进正文。

### 篇幅基线

中位数 28 页，常见区间 20–40 页。低于 15 页通常说明该查的没查；高于 50 页通常是附录失控或者把工作过程写进了正文。

## 二、专项咨询报告

读者是管理层，他要的是**判断和路径**，不是全景扫描。

```
封面
一、问题与结论          ← 结论前置，先说该做什么
二、现状诊断            ← 问题出在哪，用数据定位
三、方案                ← 几个选项，各自的代价
四、实施路径            ← 分几步、谁负责、什么时候见效
五、风险与前置条件
附录：测算过程 / 访谈纪要
```

### 与尽调报告的三个差别

**结论必须前置到第一章。** 尽调可以按"概况→分析→结论"铺陈，咨询不行——管理层没耐心等你铺垫完。

**方案必须给选项，且标明代价。** 只给一个方案等于替客户做了决定。标准写法是"方案 A / 方案 B / 不做的后果"，每个都写清成本、周期、对现有业务的扰动。

**实施路径要落到人和时间。** "建议加强内控"不是方案；"Q1 完成三张表勾稽核对表，财务经理负责，Q2 起月度执行"才是。

## 三、专项说明

针对单一事项，读者只要一个结论。

```
标题（直接写事项）
事由
依据（准则条款 / 合同条款 / 法规）
分析
结论
附件（原始凭证、计算表）
```

篇幅 3–10 页。**不要加目录，不要加摘要**——3 页的东西加目录是浪费读者的时间。

---

## 目录怎么做

做了目录的报告，绝大多数做**两级**。一级只到章，两级到节。

长页版（`md2web.py`）的目录是自动生成的，带滚动高亮；A4 版（`md2html.py`）目前目录是手写的，超过 20 页时补一份。

判据：读者会不会想跳章？会 → 做目录；3–5 页的专项说明 → 不做。

## 结构自检

- [ ] 原型认对了吗？（尽调 / 咨询 / 专项说明）
- [ ] 结论摘要能不能单独读懂？把正文全删掉，它还是不是一份完整的结论？
- [ ] 有没有「待确认事项」这一章？里面写的是缺什么，不是假设什么？
- [ ] 每章结尾有没有一句判断，还是只有数据堆着？
- [ ] 附录是不是资料清单？长度有没有超过正文的 10%？
- [ ] 目录页码对不对？（A4 版必须逐页核对，改一次正文就要重核）
