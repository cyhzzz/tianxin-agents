### 2.5 色彩使用守则

- **一处强调**：金色 `--brand-gold` 在单一屏内最多出现 2 次（1 个分隔条 / 1 个按钮 或 1 个图标 + 1 个 chip）。
- **主色 = navy / blue**：CTA、链接、焦点环、关键操作。
- **金色 ≠ 高亮**：金色承担「点睛 / 权威感」，不承担「可点击 / 链接」语义。链接统一用 `--brand-blue` 或 `--brand-sky`。
- **禁止**：渐变背景（除了 hero 暗色 → 黑色 单一方向）、紫色调、装饰性光晕、emoji 图标替代文字。
- **对比度**：主文字 `#161616` on `#FFFFFF` ≈ 18.7:1；正文 ≥ 4.5:1，UI ≥ 3:1，达标。

## 3. 字体系统

### 3.1 字体栈

```css
--font-sans:  "Noto Sans SC", "Inter", -apple-system, BlinkMacSystemFont,
              "Segoe UI", "Helvetica Neue", "PingFang SC",
              "Hiragino Sans GB", "Microsoft YaHei", Arial, sans-serif;

--font-serif: "Noto Serif SC", "Source Han Serif SC", Georgia,
              "Times New Roman", "STSong", "SimSun", serif;

--font-mono:  ui-monospace, "JetBrains Mono", "SF Mono", Menlo,
              Consolas, "Liberation Mono", monospace;
```

- **正文 / UI**：Noto Sans SC（思源黑体简体）。Latin 字符回退 Inter。
- **装饰 / 引言 / 数字印章感**：Noto Serif SC（思源宋体简体）。**慎用**——只在 hero 引言、报告扉页、印章 logo 这种「带官方气」的场合。
- **数字 / 金额 / 表单 ID**：用 `font-variant-numeric: tabular-nums` 强制等宽数字。事务所场景数字密度高，tabular 是底线。

### 3.2 字号尺度

| Token | 角色 | 数值 | 行高 |
| --- | --- | --- | --- |
| `--font-size-display` | 巨标题（hero） | 56px / `3.5rem` | 1.05 |
| `--font-size-headline` | 章节标题 | 32px / `2rem` | 1.15 |
| `--font-size-title` | 卡片 / 子区块标题 | 22px / `1.375rem` | 1.3 |
| `--font-size-body` | 正文 | 15px / `0.9375rem` | 1.5 |
| `--font-size-label` | UI 标签 / 按钮 | 14px / `0.875rem` | 1.4 |
| `--font-size-small` | 注释 / 角标 | 12px / `0.75rem` | 1.5 |

### 3.3 字重

只保留三档：

| Token | 数值 | 用途 |
| --- | --- | --- |
| `--font-weight-regular` | 400 | 正文 |
| `--font-weight-medium`  | 500 | UI 标签、按钮 |
| `--font-weight-semibold`| 600 | 标题、强调 |

`font-weight: 700` 全局禁用。粗体不是强调手段。

### 3.4 排版细节

- **display / headline (≥32px)**：`letter-spacing: -0.02em`，收紧。
- **body (15px)**：`letter-spacing: 0`，默认。
- **小字 (≤13px)**：`letter-spacing: 0.01em`，微开。
- **大写字母 (UI label)**：`letter-spacing: 0.02em`，均匀。
- **正文行宽**：`max-width: 65ch`，约 32 个汉字。
- **不**使用 `text-align: justify`（会产生河流与孤字）。

```css

```

**严禁任何圆角**。按钮 0、卡片 0、tag 0、输入框 0、头像 0。事务所场景的「方」=「正式、机构、合同感」。

卡片不用 shadow。靠 1px `--border` 描边 + 间距建立层级。popover / modal 才有 shadow。

### 5.2 最小尺寸

- 页面 / 卡片主标志：宽度 ≥ 120px。
- 页眉场景：宽度 ≥ 32px。
- favicon / 头像：16 / 32 / 48px，使用同一份 SVG 缩放。

### 5.3 安全空间

logo 周围至少保留 logo 高度 × 0.5 的空白，禁止任何元素侵入。

### 5.4 使用禁令

- ❌ 不要从 `assets/brand/` 的 PNG 再二次压缩或转格式后分发（会有二次损失）。
- ❌ 不要拉伸 / 压缩 / 倾斜 / 旋转 logo。
- ❌ 不要改变 logo 内的颜色。
- ❌ 不要把 logo 放在低对比度背景上。
- ❌ 不要给 logo 加阴影 / 描边 / 其他滤镜。
- ❌ 不要把 logo 文字部分单独抽出来用。

## 6. 组件基线

### 6.1 按钮（pill-btn）

| 变体 | 背景 | 文字 | 描边 | 用途 |
| --- | --- | --- | --- | --- |
| primary   | `--brand-navy`  | `#fff`  | none | 主要 CTA |
| primary-hover | `--brand-blue` | `#fff` | none | hover |
| outline   | `transparent`   | `#fff`  | `1px solid rgba(255,255,255,0.4)` | 深色背景上 |
| gold      | `--brand-gold`  | `#fff`  | none | 关键行动（预约咨询） |
| gold-hover| `#D4A017`       | `#fff`  | none | hover |

- 圆角 0；padding `0.75rem 2rem`（12 × 32）；字重 600；字号 14px；letter-spacing 0.02em。
- hover 仅切换背景色，不位移、不缩放、不加阴影。
- 单屏主行动按钮最多 1 个，行动按钮群最多 3 个。

### 6.2 卡片（service-card）

- 1px `--border` 描边；圆角 0；无阴影。
- 内 padding 32px；标题 22px / 600；正文 15px / 400。
- hover：背景 `--border-hover` (`#E8E8E8`)；无位移。
- 卡片之间间距 24px。

### 6.3 标签 / Chip（tag）

| 变体 | 文字 | 背景 | 用途 |
| --- | --- | --- | --- |
| tag-blue  | `--brand-blue` | `#EDF5FF` | 服务类型 |
| tag-gold  | `--brand-gold` | `#FEF7E0` | 权威 / 重要 |
| tag-navy  | `--brand-navy` | `#EDF5FF` | 类别 / 行业 |

- padding `4px 12px`；圆角 0；字号 12px；字重 400。
- letter-spacing 0.32px。

### 6.4 输入控件

- 1px `--border` 描边；圆角 0；高度 40px；padding `0 12px`。
- focus：2px `--brand-blue` 描边 + 2px offset。
- placeholder：`--muted-fg`。

### 6.5 分隔条

```css
.section-divider {
  width: 48px;
  height: 3px;
  background: var(--brand-gold);
}
```

每个章节标题上方一个，金色 3px × 48px 横条。这是品牌的「印章感」签名。

## 7. 文案声音

### 7.1 调性

- 严谨、克制、专业。
- 不卖弄、不煽情、不互联网黑话。
- 短句优先，主谓宾清晰。
- 第二人称「您」优先，避免「你」。

### 7.2 推荐用法

| 想表达 | 推荐 | 不推荐 |
| --- | --- | --- |
| 行动 | 「立即咨询」「获取方案」 | 「马上试试」「戳我一下」 |
| 信任 | 「二十年执业经验」「本土服务」 | 「最强」「全网第一」 |
| 服务 | 「审计验资 · 资产评估 · 税务服务」 | 「一站式财税管家」 |
| 数据 | 「创立于 2001 年」 | 「20 年+ 经验」（不要用「+」） |

### 7.3 数字 / 金额

- 数字一律用 `font-variant-numeric: tabular-nums`。
- 大额数字使用千分位 `1,286,500.00`，保留两位小数。
- 金额前加 ¥；合同 / 报告场景用大写金额栏。

## 8. 暗色 / 浅色双模式

品牌默认浅色。深色仅用于：

- 网站 hero 段（#161616 背景 + 白色文字）。
- 报告扉页、合同封皮。
- 名片背面（如有）。

暗色模式下的品牌色保持不变；中性色翻转：
- 背景 `#161616` ↔ `#FFFFFF`
- 文字 `#FFFFFF` ↔ `#161616`
- 描边 `#262626` ↔ `#E0E0E0`
- 弱化背景 `#262626` ↔ `#F4F4F4`

金色 `--brand-gold` 在两种背景下都可读，不变。

## 9. 设计禁止清单（项目内 lint 守门）

为了把「AI 味儿」挡在门外，所有品牌物料必须避免：

- ❌ Indigo `#6366f1` 系列紫色作为主色或链接色。
- ❌ 紫 → 蓝渐变背景。
- ❌ 圆角（任何 ≥ 4px 的 border-radius）。
- ❌ Emoji（✨🚀🎯）作为图标或装饰。
- ❌ 文字「+」「—」「...」作为标题文案。
- ❌ 字号 ≤ 11px（脚注最小 12px）。
- ❌ Inter / Roboto / Arial 单独作为 display 字体（必须配合 Noto Serif SC）。
- ❌ 单屏超过 2 处 `--brand-gold` 强调。
- ❌ 装饰性光晕 / 模糊背景 / blob SVG。
- ❌ 暖米色 / 奶油色 / 桃色 / 粉色页面底。
