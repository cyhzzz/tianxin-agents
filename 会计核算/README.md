# 会计核算线

会计师团队承接的会计核算与报告服务：报表编制与复核、附注编制、合并报表、会计政策选择、财务分析、专项会计服务（贷款报表、IPO 前期账务规范、尽调配合）。

## 与代理记账的分工

| | 代理记账（`../代理记账/`） | 会计核算（本线） |
|---|---|---|
| 团队 | 专职代账小团队 | 会计师团队 |
| 客户 | 中小微企业 | 层级更高，或专项用途（贷款、IPO 前期、尽调） |
| 干什么 | 接票 → 记账 → 月结 → 出报表 → 报税 → 工商，日常全包 | 凭证复核、报表编制与复核、附注、合并报表、会计政策、财务分析、专项会计服务 |
| 产出 | 月报、申报、工商年报 | 财务报表与附注、合并报表、财务分析、专项会计意见 |

**分界线**：日常把账做出来、报出去，是代账；在账的基础上出报表、附注、合并、做分析、定政策，是会计核算。

## 与审计的分工

- **附注制作** → 本线（会计师团队编报表和附注）
- **附注复核**（审计中检查披露完整性）→ 审计线（注会查披露对不对）
- 一句话：**做的归会计，查的归审计。**

## ⚠️ 上游是通用人设，不是所里的

`accounting-supervisor` 是通用会计主管人设，能力内嵌在提示词里，**不含天信报表模板、附注清单、合并底稿、政策手册**。

这四块已由天信补成原创 `references/`（见上），但**仍缺两样**：

| 缺什么 | 现在怎么办 |
|---|---|
| 所内报表模板（实际版式、字体、页眉） | 版式走「天信文档与报告」技能；表格走它的 Excel 轨道 |
| 所内会计科目体系（一级/二级/明细） | 按准则科目表 + 客户业务自设，设完写进该客户的 `04` 手册 |

## 需要什么材料（补齐后这条线才算"天信的"）

1. **一份真实财务报表带附注**（资产负债表 / 利润表 / 现金流量表 + 附注全文）——用真实件校准 `references/01` 的清单，看还漏哪几项
2. **一份真实的合并工作底稿**（有集团客户的话）——校准 `references/03` 的抵消分录格式
3. **所里的报表模板与科目体系**——版式与科目表补齐后写进对应客户手册
4. **专项会计服务做哪些**（贷款报表、IPO 前期账务规范、尽调配合）——决定子技能细分
