# 民间非营利组织三表与附注实例（本所真实样本）

> 来源：天台县红十字会 2023 年度审计报告，**天信会审〔2024〕第 114 号**，
> 报告编码 `浙242DQVEAV5`（注册会计师行业统一监管平台 `acc.mof.gov.cn` 可查验），
> 报告日期 2024-06-21。该报告连同三张报表与本所出具的**会计报表附注全文**已在
> 天台县红十字会公众号公开。
>
> **为什么这份重要**：本技能原有 `references/01` 讲的是**企业会计准则**口径的
> 四表一注。而事业单位、社会团体、基金会、民非单位用的是《民间非营利组织会计制度》，
> 报表张数、格式、净资产分类、附注必备项全都不一样。拿企业那套套民非，第一张表就错。

---

## 一、民非与企业准则的报表差异（先记这张表）

| | 企业会计准则 | 民间非营利组织会计制度 |
|---|---|---|
| 报表张数 | 四表一注 | **三表一注**（无所有者权益变动表） |
| 第二张表 | 利润表 | **业务活动表** |
| 权益类 | 所有者权益（实收资本／资本公积／未分配利润） | **净资产（限定性／非限定性）** |
| 收入费用 | 收入按性质分（主营／其他） | 按**来源**分（捐赠／会费／政府补助／服务／商品销售／投资／其他） |
| 特有项目 | — | **受托代理资产／受托代理负债**、文物文化资产 |
| 结余处理 | 利润分配 | 「限定性净资产转为非限定性净资产」单列一行 |
| 监管硬指标 | — | **公益支出占上年末净资产比例、占上一年总收入比例**（民非年检必查） |

**判据**：客户是基金会、社会团体、民办非企业单位（社会服务机构）、事业单位，
就走民非口径。判断错方向的代价是整份报表重做。

## 二、资产负债表（民非格式）

本所实际用的栏目（左资产／右负债和净资产），注意这几个企业报表里没有的项：

```
流动资产：货币资金 / 短期投资 / 应收款项 / 预付账款 / 存货 / 待摊费用 /
          一年内到期长期债权投资 / 其他流动资产
长期投资：长期股权投资 / 长期债权投资
固定资产：固定资产原价 / 减：累计折旧 / 固定资产净值 / 工程物资 / 在建工程 /
          文物文化资产 / 固定资产清理
无形资产 / 受托代理资产
                                ─────────
流动负债：短期借款 / 应付款项 / 应付工资 / 应交税金 / 预收账款 / 预提费用 /
          预计负债 / 一年内到期的长期负债 / 其他流动负债
长期负债：长期借款 / 长期应付款 / 其他长期负债
受托代理负债
净资产：  **非限定性净资产 / 限定性净资产**
```

样本数据（可用来验算勾稽）：

| 项目 | 期初 | 期末 |
|---|---|---|
| 货币资金 | 322,105.53 | 530,611.76 |
| 存货 | — | 59,000.00 |
| 非限定性净资产 | 1,782.36 | 9,726.12 |
| 限定性净资产 | 320,323.17 | 579,885.64 |
| 资产总计 | 322,105.53 | 589,611.76 |

> **受托代理资产**要单列：本所接受的、只是代为转交的资产（如代收代付的捐赠物资），
> 不能并进自有资产，否则净资产被虚增。样本单位无此业务，附注第七条作了否定式说明。

## 三、业务活动表（民非的"利润表"）

**双栏结构**是本表的关键：每一行都拆「非限定性／限定性／合计」三列。

```
一、收入
   其中：捐赠收入 / 会费收入 / 提供服务收入 / 商品销售收入 /
         政府补助收入 / 投资收益 / 其他收入
   收入合计
二、费用
   (一)业务活动成本       ← 按项目分：助医、助学、博爱送万家、救助、救护、
                            乡村振兴、救灾、三献、基本支出…
   (二)管理费用
   (三)筹资费用
   (四)其他费用
   费用合计
三、限定性净资产转为非限定性净资产
四、净资产变动额
```

样本勾稽（**这三条必须对上，对不上就是附注或报表有错**）：

| 校验 | 算式 | 样本值 |
|---|---|---|
| 收入 − 费用 | 4,358,941.87 − 4,091,435.64 | = 267,506.23 |
| 净资产变动额 | 期末 589,611.76 − 期初 322,105.53 | = 267,506.23 ✓ |
| 现金净增加 | 期末 530,611.76 − 期初 322,105.53 | = 208,506.23 = 现金流量表第 34 行 ✓ |

> **限定性 → 非限定性的结转要单列**，不能直接计入收入。样本第 25 行：
> 6,424.90 / −6,424.90，两栏对冲、合计为零。这一步是民非会计最容易做错的地方。

## 四、现金流量表（民非版）

三大类不变，但「经营活动」的内容按民非业务改写：

| 类别 | 流入项 | 流出项 |
|---|---|---|
| 经营活动 | 接受捐赠收到的现金／收取会费／提供服务／政府补助／其他 | 提供捐赠或者资助支付的现金／支付给职工／购买商品接受服务／其他 |
| 投资活动 | 收回投资／取得投资收益／处置长期资产 | 购建长期资产／投资所支付 |
| 筹资活动 | 吸收投资／借款 | 偿还本金／偿付利息 |

样本只有经营活动发生额：流入 3,636,944.99、流出 3,428,438.76、净额 208,506.23。

## 五、本所附注的十二节结构（照这个顺序写）

| 节 | 标题 | 本所的写法要点 |
|---|---|---|
| 一 | 基本情况 | 统一社会信用代码、机构性质、机构地址、负责人——四项齐全 |
| 二 | 财务报表的编制基础 | 一句话：符合《民间非营利组织会计制度》要求，真实完整反映财务状况、业务活动、现金流量 |
| 三 | **主要会计政策** | 16 项，见下节 |
| 四 | **会计报表主要项目注释** | 逐科目给「年初数／年末数」两栏表，只注有大额变动的 |
| 五 | **专项信息** | 民非特有，三个比例（见第七节） |
| 六 | 资产提供者设置了时间或用途限制的相关资产 | 有则详述，无则写「无」 |
| 七 | 受托代理业务情况 | 同上 |
| 八 | 重大资产减值情况 | 同上 |
| 九 | 公允价值无法可靠取得的受赠资产和其他资产 | 同上 |
| 十 | 接受劳务捐赠情况 | 同上 |
| 十一 | 对外承诺和或有事项 | 同上 |
| 十二 | 资产负债表日后非调整事项 | 同上 |

**六到十二这七节即使「无」也必须写。** 这是民非附注的必备披露项，缺一项年检
或复核就会挑出来。本所样本全部写了否定式说明（「天台县红十字会无……」）。

## 六、16 项会计政策清单（本所实际用的顺序）

写附注第三节时按这个顺序，不要自创编排：

1. 会计制度 2. 会计期间 3. 记账本位币 4. 记账基础和计价原则
5. 外币业务核算方法 6. 短期投资核算方法 7. 坏账核算办法 8. 存货核算方法
9. 长期投资核算方法 10. 固定资产计价及其折旧方法 11. 在建工程核算方法
12. 无形资产计价和摊销方法 13. 受托代理资产 14. 预计负债的确认原则
15. 限定性净资产、非限定性净资产确认原则 16. 收入确认原则

三条容易写错的：

- **第 4 项**：民非用**权责发生制**为记账基础、**历史成本**为计价原则。写成
  「收付实现制」是错的（那是预算会计）。
- **第 8 项存货**：要写清分类、计价方法（加权平均法）、盘存制度（每年定期盘点
  一次）、跌价准备确认原则——四项少一项都不完整。
- **第 16 项收入确认**：必须先区分**交换交易**与**非交换交易**，再按销售商品／
  提供劳务／让渡资产使用权／捐赠与政府补助（无条件 vs 附条件）分别说。这一段
  是民非收入确认的核心，不能只写一句「按权责发生制确认」。

> 样本里有一处可留意的笔误：存货段落写「本基金会材料、物资、商品等」，
> 而主体是红十字会。「基金会」是模板残留。**套模板时这类主体称谓必须逐处替换**，
> 这是复核最容易挑出的低级错。

## 七、专项信息（民非特有，三个比例）

第五节必须给出三组比例，这是民非年检与公益捐赠税前扣除资格的核心指标：

| 指标 | 算式 | 样本值（本年） |
|---|---|---|
| 公益事业支出占上年末净资产比例 | 公益事业支出 ÷ 上年末净资产 | 4,091,435.64 ÷ 322,105.53 = **1270.22%** |
| 公益事业支出占上一年总收入比例 | 公益事业支出 ÷ 上一年总收入 | 4,091,435.64 ÷ 9,636,213.58 = **42.46%** |
| 工资福利、行政办公支出占总支出比例 | （工资福利+行政办公）÷ 总支出 | 0.00 ÷ 4,091,435.64 = **0.00%** |

**分母是「上年末」不是「本年末」**——年报里最常见的算错点。
比例畸高（如 1270%）不是错，是因为该单位净资产基数小、当年支出大，
写的时候照实披露，不加解释性修饰。

## 八、出表前自检清单（套模板必做，四项硬性 + 八项常规）

> 为什么要这张表：样本里出现过「本基金会」而主体是红十字会的模板残留——套模板最容易留下的就是这类低级错，而复核最先挑的也是它。**十二项逐条打勾，缺一项不出表。**

### 四项硬性（错一项整份重做）

| # | 检查项 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 1 | **主体称谓** | 全文搜「基金会 / 公司 / 企业 / 集团 / 贵公司」，逐处核对 | 民非称**本单位 / 贵单位**，不称"公司"；一处不留 |
| 2 | **金额单位** | 报表与附注是否统一为"元"；正文若用"万元"是否标注 | 统一口径，表头写清单位 |
| 3 | **报告期间** | 封面、三张表表头、附注、报告日期四处是否同一年度 | 逐处对齐，跨年度的注明 |
| 4 | **比例分母** | 三个公益支出比例的分母是不是**上年末净资产 / 上一年总收入** | 用本年末数算的一律重算 |

### 八项常规

| # | 检查项 | 要点 |
|---|---|---|
| 5 | 报表张数 | **三张**（资产负债表 / 业务活动表 / 现金流量表），不是四张，**没有所有者权益变动表** |
| 6 | 净资产分类 | 非限定性 / 限定性**分两栏**，不合并成"净资产"一个数 |
| 7 | 限定性转非限定性 | **单列一行、两栏对冲、合计为零**，不得计入收入 |
| 8 | 勾稽三条 | 收入−费用 = 净资产变动额；期末−期初净资产 = 同额；现金净增加 = 现金流量表净额 |
| 9 | 附注六至十二节 | **即使"无"也必须写**否定式说明，不能省节 |
| 10 | 16 项政策顺序 | 按 §六 所列顺序，不自创编排 |
| 11 | 记账基础 | **权责发生制 + 历史成本**（写成"收付实现制"是预算会计口径，错） |
| 12 | 比较数 | 首次执行或上年数来源未定时，附注写「**比较数重述口径待确认**」，不硬填 |

> 第 8 项三条勾稽在 §三 已给样本数演示；第 9、10 项在 §五、§六。自检时对着打勾即可，不用另找文件。

## 九、与 `references/01`（企业口径）怎么分工

| 客户类型 | 用哪份 | 关键差异 |
|---|---|---|
| 公司制企业 | `references/01` 四表一注 | 有利润表、所有者权益变动表、实收资本 |
| **民非／社会团体／基金会／事业单位** | **本篇** | 三表一注、业务活动表、限定性净资产、专项信息比例 |

`references/02` 的勾稽表按企业四表设计，民非用本篇第三节那三条验算即可，
其余（注表一致、跨表一致）原则相同。

## 十、局限

- **一个样本，一个行业**（群团组织，3 人，无固定资产、无长期投资、无受托代理）。
  有固定资产折旧、限定性捐赠分拆、多个项目并行的民非，附注写法会更复杂。
- 只覆盖《民间非营利组织会计制度》，**不含**《政府会计制度》（行政事业单位，
  双分录、预算会计与财务会计平行记账）——那是另一套，本技能尚未收。
- 未取得该单位的**上年比较数据来源说明**与**审计调整分录**，无法校准「比较数
  如何重述」这一环。
