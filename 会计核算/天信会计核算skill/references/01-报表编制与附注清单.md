# 01 报表编制与附注清单

> 天信原创。上游（AI 会计主管）只讲"要编四表一注"，没给格式与逐项清单——本文件补这两块。
> **不替代准则**：条款以现行准则原文为准，本文件给的是"要核哪些项"，不是条款汇编。引用标准时写标准名，**条款号一律现查**。

## 一、先定适用框架（错了，全表重做）

| 框架 | 适用 | 报表组成 | 常见误用 |
|---|---|---|---|
| **企业会计准则** | 上市/发债/并表集团成员，或银行、政府、投资方要求 | 四表 + 附注（含所有者权益变动表） | 小微客户硬套，附注工作量翻三倍 |
| **小企业会计准则**（财会〔2011〕17号） | 符合中小企业划型标准、非上市、非金融 | 资产负债表、利润表、现金流量表、附注（简） | 已并表或要融资的客户仍套小准则 |
| 其他制度 | 民非、事业单位、村集体 | 不属本技能 | 拿企业准则套民非报表 |

判定顺序：

1. 上市 / 发债 / 是并表集团成员 → **企业会计准则**
2. 银行、政府、投资方、招标文件明确要求 → **企业会计准则**
3. 都不是，看规模与行业划型 → **小企业会计准则**

**跨年不得随意换框架**。换框架属会计政策变更，须在附注说明并重述比较数；客户只想"少编两张表"不能作为理由。

## 二、资产负债表

- 列报格式按**财会〔2019〕6号**（一般企业财务报表格式）。项目不得自行增删；确需增列的按性质判断并在附注说明。
- **净额列示**：应收账款、存货、固定资产、无形资产、在建工程按扣除坏账/跌价/折旧/摊销/减值后的净额列示；备抵科目不得单列在资产方。
- **一年内到期重分类**：长期借款、长期应收款、租赁负债、长期应付款中一年内到期部分，转"一年内到期的非流动资产/非流动负债"。
- **受限资产不入表外**：保证金、质押存单、查封冻结资产照原科目列示，受限情况在附注披露。
- **货币资金构成**：库存现金、银行存款、其他货币资金（含承兑保证金、信用证保证金、第三方支付账户）分列；**受限部分在附注单列**，不能只报一个总数。
- 年初余额 = 上年期末余额；有差错更正或追溯调整，**调年初数并在附注说明**，不许直接改上年报表了事。

## 三、利润表

- 营业利润的计算顺序：营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用 + 其他收益 + 投资收益 + 净敞口套期收益 + 公允价值变动收益 − 信用减值损失 − 资产减值损失 + 资产处置收益。
- **研发费用单列**，不得并入管理费用（高新、研发加计扣除都要看这个数）。
- **其他收益**只放与日常活动相关的政府补助、个税手续费返还等；与日常活动无关的进营业外收入。
- 利润总额 = 营业利润 + 营业外收入 − 营业外支出；净利润 = 利润总额 − 所得税费用。
- **终止经营**单独列示（本期损益 + 处置损益），不能混在持续经营里。
- 比较期数据按同口径重述，口径变了要说明。

## 四、现金流量表

- 编制方法：主表用**直接法**，附注用**间接法**（净利润调节为经营活动现金流量）。两法结果必须一致。
- 三大活动净额 + 汇率变动影响 = 现金及现金等价物净增加额；再加期初余额 = 期末余额。
- **现金及现金等价物 ≠ 货币资金**：剔除受限资金（保证金、冻结存款）、剔除三个月以上定期存款（属投资活动）。
- 承兑汇票保证金、信用证保证金、被冻结账户**不算现金**，其增减在"支付/收到的其他与筹资（经营）活动有关的现金"反映。
- 往来款按性质分流：货款进经营活动，借款进筹资活动，**不得把股东借款混进经营活动**。
- 票据贴现：不附追索权的按经营/筹资实质归类，附追索权的按**质押借款**处理（筹资活动）。

## 五、所有者权益变动表

- 纵列：实收资本（股本）、其他权益工具、资本公积、减库存股、其他综合收益、专项储备、盈余公积、未分配利润、少数股东权益、合计。
- 横列：上年年末余额 → 会计政策变更/前期差错更正 → 本年年初余额 → 本年增减（综合收益总额、所有者投入与减少、利润分配、内部结转）→ 本年年末余额。
- **综合收益总额 = 净利润 + 其他综合收益税后净额**，与利润表、资产负债表权益项三方对齐。

## 六、附注逐项清单（按这个顺序核，缺项写"待补"，不写"无"）

### 6.1 编制基础与总述

| 项 | 要点 |
|---|---|
| 企业基本情况 | 注册地、业务性质、主要经营活动、母公司/最终控制方、报表批准报出日 |
| 编制基础 | 持续经营假设、权责发生制、记账本位币、会计期间、计量属性 |
| 合并范围 | 纳入合并的子公司清单及变化（新增/处置/不再控制） |
| 重要会计政策 | 见 §6.2 |
| 重要会计估计 | 见 §6.2 |
| 遵循声明 | "本报表符合企业会计准则（或小企业会计准则）的要求" |

### 6.2 会计政策与估计（逐项写，不能一句"按准则执行"）

金融工具分类与计量 · 存货计价与跌价 · 长期股权投资核算方法 · 投资性房地产后续计量 · 固定资产折旧（分类、年限、残值率）· 在建工程转固时点 · 无形资产摊销与研发支出资本化条件 · 商誉减值测试方法 · 借款费用资本化 · 收入确认时点/时段（按时段确认的写履约进度法）· 合同履约成本与合同取得成本 · 租赁（承租人与出租人分类）· 职工薪酬与辞退福利 · 股份支付 · 政府补助（总额/净额）· 递延所得税 · 外币折算 · 合并政策 · 关联方认定口径。

### 6.3 报表项目说明（每个重要项目按"构成 → 增减 → 受限/质押 → 减值"四段写）

| 报表项目 | 必须披露的内容 |
|---|---|
| 货币资金 | 库存现金/银行存款/其他货币资金分项；**受限金额与原因**；存放在境外的款项 |
| 应收票据 | 分类（银行/商业）、已质押/已贴现未到期金额 |
| 应收账款 | 账龄结构、坏账准备计提方法与本期变动、**前五名**余额及占比、关联方余额 |
| 应收款项融资 | 以公允价值计量且其变动计入其他综合收益的应收票据/账款 |
| 预付款项 | 账龄、前五名、未结算原因（超一年单列） |
| 其他应收款 | 按性质分（押金保证金、备用金、往来款）、账龄、坏账、**关联方往来单列** |
| 存货 | 分类（原材料/在产品/库存商品/发出商品/周转材料）、跌价准备变动、**用于担保的存货** |
| 合同资产/合同负债 | 与收入的对应关系、减值、账龄 |
| 长期股权投资 | 被投资单位、持股比例、核算方法、减值 |
| 其他权益工具投资 / 其他非流动金融资产 | 公允价值层次、本期变动 |
| 投资性房地产 | 成本模式/公允价值模式、公允价值取得依据 |
| 固定资产 | 分类原值、累计折旧、减值准备、**本期增减明细**、未办妥产权证书的 |
| 在建工程 | 项目、预算数、工程进度、利息资本化金额、转固时点 |
| 使用权资产 / 租赁负债 | 租赁期限、折现率、未来租赁付款额到期分析 |
| 无形资产 | 分类（土地使用权/专利权/软件/商标）、摊销、研发支出资本化金额 |
| 商誉 | 形成来源、**资产组划分、减值测试关键假设、可收回金额确定方法** |
| 长期待摊费用 | 项目、摊销期限（装修费、模具等） |
| 递延所得税 | 可抵扣/应纳税暂时性差异明细、未确认递延所得税资产的可抵扣亏损及到期日 |
| 短期/长期借款 | 质押、抵押、保证情况；逾期未还的 |
| 应付账款 | 账龄超一年的重要款项 |
| 应付职工薪酬 | 工资、奖金、社保、公积金、工会经费与职工教育经费、辞退福利 |
| 应交税费 | 分税种列示期初、本期应交、本期已交、期末 |
| 预计负债 | 对外担保、未决诉讼、产品质量保证、亏损合同 |
| 递延收益 | 政府补助项目、本期计入损益金额 |

### 6.4 专项披露（容易整块漏掉，单独当 checklist 打勾）

- [ ] **关联方及交易**（CAS 36）：母公司、子公司、合营联营、关键管理人员及其近亲属控制的企业；交易类型、金额、未结算余额、定价政策
- [ ] **分部报告**（CAS 35）：经营分部划分依据、各分部收入/利润/资产、地区分部
- [ ] **或有事项**（CAS 13）：未决诉讼、对外担保、已贴现未到期票据、亏损合同
- [ ] **资产负债表日后事项**（CAS 29）：调整事项与非调整事项分开写，注明"截至报表批准报出日"
- [ ] **政府补助**（CAS 16）：项目、金额、计入损益或递延的金额
- [ ] **金融工具风险**（CAS 37）：信用风险、流动性风险、市场风险（利率/汇率）、到期分析
- [ ] **承诺事项**：资本承诺、经营租赁承诺、对外投资承诺
- [ ] **股份支付**：权益结算/现金结算、等待期、本期确认费用
- [ ] **非经常性损益明细**（如对外提供）
- [ ] **母公司报表**（合并报表主体必须附）

## 七、编制前要客户提供的资料（缺一样就先别动手）

科目余额表（末级）· 序时账（全年）· 上年度报表与附注 · 银行对账单与余额调节表 · 存货盘点表 · 固定资产台账与折旧表 · 借款合同与担保合同 · 租赁合同 · 销售与采购前五名 · 关联方清单 · 政府补助文件 · 诉讼与仲裁资料 · 期后回款情况。

> **红线**：资料不齐就出表，等于把客户的缺口背到自己身上。缺件清单书面发给客户，回执留档。

## 八、三个最容易翻车的地方

1. **货币资金里躺着受限的钱**——报表上是"现金"，实际不能用，现金流量表就编错。先问"这户能随便动吗"。
2. **应收账款只报净额不报账龄**——附注一查就露，且坏账准备计提依据说不清。
3. **小准则硬套企业准则格式**——列报项目对不上，被银行或税务退回重做。
