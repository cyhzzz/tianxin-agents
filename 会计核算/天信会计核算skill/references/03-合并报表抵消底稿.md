# 03 合并报表抵消底稿

> 天信原创。上游（AI 会计主管）明确未覆盖合并，本文件给**合并范围判定 + 工作底稿结构 + 抵消分录清单**。
> 边界：只给框架与分录模板，**合并范围、商誉减值、特殊交易（分步取得、处置丧失控制）须合伙人与项目注师定**。

## 一、先判合并范围（判错，后面全白做）

控制 = 三要素同时具备：

| 要素 | 要回答的问题 | 证据 |
|---|---|---|
| **权力** | 能否主导被投资方的相关活动（经营与财务决策） | 股东会/董事会表决权比例、章程特别约定、一致行动协议、委托表决 |
| **可变回报** | 是否从参与中获得可变回报 | 分红、管理费、协同收益、风险敞口 |
| **运用权力影响回报** | 是否有能力用权力影响自己的回报 | 上述两者能否建立因果 |

- **持股过半不必然控制**（有托管、一致行动、章程限制），**持股不过半也可能控制**（协议控制、潜在表决权、结构化主体）。
- **结构化主体**（信托、资管、合伙基金）：看谁是主要责任人、谁吸收最大风险。
- 母公司是**投资性主体**时，其子公司不并表，按公允价值计量——须先确认客户是否属此类。
- 判定结论写进底稿：控制依据、证据清单、判定人。

## 二、合并工作底稿结构（一张表装下全部）

列结构固定为 **8 段**：

```
项目 | 母公司 | 子公司A | 子公司B | 合计 | 抵消借方 | 抵消贷方 | 合并数
```

- **合计列**：各主体账面数简单相加（不调口径）。
- **抵消列**：只放抵消分录，每笔编号（D1、D2…），与分录清单一一对应。
- **合并数** = 合计 + 借贷方净额。
- 每笔抵消分录下附**原始依据**：内部交易明细表、往来对账单、投资协议、股权比例表。

配套附表（缺一不可）：

| 附表 | 内容 |
|---|---|
| 股权结构表 | 各子公司持股比例、取得方式（同一/非同一控制）、取得日 |
| 内部往来对账表 | 母子公司间应收应付逐户对账，差异列原因 |
| 内部交易明细表 | 存货、固定资产、服务、资金拆借，逐笔金额与未实现利润 |
| 权益抵消计算表 | 子公司净资产各项目 × 持股比例，商誉/资本公积差额计算 |
| 少数股东权益计算表 | 期初 + 损益份额 + 其他权益变动 − 分配 |
| 抵消分录汇总表 | 编号、摘要、借贷科目、金额、依据 |

## 三、抵消分录清单（按这个顺序做，不跳步）

### D1 长期股权投资与子公司所有者权益

**非同一控制**（购买法）：

```
借：实收资本（股本）
    资本公积
    其他综合收益
    盈余公积
    未分配利润（子公司账面，调整公允价值后的金额）
    商誉（差额，借方）
贷：长期股权投资（母公司账面，调整后的合并成本）
    少数股东权益（子公司净资产公允价值 × 少数股东比例）
```

差额在贷方时计入**营业外收入**（负商誉，须复核资产公允价值与负债是否漏计）。

**同一控制**（权益结合法）：不产生商誉，差额调整**资本公积**（不足冲减留存收益）：

```
借：实收资本 / 资本公积 / 盈余公积 / 未分配利润
贷：长期股权投资
    资本公积（差额，或借方）
```

比较期报表须按同一控制口径**重述**。

### D2 少数股东权益与损益

```
借：少数股东损益（子公司本期净利润 × 少数股东比例）
贷：少数股东权益
```

**注意**：子公司亏损时少数股东损益为负，仍按比例分担（除非章程/协议另有约定且该约定使少数股东不承担超额亏损）。

### D3 内部债权债务

```
借：应付账款/其他应付款/应付票据
贷：应收账款/其他应收款/应收票据
```

对账不平的先查原因（在途、票据未到、单边记账），**差额挂"待查"不许硬抵**。

### D4 内部债权计提的坏账准备

```
借：应收账款——坏账准备
贷：信用减值损失（本期计提部分）
    期初未分配利润（以前年度计提部分）
```

### D5 内部利息收支

```
借：投资收益（或财务费用——利息收入）
贷：财务费用——利息支出
```

资本化的内部利息同时调整在建工程/存货。

### D6 内部存货交易

本期销售、期末仍有存货：

```
借：营业收入（内部售价）
贷：营业成本
    存货（期末存货中含的未实现毛利）
```

期初存货本期对外售出（上年未实现利润本期实现）：

```
借：期初未分配利润
贷：营业成本
```

### D7 内部固定资产/无形资产交易

```
借：资产处置收益（或营业外收入）
贷：固定资产——原价（未实现利润）
借：固定资产——累计折旧（多提的折旧）
贷：管理费用/制造费用等（本期）＋ 期初未分配利润（以前年度）
```

无形资产同理，按剩余摊销期分摊。

### D8 内部投资收益与利润分配

```
借：投资收益（母公司确认的子公司分红）
贷：利润分配——对所有者（或股东）的分配
```

### D9 内部交易产生的递延所得税

内部交易未实现利润形成暂时性差异：

```
借：递延所得税资产
贷：所得税费用（或期初未分配利润）
```

### D10 内部现金流

按**同活动、同方向**对冲：

```
借：经营活动——购买商品、接受劳务支付的现金
贷：经营活动——销售商品、提供劳务收到的现金
```

**跨活动不抵销**（如母公司投资支出、子公司实收资本），只在合并层面调整列报方向。

### D11 以前年度抵消的延续

上期抵消影响本期期初数的（未实现利润、坏账准备、折旧），本期须通过**期初未分配利润**承接，否则本年合并数会重复计入。

### D12 外币报表折算

境外子公司报表折算差额进**其他综合收益**，处置时转入当期损益。

## 四、同一控制 vs 非同一控制（记错这套，商誉就编出来了）

| 项 | 同一控制 | 非同一控制 |
|---|---|---|
| 计价基础 | 账面价值 | 公允价值 |
| 差额处理 | 调资本公积（不足冲留存收益） | 确认商誉 / 营业外收入 |
| 合并日前的经营成果 | 纳入合并报表（视同一直存在） | 只纳入购买日之后 |
| 比较期 | 须重述 | 不重述 |
| 交易费用 | 计入当期损益 | 计入当期损益（发行权益性证券的冲资本公积） |

## 五、底稿交付前自查

- [ ] 合并范围判定有依据、有签字
- [ ] 各主体报表口径一致（会计政策、会计期间已统一，差异已调整）
- [ ] 内部往来已逐户对账，差异有说明
- [ ] 抵消分录编号连续、与汇总表一致、附件齐全
- [ ] 少数股东权益、少数股东损益计算表可复核
- [ ] 商誉只在非同一控制下出现，且减值测试有底稿
- [ ] 合并数与各主体报表加总 − 抵消合计能对上（做一次"总额校验"）
- [ ] 比较期已按本期合并范围重述（新增/处置子公司）

> **红线**：合并范围"该并不并"（藏亏损）、"不该并硬并"（做大规模），都是监管重点。判定过程必须留痕，不能只有结论。
