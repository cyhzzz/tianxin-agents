# 02 四表一注勾稽校验表

> 天信原创。上游只给了四条原则性勾稽，不够查错——本文件是**逐项可算的校验清单**。
> 用法：出表前逐条打勾，不平的写差异原因与处理，**不许抹平**。差异无法解释 → 不出表。

## 一、校验清单（按顺序做，A→B→C）

### A 组：表内自平（算错就立刻能发现）

| # | 校验 | 公式 | 常见不平原由 |
|---|---|---|---|
| A1 | 资产负债表平衡 | 资产总计 = 负债合计 + 所有者权益合计 | 漏记凭证、科目串户、未结转损益 |
| A2 | 流动/非流动划分 | 流动资产 + 非流动资产 = 资产总计 | 一年内到期部分未重分类 |
| A3 | 利润表逐级 | 营业利润 = 收入 − 成本 − 税金及附加 − 三费−研发 + 其他收益 + 投资收益 + 公允价值变动 − 信用减值 − 资产减值 + 资产处置收益 | 减值损失符号写反（应为减项） |
| A4 | 利润总额 | 营业利润 + 营业外收入 − 营业外支出 | 政府补助错放营业外 |
| A5 | 净利润 | 利润总额 − 所得税费用 | 所得税费用含了直接进权益的部分 |
| A6 | 现金流量表合计 | 经营 + 投资 + 筹资净额 + 汇率影响 = 现金净增加额 | 汇率影响漏项 |
| A7 | 现金流量表期末 | 期初余额 + 净增加额 = 期末余额 | 期初口径与上年不一致 |

### B 组：表与表衔接（最容易漏，也最容易被审计挑出）

| # | 校验 | 公式 | 排查 |
|---|---|---|---|
| B1 | 未分配利润滚动 | 期末 = 期初 + 本期净利润 − 提取盈余公积 − 分配股利 ± 其他（盈余公积补亏、所有者权益内部结转） | 先查是否漏提盈余公积、是否有利润分配未入账 |
| B2 | 盈余公积滚动 | 期末 = 期初 + 本期提取 − 弥补亏损/转增资本 | 提取比例是否按章程/法定 |
| B3 | 权益变动表综合收益 | 综合收益总额 = 净利润 + 其他综合收益税后净额 | OCI 是否含重分类进损益部分 |
| B4 | 权益变动表与资产负债表 | 本年年末余额各行 = 资产负债表所有者权益各项目 | 少数股东权益只在合并报表出现 |
| B5 | 现金流量表期末现金 | 期末现金及现金等价物 = 货币资金 − 受限资金 − 三个月以上定期存款 − 非现金等价物 | 保证金、冻结户是否剔除 |
| B6 | 现金流量表净利润起点 | 间接法起点净利润 = 利润表净利润（合并口径为归母前净利润） | 合并报表误用归母净利润 |
| B7 | 间接法调节结果 | 经营活动现金流量净额（间接法）= 经营活动现金流量净额（直接法） | 逐个调节项核对，常见漏"存货减少"或"经营性应收增加"符号 |
| B8 | 所得税与递延 | 所得税费用 = 当期所得税 + 递延所得税费用（不含直接计入权益/商誉的部分） | 递延所得税对应 OCI 的部分不得计入损益 |
| B9 | 合并报表归属 | 净利润 = 归属于母公司所有者的净利润 + 少数股东损益；所有者权益 = 归母权益 + 少数股东权益 | 少数股东损益算错（按持股比例乘归母利润） |

### C 组：附注与报表一致（AI 最容易在这里偷懒）

| # | 校验 | 要点 |
|---|---|---|
| C1 | 附注项目金额 = 报表项目金额 | 应收账款、存货、固定资产、应交税费等逐个对；附注合计 = 报表数，不是"抽几个写" |
| C2 | 附注账龄合计 | 账龄各段之和 = 该项目余额（不是净额，是与坏账准备前的余额） |
| C3 | 坏账准备表 | 期初 + 本期计提 − 本期收回/核销 = 期末；计提数 = 利润表信用减值损失中对应部分 |
| C4 | 固定资产表 | 原值期初 + 增加 − 减少 = 期末；累计折旧同理；折旧本期计提数 = 成本费用中折旧 |
| C5 | 应交税费表 | 期初 + 应交 − 已交 = 期末；与资产负债表、现金流量表"支付的各项税费"三方对 |
| C6 | 现金流量表补充资料 | 折旧、摊销、减值、处置损失等加回数 = 附注对应项目金额 |
| C7 | 收入分解 | 附注收入按类别/地区/时点分解，合计 = 利润表营业收入 |
| C8 | 前五名披露 | 前五名合计 ≤ 该项目总额；占比算式与实际数一致 |
| C9 | 关联方交易 | 关联方销售/采购金额 ≤ 营业收入/营业成本；未结算余额与往来科目对得上 |
| C10 | 分部合计 | 各分部收入合计（抵销前需说明）= 营业收入；分部资产合计与总资产差异要解释 |

## 二、不平时的排查顺序（省时间）

1. **先查 A 组**——表内都不平，说明账本身有问题，别急着找表间差异。
2. **再查 B1/B2**（权益滚动）——80% 的"表间不平"出在这里：利润分配没入账、盈余公积忘提、以前年度损益调整没结转。
3. **然后 B5/B7**（现金）——先确认"现金及现金等价物"的口径，再查调节项符号。
4. **最后 C 组**——附注与报表不一致通常是**报表改了附注没改**，重新导出附注数比对，不要手工补。

## 三、常见不平原因清单（对照着找）

| 现象 | 大概率原因 |
|---|---|
| 资产 ≠ 负债 + 权益，差额恰好等于某笔金额 | 单边记账（只记借或只记贷）、凭证未过账 |
| 未分配利润滚不平，差额 = 所得税额 | 所得税费用直接走了"未分配利润" |
| 未分配利润滚不平，差额 = 某笔分红 | 利润分配未做账，或做了但未结转 |
| 权益变动表综合收益 ≠ 净利润 + OCI | OCI 未扣税，或把重分类调整重复计入 |
| 现金流量表期末 ≠ 货币资金 | 受限资金/定期存款未剔除，或承兑保证金误当现金 |
| 间接法 ≠ 直接法 | 调节项漏项（最常见：存货、经营性应收应付、财务费用） |
| 附注合计 ≠ 报表数 | 报表出完后又有调整分录，附注未重出 |
| 合并净利润 ≠ 归母 + 少数股东 | 少数股东损益按归母净利润乘比例算的（应按子公司净利润） |

## 四、记录要求

底稿留一张**勾稽校验表**：校验编号、左值、右值、差额、结论（平/不平）、差异原因、处理方式、复核人签字。

- 差额为 0 也要留痕（证明做过）。
- 差异有正当理由的（如重分类），写清"差多少、为什么、调到哪"，附调整分录。
- **不许用"四舍五入"解释超过 1 元的差异**。

> **红线**：勾稽不平硬出表，是把风险留给签字人。审计一抽就抽到这里，且属于"未勤勉尽责"的直接证据。
