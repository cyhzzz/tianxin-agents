另外 `公用/天信文档skill/references/` 里已有报告骨架、研究深度、行文口径三份方法论，缺的是**问题拆解**和**估值**两块。

## 可复用的外部方法论

商店里 `consulting-partners` 有三个 skill 值得拆：

| skill | 内容 | 对天信的价值 |
|---|---|---|
| `hypothesis-framing` | MECE 议题树、假设驱动 | 现在的报告骨架是章节结构，不是问题拆解 |
| `evidence-analysis` | 证据分级、框架库 | 已有三级标记，但没有证据强度分级 |
| `valuation-modeling` | DCF + 可比 + 假设翻转测试（带脚本） | 正山堂、广德元真都用得上 |

**假设翻转测试**值得单独说：对模型里每个假设做单变量扰动，找出那个一旦不成立、整个推荐就要推翻的致命假设——而不是笼统说「存在不确定性」。

## 需要什么材料

不太需要额外材料，用现有案例 + 外部方法论就能起。唯一要确认的是：**这条线接不接外部委托，还是只服务内部决策**。
