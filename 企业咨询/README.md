## 两个上游包怎么分工

| 情形 | 用哪个 | 为什么 |
|---|---|---|
| 中大型企业、体系化建设、要论证有出处 | `mc-*`（管理咨询实战专家） | 11 大模块有诊断框架与设计工具，另有经典层与标杆前沿可作论据 |
| 中小企业、人少钱紧、要短周期见效、要现成模板 | `sme-*`（企效通） | 手册按"人少、钱紧、时间碎"设计，制度、函件、清单可直接成文 |

**别两边都抄一遍。** 两包在战略、人力、营销、财务上能力域重叠，先选一个当主，另一个只在缺具体模板时补。

## 和法定业务线的分工

| 客户诉求 | 归谁 |
|---|---|
| 管理建议、体系设计、经营改善、诊断报告 | **本线** |
| 审计意见、鉴证、底稿 | 审计线（`天信审计底稿`） |
| 评估结论、价值类型、报告审核 | 资产评估线（`天信资产评估`） |
| 算税、申报、汇算清缴、税务风险 | 税务线（`天信税务申报`） |
| 凭证、账簿、报表、附注、合并 | 会计核算线（`天信会计核算`） |
| 日常记账、报税、工商 | 代理记账线（`天信代账作业`） |

咨询项目里出现上述结论性判断，**转线，不越界**。

## 上游能不能直接用

- **直接可用**：11 大模块的诊断框架与工具（BLM、OGSM、三种管控模式、三定、RACI、韦斯伯德六盒、7S、九宫格、海氏岗位评估、流程 L0-L5、STP、营销 ROI 模型、杜邦分析、NPV/IRR/ROIC）、16 大领域经典源流、中小企业八大能力域模板与指标库。
- **需裁剪**：大企业体系不能直接给小微企业（三层架构、全套九宫格、宽带薪酬套改）。裁剪了什么、为什么裁，写在方案里。
- **需核出处**：经典层与前沿层的年份、理论归属、顶刊结论，进正式报告前核原始出处；上游案例一律脱敏后引用，**不得暗示是天信项目**。
- **需换基线**：`sme-2` 末尾的制造业财务指标是经验参照值，不是统计口径，对标前换成本地本行业实测。
