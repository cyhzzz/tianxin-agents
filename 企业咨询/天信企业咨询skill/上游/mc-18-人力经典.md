# 23 · 人力资源经典方法论

> 源流：从泰勒科学管理与人事管理，到梅奥人际关系学派、麦格雷戈 X/Y 理论，再到尤里奇 HR 三支柱与四角色、麦克利兰胜任力、卡佩利内部劳动力市场、哈佛 4C 模型。

---

## 一、人力资源管理理论的三个跃迁

| 阶段 | 时期 | 定位 | 核心理念 |
|---|---|---|---|
| **人事管理** | 1900s-1950s | 事务行政 | 招人、发薪、管档案；人是成本 |
| **人力资源管理** | 1960s-1990s | 职能专业 | 选育用留系统化；人是资源 |
| **战略人力资源 / 人力资本** | 2000s+ | 战略伙伴 | 人力是资本，是竞争优势来源 |

**战略人力资源的核心命题（资源基础观 RBV 视角）**：
- 人力资本满足 VRIN 条件时（价值性、稀缺性、难以模仿、不可替代），可成为持续竞争优势的来源
- **关键悖论**：单个人的能力可以流动（可被挖角），但**组织化的能力**（团队协作模式、组织惯例、文化）难以复制——这才是真正的护城河

## 二、经典理论框架

### 2.1 麦格雷戈：X 理论与 Y 理论

| 维度 | X 理论 | Y 理论 |
|---|---|---|
| 人性假设 | 人天生懒惰、逃避责任 | 人愿意工作、主动承担责任 |
| 管理方式 | 强制、控制、惩罚 | 授权、参与、自我管理 |
| 激励重点 | 物质刺激 + 监督 | 内在动机 + 成就 |
| 适用场景 | 重复性、标准化工作 | 创造性、知识型工作 |

**咨询用法**：管理制度背后都隐含人性假设。用 X 理论管知识型员工，会导致"上有政策下有对策"。诊断管理制度的错配，往往从这里开始。

### 2.2 戴维·麦克利兰：胜任力理论

**核心贡献**：区分"表象特征"与"潜在特征"

```
        水面之上（容易观测、容易培养）
        ─────────────────────────
        知识 Knowledge、技能 Skill          ← 门槛条件（基准性胜任力）
        ─────────── 水面 ───────────
        社会角色、自我概念、特质、动机        ← 鉴别性胜任力（区分绩优与平庸）
        水面之下（难以观测、难以改变）
```

**三大动机理论（麦克利兰）**：
| 动机 | 内涵 | 匹配岗位 |
|---|---|---|
| 成就需要（nAch） | 追求卓越、超越标准 | 创业者、销售、专业专家 |
| 权力需要（nPow） | 影响他人、掌控局面 | 管理者、领导者 |
| 亲和需要（nAff） | 建立良好关系、被喜欢 | 客户服务、团队协作角色 |

**咨询用法**：任职资格体系设计的理论起点。**关键原则**：门槛条件（学历、经验、知识）只用于筛选；真正决定绩效的是水下的胜任力。因此任职资格标准必须包含行为化的胜任力描述，而不是只列学历年限。

### 2.3 戴维·尤里奇：HR 四角色与三支柱

**HR 四个角色**：

| 角色 | 关注点 | 成果 | 时间取向 |
|---|---|---|---|
| **战略伙伴** | 战略 | 战略执行 | 长期/战略 |
| **行政专家** | 流程 | 效率提升 | 短期/运营 |
| **员工代言人** | 员工 | 员工承诺 | 短期/运营 |
| **变革推动者** | 变革 | 组织转型 | 长期/战略 |

**HR 三支柱模型**：

```
        ┌─────────────────────────────┐
        │  HRBP（业务伙伴）            │  ← 深入业务，识别需求
        │  Human Resources Business    │
        │  Partner                     │
        └──────────┬──────────────────┘
                   │
    ┌──────────────┴──────────────┐
    │                             │
┌───▼──────────┐        ┌─────────▼────────┐
│  COE（专家中心）│        │  SSC（共享服务中心）│
│  Center of    │        │  Shared Service   │
│  Expertise    │        │  Center           │
└──────────────┘        └───────────────────┘
   政策/方案设计             事务性服务交付
```

**三支柱的落地要点**：
- **HRBP 需不需要**取决于业务复杂度与规模；没有规模强行设 HRBP 会变成"两个 HR 部门"
- **COE 的核心是专业深度**，不是"总部机关"
- **SSC 的前提是标准化**；流程不标准就先建 SSC，只会把混乱自动化

**咨询用法**：客户提出"我们要建 HR 三支柱"时，先问三个问题：①业务单元有多少个、规模多大？②当前 HR 的标准化程度如何？③HR 团队有没有 COE 级的专业能力？三个问题中有一个是否定的，就要先补基础。

### 2.4 哈佛模型：4C 框架

| 要素 | 内涵 | 关键问题 |
|---|---|---|
| **承诺 Competence** | 员工能力 | 我们需要什么能力？如何获得？ |
| **承诺 Commitment** | 员工忠诚 | 如何提升员工的归属与投入？ |
| **一致性 Congruence** | 目标协同 | 员工与组织目标是否一致？ |
| **成本效益 Cost-effectiveness** | 效率 | 人力投入产出是否合理？ |

**咨询用法**：HR 体系的四维体检表。四个" C "互为因果——能力不足导致承诺下降，承诺不足导致一致性差，一致性差导致成本上升。

### 2.5 人才盘点与继任管理

**九宫格（绩效-潜力矩阵）**：

| | 低绩效 | 中绩效 | 高绩效 |
|---|---|---|---|
| **高潜力** | 待观察（可能是错配） | 潜力之星 | **明星/继任者** |
| **中潜力** | 需改善 | 核心骨干 | 高绩效者 |
| **低潜力** | 需调整 | 稳定贡献者 | 专业专家 |

**九宫格的正确用法**：
- 横轴绩效：用过去 2-3 年的持续绩效，不用单年数据
- 纵轴潜力：用"能否在更高层级成功"判断，不是"现在干得好"
- **爱迪生陷阱**：绩效高但潜力低的人，不要硬提拔为管理者（会毁掉一个好的工程师和制造一个差的管理者）
- 盘点结果必须与动作挂钩（晋升、发展、调岗、退出），否则盘点变成"填表运动"

**继任计划的要点**：
- 关键岗位（不是所有岗位）建立继任梯队
- 每个关键岗位至少 1-2 名"准备就绪"与"1-2 年内就绪"的后备
- 继任者培养必须有具体的历练安排（轮岗、项目、代理），不能只靠培训

### 2.6 人才发展的经典模型

**70-20-10 法则**：
| 比例 | 学习方式 | 具体形式 |
|---|---|---|
| 70% | 在岗实践 | 挑战性任务、轮岗、项目历练、代理 |
| 20% | 向他人学习 | 导师制、教练、上级辅导、同侪学习 |
| 10% | 正式培训 | 课程、认证、在线学习 |

**咨询用法**：客户抱怨"培训没效果"时，检查是否 90% 投入都放在了 10% 的正式培训上。真正的能力提升发生在岗位上——人才培养项目必须设计"有挑战的实战任务"。

**诺尔斯成人学习理论（Andragogy）**：
1. 成人需要知道"为什么学"
2. 成人有丰富的经验可作学习资源
3. 成人以问题为中心而非以学科为中心
4. 成人需要自我导向
5. 成人的学习动机来自内在（解决问题、自我实现）

**咨询用法**：设计培训项目时，先回答"学员的问题是什么"，而不是"我要讲什么知识"。

### 2.7 学习地图与任职资格

**学习地图的四层结构**：
```
① 岗位序列（管理序列 / 专业序列 / 操作序列）
      ↓
② 职级阶梯（每个序列的层级）
      ↓
③ 能力要求（每级的知识、技能、能力、经验）
      ↓
④ 学习内容（课程、实践任务、认证要求）
```

**任职资格标准的结构**：
| 维度 | 内容 | 评价方式 |
|---|---|---|
| 基本条件 | 学历、专业、年限、证书 | 资格审查 |
| 知识技能 | 专业知识、工具技能 | 考试、实操 |
| 行为标准 | 关键行为项描述 | 行为举证、答辩 |
| 绩效贡献 | 业绩结果、项目经历 | 业绩数据、案例评审 |
| 素质要求 | 胜任力项 | 测评、评价中心 |

**双通道设计**：管理通道（M 序列）与专业通道（P 序列）并行的晋升体系。关键在于**等价性**——专业通道不能成为"安慰奖"，必须在薪酬、待遇、话语权上与同层级管理岗位可比。

## 三、人力资源方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 员工执行力差、制度没人遵守 | 麦格雷戈 X/Y 理论（人性假设错配） |
| 招人与实际用人标准脱节 | 麦克利兰胜任力冰山模型 |
| 要建 HR 三支柱 | 尤里奇四角色 + 三支柱落地三问 |
| HR 体系整体诊断 | 哈佛 4C 框架 |
| 干部选拔与继任 | 九宫格盘点 + 继任梯队设计 |
| 培训没效果 | 70-20-10 + 诺尔斯成人学习理论 |
| 专业人才留不住、只能靠升官 | 双通道晋升体系设计 |
| 人才梯队断档 | 学习地图 + 关键岗位继任计划 |
| 人效低 | 哈佛模型成本效益维度 + 人效指标对标 |
