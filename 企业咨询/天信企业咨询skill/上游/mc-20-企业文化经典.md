# 25 · 企业文化经典方法论

> 源流：从 1980 年代企业文化"四重奏"（迪尔/肯尼迪、大内 Z 理论、帕斯卡尔 7S、彼得斯《追求卓越》），到沙因文化三层次与领导力、卡梅隆竞争价值框架、丹尼森文化模型、科特文化与绩效实证研究，再到文化落地的本土方法论。

---

## 一、企业文化理论的兴起：1980 年代"四重奏"

| 著作 | 作者 | 核心贡献 |
|---|---|---|
| 《企业文化——企业生活中的礼仪与仪式》(1982) | 迪尔 & 肯尼迪 | 提出文化的五要素与四种文化类型；企业文化学科奠基 |
| 《Z 理论——美国企业界怎样迎接日本的挑战》(1981) | 威廉·大内 | 在 X/Y 理论基础上提出 Z 理论，强调信任、微妙性、亲密关系 |
| 《日本企业管理艺术》(1981) | 帕斯卡尔 & 阿索斯 | 提出 7S 模型，强调"软 S"的重要性 |
| 《追求卓越》(1982) | 彼得斯 & 沃特曼 | 卓越企业八项原则；强有力的文化是成功的新"金科玉律" |

**共同结论**：**强有力的文化是企业取得成功的关键因素**。企业管理不仅是结构、制度、数字的"硬"管理，更是价值观、作风、人的"软"管理。

## 二、沙因：文化三层次与领导力（企业文化领域最权威的框架）

### 2.1 文化三层次模型

| 层次 | 内容 | 可观察性 | 调研方法 |
|---|---|---|---|
| **人工制品（Artifacts）** | 组织结构、流程、语言、着装、仪式、故事、办公布局 | 容易看到，但难以解读其意义 | 现场观察、文档梳理 |
| **信奉的价值观（Espoused Beliefs & Values）** | 战略、目标、哲学、宣称的价值观 | 容易获取，但可能是"应该怎样"而非"实际怎样" | 访谈、文化手册 |
| **基本潜在假设（Basic Underlying Assumptions）** | 无意识的信念、认知、思维模式、情感 | 难以触及，却是行为的真正根源 | 深度访谈、行为回溯、冲突情境分析 |

**最关键的洞察**：**"信奉的价值观"与"基本假设"之间常常存在差距。** 公司墙上写的"以人为本"，与员工实际感受到的"谁业绩好谁有理"，是两回事。文化诊断的真正价值是揭示第三层。

### 2.2 领导者在文化中的作用

**沙因的核心命题**：**领导力是文化形成和变革的首要力量。**

- **创始阶段**：创始人通过自身的信念、行为、招聘标准、奖惩导向，把个人假设植入组织
- **成长期**：文化通过成功经验被强化（"这样做能成功"）
- **成熟期**：文化成为约束（"我们一向这么做"）
- **变革期**：只有领导者能改变文化——因为只有领导者能重塑基本假设

**领导者植入文化的六大机制**：
1. 关注什么、衡量什么、控制什么
2. 对关键事件和危机的反应
3. 如何分配资源
4. 有意的角色示范、教导和训练
5. 如何分配奖惩与地位
6. 招聘、选拔、晋升和辞退的标准

**领导者传播文化的次级机制**：
组织结构设计、制度流程、仪式与礼仪、物理空间设计、故事与传说、正式声明与理念

**咨询用法**：文化变革项目必须从"领导者的行为"入手，而不是从"文化手册"入手。**领导者不改行为，文化不可能变。**

## 三、迪尔 & 肯尼迪：文化要素与类型

### 3.1 企业文化的五要素

1. **企业环境**（Environment）：决定文化形态的首要因素（市场、行业、竞争）
2. **价值观**（Values）：文化的核心，组织的信条
3. **英雄人物**（Heroes）：价值观的人格化载体，员工效仿的榜样
4. **礼仪与仪式**（Rites & Rituals）：文化在日常中的仪式化表达
5. **文化网络**（Cultural Network）：非正式的沟通渠道（"小道消息"、故事传播者）

**咨询用法**：文化诊断时逐项核查这五要素是否清晰、一致、有力。**"英雄人物"这一项常被忽视**——企业树立什么样的英雄（销售冠军？技术专家？老实人？），是最强的文化信号。

### 3.2 四种文化类型（按风险与反馈速度）

| 类型 | 特征 | 行业举例 |
|---|---|---|
| **硬汉型（Tough-Guy, Macho）** | 高风险、快速反馈；个人主义、崇尚强者 | 广告、娱乐、体育、咨询 |
| **拼命工作/尽情玩乐型（Work Hard/Play Hard）** | 低风险、快速反馈；重视客户、团队活动 | 销售驱动型公司、餐饮零售 |
| **赌注型（Bet-Your-Company）** | 高风险、慢反馈；重视长期判断、等级、共识 | 石油、航空、大型制造、制药 |
| **过程型（Process）** | 低风险、慢反馈；重视流程、细节、等级 | 银行、保险、政府、公用事业 |

**咨询用法**：判断客户文化类型与其业务是否需要匹配。**错配的典型**：创新驱动的业务配了"过程型"文化（层层审批、规避风险），必然死掉。

## 四、文化诊断的主流模型

### 4.1 卡梅隆 & 奎因：竞争价值框架（CVF）——最实用的文化诊断工具

**两个维度**：
- 横向：内部导向 ↔ 外部导向
- 纵向：灵活自主 ↔ 稳定控制

**四种文化类型**：

| | 内部导向 | 外部导向 |
|---|---|---|
| **灵活自主** | **家族型（Clan）** | **活力型（Adhocracy）** |
| | 像一个大家庭，重视忠诚、传统、参与、团队 | 充满活力与创造力，重视创新、试错、开拓 |
| **稳定控制** | **层级型（Hierarchy）** | **市场型（Market）** |
| | 结构严谨、流程规范，重视稳定、效率、可预测 | 结果导向、竞争激烈，重视业绩、目标、市场份额 |

**诊断方法（OCAI 量表）**：对六个方面（主导特征、领导风格、员工管理、组织粘合剂、战略重点、成功标准）各分配 100 分到四种类型，得出当前文化剖面与期望文化剖面。

**咨询用法**：这是**文化诊断与变革最可操作的工具**。步骤：①测当前文化 ②测期望文化（匹配战略所需）③算差距 ④设计变革举措。关键提醒：**不是所有文化都要变成"活力型"**——文化要与战略匹配。成本领先战略需要层级型+市场型；创新领先战略需要活力型。

### 4.2 丹尼森组织文化模型

**四个维度（各含三个子维度）**：
| 维度 | 子维度 | 核心问题 |
|---|---|---|
| **使命 Mission** | 战略方向、目标、愿景 | 我们知道要去哪里吗？ |
| **适应性 Adaptability** | 组织学习、客户关注、变革创新 | 我们能响应环境变化吗？ |
| **参与性 Involvement** | 授权、团队导向、能力发展 | 员工被赋能了吗？ |
| **一致性 Consistency** | 核心价值观、共识、协调整合 | 我们有共同的信念吗？ |

**咨询用法**：与卡梅隆 CVF 互补——CVF 看类型，丹尼森看效能。丹尼森模型特别适合关联"文化维度"与"经营绩效指标"（如客户满意度、创新能力、盈利水平）。

## 五、科特：文化与经营绩效的实证研究

**关键发现（1987-1991，对 200 多家公司的研究）**：

1. **强力型文化不必然带来好绩效**——如果文化方向错了，强力文化反而加速失败
2. **"策略合理型"文化**：文化必须与市场环境、竞争策略相匹配
3. **"灵活适应型"文化**：能持续适应环境变化的文化，长期绩效最好

**三种文化类型对长期绩效的影响**：
| 类型 | 特征 | 长期绩效 |
|---|---|---|
| 强力型 | 价值观统一、行为一致、氛围强烈 | 视方向而定（可能极好，也可能极差） |
| 策略合理型 | 文化匹配战略与市场 | 良好 |
| 灵活适应型 | 能主动适应环境、鼓励变革 | 最佳（持续优秀） |

**关键的实践洞察**：文化不是越"强"越好，而是要**方向正确 + 适应变化**。这一发现纠正了 1980 年代"强文化万能论"的偏差。

## 六、文化落地的本土方法论

### 6.1 文化落地的核心难题：知信行转化

**"两张皮"现象**：企业文化工作投入了大量资源（部门、人员、预算、活动），但因与经营管理融合不足，导致文化与管理"两张皮"，投入无法转化为效益。

**知信行三阶段模型**：

| 阶段 | 目标 | 关键动作 |
|---|---|---|
| **知（认知）** | 让员工知道文化是什么 | 宣传、培训、活动、视觉形象、沟通 |
| **信（信任）** | 让员工相信文化是真的 | 领导者以身作则、制度的文化性、承诺兑现、仪式体验、成功实践 |
| **行（行为）** | 让文化变成日常行为 | 行为标准、考核评价、激励导向、持续改进 |

**关键洞察**：**"知"最容易做（贴标语、办活动），"信"最容易被跳过（也是最关键的），"行"最难做到。** 很多企业的文化工作停留在"知"这一层，所以员工觉得"这都是虚的"。

### 6.2 文化落地的关键抓手

**抓手一：制度的文化性**

把价值观"翻译"成制度条款。例如宣称"以客户为中心"，就要检查：考核指标里客户满意度占多少权重？客户投诉的处理流程需要几个环节？权限是否给到了离客户最近的人？

**抓手二：领导行为的一致性**

员工判断文化真假，看的是领导的实际行为。**文化落地的第一战场是领导者的日程表**——领导把时间花在哪里，就是在强调什么。

**抓手三：文化仪式与符号**

| 仪式类型 | 作用 |
|---|---|
| 入职仪式 | 建立归属与身份认同 |
| 晋升/表彰仪式 | 明确什么被奖励 |
| 庆功仪式 | 强化共同成就 |
| 复盘仪式 | 建立学习与坦诚 |
| 特殊纪念日 | 传承历史与精神 |

**抓手四：文化与人力资源体系联动**

```
价值观 → 招聘标准（招什么样的人）
      → 培训内容（讲什么）
      → 考核指标（考什么）
      → 晋升标准（提什么样的人）
      → 奖惩导向（奖什么、罚什么）
```

**咨询用法**：文化落地最有效的方法不是搞活动，而是**把这五个 HR 环节全部对齐价值观**。任何一个环节错位，文化就会被稀释。

### 6.3 文化落地的量化评价

**文化考评的对象**：
- 组织层面：文化践行的整体表现（通过文化评估量表）
- 团队层面：部门文化氛围（通过团队敬业度、协作满意度）
- 个人层面：价值观践行行为（通过行为评价、360 度反馈）

**文化考评的指标体系示例**：
| 维度 | 指标 |
|---|---|
| 认知度 | 员工对价值观的知晓率、理解准确率 |
| 认同度 | 员工对价值观的认同评分、自豪感评分 |
| 践行度 | 关键行为的出现频率（如主动协作、客户第一的具体行为） |
| 影响度 | 文化对绩效的支撑度（如员工敬业度与业绩的相关性） |

**红线提醒**：文化考评要避免变成"背诵比赛"。真正的文化考评是**行为考评**，不是**知识考评**。

## 七、企业文化方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 文化诊断从哪入手 | 沙因三层次（穿透到基本假设）+ CVF 量表（测类型） |
| 文化与战略是否匹配 | 卡梅隆 CVF 当前剖面 vs 期望剖面对比 |
| 文化落地两张皮 | 知信行三阶段诊断（卡在哪一层） |
| 文化口号没人信 | 沙因六大植入机制 + 领导行为一致性检查 |
| 文化怎么与经营挂钩 | 科特"策略合理型" + HR 五环节对齐 |
| 要不要建设强文化 | 科特实证研究（方向正确 + 适应变化才关键） |
| 文化评估怎么做 | 丹尼森四维度 + 三层考评对象 |
| 并购后文化融合 | 沙因基本假设差异分析 + 双文化整合路径 |
| 文化变革推不动 | 沙因"领导力是文化变革首要力量"+ 科特八步 |
