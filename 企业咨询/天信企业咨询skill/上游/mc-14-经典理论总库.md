## 二、跨领域"母理论"——最高频引用的六块基石

以下六套理论**跨多个领域被反复调用**，是咨询方案中出镜率最高的"通用语言"。建议优先掌握。

### 基石一：波特竞争战略体系

| 工具 | 核心内容 | 适用场景 |
|---|---|---|
| **五力模型** | 供应商议价力、购买者议价力、新进入者威胁、替代品威胁、行业竞争强度 | 行业吸引力判断、进入决策 |
| **三大通用战略** | 成本领先、差异化、集中化（聚焦） | 战略定位选择 |
| **价值链** | 基本活动（进料物流/生产/出货物流/营销/服务）+ 支持活动（采购/技术/HR/基础设施） | 成本结构分析、能力识别、流程架构设计 |
| **钻石模型** | 生产要素、需求条件、相关支持产业、企业战略结构与竞争 | 区域产业竞争力、国家竞争力 |

**咨询用法**：先用五力判断"这个行业值不值得干"，再用价值链判断"我们靠哪一段赚钱"，最后用三大通用战略定"用什么姿势赢"。

### 基石二：麦肯锡 7S 与一致性原理

```
       战略 Strategy ── 结构 Structure
          │                   │
       制度 Systems ──────── 共同价值观 Shared Values
          │                   │
       风格 Style ───────── 人员 Staff ── 技能 Skills
```

- **硬件 S**（战略、结构、制度）：易于定义、易于变革
- **软件 S**（风格、人员、技能、共同价值观）：难以定义、变革慢但更根本

**核心原理**：七个要素必须**相互匹配**；任何一项变动都会牵动其余六项。咨询中用于诊断"改了一半为什么没效果"——通常是因为只动了硬件 S，没同步软件 S。

### 基石三：BLM 业务领先模型（华为战略方法论基石）

- **战略四要素**：战略意图 → 市场洞察 → 创新焦点 → 业务设计
- **执行四要素**：关键任务 → 正式组织 → 人才 → 氛围文化
- **两个底座**：领导力、价值观
- **两个起点**：业绩差距、机会差距

**关键洞察**：差距（Gap）是战略的起点，不是终点。没有差距就没有战略——因为现状已经足够好时，组织不会真正变革。

### 基石四：组织文化三层次模型（沙因）

| 层次 | 内容 | 可观察性 |
|---|---|---|
| **人工制品 Artifacts** | 可见的结构、流程、语言、仪式、着装、故事 | 容易看到，难以解读 |
| **信奉的价值观 Espoused Values** | 战略、目标、哲学、宣称的价值观 | 容易获得，可能言不由衷 |
| **基本假设 Basic Assumptions** | 无意识的信念、认知、思维模式（真正的文化） | 难以触及，却是行为根源 |

**咨询用法**：文化诊断必须穿透三层。只调研第一层（看标语、看活动）是表面功夫；真正的文化变革要触及第三层的基本假设。

### 基石五：组织变革曲线（库布勒-罗斯改编）

```
绩效
  │        ┌────────────────── 新常态
  │       /  重整期
  │      /
  │  ───┘ 谷底：混乱期（最危险，最容易失败）
  │    \
  │     \  否认 → 愤怒 → 沮丧 → 接受
  └────────────────────────────────→ 时间
```

**关键判断**：变革在谷底期最容易夭折。咨询项目的核心价值之一，就是帮客户在谷底期"不掉链子"——通过短周期胜利（Quick Win）维持信心。

### 基石六：系统思考与因果回路（圣吉）

- **增强回路**（滚雪球）：飞轮效应、规模效应、口碑效应
- **调节回路**（恒温器）：市场饱和、竞争对手跟进、资源约束
- **时间滞延**：投入与见效之间的延迟，是管理误判的主要来源

**咨询用法**：遇到"为什么越用力越糟糕"的问题（如越抓考勤效率越低、越降价利润越薄），用系统思考画因果回路，找出真正的杠杆点（Leverage Point）。

## 三、引用纪律（强制）

1. **署名规范**：引用经典理论时，可标注提出者与出处，但一律使用**方法论名称 + 提出者姓氏**的规范表述（如"波特五力模型""沙因文化三层次""韦斯伯克六盒模型"），不虚构中文译名与出版社信息。
2. **不与客户案例混淆**：经典理论归理论，客户案例必须脱敏（企业/机构/人名用代号）。两者在文档中分区呈现，不混写。
3. **不夸大适用性**：任何方法论都有其适用边界（时代背景、行业属性、企业阶段）。引用时必须说明"什么条件下适用、什么条件下需调整"，不把西方经典直接套到中国国企场景而不做适配说明。
4. **理论服务于问题**：不为显示专业而堆砌理论。每一个引用的方法论都必须对应客户的一个真实问题，能回答"用它能得出什么结论、导出什么动作"。
5. **前沿引用"三件套"**：引用科技企业案例与刊物结论时，必须同时给出 **结论 + 数据口径（样本量/覆盖范围/年份）+ 适用边界**。标杆企业的做法建立在其特定条件（技术垄断地位、创始人权威、人才密度）之上，**不做成功学式宣讲**，必须同步给出风险与前提提示。
6. **标杆数据不做精确断言**：涉及未公开或仅见于媒体报道的经营数据，标注来源类型（年报/公开访谈/权威媒体）与年份，不做无出处的精确数字断言。

## 五、前沿议题速查（2024—2026 最常被客户问到的 8 个问题）
