# 03 · 人力资源全流程 · 行政全流程

## 一、人力资源全流程（选 · 育 · 用 · 留 · 汰）

### 1. 组织与定岗定编

| 步骤 | 输出 |
|---|---|
| 战略与流程梳理 | 关键价值链与流程清单 |
| 职能分解 | 职能地图（一级职能 → 二级职能 → 岗位） |
| 岗位设置 | 岗位说明书（职责、权限、任职资格、KPI） |
| 定编测算 | 按业务量/工时/管理幅度测算编制 |
| 编制管控 | 编制表 + 增员审批规则 |

**管理幅度参照（示意）**：直线生产班组 1:8–15；职能岗位 1:5–8；高管直接下属 5–8 人。层级建议不超过 4 层。

### 2. 招聘与配置

- **需求确认**：先问"是新增业务还是补缺？能否内部调配？能否用外部资源替代？"
- **渠道分工**：管理/技术岗走内推 + 猎头；基层走本地招聘 + 劳务；校招做储备
- **结构化面试**：按胜任力维度设计题目，同一岗位用同一评分表（行为面试 STAR 法）
- **录用风控**：背景核查（学历、履历、竞业限制）、体检、入职材料与承诺书签署

### 3. 薪酬体系

| 类型 | 适用 | 结构 |
|---|---|---|
| 岗位工资制 | 职能、生产 | 基本工资 + 岗位工资 + 绩效工资 + 津贴 |
| 技能工资制 | 技术工人 | 基本工资 + 技能等级工资 + 计件/工时 |
| 业绩提成制 | 销售 | 底薪 + 提成 + 超额奖 + 年终奖 |
| 年薪制 | 高管 | 基本年薪 + 绩效年薪 + 超额分享 |

设计要点：
1. 先做**岗位价值评估**（因素计点法或简易排序）再定级差
2. 用市场分位定位（P25 / P50 / P75）决定薪酬竞争力策略
3. 固定:浮动比例——基层 8:2，中层 7:3，高层 6:4 或 5:5
4. 薪酬保密的利弊须与激励机制匹配

### 4. 绩效管理体系

中小企业推荐 **KPI + 月度复盘**，规模较大或创新业务用 **OKR**。

| 环节 | 要点 |
|---|---|
| 指标设计 | 每岗 3–5 个，可控、可测、有挑战 |
| 目标设定 | 上下沟通确认，不单向下发 |
| 过程管理 | 月度复盘会 + 季度评估，不做"年终算总账" |
| 强制分布 | 建议 A 20% / B 60% / C 15% / D 5%（若文化不接受可柔性化） |
| 结果应用 | 与奖金、调薪、晋升、培训强关联；连续 C 触发辅导，连续 D 触发调整 |

**绩效强制分布替代方案**：绝对值对标法（达标即 A）、团队绩效系数法（部门绩效决定部门奖金包，内部再分配）。

### 5. 培训与人才发展

- **体系**：新员工入职（企业文化+制度+岗位技能）→ 在岗技能 → 管理者培养 → 梯队
- **方式**：师徒制（一徒一师一考核）、岗位轮换、项目历练、外部认证
- **评估**：柯氏四级（反应—学习—行为—结果），中小企业至少做到"行为"层

### 6. 员工关系与用工风险

| 风险点 | 防范动作 |
|---|---|
| 未签劳动合同 | 入职 1 个月内签订，保留签收记录 |
| 试用期违规 | 期限与工资符合法定（不低于转正 80% 且不低于最低工资） |
| 加班与工时 | 综合工时/不定时工时需审批备案；保留考勤与加班审批记录 |
| 社保公积金 | 依法缴纳，不"自愿放弃"（无效） |
| 违纪解除 | 规章制度经民主程序并公示，保留违纪证据与送达证据 |
| 竞业限制 | 需支付补偿金，范围与期限合理 |
| 离职管理 | 交接单、工作交接确认、离职证明、保密提醒 |

**规章制度生效三要件**：内容合法 + 民主程序（职工代表/全体讨论）+ 公示告知（签收/培训记录）。

## 二、行政全流程管理

### 行政制度体系清单（中小企业最小集）

| 类别 | 制度 |
|---|---|
| 基础 | 员工手册、行政管理办法、印章证照管理办法 |
| 办公 | 办公用品管理、固定资产管理、车辆管理、门禁与访客管理 |
| 会议 | 会议管理办法（例会体系、纪要规范、决议跟踪） |
| 文书 | 公文管理办法、公文格式规范、档案管理办法 |
| 后勤 | 食堂/宿舍管理、保洁与绿化、安全保卫 |
| 费用 | 行政费用预算与报销管理 |

### 会议与决策机制

| 会议 | 频次 | 参与 | 输出 |
|---|---|---|---|
| 经营例会 | 周/月 | 管理层 | 经营数据通报、问题清单、决议 |
| 产销协调会 | 周 | 销售/计划/生产/采购 | 排产与交付决策 |
| 质量分析会 | 月 | 质量/生产/技术 | 质量异常闭环 |
| 项目/专项会 | 按需 | 相关方 | 里程碑进展与风险 |
| 月度经营分析会 | 月 | 管理层 | 指标达成分析、改善措施 |

**会议有效性三件套**：议程提前发 → 纪要当日出（决议+责任人+时限）→ 决议跟踪表闭环。

### 固定资产管理

台账（编号、名称、规格、购置日期、原值、使用部门、责任人、状态）→ 领用/调拨/维修/报废流程 → 定期盘点（年度全盘 + 季度抽盘）→ 差异处理与责任追究。

### 印章与证照管理（高风险区）

- 印章集中保管、用章审批留痕、用章登记簿（事由、文件名称、份数、经办人、批准人）
- 严禁空白盖章件；严禁私刻
- 证照原件专柜保管，复印件注明用途并登记借出
- 电子章/电子签名使用须有授权与审计日志

### 公文格式要点（国内企业通行）

标题（发文单位+事由+文种）→ 主送/抄送 → 正文（事由—依据—事项—要求）→ 附件 → 发文单位署名与日期 → 印章。紧急程度与密级按要求标注。

## 三、人力资源与行政的诊断清单

**快问快答式诊断（10 问）**

1. 关键岗位有没有说明书？编制是否被有效管控？
2. 招聘周期多长？关键岗位空缺平均多久补上？
3. 薪酬是否有级差逻辑？关键岗位是否低于市场 P50？
4. 绩效是"打分表格"还是"目标管理"？有没有月度复盘？
5. 去年有没有因为绩效问题被调整的人？比例多少？
6. 有没有一条清晰的晋升通道？员工知道吗？
7. 人均产值与人均利润近三年是升还是降？
8. 主动离职率多少？离职面谈做了吗？
9. 用工合同、社保、工时是否 100% 合规？
10. 行政费用占营收比例多少？有无预算约束？
