# 33 · 教练技术经典方法论

> 源流：教练技术（Coaching）源于体育教练领域的实践，经蒂莫西·高威（Timothy Gallwey）的"内在游戏"理论奠基，由约翰·惠特默（John Whitmore）的 GROW 模型系统化，随后发展为涵盖绩效教练、高管教练、团队教练的完整体系。与行动学习、心理咨询、导师制的边界清晰。

---

## 一、教练技术的思想源头

### 1.1 高威：内在游戏（The Inner Game）

**高威的发现**（源于网球教学）：
- 每个人的内心都有两个"自我"在对话：
  - **自我 1（Self 1）**：评判者、批评家、不断下指令（"你握拍错了""别打飞"）
  - **自我 2（Self 2）**：执行者、身体的自然学习能力
- **自我 1 的过度干预会干扰自我 2 的自然发挥**
- 教练的任务不是"教技术"，而是**减少自我 1 的干扰，让自我 2 发挥作用**

**核心公式**：
```
绩效 = 潜能 - 干扰
Performance = Potential - Interference
```

**关键洞察**：**教练不是开发潜能，而是排除干扰。** 潜能本来就存在，是内心的自我怀疑、焦虑、评判阻碍了它。

**咨询用法**：管理者带团队时，用这个公式反思——我是在"开发下属的潜能"（教他怎么干），还是在"排除下属的干扰"（帮他清除疑虑与障碍）？后者的效果通常更好。

### 1.2 惠特默：GROW 模型（教练技术的标准框架）

**GROW 四步**：

```
G - Goal（目标）
    你想达成什么？
         ↓
R - Reality（现状）
    现在是什么情况？
         ↓
O - Options（选择）
    你有哪些可能的做法？
         ↓
W - Will（意愿/行动）
    你打算做什么？什么时候开始？
```

**每一步的关键提问**：

| 阶段 | 核心问题 | 常见问题样例 |
|---|---|---|
| **Goal 目标** | 明确要达成什么 | "你希望通过这次谈话达成什么？""如果一切顺利，3 个月后是什么样子？""这个目标对你意味着什么？" |
| **Reality 现状** | 客观看清当前 | "现在实际发生了什么？""你做过哪些尝试？""哪些因素在阻碍你？""有什么资源是你可以用上的？" |
| **Options 选择** | 拓展可能性 | "你有哪些选择？""如果资源不是问题，你会怎么做？""还有别的方法吗？""如果换个角度看呢？" |
| **Will 意愿** | 承诺行动 | "你打算做什么？""什么时候开始？""可能有什么障碍？""你需要什么支持？""1-10 分，你的承诺度是多少？" |

**GROW 的关键纪律**：
- **不跳过 G**：多数人急于谈现状与方案，忘了先明确目标
- **不替对方想 O**：教练不给建议，让对方自己产生选项（哪怕选项不完美）
- **W 必须具体**：有行动、有时间、有承诺度检查

### 1.3 其他经典教练模型

| 模型 | 结构 | 适用 |
|---|---|---|
| **GROW** | Goal → Reality → Options → Will | 通用教练框架 |
| **OSKAR** | Outcome → Scaling → Know-how → Affirm & Action → Review | 解决方案焦点教练 |
| **CLEAR** | Contract → Listen → Explore → Action → Review | 强调契约与倾听 |
| **STEPPPA** | Subject → Target → Emotion → Perception → Plan → Pace → Adapt | 复杂决策教练 |
| **FUEL** | Frame → Understand → Explore → Lay out a plan | 绩效教练 |
| **AOR** | Action → Outcome → Reflection | 简明教练循环 |

## 二、教练的核心信念与原则

### 2.1 教练的四项基本信念

| 信念 | 内涵 | 实践含义 |
|---|---|---|
| **人是完整的、有资源的** | 每个人已具备解决问题所需的能力与资源 | 不替对方做决定 |
| **答案在对方心中** | 教练不是给答案，而是帮对方找到自己的答案 | 少说多问 |
| **人愿意为自己负责** | 自己得出的结论才有执行力 | 让对方自己形成行动计划 |
| **改变是可能的** | 人具备改变的能力与意愿 | 保持正向期待 |

**与"专家式"沟通的根本区别**：
| 维度 | 专家式 | 教练式 |
|---|---|---|
| 角色 | 给答案 | 帮找答案 |
| 沟通方式 | 说 | 问 |
| 责任归属 | 我负责 | 你负责 |
| 假设 | 你不知道，我知道 | 你知道，我帮你发现 |
| 长期效果 | 依赖专家 | 独立自主 |

### 2.2 教练与相邻概念的边界（重要）

| 概念 | 定位 | 与教练的区别 |
|---|---|---|
| **教练 Coaching** | 帮对方自己找到答案、提升能力 | 不给答案，关注"如何思考" |
| **导师 Mentoring** | 传授经验、给建议、指引路径 | 给经验与建议，关注"该怎么做" |
| **咨询 Consulting** | 提供专业方案、解决问题 | 专家给出方案，关注"问题的答案" |
| **培训 Training** | 传授知识技能 | 输出知识，关注"学会什么" |
| **心理咨询 Therapy** | 处理心理创伤与情绪障碍 | 处理过去与深层心理，需专业资质 |
| **顾问 Advisor** | 提供专业判断与建议 | 给意见，对方决策 |
| **管理 Managing** | 分配任务、考核结果 | 有职权与责任，教练无职权 |

**必须明确的边界（合规与伦理要求）**：
- **教练不做心理咨询**。遇到心理创伤、严重情绪障碍、精神健康问题，必须转介专业心理咨询师或医疗机构。
- **教练不做医疗与法律建议**。涉及健康、法律、税务等专业领域，转介相应专业人士。
- **教练不越界到管理**。企业教练不替管理者做人事决策，不介入劳资纠纷。

### 2.3 教练的伦理准则

| 准则 | 内容 |
|---|---|
| **保密** | 教练内容严格保密（除涉及违法违规与人身安全的情形） |
| **不评判** | 不评判对方的价值观与选择 |
| **不越界** | 不进入需要专业资质的领域（心理治疗、法律、医疗） |
| **不操纵** | 不用教练技术实现教练自己的目的 |
| **知情同意** | 明确教练目标、边界、周期、费用（尤其企业教练需明确三方关系） |
| **能力边界** | 只在自己有能力胜任的领域提供教练服务 |

## 三、教练的核心技能

### 3.1 三层倾听

| 层次 | 内容 | 表现 |
|---|---|---|
| **第一层：内在倾听** | 只听自己内心的声音（自己的判断、联想） | "我要说什么"——最差的倾听 |
| **第二层：聚焦倾听** | 专注听对方说的内容 | "他在说什么"——合格的倾听 |
| **第三层：全局倾听** | 听内容、语气、情绪、身体语言、未说出口的话 | "他没说什么？他的语气说明了什么？"——教练的倾听 |

**全局倾听要捕捉的**：
- **用语**：他反复使用的词是什么？（可能是关键信念）
- **情绪**：说到哪里情绪有波动？
- **身体语言**：停顿、叹气、姿态变化
- **省略**：他刻意回避了什么？
- **矛盾**：说的和做的是否一致？

### 3.2 有力提问

**提问的四个层次**：

| 层次 | 类型 | 示例 | 效果 |
|---|---|---|---|
| **第一层** | 封闭式 | "你试过了吗？" | 只能回答是/否 |
| **第二层** | 开放式 | "你试过什么方法？" | 打开信息 |
| **第三层** | 探索式 | "你觉得根本原因是什么？" | 引发思考 |
| **第四层** | 转换式 | "如果你已经成功了，回头看今天，你会做什么不同的事？" | 改变视角、创造突破 |

**教练提问的黄金句式**：
- "**如果……会怎样？**"（拓展可能性）
- "**你怎么知道？**"（检验假设）
- "**还有呢？**"（深挖，最有效的追问）
- "**这对你意味着什么？**"（探索意义）
- "**1-10 分，你现在是几分？**"（量化状态）
- "**什么是你现在最需要面对却一直在回避的？**"（直击核心）
- "**如果没有任何限制，你会怎么做？**"（突破框架）
- "**谁可以帮你？**"（寻找资源）

**需要避免的提问**：
- ❌ 引导性问题（"你是不是应该早点准备？"）
- ❌ 伪装的建议（"你有没有考虑过做 A 方案？"）
- ❌ 连珠炮式提问（一次问三个问题）
- ❌ "为什么"式质问（"你为什么没做？"→易引发防御。改为"是什么让你……"）

### 3.3 反馈技术

**有效反馈的结构**：

| 模型 | 结构 | 用法 |
|---|---|---|
| **BID** | Behavior（行为）→ Impact（影响）→ Do（期望） | 最简明实用 |
| **SBI** | Situation（情境）→ Behavior（行为）→ Impact（影响） | 描述性反馈 |
| **BOOST** | Balanced（平衡）→ Observed（观察到）→ Objective（客观）→ Specific（具体）→ Timely（及时） | 高质量反馈标准 |

**反馈的关键原则**：
- **对行为，不对人格**："你昨天会议上打断了三次同事的发言"（行为）vs "你太不尊重人了"（人格）
- **具体，不泛泛**："这个方案的数据来源标注得很清楚"（具体）vs "你做得好"（泛泛）
- **及时，不拖延**
- **正向优先**：正向反馈要多于负向反馈（建议 3:1 以上比例）

### 3.4 其他教练工具

| 工具 | 用途 |
|---|---|
| **平衡轮（Wheel of Life）** | 评估多个维度（工作、家庭、健康、成长等）的满意度，识别优先改善领域 |
| **逻辑层次（Logical Levels）** | 环境 → 行为 → 能力 → 信念/价值观 → 身份 → 愿景（识别问题在哪一层） |
| **时间线** | 回顾过去、立足现在、展望未来 |
| **换框法（Reframing）** | 改变看待问题的框架（意义换框、情境换框） |
| **隐喻** | 用比喻帮助理解（"如果这是一场球赛，现在打到第几局？"） |
| **心锚（Anchoring）** | 建立特定状态与刺激的关联 |
| **承诺度打分** | 1-10 分量表，量化意愿强度（低于 7 分说明还有犹豫，需继续探索） |

## 四、企业教练的应用形态

### 4.1 教练的三种企业应用

| 类型 | 对象 | 目标 | 周期 |
|---|---|---|---|
| **高管教练 Executive Coaching** | 高管/CEO | 领导力提升、决策质量、行为改变 | 6-12 个月 |
| **绩效教练 Performance Coaching** | 管理者与员工 | 绩效改善、能力发展 | 3-6 个月 |
| **团队教练 Team Coaching** | 管理团队 | 团队协作、共识建立、冲突处理 | 3-6 个月 |

### 4.2 管理者作为教练（管理教练）

**为什么管理者要做教练**：
- 命令式管理对知识型员工无效（详见 `23-hr-classics.md` 中的 X/Y 理论）
- 教练式领导能提升员工的能力、投入与主动性
- 教练是"发展他人"的核心手段

**管理者做教练的三个关键**：
1. **少给答案，多提问**：忍住"我知道怎么做"的冲动
2. **关注成长而非只关注任务**：完成任务的同时发展能力
3. **建立教练式对话的习惯**：日常工作中的 GROW 式对话（5 分钟的"你打算怎么做？"）

**管理对话的常见错误**：
| 错误 | 后果 | 替代做法 |
|---|---|---|
| 直接给答案 | 员工依赖、不成长 | 先问"你打算怎么做" |
| 只谈问题不谈目标 | 陷入问题泥潭 | 先明确目标与期待 |
| 用教练技术做说服 | 员工感到被操纵 | 真诚中立、尊重选择 |
| 只在绩效差时才谈话 | 谈话变成负面信号 | 平时就建立教练对话习惯 |

### 4.3 教练项目的设计

| 阶段 | 关键动作 |
|---|---|
| **需求诊断** | 明确教练目的（绩效改善？领导力发展？继任准备？） |
| **三方会谈** | 教练、被教练者、企业代表（HR 或上级）共同明确目标与边界 |
| **教练协议** | 明确周期、频率、保密范围、成功标准、费用 |
| **初步评估** | 360 度反馈、性格测评、访谈，形成基线 |
| **教练过程** | 每次会谈 60-90 分钟，间隔 2-4 周，围绕 GROW |
| **中期回顾** | 检查进展、调整方向 |
| **结束与评估** | 达成目标、成果评估、后续支持 |

**企业教练项目成功的关键**：
1. **明确的三方目标**（不是 HR 单方面安排，也不是教练自己定目标）
2. **被教练者的内在意愿**（"被派来"的教练很难有效）
3. **上级的支持与参与**（上级不配合，教练效果会打折）
4. **保密与信任**（保密边界事先讲清楚）
5. **成果可衡量**（有行为改变的具体证据）

## 五、教练技术方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 下属不主动、等指令 | 高威公式（绩效=潜能-干扰）+ 管理教练式对话 |
| 领导力发展项目设计 | 高管教练 + 360 度反馈 + 教练协议 |
| 中层管理者带团队能力弱 | 管理教练训练（GROW + 提问技术） |
| 团队协作差、有冲突 | 团队教练 + 反馈技术 |
| 员工绩效差但不知怎么谈 | BID/SBI 反馈结构 + GROW 对话 |
| 员工遇到难题就来问 | 三层倾听 + 有力提问（帮他自己想） |
| 教练项目效果不好 | 项目设计五要素检查（三方目标/意愿/上级支持/保密/可衡量） |
| 需要区分教练与咨询 | 边界表对照，明确本次服务的性质 |
| 高潜人才发展 | 高管教练 + 行动学习结合 |
| 目标不清晰 | GROW 的 G 阶段深挖 + 平衡轮 |
