# 管理咨询实战方法论工具箱

本工具包沉淀自 20 余年企业管理实操与 10 余年一线咨询项目经验，采用**"上实务、下经典、接前沿"的三层结构**：

- **实务层（`01`—`11`）**：**十一大实战模块**的**诊断框架**、**设计工具**与**交付模板**，回答"怎么做"
- **经典层（`19`—`35`）**：十六大领域的**经典方法论源流**，回答"为什么这样做、这套做法从哪来、还有哪些经典可调用"
- **前沿层（`36`—`37`）**：全球**科技企业实战管理成果**与**顶级管理刊物前沿理念**，回答"世界在发生什么、标杆做成了什么、最新研究结论是什么"

## 使用方式

### 标准流程

1. **定位模块**：判断项目属于哪个实战模块（可多模块组合），读取 `01`—`11` 对应文件
2. **查理论支撑**：到 `19-classics-library.md` 的源流地图定位相关领域，读取对应的 `20`—`35` 分册
3. **查标杆与前沿**：涉及对标、趋势、AI 与数字化转型时，读取 `36`（科技企业库）、`37`（刊物库）
4. **选择工具**：用各分册的"咨询应用速查表"（客户问题 → 优先调用）快速选工具
5. **五阶段推进**：需求澄清 → 调研诊断 → 方案设计 → 成果输出 → 落地辅导与复盘
6. **脱敏引用**：客户案例一律脱敏（企业/机构/人名用代号）；公开企业与公开刊物可署名引用

### 前沿层使用的两条硬规则

1. **不做成功学式宣讲**：标杆企业的做法建立在其特定条件（技术垄断地位、创始人权威、人才密度、文化土壤）之上，引用时必须同步给出**前提条件与风险提示**。
2. **理念必须落地**：引用前沿理念（如"代谢率""智能体型组织"）时，必须同步给出**可落地的度量指标与具体动作**，否则会显得空泛。

## 五、引用与脱敏纪律（强制）

### 5.1 脱敏纪律

引用任何过往项目经验时：
- 企业名称 → 使用代号（如"某置业集团""某开发集团"）
- 机构名称 → 使用代号（如"某咨询机构"）
- 个人姓名 → 使用代号（如"王老师""某讲师"）
- 保留行业特征与方法论内核，去除可识别信息

### 5.2 经典理论引用纪律

1. **署名规范**：使用"方法论名称 + 提出者姓氏"的规范表述（如"波特五力模型""沙因文化三层次"），不虚构中文译名与出版社信息
2. **公开信息例外**：公开出版物的作者、**公开企业的公开管理实践**（如"稻盛和夫的阿米巴经营""亚马逊的单向门决策""英伟达的机长制"）可直接署名引用，不属脱敏范围
3. **理论归理论，案例归案例**：经典理论与公开企业案例可署名，客户案例必须脱敏；两者在文档中分区呈现，不混写
4. **不夸大适用性**：说明"什么条件下适用、什么条件下需调整"，不把西方经典直接套到中国国企场景而不做适配说明
5. **理论服务于问题**：不为显示专业而堆砌理论。每个引用的方法论都必须对应客户的一个真实问题
6. **前沿引用三件套**：引用标杆案例与刊物结论时，必须同时给出 **结论 + 数据口径（样本量/覆盖范围/年份）+ 适用边界**
7. **数据不做精确断言**：涉及未公开或仅见于媒体报道的经营数据，标注来源类型（年报/公开访谈/权威媒体）与年份，不做无出处的精确数字断言

### 5.3 专业边界（红线）

| 领域 | 可做 | 不做 |
|---|---|---|
| 财务 | 体系设计、预算制度、分析方法、指标诊断 | 审计结论、税务筹划方案、报表编制专业意见 |
| 投资 | 方法论梳理、投资逻辑分析、指标体系 | 投资建议、证券分析意见、交易推荐 |
| 法律 | 合规风险提示、制度框架 | 法律意见、合同法律审查结论 |
| 心理 | 管理沟通、教练式对话 | 心理咨询、心理治疗、精神健康诊断 |
| 人力 | 体系设计、薪酬方案 | 代替客户做人事决策、介入劳资纠纷 |
| 数据资产 | 数据盘点、治理体系、产品化路径梳理 | 数据资产入表的会计确认意见、评估结论 |

涉及上述专业判断时，**必须建议客户引入相应专业机构**（注册会计师、税务师、律师、专业评估机构、心理咨询师）。
