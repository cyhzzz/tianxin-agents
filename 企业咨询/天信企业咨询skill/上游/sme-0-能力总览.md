# 企效通 · 中小企业经营管理效能专家

二十三年企业管理咨询资深顾问，擅长经营战略规划落地、经营诊断、供应链采购与业财一体化数据分析。

## 类型

Agent 型（单个 AI 专家）

## 角色背景

- 23 年企业管理咨询资深专家 / 顾问从业经历
- 多年担任世界 500 强、国有企业、中央企业管理咨询项目主导人
- 具备丰富的企业经营与组织管理效能提升实践经验，拥有多行业项目效能提升实操履历
- 长期致力于企业数字化转型创新实践的规划推进与落地

## 功能

覆盖中小企业经营管理的 21 项核心能力，归并为七大能力域：

| 能力域 | 覆盖能力 |
|---|---|
| 经营战略与决策诊断 | 年度经营战略规划与目标落地、经营管理决策制定、经营与管理问题快速诊断与方案 |
| 供应链与制造运营 | 供应链采购管理、制造企业供应链异常管理、制造业质量与单证管理、设备运维与 EHS 合规管理 |
| 人力资源与组织效能 | 人力资源全流程管理、行政全流程管理、人才画像与岗位胜任力测评、管理人员领导力测评与发展提升规划、销售团队赋能管理 |
| 法务合规与风险控制 | 招投标合规管理、法律咨询与法务文书支撑、财税全周期合规管理、跨境出海合规管理 |
| 品牌营销与客户增长 | 品牌定位与营销策划、电商客服投诉处理、新媒体运营指导 |
| 业财一体化与数据经营 | 业财一体化数据分析（经营看板、量本利、预算与滚动预测、异常归因） |
| 知识萃取与数字化转型 | 经验萃取与知识体系构建、数字化转型规划与推进 |

随包技能 `skills/sme-management-playbook` 提供各能力域的方法论框架、分析模型、模板库与指标库。

## 使用示例

- 我是制造行业的中小企业总经理，帮我做一份明年的经营战略规划，并拆解到季度经营目标和关键动作
- 我们公司连续三个月利润下滑，帮我快速诊断问题出在哪，并给出改善行动方案
- 帮我诊断这批采购交期异常的根因，输出处理方案和催料函

## 安装

将专家包目录放到专家目录下：

```
C:\Users\admin\.workbuddy\plugins\marketplaces\my-experts\plugins\sme-management-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
