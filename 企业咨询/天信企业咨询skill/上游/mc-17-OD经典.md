# 22 · 组织发展 OD 经典方法论

> 源流：从卢因（Kurt Lewin）的群体动力学与行动研究，到沙因的过程咨询、科特的变革八步、圣吉的学习型组织，再到卡梅隆的文化诊断、U 型理论与系统思考。

---

## 一、OD 的学科根基与核心信念

**OD（Organization Development）的定义**：基于行为科学知识，通过有计划、系统性的干预，提升组织健康度与有效性的长期努力。

**OD 的七项核心信念**：
1. 组织是开放系统，与环境持续互动
2. 变革需要系统视角（不是单点修补）
3. 数据驱动（先诊断，后干预）
4. 客户参与（不是专家单方面开方）
5. 过程与结果同等重要
6. 变革是学习过程
7. 关注人的价值与组织效能的统一

**OD 顾问的角色定位（沙因《过程咨询》）**：
| 角色 | 定位 | 适用 |
|---|---|---|
| 专家型 | 我懂，我来给答案 | 客户明确知道问题、需要技术方案 |
| 医生型 | 我来诊断，我给处方 | 客户知道有症状但不知病因 |
| **过程咨询型** | 我们一起看清问题、共同解决 | 客户才是解决问题的责任人（OD 首选） |

**沙因过程咨询的核心原则**：
- **"始终从客户的问题出发"**——不要一上来就讲你的方法论
- **"在客户准备好的时候，才给出干预"**——过早给方案会被拒绝
- **"客户拥有问题，也拥有解决方案"**——顾问是帮手，不是救世主

**咨询用法**：OD 类项目最容易犯的错误是"顾问比客户还急"。项目初期多用提问帮客户自己想清楚，方案才有真正的落地说服力。

## 二、组织诊断的经典模型

### 2.1 韦斯伯德六盒模型（Weisbord's Six-Box Model）

```
        ┌─────────────────────────────┐
        │   环境（外部压力与约束）      │  ← 不诊断但必须考虑
        └─────────────────────────────┘
    ┌──────────┐        ┌──────────┐
    │  目标    │        │  关系    │
    │ Purpose  │        │Relations │
    └──────────┘        └──────────┘
    ┌──────────┐        ┌──────────┐
    │  结构    │        │  奖励    │
    │Structure │        │ Rewards  │
    └──────────┘        └──────────┘
    ┌──────────┐        ┌──────────┐
    │  领导    │        │  帮助    │
    │Leadership│        │ 机制Help │
    └──────────┘        └──────────┘
```

**六个诊断问题**：
1. **目标**：我们主要做什么？目标清晰吗？各方理解一致吗？
2. **结构**：任务如何分工？分工合理吗？内部协调机制是什么？
3. **关系**：人们如何互动？部门之间有无合作问题？有无冲突？
4. **奖励**：有激励吗？激励指向什么行为？与目标一致吗？
5. **领导**：有人平衡六个盒子吗？领导力是否有效？
6. **帮助机制**：有无足够的辅助机制（规划、预算、信息系统、培训）？有无过度官僚？

**咨询用法**：这是 OD 诊断的"万能钥匙"。任何组织问题都可以用六盒快速定位——很多看似"人不行"的问题，实际是"奖励盒与目标盒不匹配"造成的。

### 2.2 麦肯锡 7S（详见 `19-classics-library.md`）

### 2.3 纳德尔-塔什曼一致性模型

**核心要素**：
- **关键任务**（Critical Task）：战略要求的核心工作
- **正式组织安排**：结构、流程、制度
- **非正式组织**：文化、网络、价值观
- **人员**：能力、态度、动机

**一致性原理**：四个要素必须相互匹配。任何变革都必须四个要素同步调整。

### 2.4 伯克-利特温模型（Burke-Litwin）

区分**变革的两类驱动**：

| 类型 | 要素 | 变化速度 |
|---|---|---|
| **转型型变革**（Transformational） | 外部环境 → 使命战略 → 领导 → 文化 | 慢、根本 |
| **交易型变革**（Transactional） | 结构、管理实践、系统、气候、任务要求、个人需求与价值观 | 快、表象 |
| **结果** | 个人绩效 → 组织绩效 | — |

**关键洞察**：交易型变革（改结构、改流程）如果没有转型型变革（改战略、改文化）支撑，往往无效。诊断顺序应从"外部环境"开始向下走。

### 2.5 高-琼斯（Goffee & Jones）文化类型与卡梅隆竞争价值框架

**高-琼斯双维度**：
- **社交性（Sociability）**：同事间的友好程度（是否存在真诚的私人关系）
- **团结性（Solidarity）**：对共同目标的认同与追求（是否有共同的使命）

| 类型 | 社交性 | 团结性 | 特征 |
|---|---|---|---|
| **网络型** | 高 | 低 | 友善但没有战斗力，人缘好效率低 |
| **共同体型** | 高 | 高 | 有爱有战斗力，最理想 |
| **雇佣兵型** | 低 | 高 | 目标导向、只看业绩，关系冷漠 |
| **碎片化型** | 低 | 低 | 各自为政、缺乏凝聚力 |

**卡梅隆竞争价值框架（CVF）**：

| | 内部导向 | 外部导向 |
|---|---|---|
| **灵活/自主** | 家族型（Family） | 活力型（Adhocracy） |
| **稳定/控制** | 层级型（Hierarchy） | 市场型（Market） |

**咨询用法**：这两个模型搭配使用——高-琼斯看"关系与目标"，卡梅隆看"取向与控制"。诊断结论要能回答"当前文化是什么类型、目标战略需要什么类型、差距在哪"。

## 三、组织变革的经典路径

### 3.1 科特勒：领导变革八步（John Kotter）

```
1. 树立紧迫感（危机意识）          ← 75% 的变革失败在第一步没做透
2. 组建强有力的变革领导联盟        ← 需要足够权力、专业、公信力
3. 形成愿景与战略
4. 沟通变革愿景                    ← 用一切渠道，反复讲
5. 授权员工为愿景行动（清除障碍）
6. 创造短期胜利（Quick Win）       ← 关键机制：谷底期维持信心
7. 巩固成果、推动更多变革           ← 别过早宣布胜利
8. 把变革固化为文化               ← 只有变成文化，变革才算真正成功
```

**科特的关键发现**：变革失败大多不是因为"计划不周"，而是因为"紧迫感不足"和"过早宣布胜利"。第八步（固化到文化）往往被忽视，导致变革回潮。

**《变革之心》(The Heart of Change)** 的补充洞察：**改变行为要从改变感受入手**，而不是从改变思维入手。展示最震撼的事实（让管理者亲眼看客户的抱怨、亲自体验低效流程），比给出逻辑严谨的分析报告更能推动变革。

### 3.2 卢因三阶段（详见 `21-org-classics.md`）

### 3.3 变革路线图设计要点

| 阶段 | 关键动作 | 交付物 |
|---|---|---|
| **准备期** | 紧迫感营造、联盟组建、现状诊断 | 诊断报告、变革愿景、沟通方案 |
| **解冻期** | 打破旧平衡、清除障碍、试点 | 试点方案、短期胜利清单 |
| **推进期** | 全面铺开、能力建设、机制调整 | 制度文件、培训体系、推进计划 |
| **固化期** | 制度化、文化嵌入、持续改进 | 新制度汇编、文化落地机制 |
| **复盘期** | 效果评估、经验沉淀、下一轮启动 | 复盘报告、改进清单 |

## 四、学习型组织与系统思考（圣吉）

### 4.1 五项修炼

| 修炼 | 内涵 | 关键工具 |
|---|---|---|
| **自我超越** | 不断理清并深化个人愿景，保持创造性张力 | 个人愿景与现实的差距分析 |
| **改善心智模式** | 反思、质疑并改善内在的思维定式 | 跳脱式思考、左手栏练习 |
| **建立共同愿景** | 从个人愿景汇集成集体承诺 | 愿景共创工作坊 |
| **团体学习** | 超越个人智力叠加，产生团体智慧 | 深度汇谈（Dialogue）、讨论（Discussion） |
| **系统思考** | 看清因果结构而非孤立事件 | 因果回路图、系统基模 |

### 4.2 七种学习智障

1. 局限思考（只管自己岗位）
2. 归罪于外（都是别人的错）
3. 缺乏整体思考的主动积极
4. 专注于个别事件（看不见趋势）
5. 煮青蛙的寓言（对缓慢威胁无感）
6. 从经验学习的错觉（经验有时空局限）
7. 管理团队的迷思（团队表面一致实则各自为政）

### 4.3 系统基模（System Archetypes）——最实用的部分

| 基模 | 结构 | 典型表现 | 对策 |
|---|---|---|---|
| **增长上限** | 增强回路 + 调节回路 | 前期猛涨后停滞 | 找到并解除限制因素 |
| **舍本逐末** | 症状解 + 根本解 | 依赖短期解药，根本问题恶化 | 强化根本解、弱化症状解 |
| **饮鸩止渴** | 症状缓解 + 副作用 | 解一时之痛埋下更大祸根 | 识别滞后副作用 |
| **目标侵蚀** | 降低目标以适配现状 | 不断下调标准 | 坚守愿景、提高标准 |
| **恶性竞争** | 双方相互报复升级 | 价格战、军备竞赛 | 找到共赢的第三条路 |
| **成功者诅咒** | 成功导致资源分散 | 什么都做，都做不好 | 聚焦核心 |
| **富者愈富** | 资源向优势方集中 | 强者恒强 | 分配机制调整 |

**咨询用法**：客户描述"怪圈""越努力越糟"时，用系统基模匹配，往往能一击命中问题的结构本质。这是 OD 顾问最有说服力的诊断语言之一。

## 五、U 型理论与深度变革（奥托·夏莫）

```
   观察 Observation → 感知 Sensing → 呈现 Presencing → 结晶 Crystallizing → 原型 Prototyping → 运行 Performing
   ↑                                                                                        │
   └───────────────────────── 下行（向过去学习）｜ 上行（向未来学习）──────────────────────┘
```

**核心洞察**：真正的创新不是从过去的经验中推论，而是"向正在生成的未来学习"——先深入观察现实，再退一步连接内在源头，然后快速原型验证。

**咨询用法**：面对复杂性极高、没有现成答案的战略迷茫（产业转型、颠覆期定位）时，U 型理论提供了"先深度观察、再创造原型"的路径，避免过早跳到解决方案。

## 六、OD 方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 组织整体状况诊断 | 韦斯伯德六盒模型（最快）+ 纳德尔一致性模型（最深） |
| 组织变革推不动 | 科特八步诊断（哪一步缺失）+ 卢因解冻充分性 |
| 变革总是回潮 | 科特第八步（固化到文化）+ 一致性模型四要素同步 |
| 越努力越糟糕的怪圈 | 系统基模匹配（舍本逐末/饮鸩止渴/增长上限） |
| 团队表面和谐实则低效 | 高-琼斯文化类型 + "管理团队的迷思" |
| 战略转型但组织没变 | 伯克-利特温转型型 vs 交易型变革判断 |
| 文化诊断与变革 | 卡梅隆竞争价值框架 + 沙因文化三层次 |
| 组织能力建设 | 从关键任务倒推能力要求 + 能力提升举措设计 |
