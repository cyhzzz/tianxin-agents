# 29 · 品牌营销经典方法论

> 源流：从科特勒《营销管理》的 4P 框架与 STP 理论，到里斯/特劳特《定位》的心智争夺，到戴维·阿克品牌三部曲、凯勒基于顾客的品牌资产模型、舒尔茨整合营销传播 IMC，再到华与华的超级符号与本土品牌方法论。

## 一、营销思想的演进

| 阶段 | 时期 | 核心命题 | 代表 |
|---|---|---|---|
| **生产观念** | 1900s-1920s | 生产什么就卖什么 | — |
| **产品观念** | 1920s-1950s | 好产品自然好销量 | — |
| **推销观念** | 1950s-1960s | 强力推销促成交易 | — |
| **营销观念** | 1960s-1970s | 以顾客需求为中心 | 科特勒 4P |
| **战略营销** | 1970s-1980s | 定位与竞争视角 | 里斯/特劳特定位、波特 |
| **关系营销** | 1980s-1990s | 长期关系与顾客终身价值 | 关系营销学派 |
| **数字营销** | 2000s+ | 数据驱动、精准、全渠道 | 科特勒《营销革命 4.0》 |

## 二、科特勒：营销管理的经典框架

### 2.1 STP 战略核心

```
    市场细分（Segmentation）
            ↓
    目标市场选择（Targeting）
            ↓
    市场定位（Positioning）
```

| 环节 | 关键内容 |
|---|---|
| **市场细分** | 按地理、人口、心理、行为变量划分市场 |
| **目标市场选择** | 评估细分市场的规模、增长、吸引力、匹配度；选择策略（无差异/差异/集中） |
| **市场定位** | 在目标客户心智中建立独特位置；确定价值主张与差异化组合 |

**有效细分的五条标准**：可衡量、足够大、可接近、可区分、可行动

### 2.2 4P 与扩展框架

**经典 4P**：
| P | 内涵 | 关键决策 |
|---|---|---|
| **产品 Product** | 提供给市场的产品与服务 | 产品组合、品牌、质量、包装、服务 |
| **价格 Price** | 定价策略 | 定价方法、价格体系、促销价格 |
| **渠道 Place** | 分销与触达 | 渠道结构、覆盖、库存、物流 |
| **促销 Promotion** | 沟通与推广 | 广告、公关、促销、人员推销、直销 |

**扩展为 7P（服务营销）**：+ 人员 People、过程 Process、有形展示 Physical Evidence
**扩展为 4C（客户视角）**：客户价值 Customer Value、客户成本 Cost、便利 Convenience、沟通 Communication
**扩展为 4R（关系视角）**：关联 Relevance、反应 Retentiveness、关系 Relationship、回报 Reward

### 2.3 科特勒的其他核心贡献

| 概念 | 内涵 |
|---|---|
| **营销近视症**（莱维特提出，科特勒推广） | 企业只关注产品本身，忽略客户真正需求（如铁路公司以为自己在做铁路而非运输） |
| **顾客让渡价值** | 顾客总价值 - 顾客总成本 = 顾客感知价值 |
| **顾客终身价值 CLV** | 一个顾客在整个关系周期内创造的总利润 |
| **营销 4.0** | 从产品导向到人性导向，从传统到数字，从交易到关系 |
| **营销 5.0** | 技术为人类服务，用 AI、AR、IoT 等提升营销效率 |

## 三、定位理论（里斯 & 特劳特）——影响最深远的营销理论

### 3.1 核心命题

**"营销的战场不在产品，而在顾客的心智。"**

- 不是"我们的产品有多好"，而是"客户心智中我们占据了什么位置"
- 心智的特征：**容量有限**（每个品类记住的品牌通常不超过 7 个，甚至只有 2-3 个）、**厌恶混乱**、**缺乏安全感**、**不易改变**

### 3.2 定位的四种方法

| 方法 | 说明 | 例子 |
|---|---|---|
| **抢先占位** | 第一个进入心智，成为品类第一 | "第一个"的力量最强 |
| **关联定位** | 与心智中的强势品牌关联 | "对标某某"的定位策略 |
| **重新定位对手** | 改变对手在客户心智中的位置 | 揭示对手弱点，为新定位腾出空间 |
| **聚焦细分** | 在品类中占据一个细分位置 | 在红海中找到蓝海缝隙 |

### 3.3 定位的关键原则

- **一词占领心智**：定位要能压缩成一个词或一句话（"安全"之于沃尔沃，"驾驶乐趣"之于宝马）
- **品类第一法则**：不是要做最好，而是要做第一个（第一个进入心智的比最好的更容易被记住）
- **不能改变心智，只能顺应心智**：定位不是创造新东西，而是操纵心智中已有的认知
- **聚焦与牺牲**：定位意味着放弃一部分市场（想讨好所有人的品牌，最终谁都不记得）

**"定位"在中国的影响**：定位理论自 2000 年代进入中国后，成为本土营销咨询最主流的理论工具。加多宝（王老吉）、东阿阿胶、香飘飘等品牌的成功案例，都与定位理论密切相关。

### 3.4 品类战略（定位理论的延伸）

- **品类是心智的入口**：消费者"先想品类，再想品牌"
- **开创新品类**是成为第一的最佳路径（因为新品类中没有第一）
- **品类分化**：随着市场成熟，品类会不断分化出新品类（如"饮料"→"碳酸饮料"→"无糖碳酸饮料"）

## 四、品牌资产理论

### 4.1 戴维·阿克：品牌三部曲

**《管理品牌资产》——品牌资产的五个维度**：

| 维度 | 内涵 |
|---|---|
| **品牌忠诚度** | 客户重复购买的倾向 |
| **品牌知名度** | 客户认知与回忆品牌的能力 |
| **感知质量** | 客户对产品或服务整体质量的感知 |
| **品牌联想** | 与品牌相关的所有联想（功能、情感、象征） |
| **其他专有资产** | 专利、商标、渠道关系等 |

**《创建强势品牌》——品牌识别系统**：
- **品牌精髓**（Brand Essence）：品牌的核心价值主张
- **核心识别**（Core Identity）：品牌恒久不变的本质
- **延伸识别**（Extended Identity）：品牌的丰富内涵
- **价值主张**（Value Proposition）：功能利益 + 情感利益 + 自我表达利益

**《品牌领导》——品牌架构**：
| 架构类型 | 说明 |
|---|---|
| **单一品牌** | 所有产品用一个品牌 |
| **背书品牌** | 主品牌为子品牌背书 |
| **多品牌** | 不同产品用不同品牌 |
| **品牌组合** | 多个品牌的战略组合管理 |

### 4.2 凯勒：基于顾客的品牌资产（CBBE）模型

```
           ┌──────────────────┐
    顶端   │  共鸣 Resonance   │  行为忠诚、态度依附、社群感
           ├──────────────────┤
           │  反应 Responses  │  判断 Judgments、感受 Feelings
           ├──────────────────┤
           │  含义 Meaning    │  绩效 Performance、形象 Imagery
           ├──────────────────┤
    基础   │  显著 Salience   │  品牌认知的深度与广度
           └──────────────────┘
```

**咨询用法**：CBBE 模型是品牌诊断的"阶梯"——自下而上逐层检查：
1. 客户知道我们吗？（显著度）
2. 客户认为我们是什么？（含义）
3. 客户对我们什么感受？（反应）
4. 客户与我们有什么关系？（共鸣）

**多数品牌的失败在于"跳级"**——显著度都没建立，就开始谈品牌情感与共鸣。

### 4.3 舒尔茨：整合营销传播（IMC）

**核心思想**：所有接触点传递一致的信息，形成统一的品牌形象。

**IMC 的关键**：
1. **以客户为中心**：从"我们想说什么"转为"客户想听什么"
2. **所有接触点一致**：广告、公关、促销、包装、终端、客服、社交媒体，传递一致信息
3. **双向沟通**：不是单向灌输，而是与客户对话
4. **数据驱动**：用数据识别客户、衡量效果、优化投入

**咨询用法**：客户"花了很多钱做营销但品牌形象模糊"时，检查各接触点是否一致。**IMC 最大的敌人是"各管一段"**——广告公司做广告、公关公司做公关、电商团队做促销，各自为政，形象互相抵消。

## 五、本土品牌方法论

### 5.1 华与华方法：超级符号与超级话语

**超级符号**：借用文化中已有的、被广泛认知的符号（如红绿灯、握手、龙、福字），把它与品牌绑定，让品牌"一眼认出、一次记住"。
- 原理：**借用人类文化中已有的"母体"**，营销成本最低（因为符号已经被认知，不需要教育市场）
- 类型：视觉符号（图形、颜色）、听觉符号（声音、口号）、行为符号（动作、仪式）

**超级话语**：一句话让客户记住并传播（口语化、有行动指令感）
- 例："怕上火，喝王老吉"——包含场景（上火）、行动（喝）、品牌

**华与华的其他核心观点**：
| 观点 | 内涵 |
|---|---|
| **企业战略就是产品结构** | 战略要落到"卖什么产品" |
| **品牌就是产品的牌子** | 不做虚的品牌建设，先做产品 |
| **所有的事都是一件事** | 战略、营销、品牌、传播不分割 |
| **投广告就是投资** | 广告要持续投、重复投（重复是记忆之母） |

### 5.2 本土其他方法论

| 来源 | 核心观点 |
|---|---|
| **王志纲** | 品牌是"找魂"——找到企业在时代中的独特价值与话语体系 |
| **叶茂中** | 冲突理论：营销的本质是发现冲突、制造冲突、解决冲突 |
| **杜国楹** | 产品主义：极致的产品体验是最好的营销（背背佳、好记星、E 人 E 本、8848、小罐茶） |
| **互联网营销** | 增长黑客、私域流量、内容营销、直播电商 |

### 5.3 数字营销的核心框架

**AARRR 海盗模型（用户生命周期）**：
```
Acquisition 获取 → Activation 激活 → Retention 留存 → Revenue 变现 → Referral 推荐
```

| 环节 | 关键指标 | 常见手段 |
|---|---|---|
| 获取 | CAC（获客成本）、渠道转化率 | SEO/SEM、内容、投放、裂变 |
| 激活 | 激活率、首次关键行为完成率 | 引导流程、新手礼包、Aha Moment |
| 留存 | 次日/7日/30日留存、DAU/MAU | 消息推送、会员体系、社区 |
| 变现 | ARPU、LTV、付费转化率 | 定价策略、付费点设计、增值服务 |
| 推荐 | K因子、NPS | 邀请奖励、社交分享、口碑机制 |

**关键指标关系**：
- **LTV / CAC > 3** 是常见的健康标准
- **留存是增长的核心**（"留存为王"，没有留存的增长是漏桶）

## 六、品牌营销方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 生意下滑、客户流失 | STP 重新做市场细分与定位 |
| 产品好但卖不动 | 定位理论（心智视角）+ 营销近视症检查 |
| 品牌形象模糊 | 阿克品牌识别系统 + IMC 一致性检查 |
| 品牌从零建设 | 凯勒 CBBE 逐层搭建 |
| 要与强势对手竞争 | 定位四种方法（尤其重新定位对手） |
| 要不要开创新品类 | 品类战略（分化与新品类机会） |
| 营销投入产出低 | AARRR 漏斗诊断 + LTV/CAC 分析 |
| 各渠道形象不一致 | 整合营销传播 IMC |
| 品牌记忆度低 | 超级符号 + 超级话语 |
| 多品牌怎么管理 | 阿克品牌架构设计 |
| 定价策略怎么定 | 4P 中的价格 + 顾客让渡价值 |
