# 01 · 战略管理实战方法论

> 来源：10 余年战略咨询项目沉淀（含多个地产集团、产业集团、上市公司的战略规划、战略解码与经营体系构建项目）

**本模块定位**：战略管理不是一次性的规划报告，而是**"洞察 → 选择 → 解码 → 落地 → 评价 → 迭代"的完整经营闭环**。本模块按这一闭环组织，每一环都给出诊断框架、设计工具与交付模板。

---

## 〇、战略管理全周期地图

| 阶段 | 核心问题 | 主要工具 | 交付物 |
|---|---|---|---|
| **1 洞察** | 外部发生了什么？我们在哪里？ | PESTEL、五力、行业生命周期、S 曲线、资源能力盘点 | 战略洞察报告 |
| **2 选择** | 我们做什么、不做什么？靠什么赢？ | BLM、业务组合矩阵、商业模式画布、安索夫矩阵、三地平线 | 战略规划方案 |
| **3 解码** | 战略如何变成每个人的活？ | 战略地图、OGSM、BSC、CSF 树、RACI | 战略解码与任务分解报告 |
| **4 落地** | 怎么保证执行不走形？ | 经营分析会、里程碑管控、预算衔接、经营单元 | 经营分析会机制方案 |
| **5 评价** | 我们到底做到了没有？ | KPI 体系、战略绩效评价、战略健康度评估 | 战略执行评估报告 |
| **6 迭代** | 环境变了怎么办？ | 战略情景规划、滚动修订机制、战略复盘 | 战略修订方案 |

**全周期铁律**：任何一个阶段缺失，战略都会"死"在中间某一环。**中国企业战略失败的三大高发死亡点**依次是：① 只有目标没有路径（死在"选择"）；② 只有报告没有解码（死在"解码"）；③ 只有会议没有机制（死在"落地"）。

## 一、战略洞察（第一阶段）

### 1.1 外部洞察（看市场）

| 维度 | 观察要点 | 常用工具 |
|---|---|---|
| **宏观环境** | 政策导向、经济周期、技术变革、社会趋势、环保与合规 | PESTEL |
| **行业格局** | 市场规模与增速、行业生命周期阶段、集中度变化、盈利水平走势 | 行业生命周期曲线、集中度 CR4/CR8 |
| **竞争态势** | 主要玩家格局、竞争对手策略、替代品威胁、新进入者 | 波特五力、竞争对手画像 |
| **客户需求** | 需求变化趋势、客户结构演变、支付能力与偏好迁移 | 客户分层、需求迁移图 |
| **技术曲线** | 技术成熟度、颠覆性技术出现时点、技术替代速度 | 技术成熟度曲线、S 曲线 |

**行业生命周期判断与战略取向**

| 阶段 | 特征 | 战略取向 |
|---|---|---|
| 导入期 | 增速快、格局散、标准未定 | 抢标准、抢心智、快速试错 |
| 成长期 | 高增速、玩家涌入、开始分化 | 抢份额、扩产能、建壁垒 |
| 成熟期 | 增速放缓、集中度提升、价格战 | 提效率、降成本、并购整合 |
| 衰退期 | 需求萎缩、产能过剩 | 收缩、转型、退出或收割 |

### 1.2 内部盘点（看自己）

- **资源**：资金、土地/资产、渠道、资质、数据、品牌、政企关系
- **能力**：产品力、运营力、组织力、人才储备、技术积累、供应链掌控力
- **业绩**：营收结构、利润率、现金流、周转效率（**必须与标杆对比，不能只看自己**）

**资源 vs 能力的分野（关键判断）**
- **资源**是"你有什么"（可计量、可交易、会折旧）
- **能力**是"你能反复做成什么"（难交易、靠积累、不会自动消失）
- 只有能力才构成持续竞争优势；资源在成熟市场会被迅速复制。**诊断时必须区分二者，否则会把资源当能力报给客户，方案必然落空。**

### 1.3 差距分析（BLM 核心入口）

| 差距类型 | 定义 | 分析工具 |
|---|---|---|
| 业绩差距 | 现有目标 vs 实际结果的差距 | 5Why 归因、指标分解 |
| 机会差距 | 现有业务设计 vs 潜在机会的差距 | 三地平线、业务组合评估 |

**关键区别**：业绩差距用**改善**解决（做得更好）；机会差距只能用**变革**解决（做得不同）。混淆二者是战略方案失效的最常见原因。

**5Why 深挖法**：连续追问五层"为什么"，从表象追溯到系统性根因。
- 表层：销售未达标
- 一层：客户流失率高
- 二层：交付延期
- 三层：产能排产混乱
- 四层：计划与销售信息不联动
- 根因：缺少产供销协同机制 → 对应组织与流程改善举措

> **5Why 使用纪律**：每一层追问都要有**事实数据支撑**，不能凭经验推演；追到"可被某个具体举措解决"的层级就停，不要无限追问到"人性"或"行业本质"，那样无法落地。

### 1.4 战略洞察报告结构（交付模板）

```
一、宏观与政策环境
二、行业格局与趋势判断（含行业生命周期定位）
三、竞争格局与主要玩家分析
四、客户与需求迁移
五、内部资源与能力盘点（资源/能力分列）
六、差距分析（业绩差距 / 机会差距）
七、核心判断与战略命题（3-5 条，必须可被证伪）
```

> **最后一条最关键**：诊断报告的收口不是"情况综述"，而是**3-5 条可被证伪的战略命题**。例如"公司过去三年的增长主要来自行业红利而非能力提升，行业红利退潮后现有模式将无法维持 5% 以上增速"——这样的命题能直接进入第二阶段讨论。

## 二、战略选择（第二阶段）

### 2.1 BLM 业务领先模型（四维十面）

| 维度 | 面 | 关键问题 |
|---|---|---|
| **战略** | 战略意图 | 我们要成为什么？使命愿景目标是什么？ |
| | 市场洞察力 | 市场发生了什么变化？机会在哪里？ |
| | 创新焦点 | 靠什么创新赢得竞争？ |
| | 业务设计 | 客户、价值主张、盈利模式、活动范围怎么定？ |
| **执行** | 关键任务与依赖关系 | 支撑战略的关键任务是什么？依赖什么资源？ |
| | 正式组织 | 组织结构与流程能否支撑关键任务？ |
| | 人才 | 有没有合适的人？ |
| | 氛围与文化 | 组织氛围是否支持执行？ |
| **领导力** | — | 领导团队能否推动变革？ |
| **价值观** | — | 价值观是否与战略匹配？ |

**战略与执行的一致性检查**：战略四要素与执行四要素必须双向匹配——"业务设计"决定"关键任务"，"关键任务"反过来检验"业务设计"是否可行。**十面中任一面缺失或被忽略，战略就会在执行期打滑。**

### 2.2 战略选择的核心工具

**（1）业务组合矩阵（GE 矩阵 / 三层面评估）**

| 业务 | 市场吸引力 | 自身竞争力 | 战略取向 |
|---|---|---|---|
| 高吸引 + 强竞争 | 高 | 高 | 全力投入、扩大领先 |
| 高吸引 + 弱竞争 | 高 | 低 | 选择性投入或补能力 |
| 低吸引 + 强竞争 | 低 | 高 | 收割现金流、支撑新业务 |
| 低吸引 + 弱竞争 | 低 | 低 | 退出或转型 |

**（2）商业模式画布（九宫格）**

| 模块 | 关键问题 |
|---|---|
| 客户细分 | 为谁创造价值？ |
| 价值主张 | 解决什么痛点？比替代方案好在哪？ |
| 渠道通路 | 怎么触达与交付？ |
| 客户关系 | 怎么获取、维系、增值？ |
| 收入来源 | 靠什么收钱？收费方式与定价逻辑？ |
| 核心资源 | 需要什么关键资源？ |
| 关键业务 | 必须做好的几件事是什么？ |
| 重要伙伴 | 谁是不可替代的合作方？ |
| 成本结构 | 成本主要花在哪？固定/可变比例？ |

> **画布使用纪律**：画布是**检查工具**而非**创作工具**。客户往往已经画过，你要做的是逐格追问"这一格的假设有数据支撑吗"，把拍脑袋的格子标红——**画布的价值在于暴露未经检验的假设**。

**（3）三地平线布局**

| 地平线 | 时间窗 | 定位 | 资源配置占比参考 |
|---|---|---|---|
| H1 第一地平线 | 0-2 年 | 核心业务守成与发展 | 60-70% |
| H2 第二地平线 | 2-5 年 | 成长业务培育 | 20-30% |
| H3 第三地平线 | 5 年以上 | 种子业务孵化 | 5-10% |

> **占比不是铁律而是体检指标**：若客户 H3 投入接近 0，说明只有今天没有明天；若 H2+H3 超过 40% 而 H1 现金流失血，说明在"用今天赌明天"。**两个方向的失衡都是危险信号。**

**（4）战略情景规划（应对重大不确定性）**

当外部存在 2 个以上高度不确定的关键变量时，不用单一路径预测，而是构建 2×2 情景矩阵：

| | 变量 B 乐观 | 变量 B 悲观 |
|---|---|---|
| **变量 A 乐观** | 情景一：全力进攻 | 情景二：选择性布局 |
| **变量 A 悲观** | 情景三：稳守待机 | 情景四：收缩保现金 |

对每个情景写明：**触发信号（early warning indicator）+ 预案动作 + 决策责任人**。这样当环境变化时，企业不是"临时开会慌作一团"，而是"照预案切换"。

### 2.3 战略规划方案结构（交付模板）

```
一、使命、愿景与价值观（校准，不重写）
二、战略定位与总体目标（3-5 年）
三、业务组合与三地平线布局
四、各业务单元的商业模式与竞争策略
五、核心能力建设路线（要建什么能力、多久建成、怎么验证）
六、关键战略举措清单（每项含负责人、里程碑、资源需求）
七、资源需求与财务测算
八、战略情景与风险预案
```

## 三、战略解码（第三阶段）

> **这是中国企业战略管理最薄弱的环节，也是本模块最有价值的部分。** 绝大多数战略报告死在"高管讲得清、中层接不住、基层不知道"。

### 3.1 解码逻辑（四级链条）

```
战略规划 → 战略主题 → 关键成功要素(CSF) → 关键任务 → 目标与指标 → 责任分解
```

**战略主题**：把战略归纳为 3-5 个并列的主题（如"区域深耕""产品升级""组织提效"）。**主题数量超过 5 个说明战略没聚焦，必须回去重做选择阶段。**

### 3.2 战略解码会操盘（关键动作）

战略解码不是"发文件"，而是一场**需要精心设计的会议**（通常 1-2 天，核心管理层 + 部门负责人全员参加）：

| 环节 | 时长 | 动作 | 产出 |
|---|---|---|---|
| 战略宣讲 | 0.5h | 一把手亲自讲战略，不能委托 | 全员对齐战略语言 |
| 主题认领 | 1h | 各部门认领自己承接的战略主题 | 主题-部门映射表 |
| 分组拆解 | 3-4h | 按主题分组，现场拆 CSF→关键任务→指标 | 各主题任务分解初稿 |
| 交叉质询 | 2h | 上下游部门互相质询"你的任务怎么支撑我" | 依赖关系与断点清单 |
| 承诺确认 | 1h | 各部门负责人当众承诺承接内容与指标 | 战略承接确认书 |
| 指标校准 | 1h | 校准指标口径，去除重复与冲突 | 最终指标库 |

> **操盘要点**：① 一把手必须全程在场并亲自宣讲；② 每个部门必须自己讲"我承接哪一项、做哪几件事、拿什么指标证明"，不能由咨询顾问代讲；③ 交叉质询环节必须留足时间——**部门之间的依赖断点，只会在互相质询中暴露**；④ 会议结束必须有"承接确认书"签字，这是后续考核的依据。

### 3.3 战略地图四层面

- **财务层面**：营收增长、利润提升、资产效率
- **客户层面**：客户价值主张（成本领先 / 产品领先 / 客户亲密）
- **内部流程层面**：运营管理流程、客户管理流程、创新流程、法规社会流程
- **学习成长层面**：人力资本、信息资本、组织资本

> **战略地图的灵魂是"因果关系"而非"四层分类"**：必须能讲清"学习成长层面的某个动作 → 改善某个内部流程 → 提升某个客户指标 → 最终带来某个财务结果"的完整因果链。**画不出因果链的战略地图，只是一张分类表。**

### 3.4 OGSM 框架

| 要素 | 含义 | 示例 |
|---|---|---|
| Objective | 目标/目的（定性） | 成为区域市场领先的产业运营商 |
| Goal | 量化目标 | 3 年内营收达 XX 亿，市占率前 3 |
| Strategy | 策略 | 聚焦长三角，双轮驱动（开发+运营） |
| Measure | 衡量指标 | 年度营收、毛利率、客户续约率 |

### 3.5 战略解码与任务分解报告结构（交付模板）

```
一、战略主题总览（3-5 个主题及其逻辑关系）
二、主题一：XXX
   2.1 关键成功要素（CSF）
   2.2 关键任务清单（任务 / 责任人 / 里程碑 / 依赖）
   2.3 目标与衡量指标（指标定义 / 口径 / 目标值 / 数据来源）
三、主题二……（同上结构）
四、部门承接矩阵（主题 × 部门，标注主责/协同）
五、跨部门依赖关系与断点清单
六、战略承接确认书（签字版）
```

**任务分解表标准七列**：`关键任务 | 任务描述 | 责任部门/责任人 | 协同方 | 完成时间 | 交付标准 | 衡量指标`。**缺任何一列，任务都会在执行期变成"待明确"。**

## 四、战略落地（第四阶段）

### 4.1 五大落地机制

1. **目标分解**：公司级 → 部门级 → 岗位级（三级分解，层层可追溯）
2. **经营分析会**：月度经营分析（数据看板 + 问题清单 + 行动项）、季度战略回顾
3. **责任体系**：每项关键任务明确第一责任人、协同人、支持人（RACI）
4. **里程碑管控**：关键节点设置检查点与预警机制
5. **动态调整**：外部环境重大变化时启动战略修订程序

### 4.2 经营分析会机制设计（最易流于形式的环节）

**常见失败模式**：会议变成"各部门念报表"，没有分析、没有决策、没有行动项。

| 设计要素 | 要求 |
|---|---|
| 会议节奏 | 月度经营分析（90 分钟）+ 季度战略回顾（半天） |
| 数据看板 | 会前 3 天发出，会上不念数据，只讲偏差与对策 |
| 议题规则 | 只讨论"偏差超过阈值"的指标，正常指标不占用时间 |
| 分析深度 | 每个偏差必须回答"根因是什么、谁负责、什么时候解决" |
| 行动项管理 | 上次会议行动项**首先过堂**，闭环率纳入考核 |
| 决策记录 | 每个决策明确"决策事项 / 决策结果 / 责任人 / 时限" |

> **经营分析会检验标准**：会开完之后，如果没有任何决策产生、没有任何人领走任务，这个会就是无效的。**月度会议应该有能力启动"五分钟的现场汇报"和"立即执行的行动项"——这是组织作战能力的体现。**

### 4.3 战略落地与预算的衔接

战略必须"有钱办事"——经营计划与预算是战略落地的资金通道：

```
战略主题 → 关键任务 → 资源需求 → 年度经营计划 → 预算 → 月度预算执行监控
```

> **常见断点**：战略会上定了要做的事，预算会上因为"没有预算科目"被砍掉。**解法是让战略解码成果直接成为预算编制的输入项，而不是两套平行体系。** 具体做法：预算编制启动前，先把"关键任务清单 + 资源需求"作为预算申报的必填字段下发。

## 五、战略评价与迭代（第五、六阶段）

### 5.1 战略执行评价三个维度

| 维度 | 评价内容 | 关键指标 |
|---|---|---|
| 结果达成 | 目标是否实现 | 营收、利润、份额、现金流 |
| 能力提升 | 支撑战略的能力是否建成 | 组织能力评估、人才梯队、关键流程成熟度 |
| 机制健全 | 落地机制是否在运转 | 经营分析会闭环率、行动项完成率、战略承接确认率 |

> **只评价"结果达成"是最常见的错误**：结果受外部环境影响大，可能"运气好"也达标；只有同时评价**能力与机制**，才能判断战略管理是否真的在起作用，也才能在环境逆转时提前预警。

### 5.2 战略健康度自评表（快速诊断工具）

| 检查项 | 判断标准 | 是否达标 |
|---|---|---|
| 战略是否被中层说得清 | 随机抽 3 名中层，能否讲清本公司战略主题 | □ |
| 每个部门是否有承接 | 部门年度重点能否追溯到战略主题 | □ |
| 关键任务是否有指标 | 任务是否有可量化、可追溯的衡量指标 | □ |
| 是否有跨部门依赖管理 | 是否识别并管理了部门间依赖断点 | □ |
| 经营分析会是否产生决策 | 近 3 次会是否产生决策与行动项并闭环 | □ |
| 战略与预算是否衔接 | 战略任务是否有对应预算科目与额度 | □ |
| 是否做过战略复盘 | 是否周期性进行战略复盘与滚动修订 | □ |

**任一项为否，即为战略管理的具体失血点，可直接转化为改善举措。**

### 5.3 战略滚动修订机制

- **轻量修订**（每季度）：环境无重大变化时，只校准指标与任务节奏
- **中度修订**（每年）：重新审视业务组合与资源配置比例
- **重大修订**（触发式）：出现情景规划中预设的"触发信号"时，立即启动预案切换

## 七、实战经验（脱敏）

- **案例 A**：某上市产业集团战略与目标分解项目——以"战略主题—关键任务—指标—责任"四级链条贯穿，解决了战略停留在高管层、中基层不知如何承接的问题。核心动作是设置"战略承接确认会"，让每个部门自己讲清"我承接哪一项、做哪几件事、拿什么指标证明"。
- **案例 B**：某地产集团"经营致胜"能力培养与问题解决微咨询——把战略解码与干部能力培养结合，用群策群力工作坊形式让干部现场拆解自己部门的任务，做到"既产出方案，又提升能力"。
- **案例 C**：某产业集团战略解码失效复盘——客户原有战略报告完整、目标清晰，但一年后核心任务完成率不足三成。诊断发现：关键任务未落到部门（缺承接矩阵）、未识别跨部门依赖（研发与销售各做一套）、预算未与战略衔接（任务无资金）。**三个断点叠加，方案自然空转**。改善动作是按"解码—依赖—预算"三步补齐，半年后关键任务完成率提升至七成以上。
