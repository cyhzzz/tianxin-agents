# 28 · 制度管理经典方法论

> 源流：从诺斯的制度经济学（正式规则、非正式约束、实施机制），到韦伯科层制的规则治理、德鲁克《管理的实践》中制度的管理逻辑，再到 COSO 内部控制框架、《企业内部控制基本规范》的中国实践，以及"制度的文化性"这一本土深化。

---

## 一、制度的经济学基础

### 1.1 诺斯：制度的三个构成部分

**制度的定义**（道格拉斯·诺斯）："制度是一个社会的博弈规则，是一些人为设计的、型塑人们互动关系的约束。"

**制度的三重构成**：
| 构成 | 内容 | 特征 |
|---|---|---|
| **正式规则** | 法律、规章、制度、合同 | 可写明、可强制、变化相对快 |
| **非正式约束** | 行为规范、惯例、习俗、自我限定的行事准则 | 难写明、靠认同、变化极慢 |
| **实施机制** | 谁执行、怎么执行、违规怎么处理 | 决定制度是否真正有效 |

**三大关键理论**：

| 理论 | 内容 | 管理启示 |
|---|---|---|
| **交易费用** | 制度通过降低交易费用影响绩效 | 制度存在的意义是降低协作成本；不能降低成本的制度是负担 |
| **路径依赖** | 过去的制度会"锁定"未来的选择 | 旧制度的惯性极强，改革必须考虑历史包袱 |
| **非正式约束的作用** | 非正式约束是制度稳定性与持存的根源 | **制度只能管住"看得见"的，真正约束行为的是文化** |

**最重要的管理洞察**：诺斯指出，正式规则可以一夜之间改变（发文即可），但非正式约束改变极慢。**这解释了为什么制度总是"发文容易执行难"**——制度改的是正式规则，而员工的实际行为受非正式约束（习惯、文化、群体规范）支配。

**咨询用法**：客户抱怨"制度执行不下去"时，用这个框架诊断：
1. 正式规则是否清晰、可执行？（制度本身有没有问题）
2. 实施机制是否到位？（有没有人管、违规有没有成本）
3. **非正式约束是否冲突？**（员工群体实际认同的做法与制度是否相反）

第三条是最容易被忽视也最致命的。**制度与文化的冲突，制度通常会输。**

### 1.2 科斯：企业的性质与交易成本

- **企业的存在理由**：因为市场交易有成本，把交易内部化到企业可以降低这些成本
- **企业的边界**：当内部组织成本 > 市场交易成本时，就应该外包
- **管理启示**：制度与流程的价值，就是降低内部协作的交易成本。**如果一个制度的执行成本超过了它节省的成本，这个制度就是负资产。**

**咨询用法**：制度梳理时的"成本效益审查"——逐条问"这条制度省了什么、花了多少管理成本"。大量企业的制度是"历史沉积"（一条条加，从不删除），导致制度成本极高而效果极差。

## 二、制度体系的经典框架

### 2.1 韦伯科层制与规则治理

**韦伯的核心观点**：现代组织的理性化，依赖于"法理型权威"——权威来自规则，而不是来自个人魅力或传统。

**规则治理的三项特征**：
1. 规则是抽象的、普遍适用的（不针对特定人）
2. 规则由明确的程序制定与修改
3. 管理者是规则的执行者，而非规则的主人

**咨询用法**：中国企业（特别是国企与家族企业）的常见病灶是**"人治大于法治"**：制度存在，但老板一句话就可以豁免。这不是"制度不够多"的问题，而是"制度权威性不够"的问题。诊断时看一个指标：**一年内有多少次"特批""例外"？** 例外越多，制度越虚。

### 2.2 德鲁克：制度的管理逻辑

德鲁克在《管理的实践》《卓有成效的管理者》中关于制度与规则的若干核心观点：

| 观点 | 内涵 |
|---|---|
| **制度是工具，不是目的** | 制度服务于目标；不为制度而制度 |
| **简化优于完备** | 过细的制度会导致僵化与形式主义 |
| **管理者要"做正确的事"** | 制度要确保人们聚焦于正确的事，而非只是"正确地做事" |
| **分权与责任对等** | 给权限的同时给责任，否则制度会失效 |
| **例外管理原则** | 制度管常规，例外由管理者判断（但例外不能成为常态） |

**德鲁克最有价值的制度观**：**"管理的本质不在于知，而在于行。"** 制度的价值最终体现在行为改变上，而不是文本的完备性上。

### 2.3 COSO 内部控制框架

COSO（The Committee of Sponsoring Organizations of the Treadway Commission）框架是全球内控领域的标准。

**内部控制五要素**：
```
        ┌──────────────────────────────┐
        │  ① 控制环境（Control Environment）  │  ← 基础（诚信、道德、治理）
        ├──────────────────────────────┤
        │  ② 风险评估（Risk Assessment）     │  ← 识别与分析风险
        ├──────────────────────────────┤
        │  ③ 控制活动（Control Activities）  │  ← 具体的控制措施
        ├──────────────────────────────┤
        │  ④ 信息与沟通（Info & Communication）│  ← 信息流通
        ├──────────────────────────────┤
        │  ⑤ 监控（Monitoring）              │  ← 持续监督与独立评估
        └──────────────────────────────┘
```

**控制活动的常见类型**：
| 类型 | 说明 | 举例 |
|---|---|---|
| **不相容职务分离** | 涉及资产与资金的关键环节由不同人负责 | 出纳与记账分离、采购与验收分离 |
| **授权审批控制** | 明确审批权限与流程 | 分级授权表、大额双签 |
| **会计系统控制** | 会计记录与核算的规范 | 凭证管理、账实相符 |
| **财产保护控制** | 资产实物的安全 | 盘点制度、限制接触 |
| **预算控制** | 预算编制与执行监控 | 预算刚性、超支审批 |
| **运营分析控制** | 数据监测与异常分析 | 经营分析会、指标预警 |
| **绩效考评控制** | 考核与奖惩 | 绩效制度、问责机制 |
| **信息与系统控制** | 信息系统安全与权限 | 权限管理、日志审计 |

**COSO 2013 版新增的 17 项原则**：将五要素细化为 17 条原则，覆盖公司治理、董事会监督、组织架构、诚信与道德等更广泛的内容。

### 2.4 中国内控规范体系：《企业内部控制基本规范》

**中国版内控规范的五要素**（与 COSO 框架一致）：内部环境、风险评估、控制活动、信息与沟通、内部监督

**配套指引**（三大类）：
| 指引类型 | 内容 |
|---|---|
| **应用指引** | 18 项，覆盖组织架构、发展战略、人力资源、社会责任、企业文化、资金活动、采购业务、资产管理、销售业务、研究与开发、工程项目、担保业务、业务外包、财务报告、全面预算、合同管理、内部信息传递、信息系统 |
| **评价指引** | 内部控制评价的内容、程序、方法、缺陷认定与报告 |
| **审计指引** | 内部控制审计的规范 |

**咨询用法**：为中国企业做制度体系与内控体系时，**《企业内部控制基本规范》及配套指引是最权威的本土框架**，比直接套用 COSO 更符合中国监管环境与实务要求。特别是对国企、上市公司，这套规范是刚需。

## 三、制度体系设计的实操方法

### 3.1 制度体系的架构分层

| 层级 | 名称 | 内容 | 制定者 |
|---|---|---|---|
| **第一层** | 章程/基本法 | 公司治理的根本规则 | 股东会/董事会 |
| **第二层** | 基本管理制度 | 覆盖全局的管理原则与框架 | 董事会/总经理办公会 |
| **第三层** | 具体管理制度 | 各项管理职能的制度（人力、财务、采购等） | 各职能部门（报批） |
| **第四层** | 实施细则/操作规范 | 制度的实施细则、SOP 操作指引 | 各职能部门/业务单元 |
| **第五层** | 表单模板 | 各类记录、审批单、台账 | 业务单元 |

**分层设计的原则**：
- **上小下大**：越往上越精简（原则性），越往下越具体（可操作）
- **不越层**：上层不写上层以下的细节，下层不违背上层原则
- **一致性**：下层制度必须与上层制度冲突检查通过

### 3.2 制度文件的标准结构

一份完整的管理制度通常包含以下要素：

| 要素 | 内容 |
|---|---|
| **第一章 总则** | 制定目的、编制依据、适用范围、术语定义、管理原则 |
| **第二章 职责分工** | 各相关角色的职责（决策机构、归口部门、执行部门、监督部门） |
| **第三章 管理内容** | 核心条款（按业务逻辑展开，可分章） |
| **第四章 流程与要求** | 具体操作流程、时限、标准 |
| **第五章 检查与考核** | 监督检查方式、违规处理、问责机制 |
| **第六章 附则** | 解释权归属、生效日期、修订说明 |
| **附件** | 表单模板、流程图、权限表 |

**制度条款的编写要求**：
- **可执行**：明确"谁"在"什么条件下"做"什么"，避免"原则上""努力做到"等模糊表述
- **可检验**：能否被检查、能否被判定违反
- **无歧义**：同一表述不产生两种解释
- **完整**：有行为要求，也要有违规后果

**反面样例（不合格条款）**：
- ❌ "各部门应积极配合相关工作" —— 谁配合？配合什么？不配合怎么办？
- ❌ "原则上应当在 3 个工作日内完成" —— "原则上"就是可以不做
- ❌ "严格按照公司相关规定执行" —— 循环引用，等于没规定

**正面样例**：
- ✅ "采购部门应在收到完整请购单后 3 个工作日内完成询价并提交比价结果；逾期未完成的，由部门负责人在月度经营会上说明原因。"

### 3.3 制度与流程、文化的关系

```
            ┌──────────────┐
            │  文化（非正式约束）│ ← 最深层、最难改、约束力最强
            └───────┬──────┘
                    │ 影响
            ┌───────▼──────┐
            │  制度（正式规则）│ ← 明文规定、可强制
            └───────┬──────┘
                    │ 保障
            ┌───────▼──────┐
            │  流程（做事路径）│ ← 横向协同、可优化
            └──────────────┘
```

**三者的正确关系**：
| 关系 | 说明 |
|---|---|
| **流程是主干** | 先理清"怎么做"（流程），再定"必须这么做"（制度） |
| **制度是保障** | 制度确保流程被遵守，为流程提供权威性 |
| **文化是土壤** | 文化决定制度能否被真正认同与执行 |

**制度的文化性（本土深化）**：
把企业文化融入制度，是文化落地的关键路径。具体做法：
1. **价值观具象化**：把"客户第一"翻译成具体的制度条款（客户投诉 24 小时响应、客户满意度纳入考核）
2. **制度导向检查**：逐条检查制度是在鼓励还是抑制价值观倡导的行为
3. **奖惩一致**：制度奖励的必须与价值观一致（不能口号说团队协作，考核却只算个人业绩）

**咨询用法**：制度建设的正确顺序是 **"战略 → 流程 → 制度 → 文化渗透"**。跳过流程直接写制度，会写出"部门本位"的制度（每个部门都从自己角度写，互相打架）。

### 3.4 制度全生命周期管理

| 阶段 | 关键动作 | 交付物 |
|---|---|---|
| **规划** | 制度体系框架设计、制度清单梳理、废改立计划 | 制度体系框架、制度清单、年度制度计划 |
| **起草** | 归口部门起草、征求意见、会签 | 制度草案 |
| **评审** | 合规性审查、冲突检查、可执行性评估 | 评审意见 |
| **审批发布** | 按权限审批、正式发文、宣贯 | 正式制度文件、宣贯材料 |
| **执行** | 培训、执行检查、问题收集 | 检查记录、问题清单 |
| **评估修订** | 定期评估、修订或废止 | 修订记录、制度版本更新 |
| **归档** | 版本管理、作废标识、历史留存 | 制度库 |

**制度冲突检查的要点**：
- 同一事项是否有多份制度规定？（重复）
- 不同制度间是否存在矛盾要求？（冲突）
- 制度与上位制度/法律法规是否一致？（合规）
- 制度与流程是否匹配？（落地）

**咨询用法**：制度梳理项目最常见的产出是"制度三张清单"——
1. **保留清单**：现行有效、继续执行
2. **修订清单**：需修订、注明修订要点
3. **废止清单**：过时、重复、冲突，建议废止

**关键提醒**：制度梳理必须有"废止"这一环。只加不减的制度体系会越来越臃肿，最终无人使用。

## 四、制度执行的保障机制

### 4.1 制度失效的常见原因诊断

| 失效原因 | 表现形式 | 对策 |
|---|---|---|
| **制度本身不合理** | 无法执行、执行成本过高 | 制度评估与修订 |
| **制度不清、有歧义** | 各人理解不同 | 制度宣贯与细化 |
| **无人负责** | 不知道谁管 | 明确责任主体与责任人 |
| **违规无成本** | 违反了也没事 | 建立检查与问责机制 |
| **执行成本高于收益** | 大家都觉得麻烦 | 简化制度或改为流程控制 |
| **文化冲突** | 群体认同的做法与制度相反 | 从文化入手（长期）或调整制度（短期） |
| **例外过多** | 天天特批 | 收紧例外权限，例外纳入统计 |
| **领导带头违规** | 领导不遵守，员工也不遵守 | **这是最致命的，必须先解决** |

### 4.2 制度执行的三大机制

| 机制 | 内容 | 关键设计 |
|---|---|---|
| **责任机制** | 每项制度有归口部门、执行责任人、监督责任人 | 制度文件必须写明职责分工 |
| **检查机制** | 定期检查 + 专项检查 + 自查 | 检查有标准、有记录、有反馈 |
| **考核机制** | 制度执行纳入绩效 | 制度执行有可量化的指标 |

**"制度执行率"的量化方法**：
- 抽取关键制度条款，设计检查清单
- 定期（季度/半年）开展执行情况抽查
- 计算执行率 = 合规项数 / 检查项数
- 结果与部门绩效挂钩

### 4.3 制度的简化原则

**制度越多≠管理越好**。判断制度是否过度的信号：
- 员工做任何事都要查制度
- 新员工培训大量时间在讲制度
- 制度条文数量逐年在增但执行率在降
- 出现问题时第一反应是"再加一条制度"

**制度精简的方法**：
1. **合并**：同一主题的多个制度合并为一个
2. **降层**：把过度细化的条款从制度降为 SOP 或操作指引
3. **删除**：取消已无必要的制度（业务已不存在、已固化到系统）
4. **转为流程控制**：把"靠人检查"的制度条款，转为系统自动控制
5. **区分刚性与柔性**：区分"红线条款"（必须刚性）与"指引条款"（可柔性）

## 五、制度管理方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 制度执行不下去 | 诺斯三构成诊断（正式规则/非正式约束/实施机制） |
| 制度太多太乱 | 制度体系分层 + 制度三张清单梳理 |
| 制度之间打架 | 制度冲突检查 + 流程优先原则 |
| 制度写得没法执行 | 制度条款可执行性审改（谁/何时/做什么/不做的后果） |
| 要建内控体系 | COSO 五要素 + 《企业内部控制基本规范》配套指引 |
| 关键风险点控制 | 不相容职务分离 + 授权审批控制 |
| 制度成本太高 | 科斯交易成本视角 + 制度精简五法 |
| 人治大于法治 | 韦伯规则治理 + 例外率统计 |
| 制度与文化两张皮 | 制度的文化性（价值观具象化） |
| 制度年年修订还是没用 | 全生命周期管理 + 执行检查机制 |
