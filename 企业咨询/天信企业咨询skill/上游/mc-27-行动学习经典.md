# 32 · 行动学习经典方法论

> 源流：行动学习（Action Learning）由英国物理学家雷格·雷文斯（Reg Revans）在 1940 年代提出，核心公式 L = P + Q。后经马奎特（Michael Marquardt）、佩德勒（Mike Pedler）等人系统化，成为中国企业管理者培养与组织问题解决的主流方法。

---

## 一、行动学习的起源与核心命题

### 1.1 雷文斯与行动学习公式

**雷文斯的核心公式**：
```
L = P + Q
学习 = 程序化知识（Programmed Knowledge）+ 质疑洞察（Questioning Insight）
```

**关键洞察**：
- **P（程序化知识）**：书本知识、课程培训、既有方法论——可以被传授
- **Q（质疑洞察）**：在真实情境中提出好问题、反思、形成新理解的能力——只能通过实践获得
- **传统培训只有 P，没有 Q**——这是企业培训"学完就忘、学完不用"的根本原因

**雷文斯的其他核心观点**：
| 观点 | 内涵 |
|---|---|
| **没有行动就没有学习** | 学习必须在解决真实问题的过程中发生 |
| **没有学习就没有明智的行动** | 只为解决问题而不反思，不是行动学习 |
| **学习 = 做事 + 反思** | 两者缺一不可 |
| **"要么行动，要么学习"是错误二分** | 行动与学习是一体两面 |
| **最好的学习来自对真实问题的共同探索** | 小组共同研讨比自己闭门思考更有效 |

**咨询用法**：客户说"我们的培训没效果"时，用 L = P + Q 诊断——如果培训只给了 P（知识），缺失 Q（针对自己问题的质疑与反思），效果必然有限。**行动学习就是为补上 Q 而生的方法。**

### 1.2 行动学习的六大要素（马奎特）

| 要素 | 内涵 | 关键要求 |
|---|---|---|
| **问题（Problem）** | 真实、紧迫、有挑战性、无现成答案 | 不能是"假问题"或已有标准答案的问题 |
| **小组（Group/Set）** | 4-8 人，多元背景 | 成员差异是学习资源，不是障碍 |
| **质疑与反思（Questioning & Reflecting）** | 通过提问澄清、反思 | **这是行动学习区别于普通研讨的核心**：先提问，后给建议 |
| **行动（Action）** | 必须有实际行动与实施权力 | 只研讨不行动=无效；有行动权才能落地 |
| **学习（Learning）** | 个人、团队、组织三个层面 | 学习成果要显性化 |
| **教练（Coach/Facilitator）** | 促进学习过程，不干预内容 | 教练管过程，小组管内容 |

**最关键的两个要素**：**质疑反思**（区别于普通研讨）与**行动**（区别于普通培训）。

## 二、行动学习的经典公式与流程

### 2.1 行动学习的核心循环

```
      提出问题
         ↓
    ┌─────────┐
    │ 质疑反思 │ ←─── 教练促进
    └────┬────┘
         ↓
      形成方案
         ↓
      采取行动
         ↓
      产生结果
         ↓
    ┌─────────┐
    │ 反思学习 │ ──┐
    └────┬────┘   │
         │        │ 循环
         └────────┘
```

### 2.2 经典行动学习工作坊流程

| 阶段 | 时间参考 | 关键动作 | 产出 |
|---|---|---|---|
| **问题澄清** | 30-60 min | 问题提出者陈述问题；小组只提问不给建议（澄清问题） | 问题定义与澄清 |
| **问题重构** | 30 min | 通过提问识别真正的问题（往往不是表面问题） | 重构后的核心问题 |
| **方案共创** | 90-180 min | 小组讨论、头脑风暴、形成可选方案 | 2-3 个方案 |
| **方案评审** | 60 min | 评估方案可行性、资源需求、风险 | 优选方案 |
| **行动计划** | 60 min | 拆解任务、明确责任人/时间/标准 | 工作行动计划 |
| **承诺与执行** | — | 责任人对行动计划做出承诺 | 承诺书 |
| **复盘学习** | 下次会议 | 回顾执行结果、提炼规律 | 复盘报告与学习成果 |

**关键规则："提问，不给建议"**
- 在澄清与重构阶段，小组成员只能提问，不能给建议
- 目的：帮助问题拥有者自己看清问题，而不是被别人的答案牵着走
- 这一规则是行动学习最有力量的机制，也是最难坚持的

### 2.3 群策群力工作坊（GE Work-Out 本土化）

**GE 的 Work-Out（群策群力）机制**：

| 要素 | 说明 |
|---|---|
| **参与对象** | 跨层级、跨部门（包含一线员工与高管） |
| **议题** | 真实的业务问题（效率、成本、客户、流程） |
| **规则** | 现场决策（领导者当场答复）或明确答复期限 |
| **形式** | 小组研讨 → 方案陈述 → 领导现场回应（同意 / 不同意并说明理由 / 需要更多信息） |
| **目标** | 去除官僚、加速决策、激活一线智慧 |

**GE Work-Out 的三类决策**：
1. **可以立即决定**：领导当场拍板
2. **需要更多信息**：明确何时答复（不超过约定时限）
3. **不能同意**：领导者必须**当场说明理由**（这是关键——不能只说"不行"）

**五步工作坊框架（本土化）**：
```
① 现状描述 → ② 影响因素分析 → ③ 工作行动计划 → ④ 风险规避计划 → ⑤ 过程地图
```

**咨询用法**：这是本土最成熟的行动学习工作坊结构。**核心价值**在于：
- 让一线员工参与问题解决（激活一线的智慧）
- 让高管现场决策（打破层层上报的官僚）
- 产出可执行的工作行动计划（不是"讨论完就完"）

## 三、行动学习与中国企业的实践

### 3.1 行动学习本土化的三条路径

| 路径 | 特点 | 适用 |
|---|---|---|
| **GE Work-Out 模式** | 聚焦业务问题解决、强调现场决策 | 大企业、效率改善、破除官僚 |
| **管理者培养模式** | 以真实业务问题为学习载体，培养管理者 | 干部培养、领导力发展 |
| **战略落地模式** | 用行动学习推动战略解码与落地 | 战略转型、组织变革 |

**中国企业的经典实践**：
- **华润**：行动学习作为集团管理工具的长周期实践（"群策群力"、"行动学习 + 业务"）
- **中粮**：行动学习与战略推进结合
- **中投系统**：行动学习与业务问题解决、干部培养结合
- 这套方法已成为中国大型企业（尤其央企国企）管理者培养与组织变革的主流工具

### 3.2 行动学习与培训体系的区别

| 维度 | 传统培训 | 行动学习 |
|---|---|---|
| **知识来源** | 讲师的知识（P） | 学员在实践中的质疑与反思（Q） |
| **学习载体** | 课程、案例（别人的） | 真实问题（自己的） |
| **成果形态** | 知识掌握 | 问题解决 + 能力提升 + 组织成果 |
| **效果持续性** | 低（学完就忘） | 高（边做边学，即时应用） |
| **角色** | 讲师主导 | 学员主导，教练促进 |
| **风险** | 学用脱节 | 需要真实问题与决策权限 |

**关键洞察**：行动学习不是"培训形式的创新"，而是**学习范式的转换**——从"接受知识"转为"在解决问题中建构知识"。

### 3.3 行动学习项目的设计要点

| 要点 | 关键设计 |
|---|---|
| **问题选择** | 真实、重要、有挑战、无标准答案、有行动空间 |
| **小组组建** | 4-8 人、背景多元、有相关权限、有行动能力 |
| **教练配备** | 熟悉行动学习流程、能坚持"只提问不给建议"、能处理小组动力 |
| **高管参与** | 高层选择问题、参与方案评审、现场决策、提供资源 |
| **周期安排** | 通常 3-6 个月，包含多次集中 + 期间行动 + 复盘 |
| **成果导向** | 项目要有明确的业务成果与学习成果双目标 |
| **组织支持** | 时间保障、资源支持、成果认可机制 |

**常见失败原因**：
1. 问题不是真实的（假问题、教科书式问题）
2. 小组没有行动权限（讨论了但改不了）
3. 教练过度介入内容（变成"讲师的研讨会"）
4. 高管只在开场露面（不参与决策，方案无法落地）
5. 没有复盘环节（只有解决问题，没有学习）
6. 变成"变相的汇报会"（小组向领导汇报，失去了质疑反思的精神）

## 四、行动学习的教练技术

### 4.1 教练的角色定位

**行动学习教练的两条铁律**：
1. **管过程，不管内容**：教练不提供业务答案，只管理学习流程
2. **促进，不主导**：让小组自己找到答案

**教练的核心技能**：
| 技能 | 说明 |
|---|---|
| **提问** | 提出开放性问题，促进思考（"你怎么知道这是根本原因？""还有别的可能吗？"） |
| **倾听** | 听到话语背后的假设与情绪 |
| **反馈** | 及时反馈小组的过程表现（"我观察到刚才大家都在给建议，没有人提问"） |
| **处理动力** | 识别小组中的权力动态、沉默者、主导者 |
| **保持中立** | 对方案内容不表态（不能暗示自己倾向哪个方案） |
| **时间管理** | 把握节奏，确保关键环节不被跳过 |

### 4.2 有效提问的框架

**澄清式提问**：
- "你说的这个问题，具体表现是什么？"
- "这个情况持续多久了？"
- "你是怎么知道的？有什么数据支持？"

**深挖式提问**：
- "为什么会这样？"（连问 5 层）
- "如果这个问题解决了，会带来什么变化？"
- "真正的障碍是什么？"

**视角转换式提问**：
- "如果你是客户，你会怎么看？"
- "如果你的竞争对手面对这个问题，他会怎么做？"
- "三年后回头看，你希望当时做了什么？"

**假设检验式提问**：
- "你这个判断基于什么假设？"
- "如果这个假设不成立呢？"
- "有什么证据能证明或推翻它？"

**行动导向式提问**：
- "你打算做什么？"
- "你需要什么支持？"
- "什么时候可以有第一个结果？"

### 4.3 小组动力的处理

| 症状 | 处理 |
|---|---|
| 有人主导全场 | 提问："其他人怎么看？我们听听还没发言的伙伴" |
| 有人沉默 | 邀请："你怎么看？你的视角可能很不同" |
| 陷入细节争论 | "我们先回到核心问题——这跟我们要解决的事有什么关系？" |
| 开始给建议（违反提问规则） | 提醒："我们先只用提问，暂时不给建议，好吗？" |
| 情绪化对抗 | 暂停，处理情绪："我们先停一下，说说现在各自的感受" |
| 急于跳到方案 | "先别急，我们把问题真正搞清楚再想方案" |

## 五、行动学习成果的显性化

### 5.1 三类学习成果

| 层面 | 成果 | 交付物 |
|---|---|---|
| **个人学习** | 能力提升、认知改变 | 个人学习总结、能力提升记录 |
| **团队学习** | 协作能力、团队默契 | 团队复盘报告 |
| **组织学习** | 制度优化、知识沉淀、问题解决 | 方案成果、制度改进建议、案例库 |

### 5.2 复盘的经典四步法

```
① 回顾目标（我们本来要做什么？）
        ↓
② 评估结果（实际结果是什么？差距在哪？）
        ↓
③ 分析原因（为什么有差距？成功/失败的关键因素？）
        ↓
④ 总结规律（学到了什么？下次怎么做？）
```

**复盘的关键纪律**：
- **对事不对人**：聚焦事情的过程与决策，不追责
- **坦诚开放**：敢于面对失败与不足
- **以学习为导向**：目的不是评价，是改进
- **沉淀为制度/方法**：复盘的成果要转化为可复用的内容

**复盘的三种层次**：
| 层次 | 内容 | 转化 |
|---|---|---|
| 事件层 | 这次发生了什么 | 事实记录 |
| 决策层 | 为什么做这个决策、效果如何 | 决策经验 |
| 规律层 | 背后的规律是什么 | 方法论、制度、课程 |

## 六、行动学习方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 培训没效果、学用脱节 | L = P + Q 诊断 + 行动学习替代方案 |
| 业务问题解决慢 | 群策群力工作坊（五步框架） |
| 干部培养缺少实战 | 行动学习项目（真实问题为载体的培养） |
| 部门墙严重、协同差 | 跨部门行动学习小组 |
| 战略落地难 | 战略落地型行动学习（战略解码 + 群策群力） |
| 组织缺乏学习氛围 | 行动学习 + 复盘机制建设 |
| 一线智慧没被激活 | GE Work-Out 模式（一线参与 + 现场决策） |
| 会议多但无决策 | 群策群力工作坊（现场决策机制） |
| 经验无法沉淀 | 复盘四步法 + 知识萃取（详见 `08-knowledge.md`） |
| 需要教练技术 | 有效提问五类框架 + 小组动力处理 |
