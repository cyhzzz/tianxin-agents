# 21 · 组织与管控经典方法论

> 源流：从泰勒科学管理、法约尔十四项原则、韦伯科层制，到巴纳德协作系统、西蒙有限理性，再到明茨伯格组织结构理论、伯恩斯/斯托克机械-有机论、加尔布雷斯信息处理理论。

## 一、组织理论演进脉络

| 阶段 | 时期 | 核心命题 | 代表 |
|---|---|---|---|
| **古典理论** | 1900s-1930s | 组织是追求效率的机器 | 泰勒科学管理、法约尔十四项原则、韦伯科层制 |
| **行为理论** | 1930s-1960s | 组织是人的协作系统 | 梅奥霍桑实验、巴纳德《经理人员的职能》、麦格雷戈 X/Y 理论 |
| **系统理论** | 1960s-1970s | 组织是开放系统，与环境互动 | 伯恩斯/斯托克机械-有机论、劳伦斯/洛尔希权变理论 |

## 二、经典组织结构理论

### 2.1 韦伯：科层制（Bureaucracy）

**理想科层制的六项特征**：
1. 明确的职权层级
2. 专业分工与岗位职责
3. 规则与程序制度化
4. 非人格化的关系（对事不对人）
5. 基于能力的选拔与晋升
6. 书面文件化的行政

**咨询用法**：科层制是**中性工具**，不是贬义词。判断标准是"是否匹配业务特征"——标准化、规模化的业务需要科层制；创新型、快速变化的业务需要更扁平灵活的结构。中国国企的组织问题往往不是"科层制太多"，而是"科层制不彻底"（规则不清、职责不明、人情凌驾制度）。

### 2.2 法约尔：管理十四项原则（企业管理理论奠基）

| 原则 | 内涵 |
|---|---|
| 分工 | 专业化提升效率 |
| 权力与责任对等 | 有权必有责 |
| 纪律 | 服从与尊重规则 |
| 统一指挥 | 一个下属只接受一个上级指令 |
| 统一领导 | 同一目标的活动由同一领导负责 |
| 个人利益服从整体利益 | — |
| 合理报酬 | 公平且能激励 |
| 集权与分权适度 | 视情况调整集中程度 |
| 等级链 | 从最高到最低的指挥链 |
| 秩序 | 人与物各得其所 |
| 公平 | 公正对待下属 |
| 人员稳定 | 降低流动率 |
| 首创精神 | 鼓励主动创新 |
| 团队精神 | 协作与和谐 |

**咨询用法**：组织诊断的"体检表"。逐一核对十四项原则是否被违反，快速定位组织管理的系统性缺陷。

### 2.3 巴纳德：协作系统理论与权威接受论

- **组织本质**：两个以上的人自觉协作的系统
- **组织的三个基本要素**：共同目标、协作意愿、信息沟通
- **权威接受论**（革命性观点）：权威不来自上级任命，而来自下级接受。只有当下属同时满足四个条件时，权威才成立：
  1. 他理解指令
  2. 他相信指令与组织目标一致
  3. 他认为指令与个人利益相容
  4. 他有能力执行

**咨询用法**：客户抱怨"执行力差""指令没人听"时，用权威接受论诊断——不是下属不服从，而是指令不满足被接受的条件。这是研究"执行力"问题最深的理论根源。

### 2.4 伯恩斯/斯托克：机械式与有机式组织

| 维度 | 机械式（Mechanistic） | 有机式（Organic） |
|---|---|---|
| 任务 | 高度专业化、明确界定 | 共同调整、不断重新定义 |
| 协调 | 层级、规则、程序 | 横向沟通、协商 |
| 决策 | 集中于高层 | 分散在信息所在处 |
| 权威 | 职位权威 | 知识权威 |
| 适用环境 | 稳定、可预测 | 动荡、不确定 |

**咨询用法**：判断组织形态是否与环境匹配。稳定环境用机械式（效率优先），动荡环境用有机式（适应优先）。**常见病灶**：环境已变但组织仍是机械式，导致"反应慢、创新死"。

### 2.5 明茨伯格：《卓有成效的组织》

本书是组织结构理论的集大成之作，核心框架如下：

**五个协调机制**（组织协调工作的五种方式）：
1. 相互调节（非正式沟通，最简单原始）
2. 直接监督（一人对多人负责）
3. 工作流程标准化（规定工作步骤）
4. 工作输出标准化（规定结果标准）
5. 工作技能标准化（通过培训统一技能，如医生、律师）

**组织的五个组成部分**：
```
       战略高层（Strategic Apex）
              │
    中间线（Middle Line）
              │
     运营核心（Operating Core）
       │              │
技术结构（Technostructure） 支持人员（Support Staff）
```

**九大设计参数**：专业化程度、行为规范化、培训和教化、部门化、部门规模、计划控制系统、联络装置、垂直分权、水平分权。

**四组情景因素**：年限与规模、技术系统、环境、权力。

**五种基本结构配置**：

| 结构类型 | 协调机制 | 关键部分 | 适用环境 | 典型组织 |
|---|---|---|---|---|
| **简单结构** | 直接监督 | 战略高层 | 简单动态 | 创业公司、小企业 |
| **机械式科层** | 工作流程标准化 | 技术结构 | 简单稳定 | 传统制造、政府部门 |
| **专业式科层** | 工作技能标准化 | 运营核心 | 复杂稳定 | 医院、大学、律所 |
| **事业部结构** | 工作输出标准化 | 中间线 | 多元化市场 | 大型集团、多元化企业 |
| **变形虫/专案结构** | 相互调节 | 支持人员/全体 | 复杂动态 | 项目型、创新型企业（如 NASA、影视制作） |

**咨询用法**：这是组织设计最实用的诊断框架。客户组织出问题时，先判断"五个协调机制中，哪种在上、哪种在下"。常见病灶：**协调机制错配**——比如创新业务却用"工作流程标准化"管，或者跨部门协作却缺少"联络装置"（联络人、特遣队、整合者角色）。

### 2.6 加尔布雷斯：信息处理理论

**核心命题**：组织设计的本质是**信息处理能力与信息处理需求之间的匹配**。

- **信息处理需求**由任务不确定性决定
- **信息处理能力**由组织结构的层级缓冲（Slack Resource）、任务自主性、信息系统的丰富性决定

**降低信息处理需求的方法**：
1. 增加松弛资源（缓冲库存、预留时间）
2. 建立自我包含的任务单元（自组织团队）
3. 投资垂直信息系统

**提升信息处理能力的方法**：
1. 建立横向联系机制（联络人、任务组、整合部门）
2. 投资横向信息系统

**咨询用法**：诊断"为什么组织越来越忙但越来越乱"——通常是不确定性增加导致信息处理需求暴增，而组织结构未同步升级信息处理能力。

## 三、集团管控经典框架

### 3.1 三种管控模式（集团对下属单位）

| 模式 | 管控重点 | 总部职能 | 适用条件 | 集权程度 |
|---|---|---|---|---|
| **财务管控型** | 只看财务结果指标 | 财务、投资、法务 | 业务相关度低、多元化、子公司在成熟行业 | 最低 |
| **战略管控型** | 战略方向 + 财务结果 | 战略、财务、人力、投资 | 业务相关度中等、有协同潜力 | 中等 |
| **运营管控型** | 深入经营过程管理 | 全职能共享服务 | 业务高度相关、单一主业、规模效应明显 | 最高 |

**模式选择的影响因素**：
- 集团战略（相关多元化 vs 非相关多元化）
- 各业务单元的相关度与协同潜力
- 总部的能力深度（管控是需要能力的，能力不足强行管控会搞乱业务）
- 业务所在行业的成熟度与竞争强度
- 外部监管要求（国企、金融、上市公司有额外要求）

**咨询用法**：管控咨询的第一问——"集团到底要给下属单位创造什么价值？"回答不出来就别谈管控。没有价值创造的总部管控，本质是增加成本。

### 3.2 权责体系设计的核心工具

**授权审批权限表（DOA）**：
- 横向：按事项分类（投资、采购、人事、财务、合同）
- 纵向：按金额/重要性分级
- 单元格：申请 → 审核 → 审批 → 备案（明确每个环节的角色）

**三会一层议事规则**：
| 治理层 | 核心职责 | 议事规则要点 |
|---|---|---|
| 股东会 | 重大事项最终决策 | 表决权、特别决议事项、法定人数 |
| 董事会 | 战略决策与监督 | 董事构成、专门委员会、回避规则 |
| 监事会 | 监督 | 独立性、检查权 |
| 经营层 | 日常经营执行 | 授权范围、报告机制、责任制 |

**母子公司管理界面**：把总部与子公司的职责事项逐条列出，明确"总部独有""子公司独有""共同参与（谁主导）"。

**咨询用法**：权责不清是国企与集团型企业最普遍的问题。诊断方法：随机抽取 20 个实际发生的审批事项，回溯"谁签了字、谁该签、谁没签"，用事实暴露权责错配。

### 3.3 组织效能诊断

**诊断维度**：
| 维度 | 关键问题 | 诊断方法 |
|---|---|---|
| **结构效能** | 层级是否冗余、幅度是否合理 | 管理层级数、平均管理幅度 |
| **流程效能** | 跨部门协同是否顺畅 | 关键流程的环节数、审批节点数、平均耗时 |
| **权责效能** | 决策是否在正确的层级 | 决策事项分布、审批链长度 |
| **人效效能** | 人均产出、人均成本是否合理 | 人效指标对标 |
| **协同效能** | 部门墙是否严重 | 跨部门协作频率与满意度调研 |

**组织健康度量化的常见指标**：
- 管理层级数（一般不超过 5-6 层）
- 管理幅度（一般 6-15 人，视业务复杂度）
- 人均营收、人均利润（与标杆对标）
- 决策周期（从提出到决策完成的天数）
- 会议时长与数量（会议过多是组织失效的信号）

## 四、组织变革经典框架

### 4.1 卢因：解冻-变革-再冻结

```
解冻（Unfreeze）→ 变革（Change）→ 再冻结（Refreeze）
  打破旧平衡        实施新做法         固化新常态
```

**关键洞察**：变革失败的常见原因不是"变革阶段做得不好"，而是"解冻不充分"——旧习惯没被打破，新做法就落不下去。

### 4.2 科特：领导变革八步（详见 `22-od-classics.md`）

### 4.3 组织变革的阻力管理

| 阻力来源 | 表现 | 应对 |
|---|---|---|
| 既得利益 | 权力、资源、职位受威胁 | 明确利益安排、过渡方案 |
| 习惯惯性 | 不愿改变熟悉的方式 | 培训、示范、陪伴过渡 |
| 认知不足 | 不理解为什么要变 | 充分沟通、数据说话 |
| 能力焦虑 | 担心自己跟不上 | 能力培训、岗位调整 |
| 信息失真 | 谣言与误解 | 透明沟通、正式渠道为主 |

## 五、组织与管控方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 组织效率低、反应慢 | 伯恩斯/斯托克环境匹配判断 + 钱德勒"结构追随战略" |
| 部门墙严重、协同差 | 明茨伯格"联络装置"设计 + 加尔布雷斯横向联系机制 |
| 集团对子公司管太多/管太少 | 三种管控模式选择 + 母子公司管理界面 |
| 审批太长、决策太慢 | DOA 权限表重构 + 决策层级分析 |
| 指令没人听、执行力差 | 巴纳德权威接受论（四条接受条件） |
| 管理层级臃肿 | 明茨伯格结构配置判断 + 层级/幅度测查 |
| 该用什么样的组织结构 | 明茨伯格五种结构配置对照 |
| 组织跟不上新业务 | 机械式→有机式转型设计 |
