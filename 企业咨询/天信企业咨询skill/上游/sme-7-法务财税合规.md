# 05 · 招投标合规 · 法务与文书 · 财税合规 · 跨境出海合规

> **通用免责提示**：本文件提供经营与合规视角的分析框架，不构成正式法律意见或税务申报口径。涉及具体案件、申报与处罚，须由执业律师、注册会计师/税务师或主管部门复核确认；法规条款请以现行有效版本为准。

---

## 一、招投标合规管理

### 1. 投标资格条件合规自查

- [ ] 招标公告/文件中的资格条件是否与项目实际需要相关（不得设置不合理限制或排斥潜在投标人）
- [ ] 是否被要求提供与本项目无关的资质、业绩、奖项
- [ ] 保证金、履约金比例是否超出合理与法定范围
- [ ] 是否被设置歧视性的地域、所有制、规模门槛
- [ ] 是否存在指定品牌、指定分包、指定材料等排他性条款

### 2. 投标文件内部合规检查清单

| 检查项 | 要点 |
|---|---|
| 主体资格 | 营业执照、经营范围覆盖、资质证书在有效期内 |
| 授权 | 法定代表人授权书、投标人代表身份证明、签章齐全 |
| 业绩 | 业绩证明真实、可核查（合同+验收/发票），严禁伪造 |
| 财务 | 财务报告与审计报告一致，无重大失信记录 |
| 技术 | 响应偏离表如实填写，不虚假响应 |
| 报价 | 报价不超最高限价、不低于成本；分项报价与总价勾稽一致 |
| 格式 | 按招标文件要求逐项响应，避免形式废标（漏签、漏章、错页、装订不符） |
| 电子标 | CA 锁有效、文件格式与加密要求、上传时间留足余量 |

### 3. 高风险红线（必须提示）

- **串通投标**：与其他投标人协商报价、约定中标人、轮流中标——法律后果严重
- **挂靠/借用资质**：以他人名义投标或允许他人以本单位名义投标
- **弄虚作假**：伪造业绩、资质、财务数据、人员证书
- **围标陪标**：组织多家关联企业陪标
- **恶意低价**：低于成本报价扰乱秩序
- **行贿**：向招标人、评标专家输送利益

> 遇到上述诉求，**只给合规路径**（提升自身竞争力、优化方案、依法质疑投诉），不为规避监管的行为提供方案。

### 4. 异议与投诉路径

依法提出异议（招标文件、开标、评标结果各有法定时限）→ 未获答复或答复不满意可向行政监督部门投诉 → 保留证据链（时间、内容、送达凭证）。**时限意识是关键，逾期丧失权利。**

## 二、法律咨询与法务文书支撑

### 合同审查五步法

1. **主体**：名称与营业执照一致、签字人有权、印章真实、分支机构有无授权
2. **标的**：品名规格数量清晰、技术标准与验收标准明确
3. **价格与支付**：金额、币种、税率、付款节点与条件、发票类型与时点
4. **履行**：交付时间地点方式、风险与所有权转移时点、验收流程与期限
5. **责任**：违约情形与计算方式、赔偿上限、不可抗力、争议解决（管辖法院/仲裁机构）与法律适用

### 高频风险条款清单

| 条款 | 风险 | 修改建议 |
|---|---|---|
| 验收条款 | "验收标准由甲方另行确定" | 明确标准、期限、逾期视为通过 |
| 付款条款 | "验收合格后付款"无期限 | 约定具体天数与起算点 |
| 违约金 | 单方违约金过高/过低 | 双向对等，参考实际损失可预见范围 |
| 争议解决 | 约定对方所在地管辖 | 争取己方所在地或中立仲裁 |
| 知识产权 | 成果归属不清 | 明确背景知识产权与新产生成果归属 |
| 保密 | 无期限无范围 | 明确保密范围、期限、违约后果 |
| 不可抗力 | 笼统表述 | 列举情形、通知义务、后果处理 |
| 单方解除 | 对方任意解除权 | 限缩解除条件或约定补偿 |

### 常用文书结构

**催告/通知类**：事由 → 事实与依据 → 我方要求与期限 → 逾期后果 → 落款盖章
**律师函思路**（须由律所出具）：身份声明 → 事实陈述 → 法律依据 → 明确要求 → 后果告知
**协议类**：主体 → 背景 → 权利义务 → 履行与验收 → 价款支付 → 违约责任 → 争议解决 → 生效与份数

### 争议解决路径选择

协商 → 调解（商会/行业/人民调解）→ 仲裁（有仲裁条款时排除法院诉讼）→ 诉讼。选择时考虑：成本、时间、保密性、执行难度（跨境尤其重要）。

**诉讼时效提示**：普通民事权利诉讼时效一般为三年，自知道权利受损及义务人之日起算，及时主张并保留主张证据（书面催告可导致时效中断）。

## 三、财税全周期合规管理

### 1. 财务基础规范自查

- [ ] 会计凭证、账簿、报表齐全，账实相符、账证相符、账账相符
- [ ] 银行账户、库存现金盘点有记录；印鉴与网银 U 盾分人保管
- [ ] 存货有定期盘点，差异有审批与处理
- [ ] 固定资产有台账与折旧政策，与实物核对
- [ ] 往来款定期对账，长账龄有说明与催收记录
- [ ] 关联交易定价合理、有商业实质

### 2. 发票与税务风险自查

| 风险点 | 自查动作 |
|---|---|
| 发票内容与实际业务不符 | 核查"三流一致"（合同流、资金流、发票流） |
| 虚开风险 | 严禁无真实交易的发票；核查供应商资质与开票能力 |
| 进项抵扣 | 不得抵扣项目单独管理；及时认证 |
| 收入确认 | 按权责发生制确认，避免跨期调节 |
| 成本费用 | 凭证齐全、有审批、与经营相关 |
| 优惠适用 | 逐项对照适用条件，留存备查资料 |
| 个税 | 工资薪金、劳务、股息红利、股权激励的代扣代缴合规 |

> 税收优惠政策（小微企业、高新技术、研发费用加计扣除、出口退税等）适用条件严格且会调整，**务必以现行有效政策及主管税务机关口径为准**，并留存备查资料。

### 3. 资金与现金流管理

- **现金流三表**：经营、投资、筹资；重点看经营现金流是否为正
- **13 周滚动资金计划**：周度预测收款与付款，识别缺口提前安排
- **应收账款管理**：信用额度与账期分级、开票即对账、超账龄预警、催收升级机制
- **付款策略**：优先保障工资、税、核心供应商；非刚性付款按账期统筹
- **票据管理**：票据台账、贴现成本测算、到期兑付提醒

### 4. 内控关键岗分离（小企业最小内控）

出纳与会计分离、采购与付款审批分离、仓库与记账分离、审批与执行分离。人手不足时的替代方案：老板/负责人直接复核关键环节 + 银行流水与业务单据定期交叉核对。

## 四、跨境出海合规管理

### 1. 市场准入与主体安排

| 事项 | 要点 |
|---|---|
| 主体形式 | 直接出口 / 香港或新加坡中间平台 / 目标国子公司（视税务与资金安排而定） |
| 产品准入 | 目标国强制认证（如 CE、UL、FDA、REACH、RoHS 等）、标签与说明书语言要求 |
| 资质许可 | 进出口经营权、海关备案、原产地证、商检要求 |
| 知识产权 | 目标国商标/专利先行布局，避免被抢注或侵权 |

### 2. 贸易与结算

- **Incoterms**：EXW / FOB / CIF / DDP 责任与费用划分差异，DDP 下卖方承担进口清关与关税风险最大
- **结算方式**：T/T 预付、L/C 信用证（注意软条款）、D/P、O/A；新客户建议提高预付比例
- **汇率风险**：锁汇、币种匹配、自然对冲（收付同币种）

### 3. 出口管制与经济制裁

- 核查产品是否属于管制物项（两用物项、军民两用技术）
- 核查交易对手、最终用户、最终用途是否涉及制裁名单（建议建立客户筛查流程）
- 高风险地区/行业订单需加强尽调与留痕
- 反商业贿赂（FCPA、UKBA 等域外效力）风险提示

> 出口管制与制裁清单动态更新，具体核查须依据最新官方清单与专业意见。

### 4. 数据与隐私合规

- **GDPR**（欧盟）与类似法规：合法性基础、目的限制、数据最小化、跨境传输机制、数据主体权利响应、DPA 协议
- **国内**：数据出境安全评估/标准合同/认证路径，个人信息处理告知同意
- **实务建议**：梳理数据流图，识别跨境传输环节，签订数据处理协议，建立数据主体请求响应流程

### 5. 跨境电商平台合规

- 平台规则（知识产权投诉、禁限售、评价操纵、虚假宣传）
- 税务合规：欧盟 VAT/IOSS、美国销售税、平台代扣代缴
- 消费者权益：无理由退货、保修、广告合规
- 产品合规：目标国安全标准、责任险

### 6. 跨境合规风险自查清单

- [ ] 目标市场准入资质与认证齐全
- [ ] 商标专利已完成布局
- [ ] 客户与最终用户筛查流程已建立并留痕
- [ ] 合同含适用法律、争议解决、合规承诺条款
- [ ] 数据跨境传输有合法机制与协议
- [ ] 平台规则与税务义务已梳理
- [ ] 反商业贿赂政策已向业务人员传达
