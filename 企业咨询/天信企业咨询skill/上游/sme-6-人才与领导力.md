# 04 · 人才画像 · 岗位胜任力 · 领导力测评与发展

## 一、岗位胜任力模型

### 模型结构（三层）

| 层级 | 内容 | 示例（生产总监） |
|---|---|---|
| **通用素质** | 全员适用 | 责任心、执行力、学习能力、团队协作、诚信 |
| **专业能力** | 岗位所需硬技能 | 工艺与设备知识、计划排产、成本控制、质量体系、精益改善 |
| **领导/管理能力** | 管理岗必备 | 目标管理、团队建设、跨部门协同、决策判断、育人能力 |

### 每个能力项的定义要素

**名称 → 定义 → 分级行为描述（建议 4 级）→ 测评方式 → 权重**

| 等级 | 行为描述（以"团队建设"为例） |
|---|---|
| L1 入门 | 能清晰分配任务并跟进完成 |
| L2 熟练 | 能根据成员特点分工，定期反馈辅导 |
| L3 精通 | 能组建梯队，培养出可接替自己的骨干 |
| L4 卓越 | 能塑造团队文化，带动整体绩效跨越式提升 |

### 能力项权重建议

- 基层岗：专业能力 70% + 通用素质 30%
- 中层管：专业能力 40% + 管理能力 40% + 通用素质 20%
- 高层岗：管理能力 50% + 专业能力 30% + 通用素质 20%

## 二、人才画像

### 画像标签体系（六维）

| 维度 | 标签示例 |
|---|---|
| 基本信息 | 年龄、学历、专业、工作年限、司龄 |
| 经验背景 | 行业、企业规模、岗位序列、项目经历 |
| 能力特征 | 专业能力等级、管理能力等级、通用素质评级 |
| 绩效表现 | 近三年绩效等级、关键成果、荣誉 |
| 潜力评估 | 学习敏锐度、进取心、跨界适应力、影响力 |
| 稳定性/意愿 | 离职风险、晋升意愿、地域与家庭约束、价值观匹配 |

### 高潜人才判定（四维）

1. **学习敏锐度**：新环境快速上手、主动求变
2. **结果导向**：持续超额达成
3. **人际影响力**：能推动他人与跨部门协作
4. **进取心**：主动承担更大责任

> 高潜 ≠ 高绩效。绩效是"当下贡献"，潜力是"未来可能"，二者需分开评价。

## 三、人才九宫格盘点

横轴 = 绩效（低/中/高），纵轴 = 潜力（低/中/高）。

| | 潜力低 | 潜力中 | 潜力高 |
|---|---|---|---|
| **绩效高** | 熟练专家（保留、激励） | 核心骨干（重点保留） | **明星人才**（加速培养、晋升） |
| **绩效中** | 稳定贡献者（维持） | 中坚力量（培养提升） | 高潜新星（轮岗历练） |
| **绩效低** | **待处理**（辅导或调整） | 观察对象（限期改善） | 潜力错配（换岗试用） |

### 盘点实施步骤

1. 明确评价维度与标准（提前告知，避免"玄学评价"）
2. 直接上级初评 + 隔级/HR 校准（校准会是关键，避免各负责人尺度不一）
3. 输出九宫格分布，识别关键人才与风险人群
4. 制定差异化行动：**明星人才给舞台、核心骨干给激励、待处理者给期限**

### 关键人才保留策略（按需求层次）

| 诉求 | 保留手段 |
|---|---|
| 钱 | 薪酬对标、专项奖金、长期激励（期权/分红/跟投） |
| 成长 | 轮岗、项目主导权、外部培训、职级晋升 |
| 认可 | 公开表彰、授权、参与重要决策 |
| 关系 | 直接主管的关系质量往往比薪酬更关键 |
| 稳定 | 工作强度、通勤、家庭因素（尤其关键岗位） |

## 四、人岗匹配分析

**匹配度 = Σ(岗位要求权重 × 任职者实际水平) / Σ(岗位要求权重 × 要求水平)**

输出三种结论：
- **匹配（≥85%）**：保留并加压，考虑更大责任
- **基本匹配（70–84%）**：补短板培训，明确改进期
- **不匹配（<70%）**：换岗、降级使用或调整

> 先看"能力缺口"还是"意愿缺口"：能力强意愿低 → 激励与沟通；能力弱意愿高 → 培训与辅导；两者皆低 → 果断调整。

## 五、领导力测评与发展

### 领导力模型（五维，适用于中小企业管理层）

| 维度 | 关键行为 |
|---|---|
| 战略与经营思维 | 看懂经营数据、制定目标、权衡取舍 |
| 团队与人 | 选人用人、辅导反馈、激励士气、处理冲突 |
| 执行与结果 | 目标拆解、过程管控、复盘纠偏、拿结果 |
| 协作与影响 | 跨部门协同、向上管理、对外沟通 |
| 自我管理 | 情绪稳定、以身作则、持续学习、诚信底线 |

### 测评方法组合（多源评估更可靠）

| 方法 | 用途 | 成本 |
|---|---|---|
| 360 度评价 | 行为表现的多视角反馈 | 中 |
| 上级评价 + 自评 | 常规年度评估 | 低 |
| 行为面试 / 述职答辩 | 关键岗位选拔 | 低 |
| 情景模拟 / 无领导小组 | 高潜识别 | 中高 |
| 心理与性格测评 | 特质与风险识别 | 低 |

**360 度评价设计要点**：评价维度 6–10 项、匿名保护、样本 ≥6 人、结果用于发展而非直接扣分（否则失真）。

### 领导力发展计划（IDP）模板

| 项 | 内容 |
|---|---|
| 发展目标 | 未来 6–12 个月要提升的 2–3 项能力 |
| 差距分析 | 现状行为 vs 目标行为（360 反馈为依据） |
| 发展动作 | 70% 岗位历练 + 20% 他人辅导 + 10% 课堂学习 |
| 关键历练 | 具体项目/任务、承担的额外职责 |
| 支持资源 | 导师、上级辅导频次、外部课程 |
| 衡量标准 | 行为改变的可观察证据 + 业务结果 |
| 复盘节点 | 季度复盘，半年重评 |

### 继任者梯队

对每个关键岗位明确：**现在可接替（Ready Now）/ 1–2 年可接替（Ready Soon）/ 3 年以上（Long Term）**，并有针对性地安排历练与交接。关键岗位无继任者是重大组织风险，必须列入经营层议事。

## 六、销售团队赋能（协同 04 与 06）

| 模块 | 动作 |
|---|---|
| 组织 | 按区域/行业/产品线划分，明确"谁负责什么客户" |
| 流程 | 统一销售流程阶段与准入准出标准（Leads→商机→方案→商务→签约→回款） |
| 能力 | 产品知识、客户洞察、方案呈现、谈判、客户关系 |
| 训练 | 角色扮演、陪访辅导、录音复盘、案例库 |
| 激励 | 提成设计（阶梯/毛利导向）、超额奖、团队奖、新客户奖 |
| 管理 | 周报/周会、商机漏斗看板、丢单复盘、大客户作战地图 |

**提成设计要点**：优先按**毛利而非营收**计提；设置回款条件；新客户提成系数高于老客户；避免"只卖好卖的"。
