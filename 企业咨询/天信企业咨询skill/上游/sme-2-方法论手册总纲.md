# 中小企业经营管理效能方法论手册

本手册是"企效通"专家的知识底座，汇集二十三年管理咨询实践中沉淀的框架、模型、模板与检查清单。所有内容面向**中小企业"人少、钱紧、时间碎"**的现实约束设计，优先低成本、短周期、见效快的切口。

## 使用方式

1. 先判断用户诉求落在哪个能力域（见下方索引）
2. 读取对应 reference 文件，取用其中的框架与模板
3. **不要照搬全文**：根据用户行业、规模、阶段做裁剪，明确说明哪些条款已裁剪及原因
4. 模板类内容（制度、函件、清单）应输出为可直接使用的完整文本

## 通用交付原则

- **结论先行**：第一屏给出一页纸摘要（结论、依据、动作、风险）
- **可量化**：能算就算，给出公式、代入过程、结果与敏感性区间
- **可执行**：每条动作必须含"动作 + 责任人角色 + 时间 + 交付物 + 验收标准"
- **显式假设**：数据缺失时用行业区间做示意，必须标注"假设值/示例值"
- **不替代持牌意见**：诉讼策略、税务申报口径、审计意见须由执业律师/注册会计师复核
- **合规底线**：只给合规路径，不为规避监管的行为提供方案

## 常用分析工具速查

| 工具 | 适用场景 |
|---|---|
| 5Why / 鱼骨图 | 单一问题的根因穿透 |
| 帕累托（80/20） | 找出主要矛盾（客户、产品、成本项、异常类型） |
| 量本利（CVP） | 盈亏平衡、保本点、边际贡献分析 |
| 结构分析法 | 收入/成本/费用的构成与同环比变动归因 |
| SWOT / 五力 | 战略环境与竞争格局判断 |
| 平衡计分卡 / OGSM | 战略目标分解与落地 |
| RACI | 职责与协作边界划分 |
| 决策矩阵（加权评分） | 多方案比选 |
| 九宫格 | 人才盘点与差异化用人 |
| PDCA / 复盘四步法 | 执行纠偏与经验固化 |

## 附：行业通用财务指标基线（制造业示意，仅作参照）

| 指标 | 一般区间（示意） | 预警信号 |
|---|---|---|
| 毛利率 | 15%–30% | 连续两季下滑 >3pct |
| 净利率 | 3%–8% | 低于 2% |
| 期间费用率 | 10%–20% | 费用增速持续高于收入增速 |
| 存货周转天数 | 45–90 天 | >120 天 |
| 应收账款周转天数 | 45–90 天 | >120 天或账龄结构恶化 |
| 经营性现金流 | 正值 | 连续两季为负 |

> 以上为经验参照值，实际应以企业历史基线和细分行业对标为准。
