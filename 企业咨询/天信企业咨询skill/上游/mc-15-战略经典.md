# 20 · 战略管理经典方法论

> 源流：从钱德勒《战略与结构》(1962)、安索夫《公司战略》(1965)，到波特三部曲、明茨伯格十大学派、哈默尔核心竞争力，再到柯林斯实证研究、金伟灿蓝海战略、克里斯坦森颠覆式创新。

---

## 一、战略思想的四个演进阶段

| 阶段 | 时期 | 核心命题 | 代表人物与著作 |
|---|---|---|---|
| **规划学派** | 1960s | 战略是理性设计的过程，可被系统规划 | 钱德勒《战略与结构》、安索夫《公司战略》、安德鲁斯 SWOT |
| **定位学派** | 1980s | 战略是选择有吸引力的行业位置 | 波特《竞争战略》《竞争优势》 |
| **资源能力学派** | 1990s | 战略是培育难以模仿的核心能力 | 哈默尔/普拉哈拉德《公司核心竞争力》、巴尼 RBV |
| **动态与创新学派** | 2000s+ | 战略是持续重构、试错与颠覆 | 克里斯坦森颠覆式创新、金伟灿蓝海战略、麦格拉思《竞争敏捷》 |

**咨询用法**：判断客户处于什么竞争环境——稳态行业用定位学派（选位置），动荡行业用动态能力学派（快试错）。不要用稳定期的工具做动荡期的决策。

---

## 二、经典战略工具全景

### 2.1 钱德勒：结构追随战略（Structure Follows Strategy）

- **核心命题**：组织结构不是先验设计的，而是为执行战略而生的。战略变了，结构必须跟着变。
- **历史证据**：杜邦、通用汽车、标准石油的组织变革史——从职能制到事业部制，都是多元化战略的必然结果。
- **咨询用法**：客户抱怨"组织效率低"时，先问"战略近几年变了吗"。战略已转向但结构未跟上的情况极常见，此时改结构而非改人。

### 2.2 安索夫：战略四要素与产品市场矩阵

**战略四要素**：
1. **产品市场范围**：企业做什么业务、服务什么客户
2. **增长向量**：往哪个方向长（市场渗透 / 市场开发 / 产品开发 / 多元化）
3. **竞争优势**：凭什么比对手强
4. **协同效应**：业务之间能否 1+1>2

**安索夫矩阵**：

| | 现有产品 | 新产品 |
|---|---|---|
| **现有市场** | 市场渗透（风险最低） | 产品开发 |
| **新市场** | 市场开发 | 多元化（风险最高） |

**咨询用法**：业务组合规划的基础工具。做多元化决策前，先问"协同效应在哪"——没有协同的多元化，本质是分散风险而非创造价值。

### 2.3 波特：五力模型与三大通用战略

**五力模型**：
```
            新进入者威胁
                 ↓
供应商议价力 → 行业竞争强度 ← 购买者议价力
                 ↑
            替代品威胁
```

| 力量 | 关键判断指标 |
|---|---|
| 新进入者威胁 | 进入壁垒（规模经济、品牌、渠道、政策、资本） |
| 供应商议价力 | 供应商集中度、转换成本、前向一体化可能 |
| 购买者议价力 | 客户集中度、产品标准化程度、后向一体化可能 |
| 替代品威胁 | 替代品性价比、转换成本、趋势 |
| 行业竞争强度 | 玩家数量、行业增速、固定成本占比、退出壁垒 |

**三大通用战略**：

| 战略 | 本质 | 前提条件 | 典型风险 |
|---|---|---|---|
| **成本领先** | 全行业最低成本结构 | 规模经济、高效流程、严格成本控制 | 技术变革使投资失效、对手模仿 |
| **差异化** | 客户愿意为独特性付溢价 | 品牌、技术、服务、渠道独特性 | 溢价过高、差异化被模仿 |
| **集中化** | 聚焦细分市场，在窄域做到最好 | 细分市场需求独特、容量足够 | 细分市场被大厂顺手占据 |

> **波特的核心警告**：夹在中间（Stuck in the Middle）最危险——既没有成本优势，又没有差异化。但实践中"成本+差异化"双优（如丰田、华为）是可能的，前提是流程与技术创新带来结构性优势。

### 2.4 哈默尔/普拉哈拉德：核心竞争力

**三大判定标准**（缺一不可）：
1. **客户价值**：能显著提升客户感知价值
2. **竞争差异化**：竞争对手难以模仿
3. **延展性**：能衍生出多个产品/业务

**经典案例**：本田的核心竞争不是"发动机制造"，而是"发动机与动力总成的设计与制造能力"——由此延伸到汽车、摩托、割草机、发电机、船外机。

**咨询用法**：帮客户区分"核心业务"与"核心能力"。核心业务可能被淘汰，核心能力可以迁移。战略规划中必须回答：我们真正不可替代的能力是什么？

### 2.5 明茨伯格：战略十大学派与"手艺式战略"

| 学派 | 核心主张 |
|---|---|
| 设计学派 | 战略是概念形成过程（SWOT、CEO 主导） |
| 计划学派 | 战略是正式规划过程（目标-预算-程序） |
| 定位学派 | 战略是分析选择过程（波特的行业定位） |
| 企业家学派 | 战略是愿景构建过程（创始人直觉） |
| 认知学派 | 战略是心智过程（认知地图、信息处理） |
| 学习学派 | 战略是涌现过程（边做边学、试错） |
| 权力学派 | 战略是谈判过程（内外部利益博弈） |
| 文化学派 | 战略是集体信念过程（文化决定战略） |
| 环境学派 | 战略是对环境的被动反应 |
| 结构学派 | 战略是转型过程（各阶段形态切换） |

**明茨伯格的关键贡献**：
- **战略是"手艺"（Craft）**：不是纯理性规划，需要经验、直觉与临场调整
- **涌现战略（Emergent Strategy）**：实际战略 = 意图战略 + 涌现战略 - 未实现战略
- **对规划崇拜的批判**：规划无法替代战略思考；规划是分析，战略是综合

**咨询用法**：客户说"我们要做五年战略规划"时，提醒——规划产出的是"意图战略"，真正的战略在执行中涌现。咨询的价值是设计"战略学习机制"（复盘、试点、快速迭代），而不只是一份静态规划书。

### 2.6 柯林斯：从优秀到卓越与基业长青

**《从优秀到卓越》核心框架**：

| 概念 | 内涵 |
|---|---|
| **第五级领导力** | 谦逊个性 + 职业意志的矛盾统一体 |
| **先人后事** | 先找对人，再决定做什么（Who before What） |
| **直面残酷现实** | 斯托克代尔悖论——坚信必胜，同时直面最残酷现实 |
| **刺猬理念** | 三个圆的交集：你热爱什么 / 你擅长什么 / 什么驱动经济引擎 |
| **飞轮效应** | 持续推动同一方向，积累动能，最终突破临界点 |

**刺猬理念三环**：
```
        真正热爱的事业
              ▲
             ╱ ╲
            ╱   ╲
           ╱ 交集 ╲
          ╱       ╲
   做到世界 ▲───────▲ 驱动经济
   最好的事           引擎的事
```

**《基业长青》核心发现**：
- **造钟，不是报时**：伟大的公司缔造机制（钟），而非依赖一个伟大构想（报时）
- **保存核心，刺激进步**：核心理念恒定不变，经营策略与做法持续进化
- **胆大包天的目标（BHAG）**：设定看似不可能的目标以激发组织潜能
- **教派般的文化**：强力文化 + 严格筛选 + 强化认同
- **择强汰弱的进化**：像生物进化一样，让好的做法自然生长
- **自家长成的经理人**：核心人才内部培养
- **永远不够好**：持续改进的自我驱动

**咨询用法**：诊断企业"为什么长不大"时，用"造钟 vs 报时"判断——是否过度依赖创始人个人能力，而缺少机制建设。

### 2.7 金伟灿/莫博涅：蓝海战略

**核心逻辑**：不在红海里与对手血拼，而是通过价值创新开创无人竞争的市场空间。

**四步动作框架（ERRC）**：

| 动作 | 含义 | 例（太阳马戏团） |
|---|---|---|
| **消除 Eliminate** | 行业长期竞争但客户不真正在乎的要素 | 动物表演、明星演员 |
| **减少 Reduce** | 被过度供给的要素 | 惊险刺激、幽默 |
| **提升 Raise** | 被行业忽视但客户看重的要素 | 艺术性、主题故事 |
| **创造 Create** | 行业从未提供的新价值 | 剧场环境、多元艺术融合 |

**战略布局图（Strategy Canvas）**：横轴为竞争要素，纵轴为供给水平，画出行业平均曲线与自身曲线的差异，寻找"价值曲线"的分歧点。

**咨询用法**：客户陷入价格战、利润趋零时，用 ERRC 强制跳出"比对手更好"的思维，转向"与对手不同"。

### 2.8 克里斯坦森：颠覆式创新

**两类创新**：

| 类型 | 特征 | 客户 | 商业模式 |
|---|---|---|---|
| **延续性创新** | 沿着主流客户看重的性能维度改进 | 现有优质客户 | 更高毛利、更复杂 |
| **颠覆式创新** | 在主流客户不看重的维度（更便宜/更简单/更便捷）切入 | 边缘客户、非消费者 | 更低成本、更简单 |

**关键洞察**：优秀企业之所以失败，恰恰是因为"太听客户的话"——它们被优质客户绑在延续性创新的轨道上，看不见低端市场的颠覆力量。

**咨询用法**：客户问"要不要做新业务"时，用这个框架判断：这是延续性投入（提升现有竞争力）还是颠覆式布局（开辟新曲线）。

### 2.9 鲁梅尔特：好战略 / 坏战略

**坏战略的特征**：
- 空话套话（"成为行业领导者"）
- 把目标当战略
- 罗列一堆互不协同的行动清单

**好战略的内核（Kernel）**：
1. **诊断**：识别问题的本质（不是现象）
2. **指导方针**：应对诊断的总体思路（创造优势、避免劣势）
3. **连贯性行动**：相互配合、协调一致的具体行动

**咨询用法**：审阅客户战略文件时，用这个结构做"体检"——没有诊断就开药方的战略，都是坏战略。

### 2.10 中国本土战略思想

| 来源 | 核心观点 | 咨询应用 |
|---|---|---|
| **《孙子兵法》** | "先胜而后求战""不战而屈人之兵""致人而不致于人" | 战略本质是塑造有利态势，不是硬拼 |
| **王志纲论战略** | 战略是"找魂"——找到企业在时代中的生态位与独特价值 | 产业战略、区域战略的价值观定位 |
| **华为战略实践** | "方向大致正确，组织充满活力"；战略是取舍的艺术 | 不确定环境下的战略管理 |

## 三、经典战略方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 该不该进入这个行业 | 波特五力 + 安索夫矩阵 |
| 我们凭什么赢 | 三大通用战略 + 核心竞争力三标准 |
| 战略落不了地 | BLM 一致性检查 + 战略解码 |
| 业务组合怎么规划 | 三地平线 + 安索夫矩阵 + 协同效应分析 |
| 陷入价格战怎么办 | 蓝海 ERRC + 差异化战略 |
| 为什么长不大 | 柯林斯"造钟 vs 报时" + 飞轮效应 |
| 战略文件像空话 | 鲁梅尔特好战略内核体检 |
| 新业务该不该做 | 克里斯坦森颠覆式创新判断 |
| 组织跟不上战略 | 钱德勒"结构追随战略" |
