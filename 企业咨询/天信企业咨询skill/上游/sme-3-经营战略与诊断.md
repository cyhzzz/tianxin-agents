# 01 · 经营战略规划与经营诊断

## 一、年度经营战略规划（BP）标准结构

中小企业年度经营计划建议控制在 **15–25 页**，核心是"少而准"。

| 章节 | 内容要点 | 常见错误 |
|---|---|---|
| 1. 复盘与现状 | 上年目标达成率、量本利结构、关键问题清单 | 只讲业绩不讲归因 |
| 2. 外部环境 | 市场容量与增速、竞争格局、客户需求变化、政策与合规变化 | 大段宏观复述，无结论 |
| 3. 内部能力 | 产品、渠道、交付、成本、人才、资金六维体检 | 只讲优势不讲短板 |
| 4. 战略选择 | 3 年方向 + 1 年主题（增长/提效/转型/聚焦） | 什么都想做 |
| 5. 目标体系 | 财务目标 + 客户目标 + 过程目标 + 能力目标 | 只有收入利润 |
| 6. 关键举措 | 每项目标对应 2–4 条举措，明确"做什么、不做什么" | 举措与目标脱节 |
| 7. 目标分解 | 公司 → 部门 → 岗位，含责任人、时间、指标 | 分解到部门即止 |
| 8. 资源配置 | 人、财、物、IT 的预算与授权 | 有目标无资源 |
| 9. 风险与预案 | 前三大风险及应对 | 罗列风险无预案 |
| 10. 推进机制 | 例会节奏、看板、复盘周期、奖惩 | 无过程管理 |

### OGSM 一页纸战略（推荐给中小企业）

| 要素 | 说明 | 示例 |
|---|---|---|
| **O**bjective 目的 | 定性方向，一句话 | 从"接单生产"转向"高毛利细分方案商" |
| **G**oal 目标 | 可量化，3–5 条 | 营收 2.4 亿（+20%）、毛利率 25%（+3pct）、应收账款周转 ≤75 天 |
| **S**trategy 策略 | 达成目标的路径，3–4 条 | ①砍掉 3 条低毛利产品线 ②开发 2 家行业头部客户 ③推行标准成本管理 |
| **M**easure 衡量 | 每条策略的月度过程指标 | 新品毛利贡献率、头部客户送样数、标准成本覆盖率 |

### 目标分解（三层法）

1. **公司级**：股东/董事会关注的财务与战略指标（3–5 个）
2. **部门级**：承接公司目标的部门 KPI（每部门 3–5 个，避免全能型指标）
3. **岗位级**：部门 KPI 落到岗位的关键动作与个人指标（3–5 个）

分解检查三问：
- 加总一致？——部门指标汇总能否支撑公司目标
- 权责匹配？——指标是否落在可控范围
- 有无冲突？——销售冲量 vs 财务控账期是否打架

## 二、经营问题快速诊断：五层穿透法

适用于"利润下滑、成本上升、交期恶化、现金紧张、人均效能下降"等复合问题。

| 层次 | 穿透问题 | 常用工具 | 输出 |
|---|---|---|---|
| **现象层** | 到底表现为什么？量化到指标与时间 | 同环比、结构比 | 问题陈述（如：近3月毛利率 22%→15%） |
| **数据层** | 哪个因子在恶化？贡献度多少？ | 因素分解、帕累托 | 主因权重排序 |
| **流程层** | 哪个环节的流程断了？ | 流程图、节点卡点分析 | 断点清单 |
| **组织层** | 谁负责？权责是否清晰？能力是否够？ | RACI、岗位职责比对 | 职责缺口 |
| **机制层** | 考核、激励、审批、信息机制是否反向激励？ | 制度与行为对照 | 机制性问题 |

> **关键原则**：中小企业的问题，**80% 落在机制层和组织层，而不是流程层**。只优化流程不改机制，问题会复发。

### 利润下滑标准诊断路径

```
利润 = 收入 − 成本 − 费用
  ├─ 收入端：量（订单数/产量）× 价（单价/折扣）× 结构（产品/客户/区域）
  ├─ 成本端：料（采购价/损耗/替代）× 工（工时效率/加班）× 费（制造费用分摊）
  └─ 费用端：销售费用率 × 管理费用率 × 财务费用（利息/汇兑）
```

逐项做**量价结构三因素分解**，找出贡献最大的 2–3 项，即为主要矛盾。

### 五类高频问题的快速判断

| 症状 | 首要排查方向 |
|---|---|
| 收入增长但利润下降 | 产品/客户结构恶化、折扣失控、成本上涨未传导 |
| 订单多但交不出 | 产能瓶颈（哪道工序？）、排产机制、外协管理 |
| 账面有利润没现金 | 应收账款账龄、存货积压、预付款激增、票据占比 |
| 人均产值停滞 | 组织冗余、流程内耗、自动化不足、人均产品结构 |
| 员工流失率高 | 薪酬分位、直接主管管理能力、晋升通道、加班强度 |

## 三、管理决策分析框架

### 六步决策法

1. **定义问题**：把"要不要上 ERP"还原成"当前哪 3 个具体痛点需要系统解决"
2. **明确目标与约束**：成功标准、预算上限、时间窗、不可动用的资源
3. **生成备选方案**：至少 3 个（含"什么都不做"作为基线）
4. **设定评价维度与权重**：财务（ROI/回收期）、战略契合、风险、实施难度、可逆性
5. **加权评分 + 敏感性分析**：改变关键假设（如订单量、成本降幅）看结论是否反转
6. **给出建议 + 决策条件**：明确推荐方案、成立前提、放弃条件（kill criteria）

### 决策矩阵模板

| 评价维度 | 权重 | 方案A 得分 | 方案A 加权 | 方案B 得分 | 方案B 加权 | 方案C 得分 | 方案C 加权 |
|---|---|---|---|---|---|---|---|
| 投资回报（NPV/回收期） | 30% | | | | | | |
| 战略契合度 | 25% | | | | | | |
| 实施风险 | 20% | | | | | | |
| 实施难度 | 15% | | | | | | |
| 可逆性 | 10% | | | | | | |
| **合计** | 100% | | | | | | |

> 评分 1–5 分。结论必须写明：若"订单增长 <10%"则方案 B 反超。

### 中小企业常见重大决策的特别提示

| 决策 | 关键提醒 |
|---|---|
| 扩产 / 建新厂 | 先确认瓶颈工序与需求可持续性；用"边际贡献 × 增量产能 − 固定成本增量"判断 |
| 上信息系统 | 先理流程再选系统；预算 30% 留给实施与培训；避免"上系统=解决问题"的幻觉 |
| 裁撤产品线 | 用"完全成本 vs 边际贡献"双口径判断；注意共用产能与客户连带采购 |
| 组织架构调整 | 先明确战略与流程，再定架构；避免"因人设岗"和"换汤不换药" |
| 引入合伙人 / 股权激励 | 明确进入退出机制、业绩对赌、表决权设计、税务成本 |
