# 26 · 精益管理经典方法论

> 源流：从泰勒科学管理、福特流水线，到丰田生产方式 TPS（大野耐一、丰田喜一郎），到沃麦克/琼斯《改变世界的机器》《精益思想》，莱克《丰田模式》，高德拉特约束理论 TOC，以及六西格玛、戴明质量管理。

---

## 一、精益的思想源流

| 阶段 | 时期 | 贡献 |
|---|---|---|
| **科学管理** | 1911 | 泰勒：标准化、最佳方式、时间研究 |
| **流水线生产** | 1913 | 福特：标准化零件 + 移动装配线 → 大规模生产 |
| **丰田生产方式 TPS** | 1950s-1970s | 大野耐一：准时化 JIT + 自働化 Jidoka，多品种小批量 |
| **精益思想国际化** | 1990s | 沃麦克/琼斯《改变世界的机器》《精益思想》系统化总结 |
| **精益扩展** | 2000s+ | 从制造延伸到服务、办公、医疗、政府（精益服务、精益办公） |
| **精益 + 数字化** | 2010s+ | 精益与工业互联网、数字孪生结合 |

## 二、丰田生产方式 TPS 的两大支柱

```
                ┌──────────────────────┐
                │   丰田生产方式 TPS     │
                └──────────┬───────────┘
              ┌────────────┴────────────┐
    ┌─────────▼─────────┐    ┌─────────▼─────────┐
    │ 准时化（JIT）      │    │ 自働化（Jidoka）   │
    │ Just In Time      │    │ 带人字旁的自动化    │
    │ 只在需要时按需生产  │    │ 异常立即停止        │
    └───────────────────┘    └───────────────────┘
              │                        │
              └──────────┬─────────────┘
                ┌────────▼────────┐
                │  均衡化生产 Heijunka │
                │  标准作业             │
                │  持续改善 Kaizen      │
                └─────────────────────┘
```

**准时化（JIT）的核心工具**：
| 工具 | 作用 |
|---|---|
| **看板（Kanban）** | 用后工序拉动前工序的信息载体 |
| **拉动式生产** | 后工序取用多少，前工序生产多少 |
| **节拍时间（Takt Time）** | 客户需求决定的生产节奏 = 可用时间 ÷ 需求量 |
| **一个流（One-Piece Flow）** | 单件流转，减少在制品 |
| **SMED（快速换模）** | 缩短换型时间以支持小批量多品种 |
| **均衡化（Heijunka）** | 平滑生产负荷，避免波峰波谷 |

**自働化（Jidoka）的核心**：
- 设备具备"发现异常自动停止"的能力
- 人也可以"拉停安灯（Andon）"，停止生产线
- 核心理念：**质量内建（Built-in Quality）——不把不良品流到下一工序**

**咨询用法**：很多企业学精益只学工具（看板、5S），不学机理。**JIT 的前提是"稳定"**——需求稳定、质量稳定、设备稳定。没有稳定就上 JIT，会导致缺料停线。诊断顺序：先稳定（质量、设备、计划），再谈拉动。

## 三、精益思想五大原则（沃麦克 & 琼斯）

```
1. 定义价值（Value）         —— 从客户视角定义什么是价值
        ↓
2. 识别价值流（Value Stream）—— 绘制价值流图，区分增值/非增值活动
        ↓
3. 让价值流动（Flow）        —— 消除阻碍，让价值连续流动
        ↓
4. 建立拉动（Pull）          —— 客户需求拉动生产，而非推动
        ↓
5. 追求完美（Perfection）    —— 持续改善，永不停止
```

**七大浪费（TIMWOOD）**：

| 浪费 | 英文 | 表现 | 精益对策 |
|---|---|---|---|
| **等待** | Waiting | 人等料、料等人、等审批 | 均衡化、拉动、流程优化 |
| **库存** | Inventory | 原料/在制品/成品积压 | JIT、看板、降批量 |
| **搬运** | Transportation | 不必要的物料移动 | 布局优化、U 型线 |
| **过度加工** | Over-processing | 超出客户要求的加工 | 明确客户标准、简化 |
| **过度生产** | Overproduction | 生产超过需求（**最严重的浪费**） | 拉动式生产 |
| **动作** | Motion | 人的无效动作（找工具、弯腰） | 动作经济原则、5S |
| **不良品** | Defects | 返工、报废、客诉 | 自働化、防错 Poka-Yoke |

**第八大浪费**（现代精益扩展）：**未利用的员工智慧**（Untapped Talent）

**咨询用法**：价值流图（VSM）是精益诊断的核心工具。绘制"当前状态图"→ 计算增值时间与非增值时间比 → 找出瓶颈 → 绘制"未来状态图"→ 制定改善计划。**关键发现通常令人震惊**：很多流程的增值时间占比不到 5%，95% 的时间都在等待和搬运。

## 四、丰田模式 14 项原则（莱克）

**第一类：长期理念**
1. 管理决策以长期理念为基础，即使牺牲短期财务利益

**第二类：正确的流程（产生正确的结果）**
2. 建立连续的作业流程以使问题浮现
3. 使用拉动式生产以避免生产过剩
4. 使工作负荷平均（均衡化）
5. 建立立即暂停以解决问题、从一开始就重视质量的文化（自働化）
6. 工作的标准化是持续改善与员工授权的基础
7. 运用视觉管理使问题无处隐藏
8. 使用可靠的、已经过充分测试的技术以协助员工及生产流程

**第三类：借助员工与伙伴发展**
9. 培养与发展认同公司理念、彻底了解工作、能教导他人的领导者
10. 培养与发展遵循公司理念的杰出人才与团队
11. 尊重合作伙伴与供应商网络，激励并帮助他们改善

**第四类：持续解决根本问题**
12. 亲临现场查看以彻底了解情况（现地现物 Genchi Genbutsu）
13. 不急躁，以共识为基础，彻底考虑所有可能选择，快速执行决策（根回 Nemawashi）
14. 通过不断地省思与持续改善，变成一个学习型组织

**咨询用法**：莱克的 14 项原则说明了**精益不是工具箱，而是管理系统与文化**。客户说"我们做了 5S 和看板但没效果"时，检查是否只做了第 2-8 项（流程工具），而缺了第 1 项（长期理念）、第 9-11 项（人才培养）和第 12-14 项（持续学习）。

## 五、约束理论 TOC（高德拉特）

### 5.1 核心命题

**"任何系统的产出，由系统中最薄弱的环节（约束）决定。"** 改善非约束环节毫无意义。

### 5.2 五大聚焦步骤

```
1. 识别约束（Identify）—— 找到瓶颈在哪里
        ↓
2. 挖尽约束（Exploit）—— 让瓶颈满负荷运转，不做无价值的事
        ↓
3. 迁就约束（Subordinate）—— 其他环节配合瓶颈的节奏
        ↓
4. 提升约束（Elevate）—— 增加瓶颈的资源与产能
        ↓
5. 回到第一步（Repeat）—— 约束转移后重新开始
```

**关键洞察**：不要急着"提升约束"（第 4 步，需要投资），先做好第 2、3 步（零成本挖潜与配合）。这是 TOC 与一般改善方法最大的差异。

### 5.3 鼓-缓冲-绳（DBR）与关键链

| 工具 | 机制 |
|---|---|
| **鼓（Drum）** | 约束环节的生产节奏（决定全系统节拍） |
| **缓冲（Buffer）** | 在约束前设置时间缓冲，保护约束不停工 |
| **绳（Rope）** | 按鼓的节奏向前工序发布投料指令，避免在制品堆积 |
| **关键链（CCPM）** | 项目管理中，考虑资源约束的最长路径；用项目缓冲集中管理不确定性 |

**咨询用法**：
- 生产型企业"到处改善但产出没提升"→ 用 TOC 找真正的瓶颈
- 项目型企业"项目总是延期"→ 用关键链法：集中缓冲替代分散缓冲、消除学生综合症（Student Syndrome）与帕金森定律
- **TOC 与精益的关系**：精益关注消除浪费（成本视角），TOC 关注提升产出（吞吐量视角）。**实践中两者结合最佳**——用 TOC 定位改善优先级，用精益工具消除该环节的浪费

## 六、质量管理的经典体系

### 6.1 戴明十四要点

1. 建立改进产品与服务的长远目标
2. 采纳新哲学（不接受劣质）
3. 停止依赖检验来保证质量（质量内建）
4. 结束仅以价格为基础的采购
5. 持续不断地改善生产与服务系统
6. 建立在岗培训制度
7. 建立领导力（而非监督）
8. 驱除恐惧，让员工敢说话
9. 打破部门壁垒
10. 取消对员工的口号与训诫
11. 取消数量化的定额与目标管理（不加方法支持的目标是空话）
12. 消除妨碍员工工作自豪感的障碍
13. 建立教育与自我改进的 vigorous 计划
14. 让全体都参与转型

**戴明链条反应**：改善质量 → 成本下降（减少返工、浪费） → 生产力提升 → 以更低价格提供更好产品 → 占领市场 → 提供更多就业 → 长期繁荣

### 6.2 六西格玛 DMAIC

```
D - Define 定义    —— 定义问题、目标、客户需求、范围
M - Measure 测量   —— 测量当前绩效，验证测量系统
A - Analyze 分析   —— 分析根本原因（数据分析、假设检验）
I - Improve 改进   —— 设计并实施改进方案
C - Control 控制   —— 建立控制机制，防止倒退
```

**六西格玛的统计基础**：每百万机会缺陷数 DPMO。6σ = 3.4 DPMO

**关键分工**：
| 角色 | 职责 |
|---|---|
| 倡导者 Champion | 高层支持、资源保障 |
| 黑带大师 MBB | 方法专家、培训与指导 |
| 黑带 BB | 领导改善项目 |
| 绿带 GB | 兼职参与项目 |

**精益与六西格玛的结合**：精益消除**速度型浪费**（快），六西格玛消除**变异型缺陷**（稳）。**精益六西格玛**是最常见的企业实践组合。

### 6.3 质量管理七工具与持续改善

**品质管理七工具（QC 七大手法）**：
1. 检查表（Check Sheet）
2. 层別法（Stratification）
3. 柏拉图（Pareto Chart）
4. 特性要因图（鱼骨图 Ishikawa/Fishbone）
5. 直方图（Histogram）
6. 散布图（Scatter Diagram）
7. 管制图（Control Chart）

**5S 与目视管理**：

| 5S | 日文 | 含义 |
|---|---|---|
| 整理 Seiri | 要与不要，一留一弃 | 区分必要与不必要 |
| 整顿 Seiton | 科学布局，取用快捷 | 定位定量定容 |
| 清扫 Seiso | 清除垃圾，美化环境 | 保持清洁 |
| 清洁 Seiketsu | 形成制度，贯彻到底 | 标准化、制度化 |
| 素养 Shitsuke | 养成习惯，以人为本 | 习惯与素养 |

**咨询用法**：5S 不是"打扫卫生"，而是**通过物理环境的秩序建立行为规范的认识**。5S 是精益最基础的入口，也是对员工行为规范影响最直接的工具。

## 七、精益管理方法论咨询应用速查

| 客户问题 | 优先调用 |
|---|---|
| 交期长、效率低 | 价值流图 VSM + 七大浪费识别 |
| 库存高、占用资金 | JIT 拉动 + 看板 + 均衡化 |
| 生产忽快忽慢 | 均衡化 Heijunka + 节拍时间分析 |
| 质量问题频发 | 自働化 Jidoka + Poka-Yoke 防错 + 鱼骨图 |
| 到处都是问题不知从哪改 | TOC 五大聚焦步骤（先找约束） |
| 改善后产出没提升 | TOC 约束识别（改错了环节） |
| 项目总延期 | 关键链 CCPM + 集中缓冲 |
| 换型时间长 | SMED 快速换模 |
| 成本要降 | 七大浪费消除 + 六西格玛降变异 |
| 现场混乱、纪律差 | 5S + 目视管理 |
| 学精益学不会 | 莱克 14 原则对标（是否只学了工具） |
