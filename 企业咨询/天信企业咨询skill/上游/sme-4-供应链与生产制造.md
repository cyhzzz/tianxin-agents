# 02 · 供应链采购 · 制造运营 · 质量单证 · 设备与EHS

## 一、采购管理体系搭建

### 采购制度五件套（中小企业最小可用版本）

| 文件 | 核心内容 |
|---|---|
| 采购管理办法 | 职责分工、审批权限、采购方式（询比价/招标/单一来源）适用条件 |
| 供应商管理办法 | 准入、分级、考核、淘汰、黑名单 |
| 价格与成本管理办法 | 询价规则、比价记录留存、价格有效期与调价机制 |
| 合同管理办法 | 合同模板、评审流程、用章管理、归档 |
| 付款管理办法 | 付款条件、账期、预付审批、三单匹配（合同/入库/发票） |

### 采购权限矩阵（示例，按金额分级）

| 金额区间 | 询价家数 | 审批人 | 是否需比价记录 |
|---|---|---|---|
| < 1 万 | 1 家 | 采购主管 | 否 |
| 1–10 万 | ≥ 2 家 | 采购经理 + 财务 | 是 |
| 10–50 万 | ≥ 3 家 | 副总 | 是（附比价表） |
| > 50 万 | ≥ 3 家 + 招标/议价 | 总经理 | 是（附评审纪要） |

### 供应商分级与考核（QCDS 四维）

| 维度 | 权重（建议） | 考核指标 |
|---|---|---|
| Quality 质量 | 35% | 来料合格率、批次不良率、客诉关联次数 |
| Cost 成本 | 25% | 价格竞争力、年降幅度、成本透明度 |
| Delivery 交付 | 30% | 准时交付率 OTD、交期达成率、紧急插单响应 |
| Service 服务 | 10% | 响应速度、技术配合、异常处理及时性 |

分级规则：A 级（≥90 分，战略供应商，优先份额）/ B 级（75–89，合格）/ C 级（60–74，限份额+改善）/ D 级（<60，限期整改或淘汰）。

### 降本路径（按见效速度排序）

1. **快速见效（1–3 个月）**：集中采购合并订单、比价议价、付款条件换价格、替代料验证
2. **中期（3–6 个月）**：标准化减少料号、包装与运输方式优化、供应商早期介入（ESI）
3. **长期（6–12 个月）**：价值工程（VA/VE）、供应商协同开发、自制/外购策略重估

> 降本必须做**成本拆解（Should-Cost）**：料 + 工 + 制费 + 管理 + 利润，否则议价无抓手。

## 二、供应链异常管理（交期 / 质量 / 数量 / 价格）

### 异常分级与响应机制

| 级别 | 判定标准 | 响应时限 | 处理主体 |
|---|---|---|---|
| Ⅰ级（重大） | 影响客户交付或产线停线 | 2 小时内启动 | 总经理/供应链负责人 |
| Ⅱ级（较大） | 影响排产但不即刻停线 | 24 小时内 | 采购经理 + 计划 |
| Ⅲ级（一般） | 局部延迟、可内部消化 | 3 个工作日 | 采购员 |

### 异常处理闭环六步

1. **登记**：异常台账（日期、物料、供应商、类型、影响、责任人）
2. **定级**：按上表定级，触发对应响应
3. **根因**：先区分"供应商原因 / 我方原因（预测、图纸、付款）/ 外部原因（行情、物流、政策）"
4. **临时对策**：保交付优先——调拨、替代、空运、外协、调整排产
5. **永久对策**：供应商整改、二供开发、安全库存重设、合同条款加固
6. **复盘与归档**：纳入供应商考核，更新风险清单

### 四类异常专项要点

| 类型 | 排查要点 | 根治手段 |
|---|---|---|
| 交期异常 | 是产能不足、排产优先级、还是我方订单变更？ | 双源供应、安全库存、滚动预测与供应商共享、合同违约金条款 |
| 质量异常 | 是来料、制程、还是标准不清？ | 图纸与检验标准对齐、首件确认、驻厂检验、索赔与整改闭环 |
| 数量异常 | 计量方式、损耗约定、包装计数差异 | 明确计量口径与允差、净重/毛重约定、收货复核 |
| 价格异常 | 原材料行情、汇率、垄断性供应 | 价格联动公式、锁价周期、比价机制、框架协议年降条款 |

### 催料函模板（可直接使用）

```
关于【物料名称/编号】交货延期的催告函

【供应商全称】：

我司于【日期】向贵司下达采购订单（订单号：【XXX】），约定交货日期为【日期】，
数量【XXX】。截至本函发出之日，我司尚未收到该批物料，已对我司生产计划
及客户交付造成影响。

现函告如下：
一、请贵司于【日期】前书面回复以下内容：延期原因、当前生产进度、
    可交付的最早日期及分批交付方案。
二、请贵司于【日期】前完成全部交付。我司保留依据采购合同第【X】条
    追究延期违约责任的权利。
三、如贵司确因客观原因无法按期交付，请立即告知，我司将启动替代供应
    方案，由此产生的差价及损失依合同约定处理。

请贵司高度重视，务必在【日期】前回复。

【我司全称】（盖章）
【日期】
```

### 供应商问题约谈记录要点

约谈目的、问题事实与证据、对方承认与解释、整改要求（措施/责任人/完成时间）、验证方式、后续考核影响、双方签字。

## 三、质量与单证管理

### 质量三检与不合格品处理

| 环节 | 要点 | 记录 |
|---|---|---|
| 来料检验 IQC | 按 AQL 抽样、检验标准与图纸一致 | 来料检验报告 |
| 制程检验 IPQC | 首件确认、巡检频次、关键工序 SPC | 首件记录、巡检表 |
| 出货检验 OQC | 按客户标准与出货批检验 | 出货检验报告 |
| 不合格品 | 标识—隔离—评审—处置（让步接收/返工/返修/报废/退货） | 不合格品处置单 |

**8D 报告结构**（客户要求或重大质量事故时使用）：D1 团队 / D2 问题描述 / D3 临时遏制 / D4 根因分析 / D5 纠正措施 / D6 实施验证 / D7 预防再发 / D8 团队表彰。

### 单证一致性核对清单（外贸与国内大宗通用）

**核心原则：合同、发票、装箱单、报关单、提单（运单）五单一致。**

- [ ] 品名、规格、型号与合同完全一致（含中英文品名）
- [ ] 数量、单位、毛净重、件数一致
- [ ] 金额、币种、单价、贸易术语（Incoterms）一致
- [ ] 收发货人名称、地址、联系方式与报关信息一致
- [ ] 原产地、HS 编码与申报要素一致
- [ ] 唛头、批次号、生产日期/有效期一致
- [ ] 签章、日期、编号连续可追溯
- [ ] 随附文件（许可、认证、检验报告）齐全且在有效期内

> **风险提示**：单证不符是跨境业务最典型的"合规→清关→收款"连锁风险来源，务必在出货前 3 个工作日完成单证复核。

## 四、设备运维管理

### 设备管理最小体系

| 模块 | 内容 |
|---|---|
| 设备台账 | 设备编号、名称、型号、购置日期、原值、位置、责任人、状态 |
| 点检 | 日常点检表（操作工）、专业点检（维修工）、点检路线与频次 |
| 保养 | 一级保养（操作工，周/月）、二级保养（维修工，季/年），保养计划与记录 |
| 维修 | 报修—派工—维修—验收—记录；MTBF（平均故障间隔）、MTTR（平均修复时间）统计 |
| 备件 | 关键备件清单、安全库存、领用记录、呆滞备件清理 |
| 关键设备 | 识别瓶颈设备，制定专保方案与备机预案 |

### TPM 落地要点（中小企业版）

1. 先做 **5S 与自主保全**（操作工自己清洁、点检、加油）
2. 建立 **设备综合效率 OEE = 时间开动率 × 性能开动率 × 合格品率**，先测基线再改善
3. 聚焦 **瓶颈设备**，做故障模式分析与再发防止
4. 用"故障停机时长"作为唯一考核指标，简单有效

## 五、EHS 合规管理

### EHS 体系四要素

| 要素 | 内容 | 检查频次 |
|---|---|---|
| 环境 | 排污许可与台账、危废转移联单、废水废气噪声监测、环保设施运行 | 月度 |
| 职业健康 | 职业病危害因素检测、告知与警示标识、职业健康体检、防护用品配发 | 年度 |
| 安全 | 安全生产责任制、风险分级管控与隐患排查治理（双控体系）、特种设备与作业人员资质、动火/受限空间等特殊作业审批 | 周/月 |
| 应急 | 应急预案备案、应急物资、演练（消防、化学品泄漏、逃生） | 半年/年 |

### 隐患排查整改闭环

```
排查（人/机/料/法/环）→ 登记（隐患台账）→ 定级（重大/一般）→
定责（责任人+期限）→ 整改 → 验证 → 销号 → 统计分析
```

### 高频合规红线（务必提示）

- 危废不得混入一般垃圾、不得无联单转移
- 特种设备（叉车、行车、压力容器）必须定期检验、持证操作
- 消防通道、灭火器、应急照明保持有效，消防控制室值班持证
- 职业健康体检与危害告知是法定动作，缺失易引发劳动纠纷与行政处罚
- 新改扩建项目需履行环评（及排污许可）手续，避免"未批先建"
