# 07 · 业财一体化经营分析

## 一、核心理念

**业财一体化 = 把"业务动作"翻译成"财务结果"，让经营者知道"哪个动作值钱、哪个动作亏钱"。**

三个层次的打通：
1. **数据打通**：业务单据（订单、工单、领料、入库、发货、收款）与财务凭证同源
2. **口径打通**：业务指标（产量、交付、良率）与财务指标（成本、毛利、周转）用同一套主数据
3. **决策打通**：分析结论直接对应到可执行动作与责任人

## 二、经营分析指标库

### 1. 盈利能力

| 指标 | 公式 | 用途 |
|---|---|---|
| 毛利率 | （营收 − 营业成本）÷ 营收 | 产品/客户/订单级的赢利能力 |
| 净利率 | 净利润 ÷ 营收 | 整体经营质量 |
| 边际贡献率 | （营收 − 变动成本）÷ 营收 | 接单决策、产能分配 |
| 期间费用率 | （销售+管理+研发+财务费用）÷ 营收 | 费用效率 |
| 人均产值/人均利润 | 营收（净利）÷ 期末人数 | 组织效能 |
| 单位产品盈利 | 单价 − 单位完全成本 | 产品取舍 |

### 2. 结构分析（最容易被忽视但最有价值）

- **产品结构**：各产品线收入占比与毛利贡献占比是否匹配（常见陷阱：80% 收入来自 20% 低毛利产品）
- **客户结构**：客户集中度（前 5 大客户占比）、单客户毛利率、单客户服务成本
- **订单结构**：订单规模分布（小单多但成本高）、急单占比
- **区域结构**：区域毛利率（扣除运费与服务成本后）
- **渠道结构**：直销/经销/电商的毛利与费用对比

> **结论口径**：收入结构 ≠ 利润结构。分析必须做"收入占比 vs 毛利贡献占比"的对比表。

### 3. 成本与效率

| 指标 | 公式 |
|---|---|
| 单位产品成本 | 变动成本 + 分摊固定成本 |
| 材料成本率 | 材料成本 ÷ 营收 |
| 工时效率 | 标准工时 ÷ 实际工时 |
| 设备利用率 | 实际运行时间 ÷ 可用时间 |
| 制造费用分摊率 | 制造费用 ÷ 产量（或工时） |
| 不良质量成本 COQ | 内部损失 + 外部损失 + 鉴定成本 |
| 降本完成率 | 实际降本额 ÷ 目标降本额 |

### 4. 资产与现金流

| 指标 | 公式 | 预警 |
|---|---|---|
| 存货周转天数 | 平均存货 ÷ 营业成本 × 365 | >120 天 |
| 应收账款周转天数 | 平均应收 ÷ 营收 × 365 | >120 天 |
| 应付账款周转天数 | 平均应付 ÷ 成本 × 365 | 越低代表越依赖预付 |
| 现金转换周期 CCC | 存货天数 + 应收天数 − 应付天数 | 越长越缺钱 |
| 经营现金流净额 | 经营活动现金流入 − 流出 | 连续为负 |
| 流动比率 | 流动资产 ÷ 流动负债 | <1.2 |
| 资产负债率 | 总负债 ÷ 总资产 | >70%（制造业） |
| 利息保障倍数 | EBIT ÷ 利息费用 | <3 |

### 5. 量本利分析（CVP）

```
保本点销量 = 固定成本 ÷ 单位边际贡献
保本点销售额 = 固定成本 ÷ 边际贡献率
目标利润销量 = (固定成本 + 目标利润) ÷ 单位边际贡献
安全边际率 = (实际销量 − 保本点销量) ÷ 实际销量
```

**决策应用**：
- 是否接低于完全成本但高于边际成本的订单？→ 只要有闲置产能，**边际贡献为正即可接**（但须防止扰乱市场与客户预期）
- 是否上自动化设备？→ 比较"固定成本增加额"与"变动成本节约额 ÷ 增量产量"的平衡点产量

### 6. 敏感性分析

对关键假设（售价、材料成本、销量、汇率、人工成本）做 ±5%/±10% 波动，观察利润变化幅度，识别**利润最敏感的因子**——这就是管理的重点。

## 三、经营分析看板设计

### 四层看板结构

| 层级 | 使用者 | 内容 | 频次 |
|---|---|---|---|
| L1 经营总览 | 总经理/股东 | 营收、利润、现金流、订单、交付达成 | 月度/周度 |
| L2 经营单元 | 部门负责人 | 分产品/客户/区域的收入毛利、费用、库存 | 月度/周度 |
| L3 过程指标 | 中层/班组 | 产量、良率、准时交付、单位成本、工时效率 | 日/周 |
| L4 异常预警 | 责任人 | 偏差超阈值的指标清单与责任人 | 实时/日 |

### 看板设计要点

1. **一屏原则**：每层看板一屏可看全，避免几十个指标并列
2. **对比三件套**：目标 vs 实际、同比、环比
3. **红黄绿阈值**：明确触发条件与责任人（红=需立即处置）
4. **下钻路径**：从总览指标可下钻到明细单据/订单
5. **少即是多**：中小企业 L1 看板 8–12 个指标足够

### L1 经营总览建议指标（12 项）

营收达成率、毛利率、净利率、期间费用率、经营现金流净额、应收周转天数、存货周转天数、订单交付准时率、人均产值、客户集中度、前 5 大客户毛利贡献、安全边际率。

## 四、预算与滚动预测

### 预算编制要点（中小企业简化版）

1. **自上而下定目标 + 自下而上编预算**，两轮对齐
2. **销售预算是起点**（量 × 价 × 结构），据此推算成本与费用
3. **明确关键假设**：订单量、单价、材料价格、人工成本、汇率
4. **费用分类**：固定/变动、刚性/弹性、必要/可选
5. **审批与授权**：预算内授权、超预算审批规则

### 滚动预测（Rolling Forecast）

- **13 周滚动现金流**：周度预测收付款，识别缺口
- **月度滚动损益**：每月末更新未来 3–6 个月预测
- **偏差分析**：预算偏差 >5% 时分析原因并调整动作（而非只调数字）

## 五、异常指标归因路径（速查）

| 异常 | 归因路径 |
|---|---|
| 毛利率下降 | 售价（折扣/竞争）→ 产品结构 → 材料成本 → 人工效率 → 制造费用分摊 → 废品率 |
| 费用率上升 | 费用绝对值增长 vs 收入下降，区分"投入型"与"失控型" |
| 存货周转变慢 | 原材料（超采/呆滞）→ 在制（批量过大/瓶颈）→ 成品（滞销/预测偏差） |
| 应收账龄恶化 | 客户信用放松 → 开票与对账延迟 → 催收不力 → 客户自身经营恶化 |
| 现金流紧张 | 三大来源：经营（利润质量）、投资（扩张节奏）、筹资（负债结构） |
| 人均产值下降 | 人员增长快于收入、产品结构变差、自动化不足、管理内耗 |

## 六、分析报告结构（月度经营分析会材料）

1. **一页纸结论**：本期经营概况、三大问题、三项动作
2. **指标达成**：目标 vs 实际，红黄绿标识
3. **结构分析**：产品/客户/区域/渠道的收入与毛利对比表
4. **成本费用**：重点科目的同环比与归因
5. **资产与现金**：周转指标、账龄、现金流预测
6. **问题清单与决议**：问题、根因、责任人、时限、跟踪状态
