# 06 · 品牌定位 · 营销策划 · 电商客诉 · 新媒体运营

## 一、品牌定位

### 定位四问（STP）

1. **给谁**（Segmentation）：按行业/规模/场景/痛点切分，选 1–2 个主攻人群
2. **要什么**（Targeting）：目标人群最在意的 1–2 个决策因素
3. **凭什么**（Positioning）：我们的差异化优势，且客户能感知、竞品难复制
4. **怎么说**（Messaging）：一句话价值主张 + 三条支撑理由

### 定位陈述模板

```
对于【目标客户】，在【使用场景】下，
【品牌】是唯一/最【差异化优势】的【品类】，
因为【支撑理由1/2/3】。
```

### 品牌价值主张与信任状

| 要素 | 内容 |
|---|---|
| 功能价值 | 解决什么问题、提升什么效率、降低什么成本 |
| 情感价值 | 安全感、身份认同、省心 |
| 信任状 | 认证资质、标杆客户、专利技术、数据实证、第三方评测 |

### 定位常见误区

- 讨好所有人 → 谁都不记得
- 只讲"质量好、服务好" → 无差异
- 定位与能力不匹配 → 承诺兑现不了
- 频繁更换定位 → 品牌资产无法积累

## 二、营销策划

### 年度营销策划六步

1. **目标**：营收、销量、新客数、获客成本、老客复购率
2. **市场与竞品**：容量、增速、竞品动作、价格带分布
3. **策略组合（4P）**：产品（组合与迭代）、价格（分层与促销）、渠道（线上/线下/经销）、推广（内容/投放/活动）
4. **活动排期**：全年节奏表（旺季、节点、新品、展会）
5. **预算分配**：按渠道 ROI 历史数据分配，预留 10–15% 试错预算
6. **衡量与迭代**：分渠道指标看板，月度归因与优化

### 渠道选择决策表

| 渠道 | 适用条件 | 关键指标 |
|---|---|---|
| 直客/直销 | 高客单、重决策、需方案 | 商机数、转化率、销售周期、客单价 |
| 经销/代理 | 需本地服务与垫资 | 渠道库存、动销率、渠道毛利 |
| 电商平台 | 标品、价格敏感、有流量 | GMV、转化率、ROI、退货率 |
| 内容/社媒 | 需教育与种草、长决策链 | 曝光、互动、留资、获客成本 |
| 展会/行业活动 | B2B、项目型 | 有效线索数、线索成本、转化 |
| 老客复购/转介绍 | 已有客户基数 | 复购率、NPS、转介绍占比 |

### 营销效果指标基线（示意）

| 指标 | 计算 | 关注点 |
|---|---|---|
| 获客成本 CAC | 营销费用 ÷ 新客数 | 与客户终身价值 LTV 比，LTV/CAC ≥ 3 较健康 |
| 转化率 | 成交数 ÷ 线索数 | 分渠道看，避免混合平均 |
| ROI | 营收 ÷ 投入 | 不同渠道不可简单横向比较 |
| 复购率 | 复购客户数 ÷ 总客户数 | 反映产品与服务质量 |
| NPS | 推荐者% − 贬损者% | >30 较好 |

## 三、电商客服与投诉处理

### 投诉分级与响应时限

| 级别 | 情形 | 时限 | 处理人 |
|---|---|---|---|
| 一级（危机） | 舆情扩散、平台介入、媒体关注、批量投诉 | 30 分钟内响应 | 客服主管+品牌负责人 |
| 二级（严重） | 明确质量/安全/欺诈指责、要求赔偿 | 2 小时内 | 客服主管 |
| 三级（一般） | 物流慢、包装破损、色差、尺码 | 24 小时内 | 客服专员 |

### 客诉处理六步（LEARN 思路）

1. **Listen 倾听**：让客户说完，复述确认理解
2. **Empathize 共情**：先处理情绪再处理问题（"我理解您的着急"）
3. **Apologize 致歉**：对体验致歉，不轻易对事实定性
4. **Resolve 解决**：给出方案（退/换/补/赔/赠），明确时限与责任人
5. **Notify 跟进**：主动回访确认闭环，避免客户再次追问
6. **Prevent 预防**：归类分析，反哺产品、仓储、物流、描述页

### 话术要点

- **不承诺做不到的事**：给方案前先确认内部可执行
- **不当场争对错**：先安抚、后核实
- **不推诿**：即使非我方责任，也先给客户一个出口
- **记录留痕**：聊天记录、通话录音、赔付凭证归档

### 舆情与差评处置

- 差评优先**私信沟通**，公开回复保持专业、简短、有担当
- 恶意差评/职业索赔：取证 → 平台申诉 → 必要时法律途径
- 建立**高风险关键词监测**（质量问题、投诉、举报、曝光）

### 客诉数据反哺（月度）

| 分析维度 | 用途 |
|---|---|
| 投诉类型 TOP5 | 定位产品与流程问题 |
| 渠道/客服组对比 | 识别服务短板 |
| 首响时长与解决时长 | 评估服务效率 |
| 赔付金额与占比 | 评估质量成本 |
| 重复投诉客户 | 识别系统性风险 |

## 四、新媒体运营指导

### 账号矩阵设计

| 账号类型 | 作用 | 内容侧重 |
|---|---|---|
| 品牌主账号 | 品牌形象与信任 | 企业实力、案例、价值观 |
| 创始人/专家号 | 建立个人 IP 与专业信任 | 行业洞察、方法论、观点 |
| 产品/垂类号 | 精准获客 | 使用场景、痛点解决、测评 |
| 员工/服务号 | 增强真实感与转化 | 幕后、客户故事、答疑 |

平台选择参考：B2B 与专业内容（公众号、视频号、知乎、小红书）；B2C 视觉类（抖音、小红书、快手）；出海（TikTok、YouTube、LinkedIn）。

### 内容生产 SOP

```
选题（痛点/热点/常问问题）→ 脚本（钩子3秒—痛点—方案—证据—行动号召）→
拍摄/制作 → 审核（合规、品牌、事实）→ 发布（标题/封面/标签/时间）→
数据复盘（完播/互动/留资）→ 二次分发（多平台改编）
```

### 选题来源四类

1. 客户最常问的 20 个问题
2. 行业热点与政策变化
3. 竞品爆款拆解与差异化重做
4. 内部真实案例与数据（脱敏后）

### 关键指标

| 阶段 | 指标 |
|---|---|
| 冷启动 | 更新频次、完播率、互动率 |
| 增长 | 粉丝增速、爆款数量、搜索占比 |
| 转化 | 留资数、私域加粉、成交额、内容 ROI |

### 团队与投入建议（中小企业）

最小可行配置：1 名内容策划/编导 + 1 名拍摄剪辑 + 业务专家出镜（可由负责人兼任）。外包策略：脚本自研 + 拍摄剪辑外包，保证专业性与成本平衡。**先做透 1 个平台再做矩阵，切忌全面铺开。**

## 五、销售团队赋能（补 04 的落地细节）

### 销售流程阶段与准出标准

| 阶段 | 准出标准 |
|---|---|
| 线索 Leads | 有明确需求与联系方式 |
| 商机 Opportunity | 确认预算、决策链、时间窗、痛点 |
| 方案 Proposal | 方案已提交并得到反馈 |
| 商务 Negotiation | 进入价格与合同条款谈判 |
| 签约 Won | 合同签署 |
| 回款 Collected | 首款到账 |

### 销售管理节奏（最小集）

- **日**：CRM 更新、关键动作打卡
- **周**：周会（漏斗、丢单原因、下周重点）
- **月**：绩效评估、大客户作战地图复盘

### 提成设计示例（示意）

| 结构 | 规则 |
|---|---|
| 底薪 | 保障基本生活，体现岗位价值 |
| 提成 | 按毛利计提，阶梯递增（如毛利 25% 以上部分系数上浮） |
| 回款挂钩 | 提成按回款进度分批发放 |
| 新客奖 | 新客户额外系数或一次性奖金 |
| 超额奖 | 超目标部分加倍计提 |

> 提成必须"算得出、算得清、月月兑现"，否则激励失效。所有规则书面化并公示。
