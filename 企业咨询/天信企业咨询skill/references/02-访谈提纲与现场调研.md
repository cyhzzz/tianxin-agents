# 02 访谈提纲与现场调研

> 天信原创。上游给"该做什么"（16 个管理模块），没给"怎么问出来"。
> 县城中小企业的真实情况，八成不在报表里，在老板的账本、车间的地上、仓管的抽屉里。**访谈与现场是唯一能拿到 B 级证据的途径。**

## 一、访谈的组织（先排顺序，别一上来就找老板）

| 顺序 | 对象 | 时长 | 目的 |
|---|---|---|---|
| 1 | 老板 / 实际控制人 | 90–120 分钟 | 定问题、定期望、定边界（**这次到底要解决什么**） |
| 2 | 财务负责人（或代账会计） | 60 分钟 | 数从哪来、口径怎么定、哪些数不可信 |
| 3 | 业务口：销售 / 生产 / 采购 / 仓储 | 各 45–60 分钟 | 流程真实怎么跑、卡在哪 |
| 4 | 一线员工（2–3 人，随机） | 各 20–30 分钟 | 制度落地到什么程度 |
| 5 | 客户 / 供应商（各 2 家，需客户同意） | 各 30 分钟 | 外部视角：为什么选你、为什么走 |

**为什么不先找老板**：先找老板，后面所有人都会按老板的说法回答。**先听基层，再听老板**，交叉验证才有价值。
（实操上第 1 步常必须先见老板——那就把"定问题"和"听细节"分开：第一次只定问题，细节放到 3、4 步。）

## 二、老板访谈：12 个必问

1. 去年到今年，最让您睡不着的一件事是什么？
2. 这门生意，您觉得钱是从哪一步赚出来的？（利润来源）
3. 近三年最大的三个判断失误是什么？当时依据什么做的决定？
4. 如果只能改一件事，改哪件？
5. 现在最不敢放手的是哪块？为什么不放手？
6. 关键岗位有几个人是"走了就麻烦"的？有没有备份？
7. 客户主要靠什么来的？老客户复购靠什么？
8. 同行里您最佩服谁？为什么？
9. 未来三年想做成什么样？有没有具体数字（收入/产能/门店数）？
10. 这次找我们，希望三个月后看到什么变化？
11. 哪些事是**不能动**的（家族、老员工、某个客户、某块业务）？
12. 我们能看哪些数？哪些不能看？

**第 11 问最关键**：不知道禁区，方案一定做不下去。

## 三、部门访谈提纲（四段式，通用）

1. **做什么**：你这个岗位，一天/一个月按顺序做哪些事？
2. **卡在哪**：最近一个月，哪件事最耽误时间？等谁？等多久？
3. **怎么核**：这件事做完，谁检查？有没有记录？出错怎么发现？
4. **如果改**：如果给你加一个人 / 换一套系统，你最想解决哪个环节？

**追问三句**（把"感觉"逼成"事实"）：

- "能举个例子吗？最近一次是什么时候？"
- "这个数大概多少？有表吗？"
- "如果和您说的不一样，可能是什么原因？"

## 四、现场调研：看六处，比问十个人有用

| 看哪里 | 看什么 | 能看出什么 |
|---|---|---|
| **仓库** | 有没有分区、标识、账实是否对得上、呆滞品堆在哪 | 存货管理真实水平、跌价风险 |
| **车间 / 产线** | 在制品堆放、设备停机、返工区 | 产能瓶颈、质量成本 |
| **财务室 / 电脑** | 用几个 Excel、几套账、谁有权限 | 数据可信度、内控 |
| **单据流** | 随机抽 3 张入库单/发货单，跟着走一遍 | 制度是否落地 |
| **门店 / 前台** | 客流、成交、退货、客户问什么 | 销售真实情况 |
| **老板手机** | 审批在微信群里做？ | 授权体系真实形态（很多小企业就是这样） |

**拍照与记录**：先征得同意；不拍客户名单、不拍价格表、不拍身份证件。

## 五、开口要的数据清单（先给清单，再谈访谈）

| 类 | 要什么 | 用途 |
|---|---|---|
| 财务 | 近 3 年报表 + 科目余额表（末级）、月度管理报表 | 趋势与结构 |
| 收入 | 分产品/客户/区域收入明细（近 12 个月） | 结构分析 |
| 成本 | 单位成本构成、主要原材料采购价（近 12 个月） | 毛利归因 |
| 人员 | 人员编制表、工资表、社保缴纳明细、离职率 | 人效 |
| 运营 | 产能/产量、交付周期、库存周转、退货率 | 效率 |
| 客户 | 客户分层（ABCD）、前 20 名客户收入与账期 | 依赖度与风险 |
| 合同 | 主要客户合同（价格条款、账期、违约条款） | 议价能力 |

**要不到怎么办**：写进报告"未取得"，不要用估计值替代，更不要让客户口头报个数就当数据。

## 六、记录与归档

- **访谈纪要当天整理**：时间、地点、对象、职务、要点、原话（打引号的必须是原话）、待核事项。
- 录音须**事先征得同意**，说明用途与保存期限；不同意就笔记。
- 纪要给受访者确认（关键结论请他签字或回邮件确认），避免事后"我没这么说"。
- 所有原始记录进项目底稿，与报告一起归档（含现场照片、数据表）。

## 七、六个常见错误

1. **只跟老板聊**——得到的是老板的认知，不是企业的现实。
2. **问"你觉得"**——得到观点；要问"最近一次""多少""哪张表"。
3. **一次问 30 个问题**——受访者答到第 10 个就烦了；一次聚焦 8–10 个。
4. **带着结论去问**——只找支持自己的证据（确认偏误），最后报告全是自己想听的。
5. **不看现场**——报告写得漂亮，方案一落地就发现"仓库根本没分区""审批全在微信群"。
6. **纪要拖到项目结束才写**——细节全忘，只剩印象。

> **红线**：访谈内容属客户商业信息，不写进示例、不进公共仓库、不在同行面前提客户名。引用原话要匿名化（"某客户""一位车间主任"）。
