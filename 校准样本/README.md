# 校准样本

**用途**：这里放的是**天信自己真实出具、且已公开**的报告，用来校准各业务线技能的口径与结构。
不是外部专家包（外部包原文在各自 `上游/`），也不随 `install.py` 装到使用方机器——它是仓库级的「所内真实样本」。

**为什么需要它**：六条业务线目前全部是初稿，底座是外部专家包原文，没有用所里真实材料校准过。
这些公开报告是**本所真实交付物**（文号、签字注师、格式都对得上），比任何外部包都更适合做对齐基准。

## 使用纪律

1. **只用于校准，不随技能安装**——`install.py` 不复制本目录。真正要沉淀进技能的，是把样本里的**结构与口径**提炼成对应 `references/`，而不是把整份 PDF 塞进技能。
2. **这些都是公开信息**（政府公示、交易所公告），引用时仍应去掉与本所无关的客户敏感细节；新增样本须在本文登记来源、文号、下载时间、sha256。
3. **禁止把样本当模板直接套用**：报告里的客户名、金额、结论只属于该案例，不得出现在对外交付物里。
4. 想补哪类样本，先在「待补清单」登记，再找公开源下载并登记。
