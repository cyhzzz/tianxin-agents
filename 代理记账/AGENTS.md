# AGENTS.md — 代理记账业务线

> 本目录是天信代账业务线的**单一权威源（single source of truth）**。上层规则见 `../AGENTS.md`（天信本身总纲），本文件只管代账线自己的事。

## 1. 这条线是什么

- **代账**：建账、日常记账、月度结账、报表编制、纳税申报、年度归档与交接。
- **服务对象**：县城中小企业为主（小规模纳税人 + 部分一般纳税人），行业杂、资料不齐是常态。
- **定位**：以天信名义对外提供代理记账服务；AI 是作业赋能手段，不替代 CPA 判断。

## 2. 技能

- **`天信代账作业skill/`**：代账全链路作业技能（frontmatter name `天信代账作业`）。
  - 主入口：`天信代账作业skill/SKILL.md` —— **唯一由天信原创的能力说明**
  - 上游原文：`天信代账作业skill/上游/`（平台「记账账」专家全部能力，10 个文件，只读）
  - 常用模板：`assets/`（接单判定、银行调节、往来对账、工资折旧、月结清单、交接清单）

**本技能不含"改写层"。** 早前有一层 `references/01~13`（把上游 2221 行压成 498 行的中文重述），2026-10-31 已整层删除——重述一次丢一次，丢的是审批矩阵、复核清单、常见错误自查这类决定分录对错的内容。现在要细节直接读上游原文。

## 3. 核心方法：弹性编排

客户资料不齐是常态。**按客户手里有啥，从对应步骤切入**，不要死板从建账跑到底。路由表、接单四问、资料缺口处理见 `天信代账作业skill/SKILL.md` §四。

## 4. 与别的线 / 技能的关系

**本线技能独立运行，不依赖其他业务线的文件。** 与相邻线是边界关系，不是桥接：

- **税务**：报税的身份判定、算税顺序、五组勾稽校验在 `SKILL.md` §三；税率与优惠**不复制**（年年动，写死就埋雷），算税前核当期文件或调「天信税务申报」技能。复杂筹划、跨境、优惠争议 → 转持证 CPA / 税务顾问。
- **实务判断**：报表列报、职工薪酬、政府补助、减值、差错更正的要点在 `SKILL.md` §三、§五。若所内另装「天信实务知识库」可深读其判断卡，但不是必需。
- **审计**：代账客户被审时，按 `SKILL.md` §五的鉴证配合口径提供资料，不引用审计线的底稿模板。
- **文档排版**：要出 Word / PDF / 网页报告时，调「天信文档与报告」技能（见 `SKILL.md` §六）。**这是工具调用，不是知识依赖**——内容本技能负责，格式它负责。

## 5. 边界与纪律

- **不替代 CPA**：重大税务筹划、IPO / 上市特殊处理、争议事项咨询持证 CPA。
- **凭证必须有据**：做分录前确认有原始单据（发票 / 合同 / 回单 / 工资表），不基于口述做账。
- **借贷必平**：每条分录输出前自检借贷相等。
- **对外材料须复核**：给客户 / 对外的报表、申报辅助、说明，须经所内人工复核后发出（见 `../AGENTS.md` 总纪律）。
- **准则明确**：先确认客户适用企业会计准则还是小企业会计准则。
