# 05 账户核对

> 来源：记账账·reconciliation。代账月度的必做动作，也是客户信任的来源。

## 一、三类核对

1. **银行存款**：账面银行存款 vs 银行对账单，调节在途存款、未兑现支票、银行手续费 / 利息（模板见 `assets/银行余额调节表模板.md`）。
2. **往来款项**：应收账款 / 应付账款 vs 客户 / 供应商对账单（模板见 `assets/往来对账表模板.md`）。
3. **存货 / 固定资产**：账面 vs 实物盘点，差异查盘盈盘亏。

## 二、步骤

1. 取数：总账余额 + 对账单 / 盘点表。
2. 比对：逐项勾对，标未达 / 差异。
3. 列调节项：在途、未达、记账错误分类列出。
4. 出调节表：余额调节至两边一致。
5. 确认：未达项跟踪，久悬上报所内。

## 三、输出物

- 核对工作底稿（含调节表）
- 需调整分录（差异原因明确后）

## 四、纪律

- 按月核对，不攒到年底。
- 老化未达项（超 3 月）单独列示并提示风险。
- 核对底稿留存，作为审计 / 鉴证配合素材（见 12）。
