# 04 凭证编制

> 来源：记账账·journal-entry-prep。代账日常做账核心。

## 一、代账高频分录类型

- **应付计提**：水电、房租、服务费（按合同 / 历史运行率估，次期冲回）
- **固定资产折旧**：直线法为主（成本－残值）/ 年限
- **预付摊销**：长期待摊、预付费用按期摊
- **工资及社保公积金**：工资表驱动，个人 / 单位部分分开
- **收入确认**：按适用准则时点（如 CAS 14 履约义务）
- **银行收支**：据回单，借贷分明
- **税金计提**：对接 09（增值税 / 附加 / 企业所得税 / 个税）

## 二、规则

- **借贷必平**：每条分录输出前自检借贷总额相等，绝不输出不平凭证。
- **摘要规范**：谁 + 什么业务 + 金额，避免「记一笔」式废摘要。
- **附件齐全**：发票 / 合同 / 回单 / 工资表，凭证后附索引。
- **期末统一结转**：损益类结转、制造费用结转等期末一次性做，平时不转。

## 三、输出物

- 记账凭证（借贷分明 + 摘要 + 附件索引）
- （期末）结转损益凭证

## 四、纪律

- 做分录前必须有原始单据支撑（见 SKILL.md 纪律），不基于口述做账。
- 重大估计（减值、预计负债）附依据，提示所内复核。
- 按第一节的高频类型套用，保持所内口径一致；特殊业务查 `上游/finance-3-凭证编制.md`。
