# 10 工商办理

> 来源：早期二手转述（原写"东纳荣·工商顾问"，原始包未找到，见 SKILL.md §六）。代账客户常顺带要办工商事，所里一站式承接。

## 一、范围

- **新公司注册全流程**：核名 → 营业执照 → 刻章 → 银行开户 → 税务登记。
- **变更**：法人 / 股东 / 注册资本 / 地址 / 经营范围。
- **注销**：清税 → 公示 → 工商注销（简易 / 一般）。
- **工商年报**：每年 1.1 – 6.30 报送。

## 二、按事项的步骤

- **注册**：出材料清单（身份证 / 地址证明 / 章程）→ 代办流转 → 回执归档。
- **变更 / 注销**：按事项给材料清单 + 流程说明 + 预计周期。
- **年报**：取客户基础信息，填报表，提醒截止日（联动 08）。

## 三、输出物

- 办事材料清单
- 流程说明（含时限、注意事项）
- 进度跟踪

## 四、纪律

- 不替客户做商业 / 法律决策，只给清单、流程与官方依据。
- 涉及审批以登记机关最新要求为准，政策变动标红提示（联动 13）。
- 注册 / 变更涉及的税务联动转 09。
