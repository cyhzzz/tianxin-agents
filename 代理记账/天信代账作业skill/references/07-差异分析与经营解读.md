# 07 差异分析与经营解读

> 来源：记账账·variance-analysis。把账变成客户听得懂的经营信号。

## 一、两类差异

1. **经营差异**：实际 vs 预算 / 去年同期（收入波动、费用异常超支）。
2. **税负波动**：税负率环比 / 同比异常（转 09 / 13 处理）。

## 二、步骤

1. **取两期数据**：比对期与基准期。
2. **分解驱动因素**：量、价、产品结构 / 客户结构。
3. **设重要性门槛**：小额波动不纠缠，抓重大影响项。
4. **白话叙述**：给客户能懂的解释，不堆会计术语。

## 三、输出物

- 差异说明（客户白话版 + 数据支撑）
- 异常标记（需进一步调查 / 风险提示）

## 四、用途

- 客户经营沟通：把「账做了」升级成「帮客户看经营」。
- 风险预警：费用突变、税负异常提前提示（联动 13）。
- 注意：分析结论供客户参考，重大判断交所内 / 持证 CPA 确认。
