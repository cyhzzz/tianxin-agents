# 02 建账与初始化

> 来源：记账账·总流程适配。新客户或换所接账时执行。

## 一、科目表：选哪套、怎么裁

两套底子，按客户适用准则选（这个判断在第 12 节鉴证配合里还会用到）：

| 客户适用 | 科目体系 | 特点 |
|---|---|---|
| 小微企业 | 小企业会计准则 | 科目少、不计提资产减值（坏账按实际发生）、无递延所得税 |
| 一般企业 / 有外部报表要求 | 企业会计准则 | 完整体系，含递延所得税、其他综合收益、减值准备 |

裁科目三条：

- **删**：客户业务里根本不存在的（没出口就删出口退税相关，没在建工程就删在建工程）
- **启明细**：应收 / 应付按客户供应商辅助核算，费用按部门，存货按品名
- **留空号**：科目编码中间留空，以后加明细不用重排

**小规模与一般纳税人的关键差别**（这条弄错，全年增值税都做错）：
一般纳税人要设「应交税费—应交增值税」下的**进项税额 / 销项税额 / 进项税额转出 / 转出未交增值税**等专栏；
小规模只设「应交税费—应交增值税」一个明细，不设专栏、不抵扣。

## 二、步骤

1. **确认基础信息**：准则、纳税人类型、行业、会计期间、本位币。
2. **选科目表并启用明细**：删除无关科目，启用常用明细（应收 / 应付按客户供应商辅助、费用按部门等）。
3. **录入期初余额**：资产 = 负债 + 所有者权益必须平衡；不平先查来源（旧账余额表 / 交接表）。
4. **设辅助核算**：客户、供应商、部门、项目、存货等，按管理需要开。
5. **账套参数**：会计期间、凭证类型、默认税率、结账日。

## 三、输出物

- 科目余额表（期初）
- 账套说明（准则、税率、辅助核算口径、对接人）

## 四、纪律

- 期初数必须有来源依据（旧所交接表 / 上期报表），不得拍脑袋。
- 小规模与一般纳税人科目设置不同（如进项销项专栏），先定类型再建。
- 建账结论交所内复核后启用。
