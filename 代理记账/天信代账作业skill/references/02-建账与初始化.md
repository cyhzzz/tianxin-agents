# 02 建账与初始化

> 来源：记账账·总流程适配。新客户或换所接账时执行。

## 一、复用资产

- **科目表**：`tax-compliance-engine` 的科目表（含小企业会计准则版 / 企业会计准则版两套，按客户类型选用）。
- **分录模板**：`tax-compliance-engine` 的会计分录模板（计提、折旧、摊销、结转等）。

## 二、步骤

1. **确认基础信息**：准则、纳税人类型、行业、会计期间、本位币。
2. **选科目表并启用明细**：删除无关科目，启用常用明细（应收 / 应付按客户供应商辅助、费用按部门等）。
3. **录入期初余额**：资产 = 负债 + 所有者权益必须平衡；不平先查来源（旧账余额表 / 交接表）。
4. **设辅助核算**：客户、供应商、部门、项目、存货等，按管理需要开。
5. **账套参数**：会计期间、凭证类型、默认税率、结账日。

## 三、输出物

- 科目余额表（期初）
- 账套说明（准则、税率、辅助核算口径、对接人）

## 四、纪律

- 期初数必须有来源依据（旧所交接表 / 上期报表），不得拍脑袋。
- 小规模与一般纳税人科目设置不同（如进项销项专栏），先定类型再建。
- 建账结论交所内复核后启用。
