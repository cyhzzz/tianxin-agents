# 02 电子归档与保管期限

> 天信原创。上游没有一个包讲归档，但这是代账最容易被罚、也最容易在交接时扯皮的一块。
> 依据：《会计档案管理办法》（财政部、国家档案局令第 79 号）——**期限以现行办法及附表为准，本文件作速查，冲突时以办法原文为准**。

## 一、保管期限速查（代账客户最常问的这张表）

| 档案类别 | 具体内容 | 保管期限 |
|---|---|---|
| 会计凭证 | 原始凭证、记账凭证、汇总凭证 | **30 年** |
| 会计账簿 | 总账、明细账、日记账、其他辅助账簿 | **30 年** |
| 会计账簿 | 固定资产卡片 | **5 年**（固定资产报废清理后起算） |
| 财务会计报告 | 月度、季度、半年度报告 | **10 年** |
| 财务会计报告 | **年度财务报告** | **永久** |
| 其他 | 银行存款余额调节表 | **10 年** |
| 其他 | 银行对账单 | **10 年** |
| 其他 | 纳税申报表（含附表、完税凭证） | **10 年** |
| 其他 | 会计档案移交清册 | **30 年** |
| 其他 | 会计档案保管清册、销毁清册 | **永久** |

**别踩的两个坑**：① 年度财务报告是**永久**，不是 30 年；② 纳税申报表 10 年，很多所按 30 年存，虽不违规但占地方，反过来按 3 年存的**违规**。

## 二、电子会计档案：什么情况能只留电子件

按 79 号令，单位内部形成的电子会计资料，**同时满足下列条件**才可仅以电子形式保存：

1. 来源真实有效，由计算机等电子设备形成和传输；
2. 会计核算系统能准确、完整接收与读取，能输出**符合国家标准的归档格式**（如 OFD/PDF），并有经办、审核、审批的审签程序；
3. 电子档案管理系统能有效接收、管理、利用，符合长期保管要求，并与关联的纸质档案建立检索关系；
4. 有**防篡改**措施；
5. 有**备份**制度，能防自然灾害、意外、人为破坏；
6. **不属于具有永久保存价值**或其他重要保存价值的会计档案。

**实务结论**：绝大多数县城代账客户**不满足第 2、3、4 条**（用普通财务软件 + 微信传文件 + 本地硬盘存），所以——

- **原始凭证（发票、回单、合同）仍要纸质或不可篡改的影像归档**；
- 年度财务报告（永久保存）**必须留纸质或符合长期保存要求的版本**；
- 只留电子件的前提是"系统 + 制度 + 备份"三样都到位，**不是"扫描了就算"**。

## 三、代账机构的归档规矩（我们的做法）

### 3.1 目录与命名

```
客户简称/年度/月份/
├── 01-原始凭证/        2026-03-进货发票-001.pdf …
├── 02-记账凭证/        记-2026-03.pdf（凭证打印件或系统导出）
├── 03-账簿/            总账、明细账、日记账（年度导出）
├── 04-报表/            资产负债表、利润表、现金流量表（月度 + 年度）
├── 05-申报/            增值税、企税、个税、附加、社保、公积金申报表 + 完税凭证
├── 06-银行/            对账单、余额调节表
└── 07-其他/            合同、工商年报、往来对账确认
```

命名规则：`年月-事项-序号`，不用"新建文件夹""最终版""改好的"。

### 3.2 备份（三层，缺一层就等于没备）

| 层 | 做法 | 频率 |
|---|---|---|
| 本地 | 客户档案目录 + 移动硬盘 | 每月 |
| 云端 | 加密后上传（客户名可脱敏，但**不能打乱目录对应关系**） | 每月 |
| 系统 | 财务软件账套备份（.bak 等） | 每次月结后 |

**备份要能恢复**：每季度随机抽一个客户做一次恢复测试，只备不验等于没备。

### 3.3 归档时限

- 月度档案：申报完成后 **10 个工作日内**归位。
- 年度档案：年度汇算清缴完成后 **1 个月内**归档（含年度报表、年报、汇缴申报表）。
- 交接档案：客户终止委托时，**15 日内**完成移交并双签清册。

## 四、客户资料的归属与移交（最容易打官司的一段）

- **所有权归客户**，代账机构只是保管人。客户要资料，**必须给**。
- 交接清单必列：账套文件（含备份）、凭证与账簿、报表、申报表与回单、发票领购簿/税控设备/电子税务局账号与密码、CA/UK、银行回单、往来对账确认。
- 清册**双签**（移交人、接收人）+ 日期；一式两份，各存一份，保管 30 年。
- 客户欠费不是扣留资料的理由——**扣资料属于违规**，有争议走合同约定的结算条款。
- 移交后我们只留**必要的执业记录**（我们自己编的底稿、申报留档），不留客户原始凭证原件。

## 五、销毁

- **代账机构不得自行销毁客户档案**。保管期满需销毁的，由客户（档案所属单位）按 79 号令程序办理：单位负责人批准 + 两人以上监销 + 销毁清册（永久保存）。
- 未结清的债权债务凭证、正在诉讼/检查中的档案，**即使期满也不得销毁**。
- 我们自己的执业记录（工作底稿）到期销毁，同样要留清册。

## 六、自查五问（每季度一次）

1. 上月申报的回单，都在对应客户目录里吗？
2. 有没有客户的档案只存在微信/邮箱里，没进目录？
3. 备份最近一次是什么时候？恢复过吗？
4. 有没有离职客户的资料该移交还没移交？
5. 年度报告（永久）是不是和月度报表混放、到期被误删？

> **红线**：档案不是"存着就行"，是"**能拿出来、能对上账、能证明我们做过**"。税务检查、审计、诉讼，都从这里取证据。
