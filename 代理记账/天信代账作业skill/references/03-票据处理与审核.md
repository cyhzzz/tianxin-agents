# 03 票据处理与审核

> 来源：早期二手转述（原写"东纳荣·发票管理"，原始包未找到，见 SKILL.md §六）。代账日常入口，资料齐不齐往往卡在这一环。

## 一、输入

- 原始票据：增值税发票、银行回单、合同、工资表、费用单据（图片 / PDF）。

## 二、步骤

1. **结构化**：票种、金额、税额、购销方、开票日期、摘要，转成可记账清单。
2. **发票查验**：按下表逐项核，不核完不入账。
3. **业务归类**：归入对应科目与辅助核算（客户 / 供应商 / 部门）。
4. **异常标记**：抬头不符、三流不一致（票流 / 资金流 / 合同流）、超经营范围、作废红冲、走逃供应商。

### 发票查验核对清单

| 核什么 | 怎么核 | 核不过怎么办 |
|---|---|---|
| 真伪 | 电子税务局「发票查验」或全国增值税发票查验平台，输入代码+号码+开票日期（全电票用 20 位号码） | 查不到不入账，退回客户 |
| 抬头与税号 | 必须是客户**全称 + 税号** | 个人抬头或抬头错的，不能抵扣，按费用处理并提示客户 |
| 金额税额 | 价税合计 = 金额 + 税额；与合同、回单对 | 不一致退回重开 |
| 红冲 / 作废 | 看是否跨月、原票是否已抵扣 | 跨月红冲需开红字信息表，别直接冲 |
| 三流一致 | 票流、资金流、合同流三方主体对得上 | 对不上要客户书面说明，别自己圆 |
| 供应商状态 | 是否走逃失联（税务公告名单） | 已抵扣进项须转出 |

## 三、输出物

- 结构化票据清单（可导入记账）
- 待补 / 异常项清单（交客户或对接人）

## 四、纪律

- 无票费用按税法限额处理，不得虚列成本。
- 走逃供应商已抵扣进项按政策转出（提示转 09 / 13 处理）。
- 票据真实性由客户提供，AI 只做结构化与异常标记，不背书真伪。
