# 03 票据处理与审核

> 来源：东纳荣·发票管理适配。代账日常入口，资料齐不齐往往卡在这一环。

## 一、输入

- 原始票据：增值税发票、银行回单、合同、工资表、费用单据（图片 / PDF）。

## 二、步骤

1. **结构化**：票种、金额、税额、购销方、开票日期、摘要，转成可记账清单。
2. **发票查验**：对接发票合规审查（复用 `天信税务申报skill/references/05-发票合规审查.md`）——真伪、抬头、税号、红冲作废。
3. **业务归类**：归入对应科目与辅助核算（客户 / 供应商 / 部门）。
4. **异常标记**：抬头不符、三流不一致（票流 / 资金流 / 合同流）、超经营范围、作废红冲、走逃供应商。

## 三、输出物

- 结构化票据清单（可导入记账）
- 待补 / 异常项清单（交客户或对接人）

## 四、纪律

- 无票费用按税法限额处理，不得虚列成本。
- 走逃供应商已抵扣进项按政策转出（提示转 09 / 13 处理）。
- 票据真实性由客户提供，AI 只做结构化与异常标记，不背书真伪。
