# 09 税务申报

> 本模块**自己写完整**，不指向别的技能。代账客户的申报复杂度就在"小规模 vs 一般纳税人"这一条分岔上。
> 税率表不在这里——那是税务线的活。这里给的是**申报作业流程**：报哪些、从哪取数、怎么校验。

## 一、先定四件事，定错了后面全错

| 定什么 | 怎么定 | 定错的后果 |
|---|---|---|
| **纳税人身份** | 小规模 / 一般纳税人（看税务登记与年销售额） | 税率、进项抵扣、申报表全不同 |
| **征收方式** | 查账征收 / 核定征收（看税务事项通知书） | 核定户做汇算清缴是白做 |
| **申报周期** | 月报 / 季报（小规模多为季报，一般纳税人月报） | 漏报一次就是逾期 |
| **所属期** | 申报的是哪个月/季，与申报日不是一回事 | 报表期间与申报期错配 |

**先问客户要税务事项通知书**，别按经验猜。换所接手的客户，身份和征收方式经常和上一家说的不一致。

## 二、代账客户常报的税种

| 税种 | 谁要报 | 计税依据从哪来 | 周期 |
|---|---|---|---|
| 增值税 | 全部 | 开票收入 + 未开票收入（对照利润表营业收入） | 月/季 |
| 城建税及附加 | 全部（随增值税） | 实际缴纳的增值税额 | 同增值税 |
| 企业所得税 | 公司制 | 利润总额 ± 纳税调整 | 季度预缴 + 年度汇算 |
| 个人所得税 | 有雇工 | 工资表（含社保、专项附加扣除） | 月 |
| 印花税 | 有合同/账簿/资金账簿 | 合同金额、实收资本 | 按次或按季 |
| 房产税 / 城镇土地使用税 | 有自有房产土地 | 房产原值或租金、土地面积 | 按年分期 |
| 残疾人就业保障金 | 有雇工 | 在职职工人数、工资总额 | 按年 |

没有对应业务的税种**不要习惯性零申报**——零申报也要有依据，且连续零申报会被重点关注。

## 三、算税顺序不能换

```
增值税 → 城建税及附加 → 印花税 → 企业所得税（季度）→ 个人所得税
```

原因：附加税费以**实际缴纳的增值税**为基数，增值税没定下来，附加算不出；企业所得税与利润表勾稽，必须在账结完之后。

## 四、税率只作"合理性锚点"，不作计算依据

算税之前**必须核对当期有效政策**（国家税务总局公告 / 财政部文件），下表只用来判断客户给的数据离不离谱：

| 税种 | 大致量级 | 说明 |
|---|---|---|
| 增值税 | 一般纳税人 13% / 9% / 6%；小规模征收率 3% | 《增值税法》2026-01-01 施行后征收率统一为 3%，原 5% 情形另按过渡规定 |
| 城建税 | 7% / 5% / 1% | 按纳税人所在地（市区/县城或镇/其他） |
| 教育费附加 / 地方教育附加 | 3% / 2% | 以增值税为基数 |
| 企业所得税 | 25% | 小型微利企业有优惠，**资格条件每年可能调整，必须核当年文件** |
| 个人所得税 | 3%~45% 七级超额累进 | 工资薪金按累计预扣法 |

**表格核对日期 2026-10-31。** 过了季度就要重核，尤其是小微优惠和起征点类政策——这类政策年年动，写死在技能里就是给客户埋雷。
具体计算规则、完整税率表、优惠适用条件，属税务线专业范围。

## 五、勾稽校验：不做这一步等于没做

申报表填完必须交叉验，这五组对不上就是有错：

| 校验 | 对比什么 | 差异的正当理由 |
|---|---|---|
| 增值税 vs 利润表 | 申报销售额 ↔ 营业收入 | 视同销售、免税项目、跨期确认 |
| 附加税费 vs 增值税 | 附加额 ↔ 实缴增值税 × 税率 | 减免、预缴抵减 |
| 企税 vs 利润表 | 应纳税所得额 ↔ 利润总额 ± 调整 | 业务招待费、广告费、罚款等调增 |
| 个税 vs 工资 | 申报人数/金额 ↔ 工资表 | 离职当月、一次性奖金单独计税 |
| 印花税 vs 合同 | 计税金额 ↔ 合同台账 | 框架协议未执行、合同变更 |

**差异不能"抹平"，要写明理由并留档。** 说不清理由的差异，八成是账错了。

## 六、高频错误（代账线踩得最多的五个）

1. **免税销售额填进应税栏** —— 申报表有专门的免税栏，填错就是多缴税
2. **增值税报了、附加没报** —— 附加随增值税自动产生，最容易漏
3. **个税零申报，但工资表有数** —— 两边对不上，一查一个准
4. **小规模季度免税额度跨期混算** —— 按所属期算，不是按申报期
5. **房产税从价/从租选错** —— 自用按原值、出租按租金，同一房产可能两种都有

## 七、输出物

- 分客户、分税种、分期的**申报辅助稿**（不是直接申报，是交给复核的稿）
- 勾稽校验记录（含差异理由）
- 本期政策核对记录（核了哪几份文件）

## 八、边界

- **申报前必须所内复核**（见 SKILL.md 总纪律）。报出去就改不了，更正申报要留痕。
- **不替客户决定优惠适用**：优惠有资格条件，事实由客户确认，我们只提示"可能符合，请提供材料"。
- **超出代账范围转出去**：税务筹划、跨境涉税、重组特殊性税务处理、优惠适用争议 → 持证 CPA / 税务顾问。代账岗不碰这些。
