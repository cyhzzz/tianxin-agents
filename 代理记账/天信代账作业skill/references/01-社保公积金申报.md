# 01 社保公积金申报

> 天信原创。上游三个包（记账账/东纳荣/飞猫）都是 US GAAP 或工商语境，**社保一个字没有**——而县城客户家家要报，漏报一次就是补缴 + 滞纳金。
> **比例与基数上下限不写死**：浙江各市不同、每年调整，一律查当地当年公告。本文件给的是"怎么做、怎么核、错在哪"。

## 一、代账岗在社保上的边界

| 做 | 不做 |
|---|---|
| 按客户给的工资表与人员名册申报缴费基数 | 判断劳动关系（是否该缴、谁该缴） |
| 增减员、基数调整、补缴申报 | 设计薪酬方案、规避社保（**违法，不接**） |
| 与个税专项扣除、工资表勾稽 | 代理劳动争议、代签劳动合同 |
| 提醒缴费期限与欠费 | 承诺"按最低基数缴没问题" |

**一句话**：我们做申报动作，缴费义务与用工事实由客户负责，且要客户书面确认人员与工资数据。

## 二、每户接手的第一次：先把五件事问清

1. **参保地**（决定基数上下限与比例）：天台 / 台州其他县市 / 杭州——**跨市比例不同，不能套**。
2. **缴费人数与人员名册**：在职、退休返聘（不缴养老医疗）、实习生、劳务派遣（不由用工单位缴）。
3. **当前缴费基数**：是否按最低基数缴、是否与实际工资脱节。
4. **有无欠费与历史补缴**：接手客户必查，欠费会连带滞纳金与信用影响。
5. **公积金是否开户**：很多小客户只缴社保未建公积金账户。

## 三、基数怎么定（错在这里最贵）

- 基数 = 职工**上年度月平均工资**（含工资、奖金、津贴、加班费），不是基本工资，也不是当月实发。
- 上下限：当地上年度**全口径城镇单位就业人员平均工资**的 **60%–300%**（具体倍数与金额每年由当地公布，**查当年公告**）。
- 新入职：按**首月全月工资**；当年新参保的按实际工资。
- 年度调整：浙江通常在年中（7 月起）按新公布的上下限调整，**调整后要补差**（1–6 月差额），别只改当月。
- 实习生、非全日制、退休返聘：按当地口径判断，**不套"一律不缴"或"一律缴"**。

**红线**：客户要求"全部按最低基数缴"，只能书面告知风险后由客户决定；**我们不主动设计这种方案**。风险是补缴 + 滞纳金 + 影响纳税信用 + 员工举报。

## 四、申报流程（按月，卡时间窗）

| 步 | 做什么 | 时点 |
|---|---|---|
| 1 | 收当月工资表 + 人员变动（入职/离职/调薪） | 每月初 |
| 2 | 核对基数与人数：与上月比，变动要有依据 | 申报前 |
| 3 | 增减员办理（**先减后增**，避免多缴） | 当地窗口期内（多为当月 1–25 日，以当地为准） |
| 4 | 社保费申报（税务征收地区在电子税务局，人社经办地区在人社网办） | 申报期内 |
| 5 | 缴费 → 取回单 → 与工资表代扣数核对 | 缴费后 |
| 6 | 账务处理：单位部分进成本费用，个人部分从应付职工薪酬代扣 | 当月 |
| 7 | 归档：申报表、缴费回单、人员变动表 | 当月 |

**顺序纪律**：先办增减员，再申报，否则人数与金额对不上，只能作废重报。

## 五、公积金

- 缴存比例：单位与职工**同比例**，区间 5%–12%（具体档位看当地公积金中心规定）。
- 基数：一般按上年月平均工资，上下限同当地公布口径。
- 降比例或缓缴：需经职工代表大会/工会讨论通过，并向公积金中心申请，**不是客户说降就降**。
- 未开户的客户：先开户再缴；不开户而工资表里扣了"公积金"的，属于虚假代扣，必须纠正。

## 六、残保金（每年一次，容易忘）

- 按上年用人单位安排残疾人就业未达规定比例的差额人数 × 上年本地区社会平均工资（或按当地规定）× 征收标准。
- **在职职工 30 人（含）以下的企业免征**（财政部公告 2023 年第 8 号延续至 2027-12-31，**引用前核现行文件**）。
- 分档减缴政策同样有执行期限，按当年文件判断，不要沿用旧口径。
- 申报期通常在每年下半年（按当地税务公告），逾期有滞纳金。

## 七、与个税、工资表的三方勾稽（每月必做）

| 校验 | 关系 |
|---|---|
| 社保申报人数 | = 工资表人数 − 不参保人员（退休返聘等，需有依据） |
| 社保申报基数合计 | = 工资表应缴基数合计（差异要有说明） |
| 个人部分代扣 | = 工资表"个人社保"列合计 = 个税申报专项扣除中的社保金额 |
| 单位部分 | = 成本费用中社保金额 = 社保申报表单位部分 |
| 公积金 | 同上，且个人 + 单位同比例 |

对不上就查：增减员漏办、基数未随调薪更新、有人只缴工伤、个人部分忘了代扣。

## 八、常见错误（都见过）

1. **只增不减**：离职人员未减员，多缴几个月，退费流程麻烦。
2. **基数一年不动**：调薪后仍按老基数，年度稽核要补差。
3. **年度调整只改当月**：1–6 月差额没补。
4. **个人部分没代扣**：公司替员工承担，形成工资性支出，个税口径也错。
5. **申报了社保但没做账**：账上无社保费用，与申报表对不上。
6. **残保金漏报**：以为 30 人以下不用管，其实要**申报**才免（多数地区仍需零申报，按当地）。

> **红线**：社保申报数据必须来自客户书面确认的工资表与人员名册。客户口头说"这个人不用缴"，要留下书面依据——出事时这是唯一能证明我们没有过错的东西。
