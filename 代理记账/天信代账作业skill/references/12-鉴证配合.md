# 12 鉴证配合

> 来源：记账账·audit-support **适配为国内场景**（非美国 SOX）。代账客户被审 / 验资 / 评估时，我们配合准备材料。

## 一、触发场景

- 代账客户接受年报审计、专项审计、验资、资产评估。
- 金融机构尽调需函证。

## 二、配合内容

- **函证底稿准备**：银行询证函、往来询证函（模板见 `assets/`）。
- **被审计单位资料清单**提供：凭证、合同、银行对单、盘点表。
- **抽凭配合**：按审计抽样提供原始凭证。
- **重大事项说明**：关联方、或有事项、期后事项。

## 三、步骤

1. 收审计 / 鉴证机构清单。
2. 按清单备料（联动 03 / 04 / 05 底稿）。
3. 配合抽凭与现场。
4. 回函 / 出说明。

## 四、输出物

- 函证底稿
- 资料提供清单
- 重大事项说明

## 五、纪律

- **只协助准备材料，不替代审计师 / 评估师形成结论**。
- 保持独立性意识，不代客户回应专业判断问题。
- 所用底稿须与日常记账一致（见 05 / 06）。
