# 06 财务报表

> 客户最终拿到的是报表，质量决定口碑。列报要点与实务判断内联在本文件，不指向别的技能。

## 一、三表范围

资产负债表、利润表、现金流量表。

## 二、列报要点（中国准则口径）

- **资产负债表**：按流动性排序（流动资产 / 非流动资产）；"一年内到期的非流动负债"要从长期负债重分类出来，这一条最常漏。
- **利润表**：营业利润要分层——营业收入 − 营业成本 − 税金及附加 − 期间费用 + 其他收益 + 投资收益等，别把营业外收支混进去。
- **现金流量表**：经营 / 投资 / 筹资三类；经营现金流用直接法编，附注给间接法调节表。
- **通用**：金额单位统一（元或万元，全表一致）、期间标注清楚、"其他"类项目金额大要拆开、非正常项目单列。

## 三、步骤

1. **试算平衡**：借贷必平。不平就回查凭证（04），别硬调。
2. **结转损益**：期末统一结转（见 04 纪律），平时不转。
3. **出三表**：按上面的列报要点。
4. **附注**：重大会计政策、重大会计估计、或有事项主动提醒，不省略。

## 四、输出物：两个版本

| 版本 | 给谁 | 长什么样 |
|---|---|---|
| **专业版** | 所内复核 / 报送 | 标准三表 + 附注，符合列报规范 |
| **客户版** | 老板 | 一页纸，见下 |

### 客户版怎么写

代账客户多数不看会计准则，看的是"我这个月赚没赚、账上还有多少钱"。

- 一页纸四个数：**收入、毛利、净利、期末现金**，各带同比或环比
- 白话说明，不堆科目名（"管理费用比上年多了 3 万，主要是社保基数上调"而不是"管理费用同比 +18.7%"）
- **该提醒的风险单独一段**：应收账款账龄、现金够不够发下月工资、税负率异常
- 不写结论性判断（"经营状况良好"这种），只给事实和可核的数

## 五、实务判断要点

这几个事项在代账里出现频率不高，但一出现就容易做错。要点如下，完整判断框架见天信实务知识库（如已安装）：

| 事项 | 关键点 |
|---|---|
| 职工薪酬 | 工资 / 社保 / 公积金 / 职工福利费分列；辞退福利单独确认，不混在工资里 |
| 政府补助 | 先分与资产相关 / 与收益相关；总额法与净额法二选一且要一贯，不能这期总额下期净额 |
| 资产减值 | 有减值迹象才测试；可收回金额取"公允价值减处置费用"与"预计未来现金流量现值"孰高 |
| 差错更正 | 重要的前期差错**追溯重述**，不重要的在本期调整；别一律"调以前年度损益"了事 |
| 收入确认 | 按履约义务的时点或时段确认，看控制权转移，不看开票或收款时点 |

## 六、纪律

- 单位统一、期间标注、非正常项目单列。
- 验证计算准确性后再交付（把三表勾稽过一遍：资产负债表未分配利润变动 = 净利润 − 分配）。
- 对外报表须经所内复核（见 SKILL.md 总纪律）。
