# 13 政策速递与合规预警

> 来源：东纳荣·合规能力。把「做账」延伸到「帮客户避坑」。

## 一、范围

- **财税新政解读**：新出台 / 调整的财税政策，对核算、申报、税负的影响。
- **税负率测算**：客户实际税负 vs 同行业区间，异常预警。
- **风险分级**：高 / 中 / 低 + 政策依据 + 整改建议。

## 二、步骤

1. **跟踪新政**：所内同步 / 公开权威来源，不凭小道消息。
2. **影响评估**：逐客户判断受影响税种 / 科目 / 申报。
3. **税负测算**：取实际数据算税负率，对比行业区间，异常标红。
4. **出合规提示**：政策依据 + 对客户的具体建议。

## 三、输出物

- 政策影响提示（逐客户）
- 税负预警（偏离行业区间）
- 风险清单（分级 + 整改建议）

## 四、纪律

- 政策以官方发布为准，解读不臆测。
- 重大合规 / 税务风险建议，转持证 CPA / 税务顾问确认。
- 提示仅供客户参考，不构成税务意见（见 SKILL.md 边界）。
