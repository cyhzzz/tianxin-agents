# 代理记账线

建账、日常记账、月度结账、报表编制、纳税申报、年度归档与交接。

## 计划建的技能

| 技能 | 内容 | 状态 |
|---|---|---|
| `天信代账作业` | 建账 → 票据 → 凭证 → 月结 → 报表 → 申报 → 交接 | 待建 |

## 这条线的核心是「弹性编排」

客户给的资料从来不是齐的：有的给原始票据，有的给发票清单，有的连凭证都做好了只要报表。死板的流水线走不通。

商店里 `tax-compliance-team` 的做法值得抄——按用户手里有什么决定从哪一步进：

| 客户手里有什么 | 从哪步开始 |
|---|---|
| 原始票据（图片/PDF） | 票据处理 |
| 已有发票清单 | 记账 |
| 已有凭证账簿 | 报表 |
| 已有报表 | 申报 |
| 只要合规审查 | 复核 |

## 需要什么材料

1. **一份代账客户的完整月度作业**——从收到票据到报完税，中间经过谁的手
2. 常用表格：工资表、折旧表、银行余额调节表、往来对账表
3. 客户结构：多少家、什么行业、一般纳税人还是小规模
4. 交接怎么做（客户换所时资料怎么给）
