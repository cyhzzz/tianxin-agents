## 上游能不能直接用

上游是 **US GAAP / SOX 语境，除 `finance-0`、`finance-1` 外全为英文**：

- **直接可用**：`finance-3` 凭证（含审批矩阵、复核清单、常见错误自查）、`finance-4` 核对、`finance-6` 差异分析
- **仅方法论**：`finance-5` 报表（ASC 842/606 格式不对应）、`finance-8` 鉴证（整篇 SOX 404）
- **需调整**：`finance-2` 总流程、`finance-7` 结账（时点按中国申报期）

报表格式、会计科目、税务口径**永远不用上游的**，一律按中国口径，判据见 `SKILL.md` §五。

## 出报告时

内容做完后，要出 Word / A4 PDF / 网页长页 / 演示 deck / Excel 表 → **调用「天信文档与报告」技能**，品牌规范与五轨出版由它负责。本技能只管内容对（数从哪来、怎么算的、差异为什么）。没装那个技能就输出 Markdown，不自创品牌样式。

## 这条线的核心是「弹性编排」

客户给的资料从来不是齐的：有的给原始票据，有的给发票清单，有的连凭证都做好了只要报表。死板的流水线走不通。

| 客户手里有什么 | 从哪步开始 |
|---|---|
| 原始票据（图片/PDF） | 票据查验 → 编凭证 |
| 已有发票清单 | 直接编凭证 |
| 已有凭证账簿 | 出报表 |
| 已有报表 | 报税 |
| 只要合规审查 | 交叉验 + 差异分析 |

**不要强行从建账开始**——客户可能早就有账，只是换所或补一段。
