# 改进提案模板

> 复制本文件，改名成 `<技能名>-<主题>.md`，填好后：
>
> - 能跑 git：`python contribute.py --proposal <提案文件>`（自动建分支、提交、开 PR）
> - 只反馈不改代码：去 <https://github.com/cyhzzz/tianxin-agents/issues> 开 issue，把下面内容贴进去
>
> 模板填不满也能交——**写清「现在怎么写的」和「应该是」两栏就有用**，
> 「依据」栏可以留空，由合伙人核实后补。

---

## 一、基本信息

| 字段 | 内容 |
|---|---|
| **技能** | （填 frontmatter 的 name，如 `天信代账作业`） |
| **类型** | 内容有误 / 政策过期 / 缺能力 / 表述不清 / 其他 |
| **位置** | （`references/03-xxx` 第 N 行，或 `SKILL.md` 第 X 节） |
| **提交人** | （可选） |
| **日期** | |

## 二、问题

**现在怎么写的**（原文照抄，别改写）：

```
（把现在的原文贴在这里）
```

**应该是**（改成什么）：

```
（把建议的写法贴在这里）
```

**依据**（政策文号 / 准则条款 / 实务做法 / 参考来源）：

> 政策类改动**必须**给文号和执行期限。没有文号的税率、优惠比例一律不收——
> 一份 2023 年口径的税率表直接搬进来，会让客户少缴、补税加滞纳金。
> 这种错误以前出过六处。

## 提交前自查

- [ ] 「现在怎么写的」是原文照抄，不是我理解的转述
- [ ] 「应该是」写的是具体文字，不是「建议优化一下」
- [ ] 政策类改动给了文号
- [ ] 没把客户名、税号、金额写进去（这是公开仓库）
