## ⚠️ 本所只做资产评估，不做工程造价

**受托主体是天台天信会计师事务所**——本所经营范围含「资产评估；土地调查评估服务」，评估业务由本所承接，不外挂。

**工程造价不在本所经营范围**（预算编制、结算审核、全过程造价均不含），这条线**不承接造价业务**，遇到转有资质造价机构，无造价内部模板。

> 说明：**台州中兴和资产评估有限公司与天信无股权关系**（股东为两名自然人，注册地玉环），已从集团版图剔除，不作为本所评估业务的承接方。

## 和审计线的分工

评估报告和审计报告在要素上互通（委托方、目的、基准日、范围、方法、结论、限制条件），但**准则体系不同**：

- 审计：中国注册会计师审计准则
- 评估：资产评估执业准则 + 资产评估法

报告格式不能互相套用。

## 上游能不能直接用

两个包**不同源、互补**：业小勤（`appraiser-*`，2 份）给角色口吻与能力全貌；热火集（`appraise-*`，94 份）给准则原文、审核清单与模板。要依据和原文，以热火集为准。

- **直接可用**：准则与法规依据名录（26 项中评协准则 + 9 部法规文号）、**中评协准则全文 59 份**、价值类型体系、三大方法参数要点、三套测算表骨架、报告十五条骨架与主模板、三级审核负面清单、监管问询 13 个高频维度、资产基础法 28 类科目清单、3 份真实审核意见 docx 格式。
- **需替换**：地方国资口径（上游以**广州、深圳**为例），天信按浙江省及台州当地现行规定。
- **需核时效（上游自己写明的坑）**：中评协〔2026〕5/6/7 号 2026 年 7 月印发、**2027-01-01 才施行**；2026 年内出报告仍引〔2018〕36 号 /〔2017〕46 号 /〔2017〕30 号。**判现行有效看施行日，不看发布年。**
- **没收到**：热火集 README 提到的 `templates/clean-examples/`（干净版报告/说明/计算表示例 5 件）**包内实际未附带**，不是漏收。
