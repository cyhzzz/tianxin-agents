```
             ┌─ 资产评估基本准则 ──┐         （财资〔2017〕43号，唯一基本准则）
             │                      │
中国资产评估 ─┤  资产评估职业道德准则 ┤       （中评协〔2017〕30号，含 2026 修订）
准则体系     │                      │
             ├─ 程序性具体准则（6份）┤       委托合同/程序/报告/档案/利用专家/方法
             │                      │
             ├─ 实体性具体准则（7份）┤       企业价值/无形/不动产/机器设备/珠宝/森林/知识产权
             │                      │
             ├─ 评估指南（4份）────────       国资/金融国资/财务报告目的/机构质控
             │                      │
             ├─ 指导意见（14份）──────┤       价值类型/法律权属/专利/著作权/商标/金融不良/投资性房地产/实物期权/文化无形/司法处置/珠宝程序/企业并购/体育无形资产/数据资产
             │                      │
```

### 2.1 实体性准则衔接关系 ⚠️

- **知识产权（2023 新）** vs **原三项专利/著作权/商标意见（2017）**：2023 新准则与原指导意见并行有效。规则：**2023 准则统驭原 2017 三项意见**，新业务优先适用 2023 准则；旧业务按合同/委托日适用规则。
- **不动产 vs 投资性房地产**：投资性房地产评估指导意见（2017〔53〕号）专用于**以投资性目的持有、采用公允价值模式后续计量**的房地产，与不动产准则是一般↔特殊关系。
- **企业价值 vs 各资产类型准则**：评估**整体企业**时，企业价值准则是统驭准则，单项资产（机器设备/不动产/无形）仅在资产基础法分项评估时适用。

## 9 · 检索关键词 → 准则速查

> 倒排：业务场景/术语 → 首查准则。这一段是使用者日常问"原话"的入口。

### ⚠️ 跨领域术语防混（使用者双执业领域）

使用者同时持有**矿业权评估师**与**资产评估师**资格，两套准则术语**不可串用**：

| 术语 | 属于 | ❌ 误用风险 |
|---|---|---|
| **就近就新原则** | 🔵 矿业权（CMVS30800 §1.5） | 资产评估准则**无**此表述，勿写入资产评估报告 |
| **收入权益法** | 🔵 矿业权（CMVS12100） | 资产评估方法准则**无**此方法 |
| **折现现金流量法(DCF)** | 🔵 矿业权（四大方法之一） | 资产评估称"收益法"，术语不同 |
| **三大基本方法（市场法/收益法/成本法）** | 🟢 资产评估（方法准则§第二/三/四章） | 通用，但表述须按资产评估准则 |
| **评估基准日可为未来时点** | 🟢 资产评估（基本准则§第二十五条） | 矿业权亦有类似规定，但条文不同 |
| **"评估依据"章节** | 🟢 两者均有 | 引注的准则文号完全不同 |

> **铁律**：矿业权术语与资产评估术语各自成体系、条文不同，**不得跨领域套用**；矿业权部分见 `mining-rights-audit.md`。
