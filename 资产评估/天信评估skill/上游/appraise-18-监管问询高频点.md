## 二、各维度典型追问范式（由聚合关键词推导，非原文摘录）

> 下列为交易所高频追问口径的归纳，用于审核时自查"这份报告是否经得起同类追问"。

- **评估假设与披露**：关键假设（持续经营、宏观参数、特殊性假设）是否充分披露且合理；选取依据是否说明；期后事项是否披露；评估范围与权属资料是否完整齐备。
- **收益法·盈利质量**：营业收入 / 毛利率预测与历史期、同行业可比公司差异的**原因及合理性**；客户集中度 / 单一大客户依赖风险；在手订单对预测的支撑；关联交易定价公允性；期后实际经营与预测是否背离；业绩承诺可实现性。
- **核查程序与底稿**：评估机构核查程序是否到位、是否勤勉尽责；工作底稿是否足以支撑结论；独立性声明；专项核查意见是否充分。
- **资产界定**：溢余资产 / 非经营性资产识别是否完整；长期股权投资、商誉、无形资产、土地使用权、矿业权、知识产权是否恰当界定并评估。
- **收益法·预测假设**：预测期 / 永续期划分合理性；收入增长率 / 复合增长率假设依据；现金流口径（FCFF / FCFE）一致性；敏感性分析是否充分、是否覆盖关键变量。
- **市场法**：可比公司 / 可比交易选取的合理性；价值比率（EV/EBITDA、市盈率、市净率等）选择理由；修正系数是否完备、是否有据；流动性折扣 / 控制权溢价取值依据。
- **评估结论与增值**：增值率 / 评估增减值原因量化；多方法结论差异及**最终选取理由**；是否简单算术平均，有无偏向委托人。
- **关联交易与定价公允**：关联交易定价公允性；是否存在利益输送疑点；评估作价与交易定价是否一致。
- **特殊场景·年报问询**：减值计提是否充分（存货跌价、应收账款、长期资产）；信息披露监管问询中对评估假设的质疑；期后事项对年报数据的影响。
- **成本法**：重置成本 / 成新率 / 经济性 / 功能性 / 实体性贬值测算合理性；评估增值原因。
- **评估方法选择**：三种基本方法是否均予考虑；未选用方法的理由是否充分；方法适用性论证。
- **收益法·折现率**：WACC 各参数（无风险利率、β 系数、市场风险溢价、企业特定风险收益率）取值依据；与同行业、同规模可比性；债权收益率 / 资本结构假设。
- **特殊场景·减值测试**：商誉减值 / 可收回金额测算；含商誉资产组划分；减值迹象识别与可回收金额口径。

## 三、问询语气强度信号

对问询动词的聚合统计显示监管最强调**"合理性论证"**：

| 追问措辞 | 出现次数 |
|---|---:|
| 原因及合理性 | 1,579 |
| 差异原因 | 881 |
| 是否合理 | 640 |
| 请独立财务顾问（协同问询） | 511 |
| 请评估师（专项回复） | 154 |
| 请说明 / 请结合 / 请补充 | 140 |

**启示**：监管问询的核心不是"有没有"，而是"**为什么合理、差异从何而来**"。审核一份报告时，凡涉及参数选取、方法选用、结论差异、增值原因，都必须要求"给出可论证的依据"，不能止步于"已披露"。

## 四、对审核工作的前置核查清单（直接可用）

审核报告时，按以下优先级前置排查（排名来自第一节实证）：

1. 评估假设是否完整披露且逐条可论证；期后事项 / 权属资料是否齐备。
2. 收益法盈利预测（收入、毛利率、增长率）与历史、同行业差异是否有"原因及合理性"论证。
3. 评估机构核查程序与底稿是否能支撑结论、独立性是否声明。
4. 溢余 / 非经营性资产、长期股权、无形资产、土地 / 矿权 / 知识产权界定是否完整。
5. 预测期 / 永续期、现金流口径、敏感性分析是否充分。
6. 市场法可比标的与修正系数、流动性折扣 / 控制权溢价是否有据。
7. 评估结论差异与增值原因是否量化并说明选取理由（禁止简单平均）。
8. 关联交易与定价公允性是否排除利益输送疑点。
9. 年报 / 减值测试场景的计提充分性与减值迹象。
10. 折现率各参数取值是否与同行业可比、依据是否披露。
11. 三种方法是否均考量、未选方法的理由是否充分。
