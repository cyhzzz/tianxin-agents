# 资产评估报告可填充模板（通用骨架）

> **两份指南权重最高**，是报告结构的首要依据；结构依据《企业国有资产评估报告指南》（中评协〔2017〕42 号）与《金融企业国有资产评估报告指南》（中评协〔2017〕43 号），同时遵守《资产评估执业准则——资产评估报告》（中评协〔2018〕35 号）与《资产评估基本准则》（财资〔2017〕43 号）。**国资项目以此两份指南为骨架主依据**（金融企业另行适用金融国资指南）。
> 报告由"标题及文号、目录、声明、摘要、正文、附件、评估明细表和评估说明"七部分构成，须齐备。
> 本模板给出可直接填充的骨架；括号中的【】为填写提示，正式出具时删除。不同资产类别（企业价值 / 不动产 / 无形资产 / 数据资产）须按对应具体准则增删章节。
> **以用户实际模版为准**：若用户有自带报告模版，以其章节顺序与编号为准，本模板仅提供内容口径与要素完整性参考。详细章节填报要点见知识库 `report-outline.md`。
> **辅助示例（非权威）**：`templates/clean-examples/` 下提供干净版报告/说明/计算表（评估报告书.docx、评估说明.docx、评估申报表-成本法.xlsx、市场法计算表.xlsx、收益法评估明细表.xlsx），仅作撰写参考；其中为通用占位（ABC/DEF/XYZ），须替换为实际项目数据，**不替代两份指南的权威口径**。

## 三、资产评估报告声明（固定七条）

一、本资产评估报告依据财政部发布的资产评估基本准则和中国资产评估协会发布的资产评估执业准则和职业道德准则编制。

二、委托人或者其他资产评估报告使用人应当按照法律、行政法规规定和资产评估报告载明的使用范围使用资产评估报告；委托人或者其他资产评估报告使用人违反前述规定使用资产评估报告的，资产评估机构及其资产评估专业人员不承担责任。

三、资产评估报告仅供委托人、资产评估委托合同中约定的其他资产评估报告使用人和法律、行政法规规定的资产评估报告使用人使用；除此之外，其他任何机构和个人不能因得到资产评估报告而成为资产评估报告的使用人。

四、资产评估机构及其资产评估专业人员遵守法律、行政法规和资产评估准则，坚持独立、客观、公正的原则，并对所出具的资产评估报告依法承担责任。

五、资产评估报告使用人应当正确理解评估结论，评估结论不等同于评估对象可实现价格，评估结论不应当被认为是对评估对象可实现价格的保证。

六、资产评估机构及其资产评估专业人员提示资产评估报告使用人：评估结论的使用有效期通常为自评估基准日起一年；有效期内若资产状况、市场环境发生重大影响变化，应恰当使用评估结论。

七、本资产评估报告是根据委托人所提供的资料进行评定估算，资料的真实性、完整性、合法性由委托人负责。

## 五、资产评估报告正文（十五节，依《企业国有资产评估报告指南》）

### （一）绪言
【固定格式】"×××（委托人全称）：×××（资产评估机构全称）接受贵单位（公司）的委托，按照法律、行政法规和资产评估准则的规定，坚持独立、客观和公正的原则，采用×××评估方法，按照必要的评估程序，对×××（委托人全称）拟实施×××行为（事宜）涉及的×××（资产——单项资产或者资产组合、企业整体价值、股东全部权益、股东部分权益）在××××年××月××日的××价值（价值类型）进行了评估。现将资产评估情况报告如下。"

### （二）委托人、被评估单位及委托合同约定的其他评估报告使用人概况
1. 委托方：名称、统一社会信用代码、类型、住所、法定代表人、经营范围。
2. 其他报告使用人：【国资监管机构 / 交易对方 / 人民法院 / 金融机构】及其使用依据。
3. 被评估单位（产权持有人）概况：历史沿革、股权结构、主营业务与经营模式、近三年一期财务状况与经营成果、执行的主要会计政策。
4. 委托人与被评估单位关系（产权关系、交易关系、交叉持股图、关联交易）。
> 金融企业：增列金融业务许可证或准入批复、主要股东、财务核算体系、子公司/分公司构成、经营特点（银行信贷/保险险种/证券业务）。

### （三）评估目的
【明确、唯一】如：为【委托方】拟转让所持有的【被评估单位】××% 股权提供价值参考依据。
对应经济行为批准文件：【股东会决议 / 董事会决议 / 国资批复 / 法院委托书】及文号。

### （四）评估对象和评估范围
1. 评估对象：【股东全部权益 / 部分权益 / 单项资产 / 资产组（组合）/ 数据资产】。
2. 评估范围：具体资产与负债清单（含账面值），是否与企业申报范围、审计范围一致，是否经审计及审计意见类型。
3. 权属状况：权属证明编号，是否存在抵押、质押、查封、冻结、共有、许可他人使用等权利限制。
4. 表外资产：商誉、客户关系、商标、专利、数据资源、特许经营权等是否纳入及其理由；引用其他机构报告结论的资产类型与金额。
> 金融企业：增列表外业务类型与数量、客户资源/营销网络等无形资产。

### （五）价值类型及其定义
1. 价值类型：【市场价值 / 投资价值 / 清算价值 / 残余价值】。
2. 定义：按《资产评估价值类型指导意见》表述。
3. 选择理由：结合评估目的、市场条件、评估对象自身条件说明为何选择该价值类型（准则要求必须说明理由）；非市场价值须声明其不是市场价值。

### （六）评估基准日
1. 基准日：【202×年×月×日】，与资产评估委托合同约定一致。
2. 选取理由：【月末/年末结账日、与经济行为实现日接近、会计报表完整、便于取价、利率汇率变化、特定文件约束】。
3. 结论使用有效期：一年，自评估基准日起算（自基准日起至次年对应日前一日止）。
4. 基准日后的期后事项处理原则。

### （七）评估依据（五类分列）
1. **经济行为依据**：本次经济行为的批准文件（决议/批复/协议）。
2. **法律法规依据**：《资产评估法》《公司法》《证券法》《企业国有资产法》等。
3. **评估准则依据**：《资产评估基本准则》（财资〔2017〕43号）、《资产评估执业准则——资产评估程序》《资产评估报告》《资产评估方法》（中评协〔2019〕35号）、《企业价值》（中评协〔2018〕38号）/《无形资产》/《不动产》/《机器设备》/《知识产权》（中评协〔2023〕14号）等，按"名称＋文号＋发布日＋施行日"体例书写，并核对现行有效（核查途径见 `standards-and-regulations.md`）。
4. **权属依据**：不动产权证书、专利/商标注册证、著作权登记证书、设备购置合同发票、数据资源来源与授权文件、持股证明等。
5. **取价依据**：审计报告、财务报表、行业统计年鉴、公开市场数据、可比交易公告、造价指标、现行税费政策、价格指数等（须注明来源、日期、口径）。

### （八）评估方法
1. 方法适用性分析：逐项分析市场法、收益法、成本法是否适用及理由（资料可得性、市场活跃度、未来收益可预测性）。
2. 选用方法：说明最终采用的方法及不采用其他方法的具体理由。
3. 方法定义与技术思路（测算在评估说明中展开）。

### （九）评估程序实施过程和情况
按程序：明确业务基本事项 → 订立委托合同 → 编制评估计划 → 现场调查 → 收集整理资料并核查验证 → 评定估算 → 内部审核（三级复核）→ 编制出具报告并报备 → 整理归集档案。

### （十）评估假设
1. 一般假设：交易假设、公开市场假设、企业持续经营假设、资产继续使用假设。
2. 特殊假设：宏观经济与政策无重大变化；管理层经营规划可实现；利率、汇率、税负无重大变化；资料真实完整；无重大未决诉讼、担保等或有事项（或已披露）。
3. 假设变化对结论的影响提示。

### （十一）评估结论
1. 评估结论（含账面值、评估值、增减值及增减率；多种方法时先列各方法结果，再说明选取逻辑）。
2. 结论有效期：自评估基准日起一年。
3. 结论内涵说明：【是否含控股权溢价、是否考虑流动性、是否含溢余资产、币种与口径】。
4. 与账面价值比较及增值原因分析；折价或溢价情况（如有）。

### （十二）特别事项说明（至少覆盖，据实增删）
1. 权属瑕疵或权属资料不完整情况；
2. 未决事项、法律纠纷、担保与或有负债；
3. 重大期后事项；
4. 利用专家工作及相关机构（审计、律师、评估专家）工作情况；
5. 评估程序受限情况及对结论的影响；
6. 引用其他机构报告结论的情况及责任划分；
7. 数据资产：数据来源合规性、授权链条、个人信息保护与数据安全合规事项；
8. 其他需要提示的重大事项。

### （十三）资产评估报告使用限制说明
1. 本报告只能用于报告载明的评估目的和用途，不得用于其他目的；
2. 未征得出具报告的评估机构同意，报告内容不得被摘抄、引用或披露于公开媒体；
3. 委托人等未按载明使用范围使用的，评估机构不承担责任；
4. 评估结论使用有效期；超过有效期或期间发生重大变化的处理原则；
5. 评估结论不等同于可实现价格，不视为对可实现价格的保证。

### （十四）资产评估报告日
【202×年×月×日】（不得早于现场调查完成日与结论形成日）
