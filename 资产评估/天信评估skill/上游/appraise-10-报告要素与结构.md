# 企业价值评估报告与评估说明骨架

两份指南《企业国有资产评估报告指南》（中评协〔2017〕42 号）与《金融企业国有资产评估报告指南》（中评协〔2017〕43 号）**权重最高**，是报告与说明组织的首要依据；按这两份指南组织，同时遵守《资产评估执业准则——资产评估报告》（中评协〔2018〕35 号）与《资产评估基本准则》（财资〔2017〕43 号）。**所有类型报告（国资 / 非国资 / 股权 / 单项资产 / 房地产 / 无形资产 / 金融等）均可以这两份指南的报告结构与章节规范作为通用骨架与披露要求参照；国资项目及金融企业更须严格遵循**（金融企业另行适用金融国资指南）；指南要求报告由"标题及文号、目录、声明、摘要、正文、附件、评估明细表和评估说明"七部分构成，须齐备。

---

## 一、资产评估报告书结构

### 封面要素

报告编号（如"××评报字[20XX]第 0000 号"）· 册次（共 × 册，第 × 册）· 项目名称（委托人拟××涉及的被评估单位××价值项目）· 报告名称 · 评估机构全称 · 报告日期 · 机构地址。

> 封面须标注"本报告依据中国资产评估准则编制"。

### 目录

列出声明、摘要、正文各节、附件目录的页码。

### 声明（7 项固定声明）

1. 依据财政部基本准则与中评协执业准则、职业道德准则编制；
2. 报告使用人应按法律、行政法规规定和载明范围使用；违反规定使用的不承担责任；仅限委托人、合同约定的其他使用人和法定使用人使用；评估结论不等同于可实现价格，不构成对价格的保证；
3. 遵守法律、行政法规与评估准则，坚持独立、客观、公正原则，依法承担责任；
4. 评估对象涉及的资产、负债清单由委托人（被评估单位）申报并经其签名、盖章或法律允许的其他方式确认；委托人及相关当事人对资料的真实性、完整性、合法性负责；
5. 评估机构与评估师与评估对象无现存或预期的利益关系，与相关当事人无偏见；
6. 是否已对评估对象及所涉资产进行现场调查；已关注法律权属状况并查验权属资料，已如实披露发现问题，已提请完善产权；
7. 分析、判断和结果受报告载明的假设和限制条件限制。

### 资产评估报告摘要

依次列出：评估目的、评估对象与评估范围、价值类型、评估基准日、评估方法、评估结论（分方法列示，并说明最终取值的理由）、评估结果汇总表、报告使用提示、评估结论使用有效期、特别强调事项。

> 摘要末尾注明："本摘要摘自资产评估报告正文，欲了解本评估业务的详细情况和正确理解评估结论，应当阅读评估报告正文。"

### 正文（十五节，依《企业国有资产评估报告指南》第十一条）

| 序号 | 章节 | 关键内容与填报要点 |
|---|---|---|
| 一 | 绪言 | 固定格式："×××（委托人全称）：×××（评估机构全称）接受贵单位（公司）的委托，按照法律、行政法规和资产评估准则的规定，坚持独立、客观和公正的原则，采用×××评估方法，按照必要的评估程序，对×××（委托人全称）拟实施×××行为涉及的×××在××××年××月××日的××价值进行了评估。现将资产评估情况报告如下。" |
| 二 | 委托人、被评估单位及委托合同约定的其他评估报告使用人概况 | 委托人概况（名称、住所、法定代表人、注册资本、经营范围）；被评估单位概况（历史沿革、股权结构及变更、经营管理结构、主营业务与经营模式、近三年资产财务及经营状况、执行的主要会计政策）；委托人与被评估单位关系（产权/交易关系、交叉持股图、关联交易）。**金融企业应增**：金融业务许可证或准入批复、主要股东、财务核算体系、子公司/分公司构成、经营特点（银行信贷/保险险种/证券业务） |
| 三 | 评估目的 | 明确经济行为类型；说明经济行为获得批准的情况或其他经济行为依据（批件名称、批准日期、文号） |
| 四 | 评估对象和评估范围 | 以文字、表格说明评估范围；企业价值评估须说明：委托评估对象与范围是否一致及是否经审计、表外资产类型与数量、引用其他机构报告结论的资产类型与金额；单项资产须说明数量、法律权属、经济与物理状况。**金融企业应增**：表外业务类型数量、客户资源/营销网络等无形资产 |
| 五 | 价值类型 | 名称、定义、选择理由；选择市场价值以外的价值类型须说明选择理由 |
| 六 | 评估基准日 | 基准日日期；确定基准日考虑的主要因素（经济行为实现、会计期末、利率汇率变化、特定文件约束）；**结论有效期一年**（自基准日起至次年对应日前一日止） |
| 七 | 评估依据 | 五类并细化：经济行为依据（有效批复文件）、法律法规依据（国资相关）、评估准则依据（相关准则与规范）、权属依据（产权登记证、持股证明、土地/房屋/专利/商标/著作权证等）、取价依据（财务经营资料、统计技术标准与政策、询价与参数资料）；可列其他参考依据。见 `standards-and-regulations.md` |
| 八 | 评估方法 | 选用方法及理由；不选用其他方法的具体理由 |
| 九 | 评估程序实施过程和情况 | 接受委托、明确基本事项、现场调查与核查验证、收集评估资料、评定估算、编制与提交报告（依指南程序） |
| 十 | 评估假设 | 一般假设（持续经营、公开市场、交易假设）＋特殊假设（逐条列出，每条均为结论的成立条件） |
| 十一 | 评估结论 | 各方法结果、差异分析、最终取值论证；评估结果汇总表（账面价值/评估价值/增减值/增值率）；与账面价值比较及增值原因；折价或溢价情况（如有） |
| 十二 | 特别事项说明 | 产权瑕疵、未决诉讼、担保抵押查封、期后事项、未核实事项、重大不确定事项、租赁与租约、欠缴税费、账外资产 |
| 十三 | 资产评估报告使用限制说明 | 使用范围、使用人、有效期、目的限制、不得作为其他用途 |
| 十四 | 资产评估报告日 | 报告日不得早于现场调查完成日与结论形成日 |
| 十五 | 签名盖章 | 至少两名资产评估师签名，加盖机构印章；附资产评估师承诺函 |

### 附件目录

评估对象涉及的主要权属证明资料；委托人及相关当事方的承诺函；评估机构备案文件或营业执照；资产评估师的承诺函；资产评估机构资质证明；资产评估结果汇总表（签字盖章版）；其他重要文件。

## 二、资产评估说明结构

评估说明不可单独使用，须与评估报告书同时使用方为有效。国资项目须在第一章声明中写明使用范围限制（供国资监管机构及相关监管机构使用，内容不得对外提供或见诸公开媒体）。

### 第一章 关于评估说明使用范围的声明

评估机构声明 + 机构名称与日期。

### 第二章 企业关于进行资产评估有关事项的说明

由委托人与被评估单位共同撰写，单位负责人签字盖章。

### 第三章 资产评估说明

| 节 | 内容 |
|---|---|
| 一、评估对象与评估范围说明 | 评估对象；纳入评估范围的资产负债明细（附资产评估申报汇总表，列示流动资产、非流动资产及其明细、流动负债、非流动负债的账面值）；实物资产分布与状况；账外资产核实情况 |
| 二、资产核实情况总体说明 | 核实组织、核实方法与过程、影响核实的事项、核实结论（附"资产核实明细与申报核对情况"） |
| 三、评估技术说明 | 见下 |

#### 第一部分 资产基础法

- 一、流动资产的评估：货币资金、交易性金融资产、应收票据、应收账款、预付账款、应收股利、其他应收款、存货、其他流动资产；
- 二、非流动资产的评估：长期股权投资、投资性房地产、固定资产（房屋建筑物、机器设备、运输设备、电子设备）、在建工程、无形资产（土地使用权、专利、商标、软件）、长期待摊费用、递延所得税资产、其他非流动资产；
- 三、负债的评估：流动负债、非流动负债。

> 每项资产写明：账面值 → 评估方法 → 评估过程（含公式与参数） → 评估值 → 增减值原因。

#### 第二部分 收益法（十一节）

| 节 | 内容 |
|---|---|
| 第一节 | 收益法的应用前提及选择理由和依据（定义、应用前提三条件、选择理由：总体情况判断 / 评估目的判断 / 所选方法判断） |
| 第二节 | 收益预测的假设条件（一般假设、特殊假设） |
| 第三节 | 宏观经济形势现状与行业现状分析 |
| 第四节 | 企业的业务情况（主营产品、经营模式、核心竞争力、发展规划） |
| 第五节 | 企业财务分析（历史三年资产负债、收入成本、费用、现金流；财务指标分析） |
| 第六节 | 收益法评估模型（FCFF/FCFE 模型选择与公式；参数口径说明） |
| 第七节 | 收益期限及预测期的说明（收益期确定依据；预测期与稳定期的划分） |
| 第八节 | 折现率的确定（rf、ERP、Beta、特定风险 α、Ke、Kd、资本结构、WACC 逐项测算） |
| 第九节 | 经营性业务价值的估算及分析过程（收入、成本、税金及附加、期间费用、EBIT、NOPAT、资本性支出、营运资金追加、FCFF、折现、终值） |
| 第十节 | 其他资产和负债价值的估算及分析过程（溢余资产、非经营性资产与负债） |
| 第十一节 | 收益法评估结果（经营性资产价值＋溢余及非经营净值＝股东全部权益价值） |

#### 第三部分 市场法（四节）

| 节 | 内容 |
|---|---|
| 第一节 | 市场法的应用前提及选择理由（定义、四个前提条件、选择理由） |
| 第二节 | 市场法评估模型（上市公司比较法 / 交易案例比较法；价值比率选择） |
| 第三节 | 可比公司的选取及财务数据调整（筛选标准、剔除条件、财务数据口径统一） |
| 第四节 | 市场法评估计算过程及结果（价值比率测算、流动性折扣、控制权溢价、最终结论） |

#### 四、评估结论及分析

三法结果并列 → 差异量化 → 最终取值论证 → 与账面值比较及增值原因分析。

## 三、撰写体例要求

1. **口径一致**：账面值、审计后账面值、评估值的口径须在全文中统一；凡引用审计数据须写明审计机构与审计意见类型。
2. **公式可追溯**：所有计算列使用公式与单元格引用，禁止硬编码。
3. **数据来源标注**：每个关键参数标注来源与时点。
4. **签章齐全**：报告书与说明分别签章；附件齐全。
5. **有效期表述**：评估结论使用有效期为一年，自评估基准日起算；国资项目须经核准或备案后使用。
