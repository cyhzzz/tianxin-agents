# 01 造价咨询作业骨架

> 天信原创，且**必须如实标注**：这条线目前收的 96 份上游原文全是**资产评估**，工程造价一块**没有任何材料**。
> 本文件是**通用的造价作业骨架**，不是天信的执业标准，也不是浙江省定额口径的汇编。**定额、费率、信息价一律查现行版本**。

## 一、先分清：资产评估 ≠ 工程造价

| | 资产评估（本线已有） | 工程造价（本线空白） |
|---|---|---|
| 回答什么 | 这东西**值多少钱** | 这工程**该花多少钱** |
| 依据 | 中评协评估准则、评估方法（成本/市场/收益法） | 工程量清单计价规范、地方定额、信息价、合同 |
| 成果 | 评估报告（评估师签字） | 预算书、招标控制价、结算审核报告（造价工程师签字） |
| 典型触发 | 转让、出资、抵押、司法处置、财报减值 | 招标、结算、审计、变更签证、索赔 |

**最容易犯的错**：拿评估的"重置成本"去当造价的"预算价"，或拿造价结算数直接当"市场价值"。两者口径不同，**不能互相替代**。

## 二、造价咨询的活，按阶段分五类

| 阶段 | 业务 | 委托方 | 成果 |
|---|---|---|---|
| 决策 | 投资估算 | 业主 | 估算表 + 编制说明 |
| 设计 | 设计概算 | 业主/设计院 | 概算书 |
| 招投标 | **工程量清单 + 招标控制价**（编制或审核） | 业主 | 清单、控制价、编制说明 |
| 施工 | 进度款审核、变更签证、索赔评估 | 业主/施工方 | 审核意见、计量表 |
| 竣工 | **结算审核**（最常见） | 业主/审计机关 | 结算审核报告 + 审定表 |
| 争议 | **造价鉴定** | 法院/仲裁/当事人 | 鉴定意见书 |

县城所接得最多的是**结算审核**与**招标控制价编制**；造价鉴定要求资质与经验，谨慎接。

## 三、骨架 A：工程量清单与招标控制价（编制）

1. **读图与算量**：按专业（建筑/安装/市政/装饰）拆分，算量规则按现行**工程量计算规范**（GB 50854 系列，按专业分册）。
2. **列清单**：项目编码、项目名称、项目特征、计量单位、工程量——**项目特征写不清，后面必扯皮**（如"混凝土"要写强度等级、是否泵送）。
3. **组价**：套定额 → 换算 → 计取管理费、利润、规费、税金（税率按现行规定，不套旧税率）。
4. **材料价**：优先用**工程所在地信息价**（台州/浙江当期）；信息价没有的，用市场询价并留询价记录（三家以上）。
5. **控制价**：不得上调或下浮（按规定）；公布前复核合计与分部分项、措施费、其他项目费、规费税金的勾稽。
6. **交付**：清单 + 控制价 + 编制说明（含依据、取费标准、材料价来源、未考虑事项）。

## 四、骨架 B：结算审核（最常接，也最容易出事）

**程序**：

1. **收资料**（见 §六），缺件的先列清单退回，别边审边补。
2. **核合同**：计价方式（固定总价/固定单价/成本加酬金）、风险范围、变更与索赔条款、下浮率、让利。
3. **核工程量**：按竣工图与现场实测复核，**重点核隐蔽工程**（要有隐蔽验收记录 + 影像）。
4. **核单价**：合同单价优先；新增项目按合同约定的组价原则（无约定时参照同期定额与信息价）。
5. **核变更与签证**：有没有业主与监理签认、是否在时效内、是否重复计量。
6. **核取费**：管理费、利润、规费、税金的计取基数与费率是否符合合同与现行规定。
7. **出审核报告**：送审金额、审定金额、核减/核增额、核减原因分类（工程量/单价/取费/变更/其他）、逐项明细表。

**核减高频点**（复核时按这张表过）：

| 核减点 | 常见做法 |
|---|---|
| 工程量虚高 | 按竣工图重算；隐蔽工程无验收记录的，不予认可 |
| 单价套高 | 定额子目错套、换算错误、材料价用高价品牌 |
| 变更重复计 | 变更已含在原清单内的，不重复计 |
| 签证无效 | 无业主/监理签认、超时效、事后补签 |
| 取费错误 | 费率套错、计税方式错（一般计税 vs 简易计税） |
| 甲供材 | 甲供材料未从结算中扣除，或重复计取保管费 |
| 措施费 | 按实计取的措施项目按定额计，或反之 |

## 五、骨架 C：造价鉴定（司法）

- 只回答**费用问题**：工程量多少、单价多少、费用多少、增减多少。
- **不回答责任问题**：谁违约、谁该赔、质量是否合格——那是法院与质量鉴定机构的事。
- 依据材料：合同、图纸、签证、往来函件、现场勘验记录；材料不全的，在鉴定意见中**写明假设与限制条件**。
- 出具前须确认本所是否具备相应资质与注册造价工程师；不具备的，**转有资质的机构**。

## 六、资料清单（缺一样就可能全盘重做）

1. 施工合同、补充协议、招标文件与投标文件
2. 施工图、竣工图（含设计变更单）
3. 工程量清单、招标控制价（如有）
4. 变更签证、索赔资料、会议纪要、往来函件
5. 隐蔽工程验收记录、影像资料
6. 材料进场验收单、甲供材清单
7. 进度款支付记录、发票
8. 竣工结算书（送审稿）及计算底稿
9. 现场条件：是否可踏勘、是否有第三方在场

## 七、红线

- **没有注册造价工程师，不出具造价成果文件**（预算书、控制价、结算审核报告、鉴定意见都要签字盖章）。这条先确认再报价。
- **不按委托方期望"调数"**：核减多少就是多少，核减理由必须能追到图纸、合同或现场。
- **不越界做责任认定**：造价鉴定里评价质量、违约责任，属超范围。
- **定额与费率不用记忆值**：一律查浙江省现行计价依据与台州当期信息价，标注版本与期号。
- **不改客户送审稿**：审核是在送审稿之外另出审定表，**不在原稿上直接改数**（改了就没有对比痕迹）。

## 八、这条线要补齐，需要什么

| 缺什么 | 用途 |
|---|---|
| 一份真实的**结算审核报告**（可脱敏） | 校准报告结构与审定表格式 |
| 所里在用的**取费标准与常用定额子目** | 建立本地化组价习惯 |
| 台州/浙江当期**信息价**获取渠道 | 材料价来源固定下来 |
| 造价人员资质情况（一级/二级造价工程师） | 决定这条线能不能真接单，还是只能做评估侧的配合 |

> 在那之前，**这条线只能做"评估口径下的建安成本估算"**（资产评估里的重置成本），**不能对外出具造价成果文件**。这是能力边界，不是谦虚。
